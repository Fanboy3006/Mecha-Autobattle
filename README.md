# 机甲指挥（mecha-autobattle）

从「机甲战棋」（`F:\DSH-mecha\mecha-tactics`）分叉出来的**自动战斗回合制 RPG**。

- 玩家在肉鸽大地图上走格子、招募机师、拿藏品；
- 遇到战斗时，把最多 6 台机体摆进**前排 / 后排**（各 2 排 × 3 列）；
- 每回合给每台机体下一条**指令**（进攻 / 集火 / 守护 / 防御 / 换位），然后这一回合**自动打完**，看结果，再下下一回合的指令。

旧仓库**冻结保留、不改不删**，新项目只从它复制素材和代码。完整方案：`../mecha-tactics/分叉·自动战斗RPG设计方案.md`。

## 怎么跑

双击 **`index.html`** 就能打开（单文件、原生 JS、Canvas，没有依赖）。

## 怎么改代码

`src/shell.html` + `src/css/` + `src/js/` 是**唯一可编辑的源文件**；`index.html` 和 `src/artifact-fragment.html` 都是生成物，别手改。

```bash
node tools/build-src.mjs          # 由源文件生成两份 HTML
node tools/build-src.mjs --check  # 只检查是否同步
node tests/smoke.js               # 冒烟测试（不需要任何依赖）
```

细节见 `CLAUDE.md`、`src/README.md`、`协作/任务板.md`。
