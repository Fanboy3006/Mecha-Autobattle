# 机甲指挥（Mecha Autobattle）

一个在浏览器里跑的 **自动战斗回合制 RPG**：你在肉鸽大地图上走格子、招募机师、拿藏品；
战斗时摆好阵型，之后**只下大方向决策**，剩下的交给自动战斗 —— 看结果，再决定下一步。

**试玩就一步**：双击根目录的 **`index.html`**（单文件、原生 JS + Canvas，**没有任何依赖、不用装东西**）。

## 这一版怎么玩

1. **选分队** → 开局给你 **3 张招募券**（第 1 张固定是你这个分队的），**不再白送一队机体** —— 先招人。
2. **大地图**（6×4 网格 + 推进剂）：走格子消耗推进剂，格子上有普通战 / 精英 / 守军 / 黑市 / 遗迹 /
   瞭望站 / 隧道 / 休整 / 侵蚀源 / 出口。**每个节点都有代价与选择**（没有白拿的东西）。
3. **战斗 = 两层决策**（★ 这一版最大的改动）：
   - **全队层**：每回合选**一条全军方针** —— `全军突击`（默认）/ `集中攻击`（点一个敌人）/
     `攻击后排` / `前守后攻` / `全军防御`；**保持到你改为止**。
   - **单位层**：每台只决定「**大招：自动 / 保留**」（天人有额外的 TRANS-AM 开关）。
   - 站位在开战前的编队界面摆（9 格：**前排 4 + 后排 5**，错开排列，后排会被前排**挡**掉 20 命中）。
4. **看懂自己做得对不对**（三层反馈）：下决策时看**预告**（卡片上写「全队对它的预计伤害合计 X」、
   「防御值 +50」、「打得到 / 打不到后排」）→ 生效时看**即时**标签（`集中` / `被挡 −20` / `防御 少挨 N`）→
   战后看**本场战报**（本场输出占比、击破在第几回合、防御少挨多少、大招占全场伤害的百分之几）。
5. **调参室**（开场菜单里）：**难度不满意就自己拉** —— 敌人 HP × / 伤害 × / 装甲 × / 防御值 +，
   单个敌人键覆盖、Boss 脚本参数；跑 100 场看**胜率 / 回合分布 / 阵亡分布 / 谁最常先倒 / 双方伤害占比**，
   还能「**看一场**」用正常战斗界面播给你看。改动**只存在调参室**，不影响正常游戏；有「复制设置」导出。

**已经有内容的机制**：招募券系统（券 = 招募 / 晋升二选一）· 势力特色 6 件（SEED 觉醒 / 单独行动 /
月球王国光环 / 天人 TRANS-AM / ATX 打空 / 秘银岗位接力）· 藏品 50 件 · 零件 13 件 · 站桩 Boss 脚本 ·
带伤推进 / 敌方增援 / 出口两型。

## 开发：怎么改、怎么测

`src/shell.html` + `src/css/` + `src/js/` 是**唯一可编辑的源文件**；`index.html` 与 `src/artifact-fragment.html`
是**生成物**（别手改，改完源文件跑构建）。

```bash
node tools/build-src.mjs          # 由源文件生成两份 HTML
node tools/build-src.mjs --check  # 只检查生成物与源文件是否同步
node tools/verify-all.mjs         # ★ 一条命令跑全部验收：生成物同步 + 十七条测试，末尾打印「绿 N/18 红 N」
node tests/smoke.js               # 单跑某一套（smoke / sim / battle_ui / commands / run / comp / map /
                                  #   art_icons / audio / boss / heal / relic / rank / balance / grid / faction / tuner）
node tools/balance.mjs            # 平衡工具：生成 docs/平衡表.md（单挑表 + 组队表 + 结论三问）
```

- **随机数一律 `mulberry32` + 显式种子**：同一局、同种子、同决策，结果**逐字相同**（测试盯着这一条）。
- 说明书：`CLAUDE.md`（项目手册 / 口径 / 红线）；协作与设计文档在 `协作/`（含 `方向调整-全队方针与反馈.md`
  这份 2026-10-12 的方向书、敌人机制盘点、演出与机设两条线的协作文档）。
