机甲指挥 试作版 v0.0.1 · M0 仓库骨架

M0 · 仓库骨架

机甲指挥是从「机甲战棋」分叉出来的自动战斗回合制 RPG：玩家在肉鸽大地图上走格子、招募机师、拿藏品；遇到战斗时把机体摆进前排 / 后排，每回合给每台机体下一条指令，这一回合自动打完，看结果，再下下一回合的指令。

  • 站位：双方各 2 排 × 3 列，最多 6 台机体；前排全灭后后排不会自动前移。
  • 指令：进攻（默认）/ 集火 / 守护 / 防御 / 换位（M3 做全）。
  • 胜负：敌方全灭 = 胜，我方全灭或第 12 回合结束 = 败。

这个页面目前只有骨架，没有任何战斗逻辑。下一步 M1：战斗内核（数据导入、射程换算、速度与行动顺序、伤害公式、AI、胜负判定、带种子随机数），先做没有界面的 simulate()，跑 node tests/sim.js。

源文件在 src/，这个 index.html 是 node tools/build-src.mjs 生成的，不要手改。
