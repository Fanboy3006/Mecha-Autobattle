## 现在有什么

| 文件 / 目录 | 内容 | 谁在用 |
|---|---|---|
| `native/inputs.json` | 176 条**输入**（我方 / 敌方规格 / 种子 / 编成 / 藏品）+ `quick` 组（3 支快速测试队 × 3 种子）。由旧样例的输入抽出来（`tools/extract_native_inputs.gd`，那个脚本只对归档里的旧大文件有效，别再重跑） | `tools/record_native_golden.gd`、`tests/unit/test_native_goldens.gd` |
| `native/<组>.json` | Godot **原生**标准答案：`{id, 期望:{事件, 回合摘要, 结果}}`。`faction` 组按势力拆成 7 个文件 | `tests/unit/test_native_goldens.gd`（逐场重跑并对拍） |
| `card_tables/<卡包>.txt` | 卡表等价快照（`var_to_str` 序列化） | `tests/unit/test_card_table_snapshot.gd` |

| `rng_vectors.json` | Mulberry32 / 四舍五入 / 稳定排序的对拍向量 | `tests/unit/test_rng.gd` |

## 怎么重录原生样例

```
godot --headless --path godot --script res://tools/record_native_golden.gd   # 写 native/<组>.json
godot --headless --path godot --script res://tests/run_tests.gd              # test_native_goldens 逐场重跑
```

- **连录两次必须逐字节相同**（RT-2d 的硬要求；不确定就 `sha256` 对一遍）。
- 出牌策略在 `tests/native_golden_policy.gd`：**只用 `CardPlay.不可打原因` 判定、出牌调门面背后的核心函数、一次随机数都不抽**
  （`选择rng` 必须是 0，`test_native_goldens` 里有硬断言）。
- 回合摘要**只记新模式白名单字段**（每台机体的 hp / maxHp / shieldHp / 掩护盾 / buffs / debuffs / 战意 / 主武器状态 /
  武器 cd·uses / 势力状态 / 牌组各区张数 + 手牌 id；全局 回合 / 阶段 / rng / 公有三区的 id / 战况计数（不含 `满手牌推迟数`）/ 结果）。
  **不记** `战术手牌 / 待触发战术牌 / 候补初始牌 / 战术牌池 / 已打出战术牌 / 气势` —— 那些东西要么已经退役、要么不许被样例钉住。
- 非整数一律 `{"$f": 十六进制}`（IEEE-754 小端位串），用 `GoldenCompare.decode` 读。
