# 交接卡模板（Claude → 下一个 Claude 会话）

> 用法：会话快到该交接时（上下文变长、一块工作告一段落），Claude 主动提醒作者，然后照这个模板写
> `协作/交接卡-YYYY-MM-DD.md`（同一天第二张加 `-2`）。**≤ 80 行**，只写下一个会话需要的东西。
> 旧交接卡在新卡写好后移进 `协作/归档/交接卡/`。

---

```
# 交接卡 YYYY-MM-DD（Claude → 下一个 Claude 会话）

> 新会话只读：根目录 `CLAUDE.md` → 本卡 → `协作/开发路线图-v0.1.md`。其余按需再读。

## 一、协作模式有没有变
- （没变就写「同 CLAUDE.md §4」一行；变了写清作者哪天定的、改了什么）
- 作者这次在哪：主机（能跑命令）/ 远程会话（只能读写文件）

## 二、本会话做了什么（只写结论）
- <单号 / 文档>：<结果>（提交号可省，写「已提交」或「未提交」）
- **未提交 / 未验证的改动**：<文件> —— <还差什么>（没有就写「无」）

## 三、待办（按顺序，第一项写到能直接动手）
0. **【最先做】**<事情>
   - 具体步骤：…
   - 卡住时的退路：…
1. …
2. …

## 四、等作者回答的问题
- ① …（上次哪天提的）

## 五、已知事实（省得重查）
- 测试共 N 项，全量约 X 分钟；原生样例 N 场，录一次约 X 分钟。
- 永远不要打开：`tests/golden/` 下的大 JSON、`协作/架构/Godot-AST依赖清单.json`。
- 往作者电脑写文件后要读回比对。
- <本会话新踩到的坑>
```

---

## 写卡时的自检
- 第 0 项能不能不看别的文件就开工？不能就补步骤。
- 有没有把「没跑过」写成「已通过」？（CLAUDE.md §5 第 7 条）
- 有没有贴大段代码 / 日志？换成文件路径。
