### 3.2 `MechAudio` 接口（**原样搬来的，签名别改**；`local-music.js:181` 的导出行）

```js
MechAudio.play(cue)          // 切到某个 cue：淡出旧的、淡入新的（FADE = 600ms）；同一首不重头播
MechAudio.stop()             // 全部淡出
MechAudio.mute(bool)         // 静音 / 恢复
MechAudio.unlock()           // 浏览器要用户手势才能出声；播放层自己也挂了一次性监听
MechAudio.sfx(name)          // ★ 现在是**空函数**（`sfx(){}`）——音效层没搬，见 T1
MechAudio.setVolume()        // ★ 也是空函数
MechAudio.state()            // {ready, cue, track, muted, playing, time, dur}
MechAudio.themeOf(mech, tpl) // 这台机体出手时的主题曲 cue（先查 THEMES.unit[mech]，再查主势力）；没有 → null
MechAudio.hasCue(cue)        // 这个 cue 有没有曲子
MechAudio.onAvailable(fn)    // 文件读得到 / 读不到时回调 fn(true / false)
MechAudio.preview(n) / seek(t) / meta(n)      // 鉴赏页用
MechAudio.tuning             // 鉴赏页的调参（defaults / get / setDb / assign / reset / changed / exportText / dbOf / usable）
MechAudio.openRoom(opts)     // 音乐鉴赏页（由 music-room.js 挂上）
MechAudio.TRACKS / CUES / THEMES / _bad      // 三张表 + 读不到的黑名单
```

- **cue 的三种写法**：场景名（`CUES` 里的键）/ `theme:<曲名>` / `track:<曲名>`（`nameOf()` 解析）。
- **曲名**就是 `TRACKS` 的键（中文，如 `'Suno 主角'`）。
- 音量：按 `lufs` 拉平到 `REF = -17.5`、再乘 `MASTER = 0.8`（`gainOf`）；每首记住播放位置（切回来接着放）；全部 `loop = true`。
- 读不到某个文件时沿 `alt` 退；**一首都读不到** → `avail = false`（见 3.7 降级）。
- 舞台细节：曲子 URL = `MECHA_MUSIC_BASE + file`；试玩页（多文件包）会设 `MECHA_MUSIC_FLAT = true`，改成按 `id` 读 `music/<id>.mp3`（本仓库还没有多文件包，见 T9）。

## 4. 素材在哪、怎么加

### 4.1 加一首曲子（标准流程）

1. **放文件**：把曲子放进 `audio\SUNO\`（⚠️ 必须是**作者用 Suno 生成的**；文件名唯一即可，中文和空格都行，现有 9 首就是这样）。
2. **进 `TRACKS`**：在 `audio\local-music.js` 的 `TRACKS` 加一行：

   ```js
   'Suno 新曲': {file:'SUNO/新曲文件名.mp3', lufs:-13.5, id:'new-cue'},
   ```

   - `lufs` 是**实测响度**（战棋是用 ffmpeg 的 `ebur128` 量的；`gainOf()` 靠它把各曲拉到同一响度）。**必须实测**，乱填会让这首明显偏大 / 偏小。
   - `id` 是给多文件发布包 / 试玩页用的英文短名；**进仓库的曲子必须有 `id`**（`usable()` 靠它判断试玩页上读不读得到）。
3. **挂场景**（两选一）：
   - **改 `CUES`**（如 `boss:'Suno 新曲'`）——最简单，但动的是「原样复制」的文件，见下面的 ★ 口径冲突；
   - **不改它**，在 `src\js\96-音乐.js` 的 `场景曲()` 里直接 `return 'track:Suno 新曲'`（播放层认 `track:` 前缀）。
   - ⚠️ **但两步都躲不开 `TRACKS` 那一行**：曲名不在 `TRACKS` 里，`play()` 就是静音（`nameOf()` 返回 null）。所以「加新曲子」这件事**必然要动 `local-music.js`**。
