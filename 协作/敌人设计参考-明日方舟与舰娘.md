## 0. 先记一条我们自己的现状（**会直接影响下面每条的「我们已经有的敌人」那一栏**）

`src/js/10-数据.js` 的 `ENEMY_T` 是从战棋**整份复制**来的，所以**敌人身上带了一堆 `abilities`，
但我们的引擎第一期基本不读**。这件事必须写清楚，否则「我们已有这一类」会被误读成「这一类已经生效了」：

| 敌人身上的标记 | 引擎里真的有吗 | 证据 |
|---|---|---|
| `barrier`（能量屏障）、`lambdaShield`（λ 力场） | **有**，进减免管线 | `src/js/20-战斗计算.js:129,133-134` |
| `weak`（弱点 / 抗性，如 `weak:{光束:30}`） | **有**，进减免管线 | `src/js/20-战斗计算.js`（弱点抗性 → 装甲 → 防御值…） |
| 职业特色（重装嘲讽 / 近卫连斩 / 狙击打后排无惩罚 / 尖兵首击闪避 / 指挥同排命中 / 特种降命中） | **有**，且 2026-10-11 起**敌我都吃** | `src/js/72-势力.js:1029`、`src/js/60-战斗.js:134-190` |
| Boss 脚本（大技能间隔 / 半血换阶段） | **有，但只配了 `bluefish` 一个** | `src/js/71-改动.js:156-165`、`src/js/61-Boss.js` |
| `stealth`（隐形）、`summon`（召唤）、`frontArmor`、`selfDestruct`、`beamReflect`、`regen`、`jamAura`、`commandAura`、`berserk`、`laneCrush`、`chase` | **都没有**：只是 `10-数据.js` 里的字符串，全仓库没有一处读它 | 全仓库 grep 只有 `10-数据.js` 自己出现 |
| 「反面 / 背面 / 反击 / 多段」这类弱点 | **打不到**：`weak:{背面:40}`、`weak:{反击:50}` 在数据里，但**没有朝向、没有反击**，这两条永远不触发 | `docs/数值换算需求单.md` 第 1.2 节第 1、6 条 |

> 所以下面出现的「我们已有」分两种写法：**「有，且真的生效」** 和 **「数据里有这个标记，但引擎没读（等于缺）」**。
> 这条差别是 Claude 配数值、DSH 落代码时最需要先知道的一件事实。

## 1. 杠杆 A：编队选谁（带什么伤害 / 带不带修理 / 带不带特殊）

### A-1 重装 / 高防御敌人（明日方舟：**重装防御者**）

1. **原作里是什么**：整合运动的精英近战单位，「近战 物理 / 地面」，机制上就是**防御力极高、极难击溃**，没有任何技能
   （[PRTS · 重装防御者](https://prts.wiki/w/%E9%87%8D%E8%A3%85%E9%98%B2%E5%BE%A1%E8%80%85)）。
2. **它逼玩家做什么决定**：物理队砍不动 → 逼你换**法术伤害 / 真实伤害**干员（法伤看「法术抗性」而不是「防御力」）。
   决策发生在**编队阶段**（谁上场），不在战斗里的操作。
3. **换成我们的杠杆**：**编队选谁**。我们的减免顺序是「弱点抗性 → 装甲 → 防御值 → 公式 → 屏障 → λ 力场 → 护盾」，
   所以「换伤害类型打」这条**本来就成立**（用 `weak` 的弱点 / 抗性 + `dmgType`）。
   ⚠ **做不了的那一半**：「无视防御」我们**没有独立的减免阶段**——`venom` 的「λ 加农炮」写的是 `dmgType:'特殊'`，
   但那只是**绕开装甲**（数据里 `weak:{多段:30}`），防御值那一档照吃。真要「无视防御」得新开一个减免阶段，**归 Claude / 归实现**。
4. **记录里长什么样**：`洛克昂【GN 狙击步枪】→ 盾卫：命中 1204（装甲 600 减免）`。
5. **我们已经有的敌人**：**有，且真的生效** —— `shield`（盾卫）、`beetle`（甲虫型重机）、`ironwall`（铁壁）、
   `tank`（重型坦克）、`fortress`（重装要塞）。`beamcoat` / `phase` 是**反向**的一对（抗光束 / 吃光束）。

### A-2 抗光束 / 吃光束的**成对**敌人（明日方舟：**重装防御者 / 术师系的「物抗 vs 法抗」二分**）

1. **原作里是什么**：同一个战场上，敌方的「法术抗性」和「防御力」是**两条独立的减伤轴**，
   所以「物理高伤打低防怪、法伤打低法抗怪」是编队的基本功课（[PRTS · 敌人一览](https://prts.wiki/w/%E6%95%8C%E4%BA%BA%E4%B8%80%E8%A7%88)）。
2. **它逼玩家做什么决定**：**带两种伤害**。只带一种 → 一定有一半敌人打不动。
3. **换成我们的杠杆**：**编队选谁**。我们已经有 `weak`（弱点 / 抗性）：`beamcoat` 抗光束 −60、吃物理 +30；
   `phase` 吃光束 +40、抗物理 −60。**这一条我们现在就是通的**，编成表里也真的把两台摆在一起考（`70-编成.js:123-125`）。
4. **记录里长什么样**：`蕾卡【突击步枪】→ 光束涂层机：命中 3120（弱点：物理 +30%）`。
5. **我们已经有的敌人**：**有，且真的生效** —— `beamcoat` / `phase` 这一对，`mirror`（镜面装甲机，近战 +40 弱点）。

### A-3 飞行单位（明日方舟：**妖怪 / 妖怪MKII**）

1. **原作里是什么**：敌方无人机，「无人机 / 普通 / **不攻击** / **飞行**」，能力只有一条「**飞行单位**」
   （[PRTS · 妖怪](https://prts.wiki/w/%E5%A6%96%E6%80%AA)）。同类还有「威龙」「御4」等。
2. **它逼玩家做什么决定**：明日方舟的规则是**只有能打空中的干员打得到飞行单位**，
   所以飞行单位出现 = **编队里必须留对空手段**，否则它会直接飞过去漏掉。决策在编队，不在战斗操作。
   ⚠ 这里要说清：明日方舟是**格子 + 移动 + 漏怪**的游戏，「飞行 = 走直线飞过去」那部分**我们做不了**（下一段）。
3. **换成我们的杠杆**：**编队选谁**（我们这边**没有**「打不到飞行单位」这条规则，所以只能借它的**前半截**：
   「编队里必须有人能处理这一类单位」）。我们引擎里 `flying:true` 只影响图标挑图与借原型剪影
   （`src/js/78-图标.js` 的挑图规则），**不影响命中与射程**。
   ❌ **做不了的部分**：① 「飞行单位无视地面单位阻挡、直飞终点」——**没有格子、没有移动、没有终点**，
   我们只有 9 个站位格，敌人被击坠才能靠增援补位（`src/js/60-战斗.js:195-221`）。
4. **记录里长什么样**：`〔增援〕第 2 回合：敌方 2 台赶到（后1、后2：战斗机、蜂群无人机）`。
5. **我们已经有的敌人**：**部分有** —— `drone`（无人机）、`fighter`（战斗机）、`swarm`（蜂群无人机）、
   `funnel`（浮游炮母机）、`skyfort`（空中要塞）都写了 `flying:true`，但**这条标记引擎不读**，
   所以现在它们和地面单位**没有任何打法差别**（等于「缺」）。

### A-4 无视防御的术士（明日方舟：**游击队萨卡兹术师**）

1. **原作里是什么**：「萨卡兹 / 精英 / 远程 法术 / 地面」，能力 = **周期性施法，对周围所有单位造成相当于攻击力的法术伤害**；
   接触源石祭坛的脉冲波后**不受伤害且攻击范围扩大**（[PRTS · 游击队萨卡兹术师](https://prts.wiki/w/%E6%B8%B8%E5%87%BB%E9%98%9F%E8%90%A8%E5%8D%A1%E5%85%B9%E6%9C%AF%E5%B8%88)）。
   同类参考：[萨卡兹术师](https://prts.wiki/w/%E8%90%A8%E5%8D%A1%E5%85%B9%E6%9C%AF%E5%B8%88)、
   [护盾高阶术师](https://prts.wiki/w/%E6%8A%A4%E7%9B%BE%E9%AB%98%E9%98%B6%E6%9C%AF%E5%B8%88)。
2. **它逼玩家做什么决定**：**别用重装硬顶**。它打的是范围法术伤害，堆防御的干员收益很低 →
   逼你把**法抗 / 高 HP / 分散站位**当成编队条件。
3. **换成我们的杠杆**：**编队选谁**（带不被「高装甲」吃掉的输出 / 带治疗）。
   ⚠ 「对**周围所有单位**」这一条**做不了**（没有区域）：我们的范围按 `area` 走 `row`（一整排）/
   `col`（阻挡束）/ `cross`（目标位 + 左右 + 对位）/ `all`（9 格），**没有「以某格为中心的半径」**。
   能做的是「**打一整排**」——`bluefish` 的「周身冲击」已经是这个（`fire:'map'`、`area` 没写默认 `row`）。
4. **记录里长什么样**：`λ 试作机【λ 加农炮】→ 提耶利亚：命中 2560（特殊伤害：不吃装甲）`。
5. **我们已经有的敌人**：**有，且真的生效（但是靠「绕装甲」不是靠「无视防御」）** —— `venom`（λ 试作机，`dmgType:'特殊'`）；
   范围法术型**缺**（我们只有 `area:'row'` 的物理大技能）。

### A-5 自爆 / 亡语类（明日方舟：**冰爆源石虫 / 爆裂源石虫**）

1. **原作里是什么**：「冰爆源石虫」这类源石虫的特殊点在于**死亡时（或被击破时）触发范围爆炸**，
   对周围单位造成伤害（[PRTS · 冰爆源石虫·α](https://prts.wiki/w/%E5%86%B0%E7%88%86%E6%BA%90%E7%9F%B3%E8%99%AB%C2%B7%CE%B1)、
   [PRTS · 爆裂源石虫](https://prts.wiki/w/%E7%88%86%E8%A3%82%E6%BA%90%E7%9F%B3%E8%99%AB)；
   ⚠ 这两个页面的**具体能力文本以出场关卡页为准**，本文件只引到「这类源石虫有亡语爆炸」这一层，**没有抄数值**）。
2. **它逼玩家做什么决定**：**击杀顺序变成一道题** —— 先打死它会炸到你自己人，所以要么**先分散站位**，
   要么**留到最后打**，要么**用远程点在它炸不到的地方**。
3. **换成我们的杠杆**：**站位**（把人挪开）+ **集中攻击 / 攻击后排**（决定谁先死）。
   ⚠ **缺钩子**：我们**没有「击破时」这个钩子** —— 现在全仓库唯一的击破钩子是「近卫连斩」
   （`src/js/60-战斗.js:252`，写死在我方近卫职业特色里）。要给敌人加亡语爆炸，**得新开一个敌方可用的击破钩子**（归实现）。
4. **记录里长什么样**：`〔自爆〕自爆机被击破，波及 前1、前2：蕾卡 880、雷萨 880`。
5. **我们已经有的敌人**：**数据里有标记，但引擎没读（等于缺）** —— `bomber`（自爆机）写着 `abilities:['selfDestruct']`，
   全仓库没有一处读它；它现在只是一台普通的近战杂兵。

### A-6 护盾 / 屏障（明日方舟：**护盾高阶术师、屏障类**）

1. **原作里是什么**：术师一脉里有专门挂**护盾 / 屏障**的变体（[护盾高阶术师](https://prts.wiki/w/%E6%8A%A4%E7%9B%BE%E9%AB%98%E9%98%B6%E6%9C%AF%E5%B8%88)），
   表现为「**先打掉一层额外血条，本体才开始掉血**」。
2. **它逼玩家做什么决定**：**要不要先交爆发**、还是**先削盾等冷却**；也逼你判断「这个盾值不值得打」。
3. **换成我们的杠杆**：**大招开关（自动 / 保留）** —— 盾在的时候**留着大招**、盾破了再开。
   我们引擎**已经有这条管线**：`barrier`（能量屏障）走减免第 5 阶段、`lambdaShield`（λ 力场）走第 6 阶段，
   数据里 `skyfort` 还有独立的 `shield:5000 / shieldName:'力场护盾'`。
4. **记录里长什么样**：`提耶利亚【GN 火箭筒】→ 空中要塞：命中 0（能量屏障挡下，屏障剩余 1200）`。
5. **我们已经有的敌人**：**有，且真的生效** —— `skyfort`（力场护盾）、`fortress` / `flagship`（`barrier`）、
   `venom`（`lambdaShield`）。

### A-7 血很厚但打不动人的**墙**（明日方舟：**磐蟹**）

1. **原作里是什么**：磐蟹是典型的**低威胁高血量的阻挡物**（[PRTS · 磐蟹](https://prts.wiki/w/%E7%A3%90%E8%9F%B9)）。
   它的作用不是打死你，而是**占住位置、拖时间**。
2. **它逼玩家做什么决定**：**值不值得把输出花在它身上** —— 打它浪费时间，不打它挡住你打别人。
3. **换成我们的杠杆**：**集中攻击 / 攻击后排**（决定绕过它先打后排）—— 注意这正好是我们**唯一**的「绕路」手段：
   我们的近战**打不到后排**（前排没人才能打后排），直射打后排**吃「被挡 −20」**。
   ❌ 「它占住格子、挡住你的部署」**做不了**：没有部署格、没有移动。
4. **记录里长什么样**：`蕾卡【突击步枪】→ 盾卫：命中 480（被挡 −20 命中，85%）`。
5. **我们已经有的敌人**：**有，且真的生效** —— `ironwall`（铁壁，`mov:0`、`noEvade`、无武器、`weak:{多段:30}`）
   就是一台纯粹的墙；`shield`、`beetle` 也偏这一类。

### A-8 会跑过来的近战 + 速度差（明日方舟：**猎狗 / 猎狗pro**）

1. **原作里是什么**：猎狗是**移动速度很快的近战杂兵**，「猎狗 pro」「狂暴的猎狗 pro」是它的上位
   （[PRTS · 敌人一览](https://prts.wiki/w/%E6%95%8C%E4%BA%BA%E4%B8%80%E8%A7%88) 的「猎狗 / 猎狗pro / 狂暴的猎狗pro」）。
   它逼玩家做的事是**时间**：它比别的敌人先到，你必须在它到之前把前场铺好。
2. **它逼玩家做什么决定**：**先摆谁**、**谁去顶第一波**。
3. **换成我们的杠杆**：**站位** + **前守后攻 / 全军防御**（第一回合先顶住）。
   ⚠ 我们的「速度」不是移动力，是 `速度 = mov × 10 + 闪避 ÷ 2`（`docs/数值换算需求单.md` 第 1.2 节第 4 条），
   只决定**出手顺序**。所以「它先到」这一层**做不了**，能做的是「**它先出手**」。
4. **记录里长什么样**：`猎犬【猎枪】→ 蕾卡：命中 1250（剩 HP 2150）`（它在回合里排在我方某台之前）。
5. **我们已经有的敌人**：**有，且真的生效** —— `hound`（猎犬，`mov:5`）、`raider`（突击兵，`mov:6`）、
   `berserker`（狂战士，`mov:6`）——它们靠 `mov` 拿到**先手**，`speed` 排序在 `src/js/40-单位.js`。

### A-9 后排的炮台 / 奶妈（明日方舟：**炮手 / 医疗单位**）

1. **原作里是什么**：站在后排的**远程输出**（炮手系）与**治疗单位**，本身脆，但不管它就一直输出 / 一直奶。
2. **它逼玩家做什么决定**：**先杀谁** —— 前排硬但没威胁，后排脆但一直在制造损耗。
3. **换成我们的杠杆**：**攻击后排**（§1.2 五条方针之一）—— 但直射打后排吃「**被挡 −20**」，
   近战够不着后排，所以真正的解法是**带曲射 / 范围 / 狙击**（狙击职业打后排无惩罚，`src/js/30-射程.js:72`）。
4. **记录里长什么样**：`洛克昂【GN 狙击步枪】→ 狙击机：命中 5198（狙击：打后排无被挡惩罚）`。

   `turret`（固定炮台）、`pursuer`（追击炮车）。**敌方奶妈缺**（我们没有敌方修理武器）。

## 2. 杠杆 B：站位（9 格 · 前 4 后 5 · 被挡 −20）

### B-1 隐匿 / 隐身（明日方舟：**潜伏者 / 隐形弩手 / 隐形术师**）

1. **原作里是什么**：「潜伏者」= **隐匿**（**在被阻挡前无法被攻击**），PRTS 原文写「在被阻挡前无法被攻击」
   （[PRTS · 潜伏者](https://prts.wiki/w/%E6%BD%9C%E4%BC%8F%E8%80%85)）；PRTS 对「隐匿」的定义是
   **「不阻挡时不成为敌方攻击的目标」，并且受「反隐」影响**。同类还有「隐形弩手 / 隐形术师 / 技术侦察兵」
   （[PRTS · 隐形弩手](https://prts.wiki/w/%E9%9A%90%E5%BD%A2%E5%BC%A9%E6%89%8B)）。
2. **它逼玩家做什么决定**：**要先「点亮」它才能打** —— 明日方舟里的手段是**阻挡**它，或者用带**反隐**的干员。
   这是一道**编队题**（带不带反隐）而不是操作题。
3. **换成我们的杠杆**：**站位**（谁去「接」它）+ **编队选谁**（带反隐）。
   ❌ **做不了**：「**被阻挡前无法被攻击**」的判定本体就是**阻挡 / 格子 / 移动**——我们没有移动，
   所以「阻挡」这个动作不存在。我们的对应物只有「**按位阻挡**」（`F0→B0,B1` 那 8 条关系，
   `src/js/05-阵型.js` 的 `阻挡表`），它影响的是**直射打后排的命中 −20**，不是「能不能打」。
   ✅ **能做的部分**：把「反隐」做成一个**编队 / 藏品层面的开关**（带某台 / 带某件藏品 → 这台敌人才能被选中），
   这条**不需要格子**，需要的是一个新的「可选目标」过滤钩子（归实现）。
4. **记录里长什么样**：`洛克昂【GN 狙击步枪】→ 隐形侦察机：不可选中（未反隐）`（等做成之后）。
5. **我们已经有的敌人**：**数据里有标记，但引擎没读（等于缺）** —— `stealth`（隐形侦察机）写着 `abilities:['stealth']`，
   全仓库没有一处读它；它现在只是一台高闪避（`eva:30`）的狙击机。
   真正意义上的「潜伏者」类（被打之前不能被打）**完全没有**。

### B-2 贴脸刺客 / 专打后排（明日方舟：**空降兵 / 破阵者**）

1. **原作里是什么**：会直接**切你后排 / 落点在你后方**的单位（空降兵、破阵者这一脉，
   [PRTS · 敌人一览](https://prts.wiki/w/%E6%95%8C%E4%BA%BA%E4%B8%80%E8%A7%88) 的「空降兵 / 空降组长 / 破阵者 / 破阵者组长」）。
2. **它逼玩家做什么决定**：**把耐打的放在会被它打到的地方**（或者专门留一个「看后排」的干员）。
3. **换成我们的杠杆**：**站位** + **重装嘲讽** —— 这一条**我们现在就是通的**：
   嘲讽（`src/js/60-战斗.js:145`）会把单体攻击**勾到重装身上**，
   而站位决定「前排谁挡着谁」（`前1→后1,后2` 等 8 条阻挡关系）。§4.1 那张表里
   「专打后排的刺客 → 站位（把耐打的放进挡住后排的位）、嘲讽」就是照这条写的。
4. **记录里长什么样**：`〔嘲讽〕提耶利亚 把这一击勾了过去`。
5. **我们已经有的敌人**：**有，且真的生效（但是靠站位 + 嘲讽，不是靠敌人会「切后排」）** ——
   `berserker`（狂战士贴脸）、`raider`（突击兵）、`bomber`（自爆机）。

### B-3 打一整排 / 打一束的炮（明日方舟：**群体法术 / 范围溅射类**）

1. **原作里是什么**：明日方舟的敌方法术多为**半径溅射**（例：「游击队萨卡兹术师」的「献祭」=
   对半径内所有我方单位造成溅射伤害，见 A-4）。
2. **它逼玩家做什么决定**：**不要把人挤在一起** —— 分散站位让范围伤害只打到一台。
3. **换成我们的杠杆**：**站位**（错开排）。我们**没有半径**，但有三种「一整片」的落点：
   `row`（一整排：前 4 或后 5）、`col`（**阻挡束**：前2 → 前2、后2、后3）、`cross`（目标位 + 左右 + 对位）、
   `all`（9 格）。**`col` / `cross` 就是我们这里的「溅射」**，站位错开真的有用。
4. **记录里长什么样**：`蓝色大肥鱼【周身冲击】→ 我方后1、后2、后3、后4、后5：命中 3150、2560、…（一整排）`。
5. **我们已经有的敌人**：**有，且真的生效** —— `bluefish` 的「周身冲击」（`fire:'map'`，默认一整排）；
   范围武器在这一期**只有它一个敌人有**，其余敌人都是单体。**「以某格为中心的半径」缺**（没有区域概念）。

### B-4 飞行 + 地面混编（明日方舟：**无人机 + 地面单位混编**）

1. **原作里是什么**：同一关里**飞行和地面混着来**，逼你同时留对空和对地两套输出。
2. **它逼玩家做什么决定**：**编队要两条输出线**。
3. **换成我们的杠杆**：**编队选谁**。
   ❌ **做不了**：「飞行无视地面阻挡、走另一条路」——**没有移动、没有路线**，
   我们 9 个位是双方各自的固定站位，不存在「飞过去」。
   ✅ **能做的**：把「飞行」做成一个**纯数值 / 目标规则**的标记（例如「只有某些武器打得到」），
   这不需要格子，但**需要一个新的武器—目标过滤规则**（归 Claude 定要不要，归实现落）。
4. **记录里长什么样**：`蕾卡【突击步枪】→ 无人机：打不到（对空武器才能打它）`（等做成之后）。
5. **我们已经有的敌人**：**数据里有标记，但引擎没读（等于缺）** —— 见 A-3。

### B-5 反射 / 反伤（明日方舟：**有反伤 / 反弹机制的敌人**）

1. **原作里是什么**：明日方舟里有会对**特定伤害类型**做出反制的敌人（最接近的是「源石祭坛」那类**装置**的免疫与强化，
   见 [PRTS · 水产村落](https://prts.wiki/w/%E6%B0%B4%E4%BA%A7%E6%9D%91%E8%90%BD) 那类装置页面）。
   ⚠ **明确的「被打中会反伤」的中文官方名与页面：查不到**（我找到的都是装置 / 光环类，不是反伤），**不编**。
2. **它逼玩家做什么决定**：**换伤害类型 / 别用某一种打法**。
3. **换成我们的杠杆**：**编队选谁**（换伤害类型）。
   ⚠ **缺钩子**：我们的「打空」钩子只给我方 ATX 势力特色用（`72-势力.js` 的 `势力逐段未命中`，

### B-6 光环类：给同伴加命中 / 给我方减命中（明日方舟：**萨卡兹哨兵 / 鼓舞类**）

1. **原作里是什么**：明日方舟里有一批**站在场上就改变全局数值**的单位（哨兵系、光环 / 鼓舞系），

### B-7 大量低血脆皮（明日方舟：**源石虫群 / 蜂群**）

1. **原作里是什么**：一次来一大片**低血低防但数量多**的单位（源石虫系、
   [PRTS · 妖怪](https://prts.wiki/w/%E5%A6%96%E6%80%AA) 页面的「幽灵 / 幽灵组长」一脉数量型敌人）。

### B-8 漏怪 / 冲终点（明日方舟：**漏怪即失败**）

1. **原作里是什么**：明日方舟的**核心失败条件是漏怪**（敌人走到终点），而不是「我方全灭」。
2. **它逼玩家做什么决定**：**在「输出」和「拦截」之间取舍** —— 这也正是「部署费用」这套资源机制存在的理由
   （[PRTS · 关卡一览](https://prts.wiki/w/%E5%85%B3%E5%8D%A1%E4%B8%80%E8%A7%88) 各关卡页都有「可部署人数 / 费用回复」那一栏）。
3. **换成我们的杠杆**：❌ **做不了**。理由：**没有移动、没有终点、没有部署格**。
   我们的胜负只有两条：**敌方全灭 = 胜**；**我方全灭，或打到回合上限还没分出胜负 = 败（按撤退处理）**

4. **记录里长什么样**：`第 11 回合结束还没分出胜负（按撤退处理）` —— **已经有了**。
5. **我们已经有的敌人**：**有，且真的生效** —— 「时间压力」现在由**编成档位**给（`70-编成.js` 的 Boss 档 9 台摆满
   + `回合上限` 收紧），不是由某一个敌人给。

## 3. 杠杆 C：全军方针（全军突击 / 集中攻击 / 攻击后排 / 前守后攻 / 全军防御）

### C-1 会回血的头目（明日方舟：**宿主系 / 梅菲斯特这类治疗与再生**）

1. **原作里是什么**：宿主系（「宿主士兵 / 宿主重装士兵 / 狂暴宿主士兵」）与「梅菲斯特」这一脉，

5. **我们已经有的敌人**：**有，且真的生效（但用的是「定时波次」不是「召唤」）** —— 39 条编成**每条都有 `波次`**；
   敌人身上的 `summon` 标记（`drone` / `swarm`）**引擎没读**。

### C-3 复仇者 / 越打越凶（明日方舟：**寻仇者 / 复仇者**）

1. **原作里是什么**：「寻仇者 / 复仇者」这一对（[PRTS · 敌人一览](https://prts.wiki/w/%E6%95%8C%E4%BA%BA%E4%B8%80%E8%A7%88)

3. **换成我们的杠杆**：**集中攻击**（抢时间）+ **大招开关**（把大招留到它变凶之后再交，还是提前交掉压血）。
   ✅ 我方**已经有同类机制**可以照抄形状：卫星国防军的 **SEED 觉醒值**就是「每回合 +5、击破 +3，到阈值后变强」
   （`src/js/72-势力.js` 的 SEED 条目，`tests/faction.js` 第 [1]-[8] 段钉着）。

## 6. 舰娘（舰队Collection）：**节点**怎么逼玩家改编成

> 舰娘的重点**不在敌人 AI**，而在两件事：**编成**（带什么舰种 / 装备）和**路线**（走哪条路）。
> 我们**没有格子地图、没有移动**，所以舰娘的「路线」这一半**大半做不了**；
> 但「**编成被节点逼着改**」这一半**正好就是我们的「编队选谁」杠杆** —— 这是本文件里最值得搬的一块。
> ⚠ 我们**没有「一个节点 = 一个战斗」之外的结构**：肉鸽大地图有节点类型

### F-4 Boss 点的特效与弱点（装甲破砕 / 特効艦 / 陸上型）

1. **原作里是什么**：舰娘的 Boss 点有**多层特效**：
   ① **装甲破碎（装甲破砕 / 装甲破壊）**：满足条件后 Boss 变得更容易被打穿
   （[wikiwiki · 与ダメージの算定に関わる要素の考察](https://wikiwiki.jp/kancolle/%E6%88%A6%E9%97%98%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6/%E4%B8%8E%E3%83%80%E3%83%A1%E3%83%BC%E3%82%B8%E3%81%AE%E7%AE%97%E5%AE%9A%E3%81%AB%E9%96%A2%E3%82%8F%E3%82%8B%E8%A6%81%E7%B4%A0%E3%81%AE%E8%80%83%E5%AF%9F)、
   [NGA · 2024 夏活带路条件](https://ngabbs.com/read.php?tid=41012551) 这类活动页里通篇在讲「破甲条件」）；
   ② **特定舰娘 / 装备对 Boss 有特效（特効艦）**；
   ③ **陆上型（陸上基地）敌人**：需要三式弹 / 火箭弹（WG42）/ 内火艇这类**对陆装备**才打得动
   （[萌娘百科 · 舰队Collection/战斗](https://zh.moegirl.org.cn/%E8%88%B0%E9%98%9FCollection/%E6%88%98%E6%96%97) 的「火箭弹基础火力加成」那一段）。
2. **它逼玩家做什么决定**：**为这一个 Boss 专门配一次装** —— 破甲条件往往要求「带几艘某舰种走某条路 / 打某个点」，
   所以这是**编成 + 路线**的联合题。
3. **换成我们的杠杆**：**编队选谁** + **藏品** + **集中攻击**。
   ✅ 能落的部分：`weak`（弱点 / 抗性）**我们已经有**，所以「对陆装备」可以翻译成「**某个弱点属性只被某类武器打到**」；
   `bluefish` 的 `Boss脚本.阶段`（半血换阶段）**已经有**，可以扩成「先满足条件才变脆」。
   ❌ 做不了的部分：**「走某条路 / 打某个点才能破甲」** —— 没有格子地图、没有路线选择，我们只有大地图的节点顺序。
   ⚠ 缺的部分：**特效舰（特定角色打特定 Boss 有加成）**我们没有这个钩子。
4. **记录里长什么样**：`〔Boss〕蓝色大肥鱼 进入第 2 阶段（大技能间隔 2 回合、伤害倍率 ×1.25）` —— **已经有了**；
   「破甲」那条要新写，例如 `〔破甲〕蓝色大肥鱼 装甲下降（条件达成）`（等做成之后）。
5. **我们已经有的敌人**：**有，且真的生效（只有「半血换阶段」这一层）** —— `bluefish`；
   「特效舰 / 对陆装备」**缺**。

### F-5 海域的路线条件（羅針盤 / 带路 / 索敵値）

1. **原作里是什么**：海域地图有**分歧点**，走到哪一条路取决于**编成**与**索敌值**。
   真实的带路条件长这样（中部海域 6-2 的例子，[舰娘百科 · 6-2 带路条件](https://m.kcwiki.cn/wiki/%E4%B8%AD%E9%83%A8%E6%B5%B7%E5%9F%9F/6-2/%E5%B8%A6%E8%B7%AF%E6%9D%A1%E4%BB%B6)）：
   `出发点：CL+DD>=4 去B`、`BB系+CV系=4：65%去B，35%去C`、`E：索敌>=50 去J，索敌43~50 随机去I/J，索敌<43 去I`。
   通用说明见 [kcwiki · ルート分岐](https://w.kcwiki.moe/%E3%83%AB%E3%83%BC%E3%83%88%E5%88%86%E5%B2%90)。
2. **它逼玩家做什么决定**：**编成本身就是选路** —— 带 4 艘轻巡+驱逐能走一条稳路，带 4 艘主力舰就是另一条
   （而且常常是 65/35 的随机）。这是舰娘**最大的一道题**。
3. **换成我们的杠杆**：**编队选谁**。
   ⚠ 能做的一半：我们的**肉鸽大地图已经有「走哪一格」**（6×4 网格 + 推进剂，`src/js/91-地图.js`），
   所以「**用编队构成决定下一格能去哪**」这件事**机制上做得了**（我们有队伍名册 + 节点类型 + BFS 邻接）。
   ❌ 做不了的一半：**「索敌值决定走哪条路」这种战内路线分歧**——我们**一进入战斗就是固定的 9 格**，
   没有「打到一半换目标点」这回事。
   ⚠ 有意思的一点：我们**己经有「隐藏的路线压力」**——`推进剂 0 → 追击战（打完下一层上限 −2）`
   （`CLAUDE.md` M4 段），形状上很接近「走错路要付代价」，只是它不是编成决定的。
4. **记录里长什么样**：这是**大地图层面**的记录，例如 `〔路线〕CL+DD≥4 → 走 B（无战斗）`（等做成之后）。
5. **我们已经有的敌人**：**这不是敌人**。我们现有的对应物是**地图节点类型**（`src/js/91-地图.js` 的 7 种节点），
   但它们**目前不会因为编成而改变**（等于缺）。

### F-6 编成限制（出撃制限・札 / 連合艦隊）

1. **原作里是什么**：舰娘的活动图会给舰娘**贴条（札）**，一条舰队只能用某几张条；
   还有**联合舰队**（机动部队 / 水上打击部队 / 输送护卫部队）这类**改变编成规则**的系统
   （[kcwiki · 連合艦隊](https://w.kcwiki.moe/%E9%80%A3%E5%90%88%E8%89%A6%E9%9A%8A)、
   [kcwiki · 遊撃部隊 艦隊司令部](https://w.kcwiki.moe/%E9%81%8A%E6%92%83%E9%83%A8%E9%9A%8A%20%E8%89%A6%E9%9A%8A%E5%8F%B8%E4%BB%A4%E9%83%A8)）。
2. **它逼玩家做什么决定**：**这一关只能带谁** —— 逼你在名册里做取舍，而不是永远用最强的一队。
3. **换成我们的杠杆**：**编队选谁**。
   ✅ **这一条我们能落**：我们已经有**名册 / 出击上限**（`RUN.等级` 决定最多 3–6 台，
   `src/js/05-阵型.js` 的 `出击上限()`），也有**节点类型**。
   要加「本节点只能用某几个势力 / 某几个职业」是**纯编队限制**，**不需要格子**（归 Claude 定要不要）。
   ⚠ 缺：**联合舰队那种「两支队各自编成」的结构我们没有**（我们只有一支队 + 9 格）。
4. **记录里长什么样**：`〔限制〕本节点只允许 近卫 / 尖兵 出战（已满足）`（等做成之后）。
5. **我们已经有的敌人**：**这不是敌人**。我们现有的对应物是**出击上限**（3→6 台）与**队伍上限 12**
   —— 已经是一道编成约束，只是它由**等级**给，不是由**节点**给。

### F-7 资源消耗与「值不值得打」（燃料 / 弹药 / 高速修復材）

1. **原作里是什么**：舰娘每次出击都烧**燃料 / 弹药**，受伤要花**高速修复材**；
   所以「走哪条路、打几个点」直接决定这一趟的**净收益**。
2. **它逼玩家做什么决定**：**绕开某些点**（哪怕那条路更难走），或者**带支援舰队**降低损耗。
   出处：[萌娘百科 · 舰队Collection/战斗](https://zh.moegirl.org.cn/%E8%88%B0%E9%98%9FCollection/%E6%88%98%E6%96%97) 与
   [NGA · 迎海原战场笔记（新人知识库）](https://bbs.nga.cn/read.php?tid=43431601)。
3. **换成我们的杠杆**：**编队选谁** + **藏品**（带经济类藏品）。
   ✅ **我们能落而且已经有一半**：我们的肉鸽有**源碳结晶 / 希望 / 作战耐久 / 推进剂**四套资源
   （`CLAUDE.md` M4 段），而且**藏品里就有经济编制类**（战棋 50 件里 7 件是经济编制）。
   把「这个节点打完要花耐久」写成一条**节点代价**是**纯数值 + 纯界面**的事，**不需要格子**。
4. **记录里长什么样**：`〔节点〕侵蚀源：作战耐久 −1、额外源碳 +8` —— 我们的事件节点记录**已经是这个口吻**
   （`src/js/92-肉鸽界面.js` 的 `设结果()` 同一句话进 `RUN.日志`）。
5. **我们已经有的敌人**：**这不是敌人**。我们现有的对应物是**7 种节点的结算**（黑市 / 瞭望站 / 隧道 / 遗迹 /
   休整 / 出口守军 / 侵蚀源），但**战斗中「打得起打不起」这层压力还没有**（等于缺）。

### F-8 支援舰队 / 基地航空队（支援艦隊 / 基地航空隊）

1. **原作里是什么**：出击前可以派**支援舰队**（道中支援 / 决战支援）在战斗里先手打一轮；
   **基地航空队**还能对一个点派出最多三队、每队最多两次攻击
   （[萌娘百科 · 舰队Collection/基地航空队](https://mobile.moegirl.tw/%E8%88%B0%E9%98%9FCollection/%E5%9F%BA%E5%9C%B0%E8%88%AA%E7%A9%BA%E9%9A%8A)、
   [萌娘百科 · 舰队Collection/战斗](https://zh.moegirl.org.cn/%E8%88%B0%E9%98%9FCollection/%E6%88%98%E6%96%97) 的「陆航攻击」那一段）。
2. **它逼玩家做什么决定**：**把资源花在哪一场** —— 支援是有限的，用在哪一站是决策。
3. **换成我们的杠杆**：**藏品** + **大招开关**。
   ✅ **形状上我们已经有「先手一轮」**：我们的**压制射击**（`src/js/60-战斗.js:450` 的 `〔压制射击〕X 抢先开火`）
   就是「战斗开始前先打一下」，而且**我方和敌方都有**（敌方狙击机也有）。
   ⚠ 缺：**「支援」需要第二支队 / 第二套编成**，我们只有一支队。
4. **记录里长什么样**：`〔压制射击〕狙击机 抢先开火` —— **已经有了**。
5. **我们已经有的敌人**：**有，且真的生效** —— 我方狙击职业的压制射击（对称职业特色，敌方狙击机也有）。

### F-9 大破进击与退避（大破進撃 / 退避）

1. **原作里是什么**：舰娘里舰船**大破**（血量极低）时继续进击有**沉没风险**，
   所以「继续打还是回港」是每一次都要做的判断；后来还有**退避**系统让受损舰船撤出。
   ⚠ **具体规则条目**：本条我**没有找到一条可点开的权威页面写全「大破进击」的判定与后果**，
   只在攻略 / 问答类页面反复出现（例：[NGA · 2023 早春活 集中提问帖](https://ngabbs.com/read.php?page=8&tid=35512842)）。
   → **出处不完整，标注「查不到（无权威单一页面）」**，**不编**。
2. **它逼玩家做什么决定**：**风险取舍**：带着一台快死的船继续走，还是这一趟就此收工。
3. **换成我们的杠杆**：**站位** + **全军防御**（这一回合先保住它）。
   ✅ **我们引擎里最接近的是「反事实回放」**（`方向调整-全队方针与反馈.md` 第 2.5 节）：
   战后把「那一回合改成全军防御」重跑，告诉玩家「X 不会倒下 / 仍会在第 M 回合倒下」。
   这正是把「大破要不要继续」翻译成**我们看得懂的结算**——**而且它已经在计划里了**。
   ❌ 做不了：「退避」（把单位移出战斗）——**没有位移、没有撤退动作**，我们的败北只有「我方全灭 /
   回合上限到」两条，**不存在「主动撤掉一台」**。
4. **记录里长什么样**：`如果第 3 回合改成全军防御：蕾卡 不会倒下；战斗多打 2 回合`（§2.5 的写法）。
5. **我们已经有的敌人**：**这不是敌人**。我们现有的对应物是**回合上限按档收紧**（头目 11 / Boss 11）与
   **失败按剩下的敌人数扣作战耐久**（`CLAUDE.md` M4 段）。

## 8. 我们最缺的是哪一类（一句话）

**我们最缺的是「让同一个敌人因为『你带了谁 / 你怎么摆』而变得打不过或打得到」这一类规则**
—— 也就是**飞行 / 隐匿 / 潜艇 / 制空**这四种「**编队决定能不能打**」的题；
我们现在所有的敌人都只是「换个数值的靶子」，玩家能用的五条杠杆里，真正被敌人**逼出来**的只有
**集中攻击**与**站位 + 嘲讽**两条，**编队那一半几乎是空的**。
