### 3.2 素材接口（全部在 `art\mech-icons.js` 里定义；这些是**别人依赖的签名**）

```js
MI.build(id, opts)  → 绘制指令数组（传给 draw）
//   opts.pal        调色板键 'ying' | 'moon' | 'cb' | 'clyne' | 'prev' | 'atx' | 'mithril' | 'enemy' | 'acted' | 'rock'，或调色板对象
//   opts.plate      'square' | 'circle' | 'none'（底板；游戏里用 'none'，只留给对照表）
//   opts.size       显示尺寸（像素），用来推 LOD
//   opts.lod        's' | 'm' | 'l'，显式指定（覆盖 size 推断）
//   opts.role       战斗分类名，决定胸口核心色
//   opts.inset      机体相对底板的缩放（默认方形 0.94 / 圆形 0.84）
//   opts.outline    外描边颜色（推荐）· opts.outlinePx 外描边半径（单位空间，默认 0.021）
//   opts.cel        默认 true；false 关掉统一光照
MI.draw(ctx, prims, size, x, y)      // 画到 2D 上下文
MI.makeSprite(id, opts, boxPx)       // → 离屏 canvas：宽 boxPx、高 boxPx×(1+headroom)，1×1 图标盒**贴画布底部**
MI.ICON_BY_MECH                      // 机体名（数据里的 mech 字段）→ 图标 id
MI.FACTION_PAL                       // 势力名 → 调色板键
MI.NAMES / MI.ROLE_COL / MI.ROLE_OF / MI.FACTION_OF / MI.PAL / MI.ids
MI.platePrims / MI.shade / MI.mix / MI.hex2rgb / MI.rgb2hex / MI.B
```

### 3.3 我们这边怎么挑图（`src\js\78-图标.js`，照抄战棋 `20-绘制.js:424-451` 的 `iconIdOf` / `palKeyOf` / `STOCK_BY_ROLE`）

1. `MI.ICON_BY_MECH[机体名]` 命中 → 用**专属图标**（机体名 = 数据里的 `mech` 字段：我方如 `U7`、敌方是中文名如 `重型坦克`）；
2. 我方没命中 → 按 `tags.战斗分类` 借**原型剪影**：
   `图标.原型 = { 近卫:'B1', 尖兵:'B2', 指挥:'M1', 重装:'M2', 狙击:'CB2', 特种:'CB3' }`（势力配色仍按自己的势力）；
3. 敌方没命中 → 按体型 / 飞行借：`max(w,h) ≥ 3 → flagship`、`= 2 → fortress`、`flying → fighter`、其余 `grunt`；
4. 再挑不出来（连模板都没有 / 没有 canvas / 素材没注入 / id 不在 `MI.ids`）→ **退成势力色方块 + 短名**（`<span class="mic fb">`），**不抛异常**。

- 调色板：我方查 `MI.FACTION_PAL[势力]`，敌方一律 `'enemy'`。
- 画法：`MI.build(id, {pal, plate:'none', role, size})` → 画在 `逻辑尺寸 × 2` 的离屏 canvas 上 → `toDataURL()` 内联成 `<img class="mi" src="data:image/png;base64,…">`（高分屏不糊）。
- **缓存键 = `图标id|调色板|像素长`**；实测第一屏画 43 张，同一张只画一次，第二次直接复用。
- 对外只有 4 个函数：`图标.图标号(键,方)` / `图标.调色板(键,方)` / `图标.画布(键,方)` / `图标.卡(键,方,尺寸)`；
  尺寸默认 `图标.尺寸.卡 = 34`，另有 `图标.尺寸.列表 = 28`、`图标.尺寸.格 = 32`。
- ⚠️ 小坑（现状，不是 bug）：`图标.画布()` 里**永远按 `图标.尺寸.卡`（34）渲染**，缓存键里的像素长恒为 68；`图标.卡(键,方,尺寸)` 只是把 `<img>` 的 CSS 宽高改成你要的尺寸。所以把图标放到比 34px 大得多的地方会略糊。要改就改 `78-图标.js` 的 `画布()`（把 `逻辑` 改成传入尺寸），别改素材。

## 4. 素材在哪、怎么加

### 4.1 加一个新机体的图标（标准流程，照着做就行）

1. 改 `art\mech-icons.js`（**只改这一个素材文件**）：
   - `const BUILD = {}` 那一段：加 `BUILD.<新id> = (M) => { … 返回图元数组 … }`（照旁边的 `BUILD.chest` / `BUILD.grunt` 写）；
   - `const ICON_BY_MECH = {…}`：加 `机体名: '图标id'`。⚠️ **不登记就永远走借原型，画了也没人用**；
   - `const NAMES = {…}`：加中文名（对照页 / 调试用）；
   - 只有**新势力**才动 `PAL`（加一套颜色）+ `FACTION_PAL`（加一行 `势力名 → 调色板键`）；
   - 只有**新战斗分类**才动 `ROLE_COL`（加一个颜色）。
2. `node tools/build-src.mjs` —— 重新注入 ART 块（不跑这一步，双击 `index.html` 看到的还是旧图标）。
3. `node tests/art_icons.js` —— 第 [2] 段的「专属 N / 借原型 M / 退方块 0」里**专属 +1、借原型 −1** 就是接上了。
4. **双击 `art\preview.html`** 用眼睛看一遍（这是本仓库唯一能自己看素材的办法；对照表页不需要服务器）。
5. 收尾：`node tools/build-src.mjs --check` + 十六套测试全过（第 6 节）→ 提交，说明以 `[美术]` 开头。
