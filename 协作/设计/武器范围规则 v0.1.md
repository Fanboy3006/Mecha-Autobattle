# 武器范围规则 v0.1（4×4 战场 · 给 ARGON）

> 2026-10-17，游戏内容对话 × 作者。
> 作者已定：
> - 双方各 4 列 × 2 排（前排、后排），合起来是 4×4 战场。
> - 战斗中**一般没有位移**。
> - 每把武器都要设定有效打击范围。
>
> 本稿给出一套通用的范围写法。各机体的卡稿按这套来写。

## 1. 坐标与距离
- 战场从我方后排数到敌方后排，共 4 排：我方后排、我方前排、敌方前排、敌方后排。列号 1–4，两边对齐。
- **距离** = 两格之间横向差的列数 + 纵向差的排数（不走斜线）。
  - 纵向差：攻击方和目标都在前排时是 1；一方在后排时是 2；两方都在后排时是 3。
  - 横向差：同列是 0，最远 3。
  - 所以距离在 **1–6** 之间。
- **对位**：同一列的格子。**正前方**：同一列、靠近敌方的那一格。
- **顶位（某一方前排全空时，后排对近战按前排算 · 2026-10-17 作者拍板定案）**：
  - **触发条件**：某一方前排 4 格**全部为空**时，这一方后排全体进入「顶位」（敌我双方都适用）。
  - **作用范围（仅影响近战）**：顶位只影响**近战**——顶位单位能被近战打、也能用近战打人，且**近战距离**的纵向排差按站在前排计算。
  - **直射与曲射不变**：直射、曲射的距离计算（含克鲁兹的【远距·N】）与遮挡判定始终**照真实前/后排位置计算**（避免后排狙击手因前排没人而丢失距离）。
  - 只是近战判定上按前排算，**格子本身不动**，所以不算位移。
- 因为没有位移，**站位在战前编队时就决定了**。短距离武器的机体要放前排，长距离的放后排，这是编队的核心判断。

## 2. 武器的范围字段
每把武器写两项：**类型** + **距离 a–b**。

| 类型 | 规则 |
|---|---|
| 近战 | 攻击方必须在**前排**（含顶位）；只能打敌方**前排**（含顶位）。敌方前排全空时，敌方后排全部顶位，近战全都打得到。 |
| 直射 | 可以打任何一排。**遮挡**：打敌方后排时，如果目标正前方（敌方前排同列）有单位，命中 −20。 |
| 曲射 | 可以打任何一排，不受遮挡。 |
| 无视遮挡 | 写在直射或近战后面，表示不吃上面两条限制（例如隔空 λ 拳、超长距离狙击）。 |

### 范围附加（打一片）
| 写法 | 打到哪些格 |
|---|---|
| 单体 | 只打目标 |
| 溅射 | 目标，加目标十字相邻的格子（同一方阵内） |
| 贯穿 | 目标所在的一整列（敌方前后两格） |
| 横扫 | 目标所在的一整排（4 格） |
| 全体 | 敌方全部 |

### 距离参考（换算旧武器用）
| 旧射程 | 新距离 |
|---|---|
| 近战 1、1–2 | 近战 1–2 |
| 直射 1–3 | 直射 1–3 |
| 直射 1–4 到 1–5 | 直射 1–4 |
| 狙击 3–9 | 直射 2–6 |
| 超远狙击 5–14 | 直射 3–6 |
| 曲射 2–5 到 2–7 | 曲射 2–5 |

- 距离 1 只有「两边都在前排、并且同列」才达得到。
- 下限 ≥ 2 的武器（狙击）打不了正对面的前排，这是狙击的弱点。

## 3. 作废或改写的旧概念
- 移动、移动后不能用、ZOC、朝向、侧击背击、压制射击：在 4×4 里都不再适用。
- 依赖移动的牌改写成站位、遮挡、距离类效果（宗介 v0.2 和克鲁兹 v0.1 已经按这套改过）。
- 换位、拉近、推开这类位移效果：一般不做，只在个别牌上作为特殊效果。

## 4. ARGON 确认与作者拍板记录（2026-10-17）
1. **遮挡**：只看敌方前排同列（或同列前排掩体），不看我方前排。我方站后排射击可以越过自家前排。
2. **顶位**：某一方前排 4 格全空时，该方后排全部顶位；**顶位只影响近战**（能用近战、能被近战打、近战距离按前排算），直射与曲射照真实位置算。
3. **范围附加**：「单体 (`single`) / 溅射 (`splash`) / 贯穿 (`pierce`) / 横扫 (`row`) / 全体 (`all`)」与内核 `area` 字段完全对齐。
