# 月球王国势力卡牌设计 v0.2.1（月相 × 随侍 · 月光牌库版）

> **版本**：v0.2.1（2026-10-20 按审稿意见修订）
> **基准规则**：按《势力与职业卡牌设计规范 v0.3》《单机牌组规则 v0.1》《卡牌流转规则 v0.1》《武器范围规则 v0.1》《设计约定》（`协作/设计/设计约定.md`）修订，体例对齐《殖民卫星军势力卡牌设计 v0.1》《天人势力卡牌设计 v0.1》。数值均为初稿。
> **作者已拍板方向（10-16 保留 + 10-20 路线 C 确认）**：
> - 标准**战法牧三角**，适合新手。
> - 核心是王牌 **Feena**，用卡牌切换战 / 法 / 牧三种**【月相】**；**战 = 【盈月】（护盾）**，**法 = 【残月】（残月的余响）**，**牧 = 【祝福】（月光祝福，回复）**。
> - **开局月相由站位决定**：Feena 开战站前排 = 【盈月】，站后排 = 【残月】；【祝福】靠打牌切入。月相**持续**（单一状态，被替换前不变，战中换位不改变当前月相）。
> - 强调站位与关键词**【随侍】**（与 Feena 十字相邻的月球王国成员，苏菲计入）。
> - **路线 C 范围确认**：**月球王国只用我方互换；影世界可以强制敌方换位**。在 4×4 战场「无常规移动指令」的前提下，月球王国仅允许特定卡牌执行**我方 4×2 阵型内部双格互换 `swapPos(ally, posA, posB)`** 以动态调整【随侍】与前后排站位（绝不移动敌方单位）；砍掉全场前后排 8 格整体翻转等复杂原语。
> - 吸收《融合提案 v0.1》提案 04 的**三层【月光牌库】（SubDeck）**、月球王国专属状态**【月面偏导】**（仅由月光牌提供）与 Iris 个人被动**【月华溢流】**（溢出回复转护盾，与维修职业机制【过量整备】区分）。

## 0. v0.1 → v0.2 / v0.2.1 修订对照

1. **对齐四栏单机牌组与「手牌纯可打」铁律**：
   - 将原稿每人 3 张混排角色牌拆分为现行标准的 **【主武器牌】、【副武器牌】、【大招槽（左栏）】、【精神牌（抽牌堆）】**；势力牌 9 张放入全队**【公有牌】**抽牌堆（无 CD，按初始 / 剧情 / 肉鸽分层）。
   - **消除手牌置灰**：原稿中「前排限定 / 后排限定，不满足时手牌灰掉」的写法改为：
     - **武器牌 / 大招槽**：由 4×4 武器射程（`近战 1–2` 前排锁 vs `直射 2–6`）或大招亮起条件自然控制，不可打时自动收在**左侧未激活/冷却牌库**，满足时自动进入中下手牌区；
     - **精神牌 / 势力牌**：在任意排均可打出（保证抽上手 100% 可打），处于指定排或满足【随侍】时获得**额外强化**。
2. **废除「占本回合行动」，改为「主武器互斥 + 个人战意 `0..100`」**：
   - Feena 的「不打牌的回合普通行动 = 半额释放当前月相」改写为 Feena 的常驻 0 费主武器**【月光共鸣】**；
   - **Feena 的三张月相切换大招全文统一为「武器型大招（占主武器机会，亮起时进入【主武器牌】栏，打出后收起本回合的【月光共鸣】）」**——切月相的回合释放全额月相，不切月相的回合打 0 费主武器【月光共鸣】释放半额月相，与 v0.1 原意 100% 对齐。
   - 合体技【满月·月蚀】由「占三人本回合行动」改为「三人本回合均未打过主武器、各自付战意、打出后三人其余主武器收起回左栏」。
3. **补齐三层势力副牌库【月光牌库】、专属状态【月面偏导】与 3 条全局断路器**：
   - 打出带 **★【随侍】** 的牌且满足随侍条件时，除触发牌面随侍强化外，**从【月光牌库】随机抽 1 张 0 费月光牌进公有手牌**（部分牌带「并把 X 放入月光牌库」）。
   - 二级月光牌【月面偏导盾】提供月球王国专属状态**【月面偏导】**（抵消下一次受击的首段伤害，仅由月光牌提供，不作为全局通用状态）。
   - 接入 3 条全局断路器，彻底解决 v0.1 §6 担心的「额外释放 + 缩冷却 + 低费换位」死循环风险。
4. **路线 C 范围锁定（仅限我方互换）并厘清重装【掩护】叠加/替代关系**：
   - 月球王国所有换位牌统一只调我方内部双格交换 **`swapPos(ctx, 'ally', posA, posB)`**；原稿势力牌 #3「战线轮换（全军前后排整体互换）」收敛为「指定我方一列，将该列前后排 2 格互换」。
   - 明确阿布拉德骨干被动、副武器【★ 不动如山】与**重装职业通用被动【掩护】**的叠加/替代关系（见 §4.2）。

## 2. 势力核心机制：【月相】×【随侍】×【月光牌库】

### 2.1 王牌 Feena 的【月相】（借鉴《杀戮尖塔》观者姿态）

| 项 | 规则 |
|---|---|
| **唯一姿态** | Feena 身上**同时只有 1 个月相**，头像旁常驻月相图标（【盈月】金月、【残月】赤月、【祝福】银月）。 |
| **开局月相（按站位决定）** | 开战时根据 Feena 在 4×4 棋盘上的初始排位自动进入：<br>- **站在前排（`row=0`）**：开局进入 **【盈月】（战）**；<br>- **站在后排（`row=1`）**：开局进入 **【残月】（法）**；<br>- **【祝福】（牧）**：只能通过打出卡牌切入。 |
| **持续与换位** | 月相**没有持续回合限制**，只有打出另一张月相大招或势力牌【月相仪典】时才会替换。**开战之后的换位（`swapPos`）不会改变当前月相**。 |
| **被动常驻修正** | - **【盈月】（战）**：Feena 自身有效装甲 `+20%`；<br>- **【残月】（法）**：Feena 受到的伤害 `+20%`（高风险高输出）；<br>- **【祝福】（牧）**：每个我方阶段开始时，Feena 与十字相邻的【随侍】队友战意 `+3`。 |
| **切换方式（月相大招 · 全部为武器型大招）** | Feena 的三张月相牌均放在**左侧大招槽**，**全部属于【武器型大招】（亮起时进入【主武器牌】栏，打出后收起本回合其余主武器【月光共鸣】）**。打出时立即**切换为对应月相**，并当场释放 1 次该月相的**【全额共鸣】**效果。每张月相大招每回合最多打出 1 次（断路器 2）。 |
| **常驻主武器【月光共鸣】** | Feena 不装备普通枪械，武器栏固定只有 1 张 **0 费主武器【月光共鸣】**。当 Feena 本回合未打月相大招时，可手动打出（或回合结束由 AI 自动补打）【月光共鸣】，释放当前月相的**【半额共鸣】**效果。 |

#### 三种月相的【全额（打月相大招）】与【半额（打主武器「月光共鸣」）】对照表

| 月相 | 定位 | 全额释放（打出对应月相大招时立即结算） | 半额释放（打出 0 费主武器【月光共鸣】时结算） |
|---|---|---|---|
| **【盈月】** | 战（护盾） | Feena 与所有**随侍队友**获得护盾 = `Feena 最大 HP × 15%`（持续至下个我方阶段开始）。 | Feena 与所有**随侍队友**获得护盾 = `Feena 最大 HP × 8%`（持续至下个我方阶段开始）。 |
| **【残月】** | 法（余响） | **残月的余响（全额）**：对敌方当前 HP 最高的 **`(1 + 随侍数)`** 台敌机各造成 1 段 `1800` 点特殊伤害（必中，无视遮挡）。 | **残月的余响（半额）**：对敌方当前 HP 最高的 **`(1 + 随侍数)`** 台敌机各造成 1 段 `900` 点特殊伤害（必中，无视遮挡）。 |
| **【祝福】** | 牧（回复） | Feena 与所有**随侍队友**回复 `12%` 最大 HP，其余队友回复 `6%` 最大 HP（**Feena 在后排时**：改为我方全体回复 `12%` 最大 HP）。 | Feena 与所有**随侍队友**回复 `6%` 最大 HP，其余队友回复 `3%` 最大 HP。 |

### 2.2 触发关键词【随侍】与路线 C 换位范围（仅我方互换）

| 项 | 规则 |
|---|---|
| **【随侍】关系定义** | 与 Feena 在我方 4×2 阵型中处于**十字相邻格（同排左右相邻、或同列前后对位）**的存活**月球王国成员**，即为 Feena 的**【随侍】**。 |
| **随侍数（`0..3`）** | 当前与 Feena 十字相邻的存活月球王国成员数量（`0..3`）。Feena 站在中间两列（第 2、3 列）时最多 **3 人**，站在边列（第 1、4 列）时最多 **2 人**。其他势力队友站在旁边不计入随侍数，也不妨碍。 |
| **★【随侍】触发条件** | 打出带 **★【随侍】** 的牌时：<br>- 若打出者是**其他月球王国成员**：打出瞬间该成员**与 Feena 十字相邻**，即触发 `随侍：…`；<br>- 若打出者是 **Feena 本人**：打出瞬间 **`随侍数 ≥ 1`**，即触发 `随侍：…`。 |
| **触发收益（效果 + 抽月光牌）** | 触发【随侍】时：① 生效牌面写的 **`随侍：…`** 强化效果；② **从【月光牌库】随机抽 1 张牌放进公有手牌**（公有手牌满 6 张时不抽，牌留在库里；「放入 X」照常执行）。 |
| **路线 C：仅限我方双格互换** | 作者确认路线 C 范围：**月球王国只用我方互换**（通过【空中回收】【锚链调度】【阵形变换】【战线轮换】【公主挺身】调用共用底座 `swapPos(ctx, 'ally', posA, posB)`，交换我方两个格子的单位或移入我方空格，不移动敌方单位）。换位后同步刷新的 6 项内容见 §8。 |

- **界面视觉反馈**：
  - 4×4 棋盘上，Feena 十字相邻的 2~3 个格子常驻淡金色月光边框；站在里面的月球王国队友头像亮起 `〔随侍〕` 徽章。
  - 当前满足【随侍】条件的卡牌在中下手牌区亮起银月金边。

## 3. 三层势力副牌库：【月光牌库】与专属状态【月面偏导】

- 全队共享一份；月光牌一律 **0 费**，任何存活的月球王国成员都能打，**不占主武器**，算月球王国牌，本身**不带【随侍】**（防自我循环）。
- **一级、二级牌**打出后**回到月光牌库**；**三级头奖牌**每种每场限放入 1 次，打出后**移出本场**（断路器 1）。
- **月球王国专属状态【月面偏导】**：**只由二级月光牌【月面偏导盾】提供，不作为全局通用状态**。拥有【月面偏导】（上限 1 层，不可叠层，持续至下个我方阶段开始）的我方单位受到攻击时，将该次攻击的**第 1 个命中段伤害强制降为 `0`**，随后【月面偏导】移除（后续命中段正常结算装甲共享池）。

## 4. 成员卡池设计（M1–M5；★ = 带【随侍】）

> 说明：本节完整保留 v0.1 原稿每名角色的核心卡牌与站位设计，并按现行四栏单机牌组（主武器 / 副武器 / 大招槽 / 精神牌）与 4×4 距离规范补齐参数。每张大招均在表内明确标出「武器型大招 / 非武器型大招」。

### 4.1 M1 Feena（王牌 · 指挥）：核心，三张武器型大招对应三种月相

#### （1）武器栏（固定）
| 牌名 | 栏位 / 类型 | 费用 | 冷却 | 类型与范围 | 威力×段数 | 命中 / 暴击 | 效果与站位 | 代价 / 取舍 |
|---|---|---|---|---|---|---|---|---|

## 8. 依赖的引擎底座（月球王国与影世界共用）

> ★ **月球王国与影世界共用同一套底层换位原语 `swapPos` 及换位后刷新管线**，内核只需实现一份，通过参数控制两势力的作用范围。

### 8.1 共用换位原语：`swapPos(ctx, side, posA, posB, opts)`
- **功能**：在同一方阵（`side = 'ally' | 'enemy'`，各自 `4 列 × 2 排`）内部，交换格子 `posA` 与 `posB` 上的单位（若其中一格为空格，则将另一格的存活单位移入该空格；若两格均为空或 `posA === posB`，不执行操作并返回 `0`）。
- **两势力的调用权限边界（路线 C 作者确认）**：
  - **月球王国**：仅调用 `side = 'ally'`（只允许我方阵型内部互换，绝不移动敌方单位）；
  - **影世界**：可调用 `side = 'ally'` 与 `side = 'enemy'`（既可我方内部互换，也可强制敌方阵型内部互换，绝不跨阵）。

### 8.2 换位后必须同步刷新的 6 项内容（两势力共用，按序立即执行，不耗 `rng`）
每次 `swapPos` 实际改变了单位位置后，引擎按以下固定顺序立即同步刷新：
1. **坐标与「顶位」状态重算**：更新被交换单位的 `slot (row, col)`；检查我方前排 4 格或敌方前排 4 格是否因换位变成「全空」或「非全空」，实时更新后排单位的【顶位】标记。
2. **势力站位关系 / 移位计数重算**：
   - **月球王国**：实时重算与存活 Feena 十字相邻的月球王国成员名单与 **`随侍数 (0..3)`**，更新棋盘月光边框与 `〔随侍〕` 徽章；
   - **影世界**：若 `opts.isShadowCard === true`，按实际改变格子的存活单位数累加 `本回合移位 / 本场移位`，为发生位移的单位挂上本回合 **`〔错位〕`** 标记（并结算【深渊之门】追加伤害）。
3. **显式 `〔掩护〕` 护盾连线重算**：按换位后的新坐标，重新计算所有依赖相对位置（如重装通用「同列正后方」、阿布拉德【不动如山】「同列后排 + 同排左右相邻」、【骑士的誓约】「Feena 十字相邻」）的保护目标连线，保留当前剩余掩护次数。
4. **敌方行动意图 `算意图(ctx)` 实时同源重算**：
   - **第一步（原武器原目标仍合法）**：若敌机原定武器在新位置仍满足排位限制且射程覆盖原定目标，则保持原武器与原目标不变，仅重算前排遮挡（`-20`）与预计伤害；
   - **第二步（原武器可用、原目标不可达 → 同武器换目标）**：若我方被瞄准的前排单位换到了后排导致敌方近战打不到原目标，敌机保持原武器不变，在当前可达的我方目标中按 AI 规则重新选定目标；
   - **第三步（原武器在新位置不可用 → 换远程武器，无则待机）**：若敌方近战单位被影世界强制换到后排（且敌方未处于顶位）导致近战武器不可用，优先改用该敌机当前可用的远程武器；若无可用远程武器，则本回合意图变为 `〔射程不达 · 待机〕`。
5. **武器栏与大招槽可用性刷新（遵守「手牌纯可打」铁律）**：
   - 因排位或距离改变而不再满足条件的主/副武器与大招（如从前排换到后排时的【打桩臂】【小太刀·居合】【★ 月相·盈月】）立即收起至**左侧未激活牌库**；
   - 因换位新满足排位、距离或移位次数条件的武器与大招（如换到后排时的【月光狙击枪】、换到前排时的【小太刀·居合】、影世界达标亮起的【影凤凰】【连锁投掷】）立即进入**中下手牌区**并高亮。
6. **手牌关键词高亮刷新**：重新检查中下手牌区中所有带 ★【随侍】或 ★【错位（自/敌）】卡牌的当前触发状态，实时点亮或熄灭金边。
