# 单机牌组规则 v0.1（规则更新讨论稿 · 给 ARGON）

> 2026-10-17，作者 × CC。目标：从「全队一手牌 + 按速度自动行动」改成 **SRW / 兰斯式的逐台指挥**：每台机体有自己的牌、自己的气力，玩家自由选择先动哪台。
> 本稿**替换**《大招牌化规则 v0.2》中「全队共用手牌 / 全队气势」的部分；大招牌的条件发牌、冷却、回牌库规则**保留**，只是搬进各自的牌库。
> 数值均为初稿。

## 0. 作者已定（4 条）
1. **完全放弃速度顺序**：我方阶段内，玩家可以任意切换要操作的机体。
2. **每台机体有自己的气力**（SRW 式）。
3. **点击机体 → 两排牌**：上排 = 该机专属牌；下排 = 公有牌。**职业分类保留**。
4. **没操作的机体由 AI 自动出牌**。
5. **武器全部做成牌**（含普通攻击）。出牌数不用「每台 1 次行动」硬限，而是：
   - **武器牌**：打出一张后，本回合该机其余武器牌**销毁**（下回合恢复）。例外牌（如**援护射击**）不会被销毁。
   - **近卫的连续攻击**：每回合一次，让该机所有武器牌**回手**，可以再打一张武器牌。
   - **精神类卡牌**（非武器牌）**不受此限制**，靠控制发牌数量和消耗气力来限制。

## 1. 回合结构（建议：SRW 式阶段制）
1. **我方阶段**：
   - 玩家点任意一台 → 打开它的出牌界面 → 出牌；可随时切到另一台，顺序自由，也可以切回已经出过牌的机体继续打精神牌。
   - 出牌数的限制见 §4（武器牌互相销毁 / 精神牌靠发牌与气力）。
   - 点「结束回合」时，还没打过武器牌的机体由 AI 替它出牌（作者 #4）。
2. **敌方阶段**：敌方按现有逻辑行动（顺序沿用敌方内部规则，或简化为编号顺序，待 ARGON 建议）。
3. **回合结束**：冷却、buff 剩余回合等照旧结算。

> 待议：要不要保留「压制射击」（敌方抢在我方行动前开火）。在阶段制下，它可以改成「我方机体行动时，被它攻击的敌方若有压制射击则先打」——语义照旧，触发点从速度顺序换成玩家点选。

## 2. 每台机体的牌
### 2.1 专属牌（上排）
上排分两块：
- **武器牌（固定，不抽）**：该机的每把普通武器各是一张牌，**每回合开始时全部在手**（就是 SRW 的武器列表做成了牌）。
  - 武器有冷却时，冷却中的那张显示灰色。
  - 打出一张武器牌 → 本回合其余武器牌销毁；下回合开始全部恢复。
  - **例外标签「不被销毁」**：例如援护射击。别的武器打出后它仍在手，可以继续打；它自己打出后是否销毁其他武器，逐张标注。
- **专属牌库（要抽）**：**角色牌**（含大招，见大招牌化 v0.2）+ 该机专属的**精神类卡牌**。
  - 抽牌：开战起手 2 张；每回合我方阶段开始时每台抽 1 张；专属手牌上限 4（不含武器牌）。
  - 打出后进入该机自己的弃牌堆；牌库空时弃牌堆洗回。大招牌另按「回牌库 + 冷却」规则。
  - 条件发牌（大招牌化 v0.2）照旧，只是发到**这台机体自己的**上排，并高亮。
- **大招牌也算武器牌**：打出后同样销毁本回合其余武器牌；反过来，本回合已打过武器牌（其余武器已销毁）时，大招牌也不能再打。

### 2.2 公有牌（下排）
- 内容：**势力牌 + 统帅牌 + 职业牌**，全队一个公共手牌，点任何一台机体时都显示在下排。
- **职业分类**（作者 #3）：职业牌标有职业（近卫 / 狙击 / 尖兵 / 重装 / 指挥…），**只有该职业的机体能打**；点到其他职业的机体时显示为灰色。势力牌同理：只有该势力成员能打。
  - 这和 Artifact 的「颜色限制」是同一个思路：公共的牌，按身份决定谁能用。
- 谁打出，**扣谁的气力**。
- 抽牌：开战起手 3 张；每回合抽 1 张；公有手牌上限 6。
- 来源：沿用现有牌池（职业 / 势力 / 统帅三类），角色牌移到各机专属牌库。

## 3. 每台机体的气力（作者 #2）
- 初稿：开场 20，每回合 +5，上限 100。
- 额外来源：命中一次 +2、被击 +2、击破 +10（SRW 味道：越打越亢奋）。
- 费用标尺沿用现有卡（0–35），所以一台机体大约 2–3 回合打得起一张大招。
- 回气力的牌（如 ATX「眨眼」「止损」）改成「回给自己」或「回给指定的一台」，逐张标注。

## 4. 出牌数的限制（作者 #5）
不设「每台每回合 1 次行动」。两类牌各有各的限制方法：
- **武器牌（含大招）**：靠「打出一张 → 其余武器本回合销毁」限制。正常情况每台每回合打 1 张武器牌。
  - 例外牌（援护射击）：不被销毁，可在打过别的武器后补打。
  - **近卫【连续攻击】**：近卫职业能力，每回合一次，所有武器牌回手（冷却中的仍是灰色），可以再打一张武器牌。
  - 「再动」类效果（W17·中继等）统一改写成「让某台机体的武器牌回手」，和连续攻击同一套语义。
- **精神类卡牌**（buff、势力牌、职业牌、统帅牌、专属精神牌）：**不限张数**，靠两样东西限制：
  1. **发牌控制**：每回合抽几张、手牌上限、条件发牌的门槛。
  2. **气力消耗**：打出者付气力。
- 「这台机体本回合还能不能打武器」在机体头像上要一眼看得出来（例如武器牌全部销毁时头像变暗）。
- 精神牌能不能在武器牌之后再打：**能**（除非牌上写「攻击前使用」）。

## 5. 自动出牌（作者 #4）
- 结束回合时，**本回合还没打过武器牌**的机体按 AI 出牌：优先大招（若打得起且有目标），否则按现有 AI 的武器选择逻辑打一张武器牌；不打精神类卡牌和公有牌（留给玩家）。
- 可加一个「全员托管」按钮，给不想逐台操作的玩家；这时 AI 也可以打公有牌。

## 6. 对已有设计的影响
| 已有设计 | 影响 |
|---|---|
| 大招牌化 v0.2 | 保留条件发牌、冷却、回牌库。「打大招 = 本回合行动」改成「大招牌算武器牌，打出后销毁其余武器」。删去「全队手牌 10 张」 |
| 合体技（轮盘双响） | 「占两人行动」改成「两人本回合都还没打过武器牌；打出后两人的武器牌都销毁」 |
| 全队气势（开场 25，每回合 +10） | 改成每台各自的气力；与气势挂钩的牌、藏品要逐张改口径 |
| ATX v0.2 | 「冷却中的 ATX 角色牌冷却 −1」照旧（在各自牌库里）；全场光环牌放公有排，由打出者付费 |
| 秘银 v0.2【Uruz 连携作战】 | 自由出手顺序让连携更有操作空间，**是利好**；需复查依赖「行动顺序」的写法 |
| 速度属性 | 不再决定我方顺序。保留作命中 / 闪避计算，或作敌方顺序 |
| 方针（全队） | 只影响 AI 自动出牌的那几台 |

## 7. 工程影响（ARGON 评估）
- 战斗内核从「AI 驱动的 runTurn」改成**等待玩家指令**的阶段制：
  - 我方阶段 = 一串「选机体 → 出牌」指令；敌方阶段沿用现有 AI。
- 需要新的总开关 `单机牌组.开`（默认关），保住 168 场黄金样例；照 D-01 的方式登记为已接受差异。
- 每台机体的状态新增：牌库、手牌、弃牌、气力。
- 自动出牌要有一个确定性的 AI 选牌器，给测试和「托管」用。
- 敌方意图预告（`算意图`）在阶段制里价值更高，建议提前排期。

## 8. 待 ARGON / 作者讨论
1. 敌方阶段的行动顺序怎么定。
2. 压制射击、再动在阶段制里的新触发点。
3. 专属起手 / 抽牌 / 上限，公有起手 / 抽牌 / 上限这几个数字。
4. 气力的数值：开场、每回合、命中、被击、击破、上限。
5. 哪些武器带「不被销毁」标签（援护射击之外，例如支援类、反应类武器）；近卫以外的职业要不要各有一个类似连续攻击的职业能力。
6. 肉鸽：专属牌库怎么成长（买角色牌 / 武器改造 / 删牌），公有牌池怎么成长。
