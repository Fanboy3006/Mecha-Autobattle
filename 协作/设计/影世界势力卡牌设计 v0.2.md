# 影世界势力卡牌设计 v0.2.1（影界之门 × 错位 · 影门牌库版）

> **版本**：v0.2.1（2026-10-20 按审稿意见与「影镜」设定修订）
> **基准规则**：按《势力与职业卡牌设计规范 v0.3》《单机牌组规则 v0.1》《卡牌流转规则 v0.1》《武器范围规则 v0.1》《设计约定》（`协作/设计/设计约定.md`）修订，体例对齐《殖民卫星军势力卡牌设计 v0.1》《天人势力卡牌设计 v0.1》。数值均为初稿。
> **灵感来源与世界观（《超级机器人大战 A / OG》「影镜 Shadow Mirror」设定）**：
> - **势力原型**：来自《机战 A / OG》的平行世界特务军团**「影镜（Shadow Mirror）」**——依靠**次元转移系统（System XN / 影界之门）**从「那边」的世界跨越次元而来，信奉「唯有无尽的战乱与混沌才能推动人类进化（毁灭安逸秩序）」。
> - **机制与世界观的契合**：影镜的核心科技是**「次元转移（空间跳跃）」**，核心教义是**「制造混沌、撕裂敌方秩序」**——落到 4×4 棋盘上，影世界正是通过开启【影界之门】强行把敌我单位在次元裂缝间拉扯换位（`swapPos`），把敌方严整的前后排防线搅入混沌（`〔错位〕`），再由夺魂者式的王牌贴脸处决。
> **作者已拍板方向（10-16 保留 + 10-20 路线 C 确认）**：
> - 影世界的核心特色是**【影界之门：移位计数 × 错位】**，围绕两件事展开：**自身的位移**、**对敌人的强制换位**。
> - **路线 C 范围确认**：**月球王国只用我方互换；影世界可以强制敌方换位**。在 4×4 战场「无常规移动指令」的前提下，允许影世界卡牌使用统一的**同阵双格置换原语 `swapPos(ctx, side, posA, posB)`**（既可我方内部换位护人/抢位，也可强制敌方内部换位：把敌方后排拽到前排破遮挡，或把敌方前排近战推到后排使其降级/待机）；**砍掉原稿中「整排循环平移」「敌方前后排 8 格整体翻转」「全场随机乱换」三种复杂原语**。
> - 吸收《融合提案 v0.1》提案 05 的精华点子：三层**【影门牌库】（SubDeck，收纳并升级原稿衍生牌【影之种】）**、维诺**【影之种·融毁引爆】**、雷萨**【门之力·无视遮挡折跃斩】**与单兵**【炉心逆流】**，但完全保留 10-16 原稿的【移位 / 错位】主轴。

## 0. v0.1 → v0.2 / v0.2.1 修订对照

1. **路线 C 范围锁定（我方互换 + 强制敌方换位）并收敛为单一 `swapPos` 原语**：
   - **保留**：我方两格互换（【门之力】【游刃有余】【门扉轮转】【换形】）、敌方两格强制互换（【影之种】【曲射弹】【影缚】【抓投】【错乱】）。
   - **收敛改写（砍掉 3 种大洗牌原语）**：
     - 原稿 B2【影凤凰】与势力牌 #8【乱阵】的「敌方前排整排向右平移 1 格（最右回最左）」→ 改写为**指定敌方前排最多 2 对相邻/对位格执行 `swapPos`**；
     - 原稿 B3【影之森】的「每个敌人和一个随机相邻位敌人换位」→ 改写为**将所有寄生了【影之种】的敌机与其同列对位交换位置 `swapPos`，并立即引爆【影之种】造成融毁伤害**；
     - 原稿合体技【影门·双影】的「敌方阵型前后排整体翻转」→ 改写为**将敌方当前 HP 最高与最低的 2 台敌机分别与其同列对位交换位置 `swapPos`，并对敌方全体挂上本回合【错位】**。
2. **对齐《卡牌流转规则 v0.1》与《规范 v0.3》三层势力副牌库【影门牌库】**：
   - **大招槽（左栏）**原样保留「`本回合移位 ≥ N` / `本场移位 ≥ N`」实时亮起机制（【影凤凰】本回合 ≥ 2、【连锁投掷】本回合 ≥ 3、【万刃归一】本场 ≥ 6、【影门·双影】本场 ≥ 12）；

3. **补齐「敌方被强制换位后的意图重算精确规则」（见 §2.1 与 §8.2）**：
   - 明确规定当敌方近战单位被影世界强制换到后排（或原定目标脱离射程）时，`算意图(ctx)` 按「**① 原武器原目标仍合法则保留 → ② 原武器可用但原目标不可达则同武器换目标 → ③ 原武器因排位锁不可用则改用可用远程武器，无可用远程武器则本回合转为 `〔射程不达·待机〕`**」三步确定性规则实时刷新。
4. **融入《机战 A / OG》「影镜（Shadow Mirror）」设定并补齐拉米亚（W17）双势力联动**：
   - 补入影镜世界观映射，并在 §1 明确接通《拉米亚卡牌设计 v0.1》已定义的 **`A3 拉米亚（主势力 ATX / 副势力 影世界，W17 人造人）`** 双势力规则。

## 2. 势力核心机制：【影界之门】（移位计数 × 关键词【错位】× 影门牌库）

### 2.1 【移位】计数、路线 C 换位范围与敌方意图变化精确规则

| 项 | 规则 |
|---|---|
| **路线 C 换位范围（我方互换 + 强制敌方换位）** | 作者确认路线 C 范围：**月球王国只用我方互换；影世界可以强制敌方换位**。<br>影世界统一调用共用底层原语 `swapPos(ctx, side, posA, posB)`：<br>- **我方换位（`side = 'ally'`）**：在我方 4×2 阵型内交换两台存活友军，或将 1 台友军移入我方空格；<br>- **强制敌方换位（`side = 'enemy'`）**：在敌方 4×2 阵型内强制交换两台存活敌机，或将 1 台敌机移入敌方空格。敌我绝不跨阵。 |
| **【移位】计数怎么算** | **只有影世界牌**（含成员牌、影世界势力牌、影门牌库牌）使存活单位实际改变了所在格子，才计入**【移位】**：<br>- **两台存活单位互换位置**：记 **`2` 次移位**；<br>- **1 台存活单位移入空格**：记 **`1` 次移位**；<br>- 若目标已在目标位置或无合法交换对象导致未发生格子改变，记 `0` 次。<br>- 其他势力的牌造成的换位（如月球王国、秘银）不计入【移位】，但也不会清零计数。 |
| **两个计数器** | 左侧牌库面板与手牌区常驻显示：**`〔本回合移位：N〕`**（每个我方阶段开始清零）与 **`〔本场移位：M〕`**（本场累计）。用于解锁大招槽与条件牌。 |
| **★ 敌方被强制换位后，本回合意图怎么变（三步确定性规则）** | 每当影世界牌改变了我方或敌方单位的位置后，立即按以下 **3 步优先级**重算敌方本回合行动意图（`算意图(ctx)`）：<br>**① 原武器 + 原目标仍合法 → 保持不变**：若该敌机原本预告的【原武器】在新位置上仍满足排位限制，且射程 `a–b` 仍够得着【原定目标】，则意图**保持原武器与原目标不变**（仅按新位置重算前排遮挡 `-20` 与预计伤害）；<br>**② 原武器可用，但打不到原目标 → 同武器重选目标**：若【原武器】在新位置上本身可用，但因换位导致【原定目标】超出了该武器的射程或前排锁（例如我方前排目标被换到了后排，敌方近战打不到后排），则该敌机**保持【原武器】不变，按敌方 AI 选目标规则在当前可达的我方目标中重新选定 1 个目标**；<br>**③ 原武器在新位置不可用（如敌方近战被换到后排） → 改用其他可用武器，无则【待机】**：若敌方【近战】单位被影世界强制换到**敌方后排（且敌方前排仍有存活单位，未进入顶位）**，导致其原定的【近战】武器因违反「近战必须在敌方前排（含顶位）」而不可用：<br>　- **3a（改用其他武器）**：若该敌机面板上拥有当前在后排可用（未冷却且射程可达）的远程武器（直射 / 曲射），则按敌方 AI 规则改用该远程武器并选定目标；<br>　- **3b（无可用武器则待机）**：若该敌机没有其他可用武器（如纯近战敌机，或远程武器均在冷却/射程不达），则该敌机本回合意图立即变为 **`〔射程不达 · 待机〕`**（本回合敌方阶段跳过行动，不攻击）！ |

### 2.2 状态与触发关键词：【错位（自 / 敌）】

| 项 | 规则 |
|---|---|
| **状态【错位】** | 本回合内**因任何原因改变过格子位置**的单位（敌我双方均算），头顶亮起紫色 **`〔错位〕`** 标记，持续至本回合结束。 |
| **★【错位（自）】** | 打出带 **★【错位（自）】** 的牌时，若**打出者本回合已处于 `〔错位〕` 状态**：<br>① 触发牌面写的 `错位（自）：…` 强化效果；<br>② **从【影门牌库】随机抽 1 张牌放进公有手牌**。 |
| **★【错位（敌）】** | 打出带 **★【错位（敌）】** 的牌时，若**目标敌机（范围攻击看中心目标或场上有任意已错位敌机）本回合已处于 `〔错位〕` 状态**：<br>① 触发牌面写的 `错位（敌）：…` 强化效果；<br>② **从【影门牌库】随机抽 1 张牌放进公有手牌**。 |
| **公有手牌满 6 张** | 触发关键词时不抽牌（牌留在影门牌库中不浪费），但牌面强化效果与「放入 X」照常执行。 |

- **每回合的核心节奏**：**先挪人（用 0~5 费换位牌或【影之种】交换敌我位置，攒够移位计数、废掉敌方前排近战意图或把敌方后排拉出来，并挂上 `〔错位〕`）→ 大招槽自动亮起 + 打出带 ★【错位】的牌触发爆发并抽取【影门牌库】！**

## 3. 三层势力副牌库：【影门牌库】（含核心牌【影之种】）

- 全队共享一份；影门牌一律 **0 费**，任何存活的影世界成员（含副势力影世界的拉米亚）都能打，**不占主武器**，算影世界牌（造成的换位**计入【移位】**并挂 `〔错位〕`），但本身**不带 ★【错位】抽牌词条**（不会自我无限抽牌）。
- **一级、二级牌**打出后**回到影门牌库**；**三级头奖牌**每种每场限放入 1 次，打出后**移出本场**（断路器 1）。

## 8. 依赖的引擎底座（月球王国与影世界共用）

> ★ **月球王国与影世界共用同一套底层换位原语 `swapPos` 及换位后刷新管线**，内核只需实现一份，通过参数控制两势力的作用范围。

### 8.1 共用换位原语：`swapPos(ctx, side, posA, posB, opts)`
- **功能**：在同一方阵（`side = 'ally' | 'enemy'`，各自 `4 列 × 2 排`）内部，交换格子 `posA` 与 `posB` 上的单位（若其中一格为空格，则将另一格的存活单位移入该空格；若两格均为空或 `posA === posB`，不执行操作并返回 `0`）。
- **两势力的调用权限边界（路线 C 作者确认）**：
  - **月球王国**：仅调用 `side = 'ally'`（只允许我方阵型内部互换，绝不移动敌方单位）；
  - **影世界**：可调用 `side = 'ally'` 与 `side = 'enemy'`（既可我方内部互换，也可强制敌方阵型内部互换，绝不跨阵）。

### 8.2 换位后必须同步刷新的 6 项内容（两势力共用，按序立即执行，不耗 `rng`）
每次 `swapPos` 实际改变了单位位置后，引擎按以下固定顺序立即同步刷新：
1. **坐标与「顶位」状态重算**：更新被交换单位的 `slot (row, col)`；检查我方前排 4 格或敌方前排 4 格是否因换位变成「全空」或「非全空」，实时更新后排单位的【顶位】标记。
2. **移位计数 / 势力站位关系重算**：
   - **影世界**：若 `opts.isShadowCard === true`，统计本次实际改变格子的存活单位数 `k`（`1..2`），累加 `ctx.turnShiftCount += k` 与 `ctx.battleShiftCount += k`，为发生位移的单位挂上本回合 **`〔错位〕`** 标记；若 `ctx.abyssGateActive`（【深渊之门】激活中），对每个发生移位的敌方单位结算 `700` 点特殊伤害（每台敌机每回合限 3 次）；
   - **月球王国**：实时重算与存活 Feena 十字相邻的月球王国成员名单与 `随侍数 (0..3)`。
3. **显式 `〔掩护〕` 护盾连线重算**：按换位后的新坐标，重新计算所有依赖相对位置（如重装通用「同列正后方」、阿布拉德【不动如山】、【骑士的誓约】及敌方重装掩护）的保护目标连线，保留当前剩余掩护次数。
4. **敌方行动意图 `算意图(ctx)` 实时同源重算（三步确定性规则）**：
   - **第一步（原武器原目标仍合法 → 保持不变）**：若敌机原定武器在新位置仍满足排位限制且射程覆盖原定目标，则保持原武器与原目标不变，仅重算前排遮挡（`-20`）与预计伤害；
   - **第二步（原武器可用、原目标不可达 → 同武器换目标）**：若原武器在新位置仍可用，但原定目标因换位脱离射程或前排锁（如我方被瞄准的前排单位换到了后排），敌机保持原武器不变，在当前可达的我方目标中按 AI 规则重新选定目标；
   - **第三步（原武器在新位置不可用 → 换远程武器，无则待机）**：若敌方【近战】单位被影世界强制换到敌方后排（且敌方未处于顶位）导致近战武器不可用，优先改用该敌机面板上当前可用的远程武器（直射/曲射）；若无可用远程武器，则该敌机本回合意图立即变为 **`〔射程不达 · 待机〕`**（本回合敌方阶段跳过行动，不攻击）。
5. **武器栏与大招槽可用性刷新（遵守「手牌纯可打」铁律）**：
   - 因排位或距离改变而不再满足条件的主/副武器与大招立即收起至**左侧未激活牌库**；
   - 因换位新满足排位、距离或移位次数条件（如雷萨获得 `〔错位〕` 解锁全排【影刃斩】、`本回合移位 ≥ 2` 点亮【★ 影凤凰】、`本回合移位 ≥ 3` 点亮【★ 连锁投掷】、`本场移位 ≥ 6` 点亮【★ 影界·万刃归一】）的武器与大招立即进入**中下手牌区**并高亮。
6. **手牌关键词高亮刷新**：重新检查中下手牌区中所有带 ★【错位（自/敌）】或 ★【随侍】卡牌的当前触发状态，实时点亮或熄灭金边。

## 9. 影世界专项落地依赖与三层反馈

### 9.1 专项状态与断路器
1. **战况计数器与状态标记**：
   - `ctx.turnShiftCount`（本回合移位次数，每回合初清 0）、`ctx.battleShiftCount`（本场累计移位次数）、`ctx.shadowSeedPlayedCount`（本场打出【影之种 / 寄生影种·改】张数）。
   - 单位布尔标记 `unit.shiftedThisTurn`（即 **`〔错位〕`**，本回合位置发生改变时置 `true`，回合结束清 `false`）与层数标记 `unit.shadowSeedStacks`（`〔影种〕`层数）。
2. **双势力判定接口**：
   - 引擎判断「是否为影世界成员」时，统一使用 `inFaction(u, '影世界')`（检查 `u.tags.势力 === '影世界' || u.tags.副势力 === '影世界'`），使拉米亚（`A3`）无缝接入影世界公有牌与影门牌库。
3. **【影门牌库】（SubDeck）与全局断路器**：
   - 严格遵守 **3 条全局防死循环断路器**：
     - 断路器 1：三级牌【次元崩落】【深渊门扉·全开】每种每场限放入 1 次，打出后移出本场；【门的回响】【深渊之门】标「每场 1 次」打出移出；
     - 断路器 2：同一张大招每回合最多打出 1 次；
     - 断路器 3：每台机体每回合最多触发 1 次再动（【深渊门扉·全开】恢复主武器每机每回合限 1 次）。

### 9.2 三层反馈（见 `协作/设计/设计约定.md`）
- **预告**：
  - 手牌区上方显示 `〔本回合移位：N ｜ 本场移位：M〕`；大招槽上的【影凤凰】【连锁投掷】【万刃归一】实时显示距离亮起还差几次移位（如 `〔还差 1 次本回合移位〕`）；
  - 悬停任何换位牌（如【影之种】【抓投】【错乱】）时，棋盘上不仅画出双格对调箭头，还**按 §2.1 三步确定性规则实时预览换位后的敌方新意图**（例如把敌方前排近战换到后排时，敌方意图角标直接预览显示 `〔近战 → 射程不达·待机〕` 或 `〔近战 → 改用机枪〕`）。
- **即时**：
  - 换位发生时，单位头顶弹出紫色 `〔错位〕` 徽章，战斗记录输出 `〔影界之门〕敌方 B 与 C 交换位置（本回合移位 +2，当前 4 次 → 【连锁投掷】已亮起！敌方 B 近战意图变为〔待机〕）`。
- **结算**：
  - 战后战报统计：`〔影世界〕本场累计移位 M 次 / 触发【错位】强化 X 次 / 【影之种】累计削甲 Y 点 / 强制换位使敌方待机 Z 次`。
