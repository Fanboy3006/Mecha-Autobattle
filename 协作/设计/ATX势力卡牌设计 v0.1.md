# ATX 势力卡牌设计 v0.1（基于《大招牌化规则 v0.1》）

> 数值为初稿，待 ARGON 平衡。「打空」= 任一攻击段未命中，**敌我都算**（已定，沿用战况计数「未命中段」）。
> 大招牌：打出 = 该单位本回合行动；打出后回牌库并进入冷却；冷却归零且条件满足时重新发牌（高亮）。

## 势力机制【赌徒的直觉】（新版，不加资源条）
- 场上每打空一段（敌我都算），牌库中**冷却中的 ATX 角色牌**冷却 −1（每张每回合最多 −1）。
- 玩家看到的反馈：ATX 角色牌的冷却数字跳动 +「打空！」飘字。
- ATX 卡牌普遍是「压命中 / 抬暴击 / 抬闪避」——自己制造打空，加速大招轮转，代价是输出不稳。

## 构筑方向（给人类玩家的搭配空间）
- **打空引擎**：好运加护 / 烟雾弹 / 加注 → 冷却狂转，赌神早上线。
- **闪避反击**：必闪 / 读牌 / 庄家通吃 / 孤注一掷 → 敌人越打不中越亏。
- **暴击爆发**：翻倍 / 全开 / 轮盘双响 → 一回合爆发。

## 已定
- 敌方打空计入「打空」（ATX 对高闪避敌人也受益，接受）。
- 合体技占用两人本回合行动；两人大招各用过一次后进入牌库。
