# 敌人 · 阵营新机制 v0.1（N1～N5，A 稿编号）

> 2026-10-22 Claude 写。顺序照交接卡：N3 → N1 → N4 → N2 → N5。规则先写在这里，再改代码。
> 全部用**单位数据字段**开关（只有新阵营敌机带），旧敌机 / 旧编成行为不变。

## N3【λ 共振】（λ 试作群）—— 已做
- 单位字段 `λ减免`：λ 力场每下减免量（不写 = 3000）。劣化型、镜卫 1200；毒液 3000。
- 单位字段 `λ共振: true`：同侧还活着的「带 λ 力场 + λ共振」单位 ≥2 台 → 每回合减免次数 2 → 3；只剩 1 台回到 2。
- 落点：`Calc.lsLeft(u, turn, ctx)` / `Calc.λ次数上限` / `Calc.λ减免量`。旧 venom / 我方 λ 不带共振字段，照旧 2 次 3000。
- 考题：同回合往一台身上压 3～4 下；先拆便宜的劣化型让全场降一档。

## N1【封锁线】（封锁线阵营）
- 单位字段 `封锁线: true`（`cw_` 六台都带）。
- 成立条件：某一方前排 4 格都有活着的机体（或掩体），且这一方还有活着的带 `封锁线` 的机体。
- 效果：对面的**直射**打不到这一方的**后排**（`Reach.武器可达吗` 返回「封锁线：…」）；近战本来就打不到后排；曲射 / 范围（map）照打；武器无视遮挡（`ignore_block`）照打。
- 前排倒下一台 → 缺口打开 → 立即失效。`Reach.封锁线状态()` 给界面用：「完整」/ 空串。
- 牌打不出时原因写「封锁线：敌方前排 4 格塞满，直射打不到后排」。

## N4【粒子抑制场】（拟炉私军）
- 单位字段 `粒子散布: true`（`tr_spreader`）。对面每台活着的散布机算 1 层，**最多 2 层**；散布机全灭即解除。
- **改写**：A 稿写的是「大招槽充能 −25%」，但现在的大招槽是「亮起条件 + 冷却 + 战意费」，没有充能条。改成压**战意获得**：每层 −25%（四舍五入；只压加，不压扣）。战意就是大招和精神牌的燃料，效果方向一致。
- 精神牌费用 +1（不叠层）：门槛在 `CardPlay._实际费`，实扣在规则钩子「牌打出后」（`EnemyMech`）多扣 1 点并记一行〔粒子抑制场〕。
- 我方天人**不豁免**（作者 10-21 第 3 条）。
- 落点：`BattleMorale.抑制层数` / `BattleMorale.加战意`；新模块 `core/battle/enemy_mech.gd`（只认单位字段，登记在 `RuleHooks.顺序`）。

## N2【悬赏令】（私兵集团）
- 单位字段 `悬赏令: true`（`ok_` 六台）。场上还有活着的这类敌机才生效。
- **敌方阶段开始**：把我方**本回合**（刚结束的我方阶段）输出伤害最高、还活着的机体标为悬赏目标（`ctx.悬赏目标`），写一行〔悬赏令〕。
- 带悬赏令的敌机：悬赏目标够得着（近战按站位判）就**只能选它**（规则钩子「可选目标」，预告与实战同源）；打它伤害 ×1.2（「攻方伤害倍率」）。
- **赏金反咬**：下一次敌方阶段开始结算时，若上一个悬赏目标在这一回合里击破过敌机 → 它战意 +10。（A 稿是「当回合立刻 +10」；放在下次结算时给，省掉一个新钩子，效果差半拍。）
- 落点：`EnemyMech.敌方阶段初 / 可选目标 / 攻方伤害倍率`。

## N5【影锁拽位】（影界远征军）
- 模板字段 `影锁武器`（`sw_chain` = 「影锁」，直射 1600）。用这把武器打中我方**后排**且造成伤害 → 目标和同列前排换位（前排空就拽进去）。
- 走共用换位底座 `BattleSwap.换位`（刷新链 / 意图重算照常）；写一行〔影锁〕。
- 考题：谁放在会被拽的格子；抢在锁链机出手前打掉它。
