> 作者已定（10-17）：
> - 「流星小队」和「卫星国防军」合并为**殖民卫星军**，5 人。
> - 档位：**王牌拉克丝；骨干希罗、迪奥；大众脸卡嘉莉（指挥）、特洛瓦（重装）**。露娜玛丽亚删除。

> - 世界观（默认，作者未否）：卫星国防军是拉克丝复权后接手的正规军，基层来自农业卫星；流星小队是工业派在 L5 首都秘密造的 5 台特工机，霍尔斯特倒台后被拉克丝收编。迪奥沿用近卫。

## 0. 和旧版的区别
- 卫星国防军的「SEED 觉醒成长」（觉醒值累计 +50）作废，改成拉克丝一人的开关状态。
- 流星小队的「单独行动」「全图部署」作废（4×4 没有位移，站位编队时就定了）。
- 卡嘉莉的「号令加觉醒值」、史黛拉、伊萨克、露娜玛丽亚、五飞、卡托尔不进入本势力。
- 本稿早先的【和声】（「场上有人觉醒中」就触发）作废：拉克丝 SEED 不关、迪奥隐身不限时，条件几乎一直成立，玩家没有判断。

## 1. 势力机制【觉醒感应】
一句话：**还没觉醒的人，感应到同伴，把力量推给他。** 觉醒的人是终点，没觉醒的人是燃料；觉醒结束的人又变回燃料。

| 项 | 规则 |
|---|---|
| 觉醒中 | 拉克丝的 SEED、希罗的 ZERO、迪奥的隐身，三种都算「觉醒中」（见 §2）。 |
| 【觉醒感应】 | 带【觉醒感应】的牌打出时，如果**打出者自己没在觉醒中**，就从**感应牌库**随机抽 1 张，放进公有手牌。 |
| 放入 X | 部分【觉醒感应】写着「并把 X 放入感应牌库」。X 是更强的感应牌，本场有效。 |
| 感应牌库 | 全队一份。开场只有一级牌。玩家可以随时查看里面有哪些牌。 |
| 感应牌 | 0 费；任何殖民卫星军成员都能打，不占武器；算殖民卫星军牌，本身不带【觉醒感应】。一级、二级打出后**回库**，三级打出后**移出本场**。 |
| 公有手牌满 6 张 | 不抽，感应牌留在库里。 |

- **判定看打出者，不看全场**：卡嘉莉、特洛瓦永远不觉醒，所以永远能感应；拉克丝开了 SEED 就再也感应不了。
- **循环**：
  1. 开场谁都没觉醒，谁打【觉醒感应】都能抽。感应牌集中给一个人，让他提前觉醒（例如拉克丝的 SEED 从第 3–4 回合提前到第 2 回合）。
  2. 觉醒中的人不能感应，换没觉醒的人继续感应。
  3. 迪奥破隐、希罗被 ZERO 踢出之后，他们回到「没觉醒」，又能感应，把力量推给下一个人。
- **三种觉醒的分工**：拉克丝是**终点**（开了不关，最值得被推）；希罗、迪奥开开关关，是**循环**；卡嘉莉、特洛瓦是**稳定的燃料**。
- **玩家看到的**：没觉醒的成员手里的【觉醒感应】牌亮金边；觉醒中的成员头像外圈发光（SEED 蓝、ZERO 绿、隐身半透明），他手里的【觉醒感应】牌不亮。
- **和秘银、ATX 的区别**：秘银看「上一张牌」，ATX 看「打出者有没有闪字」，殖民卫星军看「**打出者有没有在觉醒**」——和 ATX 一样看打出者，但方向相反：ATX 是状态亮着才触发，这里是状态没亮才触发。

## 2. 觉醒（通用框架；每人的细节在各自的稿里）
| 项 | 规则 |
|---|---|
| 入场牌 | 每人一张「觉醒入场牌」，放在大招槽，**不算武器牌**，不销毁武器，**没有 QTE**。条件满足时亮起。 |
| 觉醒大招 | 亮起条件里写着「本人觉醒中」的大招。觉醒结束后变回灰色。 |
| 结束 | 每人的结束方式不同（下表）。结束后，入场牌进入冷却。 |
| 「觉醒」这个词 | 机体属性里也有「觉醒」（属性 + 觉醒的武器）。牌面统一写「**觉醒中**」，属性一律写「**觉醒值**」，避免混淆。 |

| | 拉克丝 · SEED | 希罗 · ZERO | 迪奥 · 隐身 |
|---|---|---|---|
| 原作 | 种子爆裂，越危险越强 | ZERO 系统让驾驶员看见所有未来，也会把驾驶员逼疯 | 超级干扰器，潜入后现身斩首 |
| 入场条件 | HP ≤ 70%，或第 3 回合起；战意 ≥ 50 | 战意 ≥ 40，HP > 30% | 战意 ≥ 20（第 1 回合就能开） |
| 觉醒中 | 命中、闪避 +15；QTE 失手视为成功；解锁 METEOR、超级 DRAGOON | 命中、闪避 +20，暴击伤害 ×2.5；QTE 完美必暴击；解锁双联破坏步枪、旋转破坏步枪 | 敌方的单体攻击不能选他（范围攻击照打）；解锁「破隐一击」「死神的收割」 |
| 代价 / 结束 | **无尽的 SEED**：开启后本场不再关闭，也不扣维持 | 每个我方阶段开始扣自身最大 HP 10%；HP ≤ 30% 时被系统踢出 | 没有时间上限、不扣维持；打出任何武器牌都会破隐 |
| 结束后 | — | 入场牌冷却 3 | 入场牌冷却 2 |
| 在循环里 | 终点 | 循环 | 循环 |

## 3. QTE 接口（本势力所有大招武器）
QTE 本体以后设计。现在只定**结果怎么用**和**测试期怎么选**。

### 3.1 什么牌有 QTE
- 殖民卫星军成员的**大招武器牌**（算武器的大招），包括卡嘉莉、特洛瓦的大招。
- 不包括：觉醒入场牌（不是武器）、普通武器、精神牌、势力牌、感应牌。

### 3.2 结果三档（标准表）
> 作者 10-17：QTE 以后可能会更复杂，现在先按这张表。

| 结果 | 本次攻击 | 打出者 |
|---|---|---|
| 失手 | 没有加成 | — |
| 成功 | 每段命中 +10，伤害 +10% | — |
| 完美 | 每段命中 +20，伤害 +25% | 到下个我方阶段前闪避 +20 |

- 加成在命中判定之前生效；多段攻击每段都吃。
- 个别大招可以在牌面上改写自己的 QTE 加成；没写的一律按标准表。

### 3.3 测试期（QTE 本体出来之前）
- 设置里加一个「QTE 结果」选项：**手动选择**（默认） / 固定完美 / 固定成功 / 固定失手 / 随机。
- 手动选择：打出大招、选好目标后弹出三个按钮「失手 / 成功 / 完美」，点哪个就按哪个结算。
- AI 自动出牌（没操作的机体、全员托管）按「成功」结算，不弹窗。
- 接口：结算前调用一次「取 QTE 结果（机体, 牌）」，返回三档之一。以后 QTE 本体做好，只替换这个函数。

## 5. 带【觉醒感应】的牌（目标约占殖民卫星军牌的 1/3）
- **规律**：只有「没觉醒时会打的牌」才带【觉醒感应】。觉醒大招、只能在觉醒中打的精神牌一律**不带**（打出时打出者一定在觉醒中，永远触发不了）。
- 势力牌 4 张（§6 ★）。
- 成员：拉克丝 5 张、希罗 4 张、迪奥 4 张、卡嘉莉 1 张、特洛瓦 1 张（各人稿 ★）。

## 8. 构筑方向
- **推王牌**：开场卡嘉莉、特洛瓦、希罗、迪奥一起感应，把「觉醒连锁」「强制觉醒」喂给拉克丝，第 2 回合就 SEED。之后拉克丝一直打觉醒大招。
- **轮转**：迪奥第 1 回合隐身 → 破隐一击后现身，打「再次潜伏」感应、放入「极限超频」→ 希罗 ZERO 中用极限超频打旋转破坏步枪 → 希罗被踢出后接着感应。
- **燃料队**：卡嘉莉、特洛瓦专打势力牌里的★和「正规军掩护」，自己不出彩，但整场都在感应。

## 9. 落地依赖（给 ARGON）
- 「觉醒中」：每台机体一个布尔状态，外加觉醒类型（SEED / ZERO / 隐身）。【觉醒感应】只查**打出者**是否觉醒中，在打出那一刻判定。
- 感应牌库：照秘银连携牌库的框架做。全队一份，随机抽；「放入」本场有效；一级、二级回库，三级移出。
- 「强制觉醒」要能让入场牌无视全部亮起条件（含冷却）。
- QTE 接口：见 §3.3。
- 隐身：敌方选单体目标时排除隐身中的机体；范围攻击不受影响。我方打出武器牌后清除隐身；结束回合 AI 自动出牌跳过隐身中的迪奥。
- 「正规军掩护」需要把一部分伤害转给另一台机体。
- 「不杀」需要「本来会击破 → 改为保留 1 HP」的判定。
- 临时武器牌（拉克丝 METEOR 锁定链），见拉克丝稿 §13。

## 10. 撞名检查
- 【觉醒感应】、感应牌库、QTE、破隐一击：项目里没有同名概念。
- 「感应」和雷欧娜的被动「T-Link 感应」同字，一个是关键词、一个是个人被动，不同势力，不冲突。
- 「觉醒」和属性「觉醒值」同字，牌面用「觉醒中」区分（§2）。
- 「隐身」和敌方能力【隐形】、杨的「ECS 隐形」字面相近，规则不同。
- 「共感」（一级感应牌）取代早先的「流星 / 坠星 / 舰炮支援」：作者 10-17 定，感应牌库不放「单纯追加一次打击」的牌（那是秘银的风格）；「坠星」也会撞月球王国的陨石设定。
- 「共鸣」已经被月球王国用过（月光共鸣），没有用。
