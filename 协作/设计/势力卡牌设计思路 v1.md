# 势力卡牌设计思路 v1（从 ATX、秘银两次设计中总结）

> 2026-10-16，游戏内容对话。用途：之后设计每个势力都先读这一份，再按模板出稿。
> 已落地的两个样板：
> - `ATX势力卡牌设计 v0.2`：机制【赌徒的直觉】
> - `秘银势力卡牌设计 v0.2`：机制【Uruz 连携作战】

## 1. 势力机制：一个关键词，挂在已有载体上
- 每个势力只要**一个核心机制**，用一个关键词表达，让玩家一眼读懂。
- **不加新资源条**。机制挂在玩家已经看得见的东西上：气势、冷却数字、手牌、出牌顺序、状态图标、站位。
  - ATX：「打空」推动冷却数字跳动。
  - 秘银：「本回合已打出的秘银牌数」，显示在手牌区，可触发的牌亮金边。
- 机制要给玩家**一个每回合都要做的判断**：
  - ATX：要不要主动压低命中、制造打空。
  - 秘银：这回合的出牌顺序怎么排。
- **少用持续状态的子规则**。秘银 v0.1 的「标定」有上限、持续回合、刷新、熄灭四条子规则，作者认为不对，改成了「出牌顺序」这种零状态的机制。

## 2. 借用熟悉的游戏概念，但名字要用作品自己的
- 可以借成熟卡牌游戏的机制，作者熟悉，沟通成本低。例：秘银的连携 = 炉石盗贼的「连击」。
- 但借来的名字只是概念，**正式名称要取自原作**。例：「连击」→「Uruz 连携作战」，关键词【连携】。
- **新名词先查有没有和已有系统撞名**。例：「标定」同时被毛的破防和旧通用卡的「标定经济」使用，玩家分不清。
- **找作者确认原作参考**。比如秘银参考《全金属狂潮》：乌鲁兹小队的番号、潜航中的 TDD-1 达纳号发射巡航导弹支援、λ 驱动器靠意志驱动。

## 3. 机制关键词只放在约 1/4–1/3 的牌上
- 一个势力共 25 张左右：15 张角色牌、1 张合体技、9 张势力牌。其中只有 **6–8 张**写着机制关键词。
- 带关键词的牌通常是**收尾牌或爆发牌**；其余的牌**各自独立有用**，同时负责给机制「垫」条件。
- 不能有单独打出就完全没用的死牌。哪怕是垫牌，也要带一个小效果，比如抽 1 张、命中 +10。
- **机制只由本势力的牌触发**。其他势力的牌不计数，但也不打断（秘银的规则）。这样混编队可以带，纯色队更强。

## 4. 成员要有分工，不是每个人都吃机制
- 允许一个「王牌」成员**不吃机制**，靠强力单卡立足。例：秘银的宗介，三张牌都没有连携，λ 大招自然适合第一张打，顺手给队友垫连携。
- 其他成员按定位分工：
  - **发动机**：便宜、垫条件（杨）。
  - **呼叫者**：生成衍生牌、召唤支援（毛呼叫达纳号）。
  - **收尾手**：机制满了才爆发（克鲁兹、克鲁佐）。
- 王牌成员的强大最好带获取门槛。例：λ 驱动·极限放出要求 HP ≤ 50% 或受击 ≥ 4，对应原作「被逼到绝境才觉醒」。

## 5. 每张牌的固定字段
| 字段 | 要求 |
|---|---|
| 类型 | 大招（= 该单位本回合行动，每台每回合最多 1 张）/ 战术 / 战术（攻击，占行动） |
| 费用 | 0–40 气势。垫牌 0–5；中坚 10–15；大招 15–35；合体技 35–40 |
| 冷却 | 1–6。垫牌 1–2；大招 3–5；合体技 5–6 |
| 获取条件 | 只用声明式触发表能表达的类型：开局在手 / 第 N 回合起 / 战况计数 ≥ N（打空、受击、闪避、暴击、击破、本势力机制计数）/ HP ≤ X% / 气势 ≥ N / 打出过大招牌 |
| 效果 | 目标**不指定**，用「HP 最高者」「对位」「相邻位」「一排」「全体」这类规则描述 |
| 代价 / 取舍 | **每张都要有**（ARGON 特别认可）。写清楚为什么不能无脑打 |

- 少写「1 回合数值 buff」。旧卡一半以上是这种，作者不喜欢。优先选改变出牌顺序、冷却、手牌、站位的效果。
- 阵型是正交 4×2：「相邻位」= 十字邻格；「对位」= 同列前后。

## 6. 合体技
- 2–3 名成员，**占用所有参与者本回合的行动**。只要有一人本回合已经行动过，就不能打出。
- 进牌库条件绑在本势力机制的计数上。例：ATX 是两人的大招各打过 1 次；秘银是本场触发连携 ≥ 6 次。
- 任一参与者被击破，这张牌就从牌库和手牌中移除。
- 打出后回牌库，冷却 5–6。

## 7. 衍生牌（秘银首次引入）
- 由其他牌「置入手牌」。打出后移除，不回牌库；手牌满 10 张时置入失败，直接作废。
- 适合表现「召唤支援」，例如 TDD-1 巡航导弹。衍生牌也算本势力的牌，可以推进机制。
- 注意防止无限循环：衍生牌加抽牌加双倍触发叠在一起时，要标给 ARGON 检查。

## 8. 设计稿模板
1. **§0 变更**：和上一版的区别，作废了什么。
2. **§1 势力机制**：关键词定义、载体、计入范围、衍生牌。
3. **§2 角色牌**：每人 3 张（含 1–2 张大招），带机制关键词的牌标 ★。
4. **§3 合体技**。
5. **§4 势力牌 9 张**：最后统计带关键词的牌数（目标约 1/3）。
6. **§5 构筑方向**：2–3 条流派。
7. **§6 落地依赖**：给 ARGON 的新状态、新关键词、触发表新增事件类型、作废项。

## 9. 和作者的协作方式
- 作者给方向通常只有一两句。第一稿要快，**预期会被改方向**；同一天内的修改直接覆盖同一版本号。
- 回复要短：
  - 先用 3–5 条要点讲机制。
  - 再列出需要作者定的事，压成 1–3 个问题，每个问题给出默认值。
  - 最后附一段**可直接复制给 ARGON 的指令**。
- 作者原话「不要太在意胜率，相信人类构筑」：数值只给初稿，平衡等试玩以后再谈。给 ARGON 的指令只请他检查无限循环和卡死。
- 设计稿双写：项目 `claude/` 一份，本地 `F:\DSH-mecha\mecha-autobattle\协作\设计\` 一份。本地那份未进 git，由作者或 CC 提交。
  - 写本地的方法：先把文件放进对话的输出目录，再用「写回电脑」的工具提交到已授权的文件夹。
