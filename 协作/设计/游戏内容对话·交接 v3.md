## 2. 新规则要点
1. **逐台指挥**：
   - 每台机体有自己的牌和自己的战意（原来的气力改名战意）。
   - 玩家自由选择先操作哪台。
   - 打牌时由玩家指定目标。
   - 没操作的机体，结束回合时由 AI 替它出一张武器。
2. **每台机体的牌分三类**：
   - **武器栏**：普通武器每回合全部恢复，打一张主武器就消掉其余主武器。副武器（例如援护射击、烟雾弹）不会被消掉。
   - **大招槽**：大招开场就在槽里，条件满足时亮起，打完留在槽里进入冷却，不进抽牌堆。不算武器的特殊牌也可以放在这里，例如 λ 驱动·启动、觉醒入场牌。
   - **精神牌**：随机抽，起手 2 张、每回合抽 1 张、上限 4 张，满了就不抽。打出后进弃牌堆，抽空了再洗回。带条件的牌第一次满足条件时放到牌堆顶。
3. **公有排**：
   - 放势力牌、分类牌、势力牌库抽出来的牌，全队一份。起手 3 张、每回合抽 1 张、上限 6 张。
   - 只有对应势力或职业的成员能打，谁打出就扣谁的战意。
4. **战场 4×4（上下对峙 4 列对齐）**，每方 4 列 × 2 排，合并成中间偏上的一个 4×4 棋盘（从上到下：`敌后排 → 敌前排 → 战线 → 我前排 → 我后排`），战斗中一般没有位移：
   - 每把武器写「类型 + 距离 a–b」。棋盘上横竖正交格数差 = 真实距离 `abs(Δcol) + (row_a + row_b + 1)`，范围 1–6。
   - 近战：必须站前排（含顶位），只能打敌方前排（含顶位）。
   - 直射：打后排时，如果目标正前方同列有人，命中 −20。
   - 曲射：不受遮挡。
   - 范围附加：单体 / 溅射 / 贯穿 / 横扫 / 全体；殖民卫星军新增了「宽贯穿」。
   - 某一方前排全空时，这一方后排「顶位」，**只对近战生效**（直射/曲射/远距照真实排位算）。
   - **援护防御（掩护/护卫）连线与次数**：废除旧版随机挡枪；所有保护效果（如塔斯克被动【掩护】同列后排 `2/2` 次、重装【横向掩护】同排相邻、宗介【掩护】分摊 30%）必须明确「**谁保护谁 + 剩余几次**」，在 4×4 格子上画护盾连线并实时显示剩余次数，与敌方意图预告 100% 同源。
   - **手牌纯可打 + 左侧未激活/冷却牌库**：中下手牌区分为【主武器牌】【副武器牌】【精神牌】【公有牌】四类，**在手牌里的牌必须 100% 当前可打**；距离不符/已收起的武器、未满足条件的大招/待入库牌、以及有冷却（CD）的牌一律留在**左侧牌库面板**（冷却牌显示为 **`X 回合后进入手牌`**，到期自动进入手牌区）。
   - 压制射击已删除。
5. **多段武器与装甲共享池**（ATX v0.3 定）：
   - 多段武器每段单独判定命中和暴击；
   - **装甲共享池**：每次攻击按每个被打目标初始化一次装甲池 `pool = round(有效装甲 × 防御倍率)`，仅命中段消耗装甲池，打穿后后续命中段直伤 HP（每段保底 10；`无视防御` 与 `特殊` 伤害整池跳过）。设计多段武器与段数改写牌时按此公式衡量。
6. **卡池分层**：每张牌标明获取方式。
   - 初始。
   - 剧情解锁：强力的大招、精神、武器放在这层。剧情模式以后会有整理牌库的功能。
   - 肉鸽：晋升 Lv20 / Lv30、战后三选一、升级成「+」版。

## 4. 作者认可的设计原则
1. **档位分三层**：
   - **王牌**：一个还原原作的独有机制，通常是开关状态。卡池 3–5 把武器 + 3 张大招 + 9–10 张精神牌，再加肉鸽升级。
   - **骨干**：一个轻量的独有关键词，打出时判定、不留状态。
   - **大众脸**：3 把武器 + 1 张大招 + 3 张通用精神牌，全部是初始牌，不做特色。
2. **势力机制要简单**：
   - 一个关键词，触发条件一眼能看懂。
   - 触发效果统一是「从势力专属牌库里抽 1 张特殊牌」。
   - 想要更强的效果，就「把更强的牌放进势力牌库」，不要做计数和 ·N 档位。
   - 带关键词的牌大约占 1/3。
3. **作者明确否决过**：复杂计数、长期持续的标记（秘银原来的「标定」）、【连携·N】、位移、换位、移动、朝向、压制射击。
4. 每张牌都要有「**代价 / 取舍**」列。
5. 新造的名词要先查有没有撞名。已占用的有：连携、筹码、赌局、闪字、闪开、九死一生、烟雾、雾袭、远距、强运、指令、λ、赌神、觉醒中、觉醒感应、感应、顶位、宽贯穿、斩首。
6. 不要太在意胜率，作者的原则是「相信人类构筑」。数值只给初稿。
