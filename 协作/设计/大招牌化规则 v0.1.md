# 大招牌化规则 v0.1（思想实验定稿，待 ARGON 落规则）

> 来源：CC × 用户 设计讨论（2026-10-16）。超出封存 JS 参考规则（js-reference-final / r1:05a9cbf9），落地时按 D-01 方式记为「已接受差异」，黄金样例走 `选项.手牌装填 = "JS参考"` 一类开关对账。

## 1. 核心
- **大招 = 角色牌**。每台机体的大招武器与其专属角色牌合并为同一概念；大招武器不再自动开火，只作为该牌的效果执行体（伤害/段数等数值沿用武器）。
- 敌方不变：敌方大招照旧自动施放。

## 2. 进牌库
- 开战时每台机体把自己持有的角色牌带入本场牌库；每台默认 1 张基础大招牌。
- **角色牌开局就有**，取消 Lv20 解锁门槛；等级只提升该牌效果（数值随等级成长）。
- 更多角色牌在肉鸽中通过商店购买 / 事件 / 藏品获得（需在肉鸽经济里留出购买角色牌的机会）。

## 3. 牌库 → 手牌（获取条件）
- 每张角色牌带一个获取条件，满足即发入手牌，**高亮显示**。
- 条件类型：开局在手 / 第 N 回合 / 战况计数达到某值（命中、打空、受击、击破…）/ 气势达到某值。
- 复用现有「待触发牌 + 检查条件发牌 + 战况计数」框架，多数条件只需填数据。

## 4. 打出与回收
- **打出后回到牌库并进入冷却**：冷却期间即使条件满足也不发牌；冷却归零后，条件再次满足才重新发入手牌。
- 冷却数值逐张设定（可复用卡牌已有的 `当前冷却` 字段）。
- **打大招牌 = 该单位本回合的行动**（替代其本回合普通行动）。
- 同一单位每回合最多一张大招牌（推论，待确认）。

## 5. 手牌与费用
- 手牌上限 6 → **10**；初始起手仍按 D-01 补到 6（保留）。
- 费用逐张平衡：可为 0、低费、高费，个别大招可回气势。回气势类强度略低于同级，并防止与低费牌形成无限循环。

## 6. 操作
- 目标**不指定**，沿用现有 AI 选目标逻辑。
- 删除「憋大招」开关（不打牌即是憋）。

## 7. 连带改动
- 现有角色牌（U_*）并入对应机体的大招，例如 U_A1【王牌决断·魂】并入 A1 大招。
- 修改大招冷却的牌（如 F_ATX_2【赌徒孤注】）需重写为「立刻发出大招牌 / 大招牌降费 / 缩短大招牌冷却」等。
- 势力机制**不强制**绑定大招牌，各势力单独设计。

## 8. 待办
- 逐台填写角色牌表：获取条件 / 费用 / 冷却 / 是否回气势 / 等级成长。
- 气势经济复核：开场 25、每回合 +10，在手牌 10 张、大招入牌后是否够用。
- 肉鸽：角色牌的商店价格、出现率、每台持有上限。
