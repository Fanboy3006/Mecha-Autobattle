# 《雪居之地》· 全游戏 调研报告

## 1. 核心循环（5 句话以内）
1. **双排小队与领袖保卫战**：双方在上下两条横排战线（每方每排最多 3 格，共 6 格）上对峙，玩家通过开战部署将唯一的「领袖（阵亡即整局直接判负）」与「伙伴」摆上战线。
2. **「打一张牌 = 全场走一拍」的倒计时驱动**：没有传统费用/能量池；场上所有敌我单位各自拥有独立的「行动倒计时」，玩家每打出一张手牌，全场所有单位倒计时同步 `-1`，归零的单位按固定索敌规则自动出手。
3. **战线走位与免费召回承伤**：由于默认攻击只打「同排最前方的第一个目标」，玩家需在战中频繁拖动单位换排、用前排伙伴/杂物替领袖挡刀，或在伙伴濒死前将其「召回」牌库回血避险。
4. **重整钟（Redraw Bell）掌管手牌流转**：手牌不会在回合末自动弃置，而是依靠一个 4 拍倒计时的「重整钟」——等钟走完 4 拍可免费弃掉全手牌重抽 6 张，若提前强行敲钟换牌则必须白交 1 拍（让全场敌人倒计时 `-1`）。
5. **城外挂件镶嵌与皇冠抢节奏**：战斗外没有复杂的属性加点，全靠在地图节点中收集「挂件（Charms，每张牌限挂 3 个）」直接给伙伴或物品牌焊上狂热/横扫/雪球等词条，以及用「皇冠（Crowns）」让核心牌在开战第 0 拍免费提前入场。

## 2. 资源与经济（每种资源：怎么获得、怎么消耗、上限、玩家在什么上纠结）
- **行动拍数 / 单位倒计时（Turn Counter，替代能量池的核心时间货币）**
  - **获得**：天然存在；可通过「太阳类」物品牌直接使我方单位倒计时 `-1` 或立即触发行动，或通过「雪球（Snow）」冻结敌方单位倒计时使其当拍不走表。
  - **消耗**：玩家每从手牌打出 1 张牌（或提前敲重整钟），全场所有未被雪球冻结的单位倒计时 `-1`。
  - **上限**：无上限（常规单位最大倒计时在 2～6 之间）。
  - **玩家纠结**：**「打这张废牌值不值得让全场敌人倒计时走 1 格」**——没有 0 费白嫖牌（除非挂了皇冠在开战阶段打），哪怕手里有一张小增益牌，只要打出去就会把对面倒计时为 `1` 的 Boss 直接推到出手线。
- **重整钟（Redraw Bell）与手牌（Hand）**
  - **获得**：敲响重整钟时弃掉当前手牌、抽满 6 张新牌；每打出一张牌重整钟冷却 `-1`（初始冷却 4 拍）。
  - **消耗**：冷却归 0 时敲钟**不消耗拍数（全场倒计时不动）**；冷却未归 0 时强行敲钟**消耗 1 拍**。
  - **上限**：默认重抽 6 张，手牌无硬性爆牌惩罚。
  - **玩家纠结**：**为了等免费敲钟而硬打 2 张低效手牌推进敌人倒计时，还是直接亏 1 拍空过敲钟找救命雪球牌**。
- **战线格位（2 排 × 3 列）与单位血量 / 废料（Scrap）**
  - **获得**：打出伙伴牌或「杂物牌（Clunkers）」占格。
  - **消耗**：伙伴承受伤害扣 HP（召回可回 5 HP）；杂物无 HP，改为拥有 `1～N` 点「废料（Scrap，即受击次数生命）」，无论挨 1 点还是 99 点伤害都只扣 1 点废料。
  - **上限**：每方每排最多 3 个单位（共 6 格）。
  - **玩家纠结**：**拿杂物和肉盾占满前排挡枪，还是腾出位置给输出伙伴对齐敌方脆皮排**。
- **挂件槽（Charm Slots）、皇冠（Crowns）与闪亮币（Bling）**
  - **获得**：战斗中击杀敌人（尤其连杀 Combo 与提前摇增援铃）掉落闪亮币；地图事件与商店获得挂件和皇冠。
  - **消耗**：每张卡牌最多永久镶嵌 3 个挂件（不可拆下）；皇冠可随时在卡牌间自由拆装。
  - **上限**：每张卡 3 挂件、1 皇冠。
  - **玩家纠结**：**把所有强力挂件全堆在 1 个大哥身上造神（怕被墨水沉默或单点秒杀），还是均摊给多张功能牌**。

## 3. 关键机制清单
1. **雪球（Snow）冻结倒计时**
   - **规则一句话**：拥有 N 层雪球的单位，其行动倒计时与反击能力被完全锁死，每经过 1 拍不减倒计时而是改为扣减 1 层雪球。
   - **制造的决策**：把「硬控」变成了可精确计算的回合加减法——面对倒计时 `1` 的毁灭性 Boss，打一张叠 2 层雪球的牌就能买出 2 拍安全输出窗口。
   - **常见反例或缺陷**：若雪球牌获取过多且无抗性限制，能够把单核 Boss 从头冻到尾使其一动不动；后期高难不得不给 Boss 加「雪球抗性（每次最多吃 1 层雪）」来强行打补丁。
2. **杂物（Clunkers）的「按次承伤（Scrap）」**
   - **规则一句话**：杂物单位没有生命值，只有「废料（Scrap）」层数；每次受到任何大于 0 的伤害（哪怕是 100 点必杀重击），都只扣除 1 点废料。
   - **制造的决策**：专门克制「低频单发超高伤害」的巨型敌人，同时极度畏惧「高频多段刮痧（Frenzy）」或「轰击（横扫整排）」，让前排挡刀手段有了极其鲜明的针对性。
   - **常见反例或缺陷**：一旦杂物被叠上高额废料且敌方缺乏多段攻击，前排会变成打不穿的铁桶。
3. **过载（Overburn）的「斩杀线引爆 AOE」**
   - **规则一句话**：过载层数平时不造成任何持续伤害，但一旦某单位身上的**「过载层数 ≥ 其当前剩余 HP」**，该单位立刻爆炸阵亡，并对**同排所有其他敌人**造成等同于该过载层数的群体伤害。
   - **制造的决策**：彻底改变了 DOT（持续伤害）墨迹的痛点！玩家必须一边压低目标实血、一边往它身上叠过载，算准「实血与过载层数交汇」的那一刀触发连环殉爆清场。
   - **常见反例或缺陷**：对单人站场的孤立 Boss 而言，爆炸的同排 AOE 收益完全归零，只剩一段斩杀。
4. **轰击（Barrage）与无瞄准（Aimless）的排位索敌**
   - **规则一句话**：常规攻击只打同行最前排第一个敌人；「轰击」同时打击目标所在整横排所有单位；「无瞄准」在目标所在横排中随机挑一个单位打。
   - **制造的决策**：让「敌我双方把单位摆在哪一排、谁顶在最前面」成为每一拍都在算的几何题——面对敌方轰击怪必须分散两排站位，面对敌方高威胁后排必须用「长手（专打最后排）」或「钩子（拉到最前排）」破阵。
   - **常见反例或缺陷**：我方带「无瞄准」词条的武器在敌人满排时极度看脸，容易漏掉残血关键怪。
5. **皇冠（Crown）的「开战第 0 拍预装」**
   - **规则一句话**：镶嵌了皇冠的卡牌固定在起手出现，且可在战斗正式开始前的「部署阶段」免费打出，不消耗第一拍时间。
   - **制造的决策**：解决卡牌肉鸽最痛的「慢热启动」问题——把关键引擎牌、核心伙伴或先手控制牌挂上皇冠，保证每场战斗第 0 秒就能摆好阵型。
   - **常见反例或缺陷**：皇冠数量过多时会直接演变成第 0 回合秒杀全场的 FTK（首回合杀）。

## 4. 身份是怎么做出来的（三大部落 / 派系差异）
《雪居之地》通过三个部落（Tribes）共享同一套倒计时与双排棋盘底座，靠**专属状态轴与召唤物机制**拉开身份：
1. **雪居者部落（Snowdwellers）**：主打**「雪球控场 + 辣椒（Spice，单次攻击爆发累加） + 废料杂物」**，靠冻结敌人倒计时买时间，攒出一刀超高额辣椒直伤。
2. **暗影部落（Shademancers）**：主打**「召唤填充物 + 献祭友军（Sacrifice） + 过载（Overburn）引爆」**，把场上格子当作消耗品工厂，靠主动杀死自家召唤物触发遗言与多层连击。
3. **机械侏儒部落（Clunkmasters）**：主打**「高频废料杂物 + 墨水（Ink，沉默敌我特效） + 垃圾牌回收与轰炸（Bom）」**，往自己手里塞 0 攻垃圾牌再用卡牌把垃圾转化成全屏弹幕。

## 6. 明确不适合本作的（各一句理由）
1. **「玩家每打一张牌，全场敌人就往前走一格倒计时并立即反扑」的拍数绑定**：本作是 SRW 式阶段制（我方整阶段自由操作完 4～6 台机体并打出多张 0 费副牌库牌/精神牌后，才轮到敌方阶段统一行动），若打一张精神牌敌人就动一下，会彻底瓦解我方多机连携（如秘银连携、天人同时开 TRANS-AM）的阶段节奏。
2. **「唯一领袖阵亡即整局游戏立刻 Game Over」的单点暴毙规则**：本作强调前排重装/近卫敢于卖血抗线、战后全队自动回 50% HP（含倒下机体复苏），绑死单核暴毙会让玩家不敢把王牌放前排。
3. **战中随时把场上受伤机体「召回」牌库腾格子**：本作已确立「4×4 棋盘战中无常规位移与上下场，站位由战前编队决定」的铁律。

## 7. 不确定的地方（记不清或资料有出入的）
- **「召回伙伴（Recall）」是否消耗回合拍数**：在《雪居之地》初代首发版本（v1.0）中，将场上的伙伴召回弃牌堆需要消耗 1 拍（推进全场倒计时）；但在后续官方大型平衡补丁（v1.0.5 及之后版本）中，官方将其修改为**不消耗拍数的免费行动（Free Action）**以降低生存压力。本报告按最新官方正式版口径描述，特此注明版本演变差异。
