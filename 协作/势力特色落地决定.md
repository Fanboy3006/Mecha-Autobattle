# 势力特色 · 作者拍板的落地决定（2026-10-10）

> 作者原话与逐条落地说明。**这份文件是「势力特色」这件事的权威清单**；
> 详细的事实摘录（战棋原文 + 逐条可行性 + 缺口）在 `协作/势力特色.md`。
> 顺序：**先把 9 格阵型（前 4 后 5 / 按位阻挡 / 出击 3→6 / 敌方增援）落地**，再铺这里的特色。
> 作者明确说过：**难度现在不用管**——特色铺下去难度会大幅下降，之后一起调。

## 0. 总原则
- **势力特色优先**；难度（精英/头目/Boss 的胜率）**排在特色之后**再一起调。
- 特色数值：战棋 `17b-角色机制.js` 有完整数值的**逐字照抄**；作者口头改了的地方按作者说的改；
  查不到的写「初稿」并注明；**缺设计的地方不自己编**（列出来问）。
- 影世界这一版**不做**严格意义的势力特色（作者第 7 条）。

## 1. 卫星国防军 —— 照战棋原样（作者：「国防军特色没问题」）
- **SEED 觉醒**：越打越强——每回合 +5、击破 +3，累计到阈值（战棋 50）换闪避 / 防御加成。
- 出处与逐字数值见 `协作/势力特色.md` 第二节；实现时照抄（含阈值与每档加成）。
- 注意：战棋的阈值是按长战斗设计的，我们 Lv20 起常常 1–2 回合结束 → **先照抄，等难度一起调**。

## 2. 流星小队 —— 作者重新定义（**不是**战棋的「身边没友军」原版）
- 作者原话：「**相邻和前方格子没有队友的时候战斗力提升**」。
- 落地：以 9 格阵型的新几何判断——
  - 「**相邻**」= 同排左右邻居 + 有阻挡关系的对位（等同 `相邻位(位)`）；
  - 「**前方**」= 这个位的**阻挡位** / 它前面的格子（等同 `阻挡位(位)`，前排位则看它左边？→ 实现时按「它自己前面的那一排」理解并写进文档）。
  - 两者都**没有队友** → 战斗力提升（战棋原版的数值是「伤害 +20%、闪避 +15%」，先照抄这两项，标初稿）。
- **依赖新阵型的几何函数**（`相邻位` / `阻挡位`），所以**必须等 9 格落地之后**做。

## 3. 月球王国 —— 围绕 Feena 构筑（作者给了两条明确改动）
- **Feena 周围的队友大规模 buff**：以 Feena 为中心，**相邻 / 周围**的队友吃到大 buff（数值照战棋"月之国"那套，查不到就初稿 + 标注）。
- **大招「残月的余响」改机制**（作者原话）：「**大招残月的余响改成队友攻击时追加一次攻击**」，
  设定解释：「她可以操作质量加速器，相当于丢一个陨石下来」。
  → 新行为：**队友攻击时，追加一次攻击**（陨石）。**触发上限没定** → 实现成一个常量（初稿：每回合最多 1 次），
  在任务板里标「初稿、待作者调」。
- 另外战棋月之国还有「只能带一个技能」这类限制，**按我们第一期的情况简化**并在文档里写明。
- 已实现的部分：Feena 的「月光祝福」/「再动」保留；「残月的余响」按上面**改掉**（原来是一整排范围伤害）。

## 4. 天人 —— TRANS-AM 按作者的新数值
- 战棋原版：持续 3 回合、威力 ×1.3 / 闪避 +15、冷却 10。
- **作者拍板：持续 2 回合、CD 3 回合**（其余倍数先照战棋 ×1.3 / 闪避 +15，标初稿）。
- 落地要点：12 回合上限下 CD 3 是能开出多次的；记录里要能看出「开 / 关 / 冷却中」。

## 5. ATX —— 「打空」按段，太强就加初始 CD
- 作者原话：「**可以试试看按段，如果太过分继续加初始CD就行**」。
- 落地：把「打空」按**段**计（`w.hits` 多段武器逐段判定，每段未命中都算一次「打空」），
  每次打空 → **减少大招冷却 / 触发 ATX 的「赌神」收益**（照战棋 `17b-角色机制.js` 的对应规则）。
- **预留一个「初始 CD / 触发上限」常量**，做成初稿值，方便作者一句话调。

## 6. 秘银 —— 作者要我先去研究原作，提一个有意思的联动机制
- 作者原话：「**去研究一下全金属狂潮原作你看看能不能想出一个有意思的联动机制**」。
- 战棋里秘银是毛的「指挥网络」5×5 三人联动 + 克鲁兹无视障碍 + 免费支援射击（**踩了 5×5 区域 / 障碍物 / 援护三样我们丢掉的东西**）。
- 做法：先做原作与机制的调研（另起文档 `协作/秘银联动机制-提案.md`），**给出 2–3 个方案让作者挑**，
  每个方案写清：在我们 9 格阵型里怎么触发、强度量级、实现量、跟现有一期机制的复用点。**不自己拍板。**
