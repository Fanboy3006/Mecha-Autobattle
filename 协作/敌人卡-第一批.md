## 卡 A · 幻影（钩子 `stealth`，逼「编队」杠杆）

| 项 | 内容 |
|---|---|
| **一句话** | 大部分时间**处于隐匿**，常规直射 / 近战很难打中它；它是**逼你为它换人**的那类敌人。 |
| **玩家看到什么** | 它的卡片常挂「**隐匿**」标；指令阶段的意图里写「打它命中 −N」；范围武器与近战不吃这个惩罚。 |
| **逼你用哪个杠杆 / 怎么破** | **编队选谁**（带近战 / 范围 / 能破隐匿的类别）+ **集中攻击的取舍**（集火它是投资还是浪费）。破法：换人、或改用范围武器。 |
| **预告** | `敌机【幻影】处于隐匿：只有近战 / 范围武器能稳定命中（你队里 X 台打不到它）` |
| **即时** | 打空时记录 `（隐匿：命中 −N）` |
| **结算** | 本场战报 `隐匿共让你打空 N 次（其中 X 次来自直射）` |
| **钩子落点** | `src\js\20-战斗计算.js` 的 `hitRate()`（命中管线已有两条负命中生产者）或开局给自身挂一个负命中 buff —— **【初稿】惩罚量级：命中原始值 −35**（照现有「特种降命中 −20」与「被挡 −20」的量级放大一档；待调参室定） |
| **测试** | 挂上后：同一发命中率**前后数字**对比；近战 / 范围**不受影响**；不带该标记的敌人**逐字不变**；同种子两次逐字相同 |

## 卡 B · 镜甲（钩子 `beamReflect`，逼「方针」杠杆）

| 项 | 内容 |
|---|---|
| **一句话** | **把一部分受到的伤害反弹回来**：谁打它谁疼，**「集中攻击」它等于自杀**。 |
| **玩家看到什么** | 卡片写「**镜甲**」；打它的伤害数字旁出现「**镜甲反弹 N**」。 |
| **逼你用哪个杠杆 / 怎么破** | **全军方针** —— 逼你从「集中攻击」改回「全军突击」（分散打）或**先清掉别的**；也逼你算**大招该不该保留**（大招打它反弹更痛）。破法：换目标顺序、或用多段低威力磨。 |
| **预告** | `敌机【镜甲】：打它会被反弹 N% 伤害`（指令阶段就写清） |
| **即时** | `镜甲反弹 N`（跟在那一下伤害后面） |
| **结算** | `镜甲共反弹 X 到你身上（占你本场损失 Y%）` |
| **钩子落点** | `src\js\60-战斗.js` 的 `resolveAction()`（约 `:434` 之后）用**可重入的** `resolveAttack()` 打回去（照 `61-Boss.js:132-143` 的形状）；**只用来结算，不许改随机数顺序**（否则同种子复现会坏） —— **【初稿】反弹比例：受到的 30%**（待调参室定） |
| **测试** | 反伤真的扣血（前后数字）；**反伤不吃二次反弹**（不会互相循环）；不改变命中 / 暴击的随机数消耗顺序；不带该标记的敌人逐字不变 |

## 卡 C · 献祭者（钩子 `selfDestruct`，逼「站位 + 全军防御」杠杆）

| 项 | 内容 |
|---|---|
| **一句话** | **被击破的瞬间自爆**，打一整排 / 一整列；**血量越低越危险**。 |
| **玩家看到什么** | 进入「濒死」区间时卡片变红、意图写「**濒死自爆**」并**预告落点**（打哪几个位）。 |
| **逼你用哪个杠杆 / 怎么破** | **站位**（别让脆皮站在它那条排 / 列上）+ **全军防御**（扛那一下）+ **击杀顺序**（等队友离开落点再杀它）。 |
| **预告** | `敌机【献祭者】濒死自爆：落点 前2、后2、后3（这一下会打这几个位）` |
| **即时** | `献祭者自爆：落点 …（防御减免 Y）` |
| **结算** | `自爆打掉你 X，防御帮你省了 Y` |
| **钩子落点** | `src\js\60-战斗.js` 的击破点（约 `:435-445`）照 `61-Boss.js:132-143` 打一发 `fire:'map'` 的范围；**落点用现成 `area`（A 档，`row`/`col` 都行）** —— **【初稿】自爆威力 = 它主武器威力 × 1.5、触发线 = HP 降到 35% 以下时**（待调参室定） |
| **测试** | 击破时真的打那几个位（逐位对）；**全军防御下的减免真的生效**；自爆**不会再触发一次**（本体已死）；不带该标记的敌人逐字不变 |
