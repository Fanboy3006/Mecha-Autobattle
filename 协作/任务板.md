### 一、根因（**三类，各自独立**，别再当成一个 bug 打补丁）

1. **跨屏叠加（层级）**：`boot.route()` 换屏时只把新视图 `visible = true`，**旧视图还亮着** → 两屏同时画。
   更重的是门面 `_自动弹窗` 会在 `screen == "battle"` 时塞一整块**全屏黑幕**「战斗」弹窗（把战斗屏盖死、
   「推进下一回合」点不到）、在 `screen == "result"` 时塞「结算」弹窗（点「继续前进」切回 `map` 后
   那个 `ResultView` **还挂在大地图上**）—— 这正是作者看到的「多个界面叠加」。
2. **屏内塌缩 / 溢出（布局）**：各视图 `extends Control`，内部根 `VBoxContainer`（`战斗屏上下列` /
   `结算屏上下列` / `地图上下列` / `编队上下列` …）**没铺满父矩形** → 塌缩成 `get_combined_minimum_size()`。

   顶栏藏品/零件栏无宽度上限 → 把右侧 4 个功能按钮**挤出右界**；`弹窗面板` 被长文本撑到 **1075px 宽**。
3. **说明信息缺失（可读性）**：机体与战术牌**完全没有 Mouse-Over 说明** —— 属性 / 武器 / 耗气 / 冷却 / 触发 / 效果都看不到。
