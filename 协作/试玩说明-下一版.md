## B 难度与战斗结构（已交付）

**难度目标（你定的）**：**Lv30 队伍打第 3 层精英要掉一半血** → 实测 **胜率 94% / 7.3 回合 / 剩 54% HP**（改前是 100% / 1.3 回合 / 剩 99%）。
**作弊上限口径**（全员 Lv30 + 满编 + 全藏品 + 会玩的指令）：13 个「层 × 档」里**只剩 1 档没饱和**（第 4 层 Boss 86%）。

**四个杠杆**（常量都在 `src/js/71-改动.js`）：藏品同类加成上限 / 绝对顶 **9 → 7** / 补上 `ENEMY_SCALE` 强度（层 × 档位权重）/ 回合上限按档收紧（头目与 Boss 11）。

**9 条结构改造**（★ = 试玩最该感受的）：
- ★ **敌人也吃职业特色**（嘲讽 / 狙击 / 特种降命中… 不再是我方独占）；
- ★ **敌人也放大招**（18 种精锐/头目/Boss 各有一把开场冷却 3 的大招）；
- ★ **战斗间 HP 继承**：队伍**带伤打下一场**，**只有休整（回 35%）与战斗内修理能回**；
- ★ **敌人数量大幅增加**：基础台数 **155 → 252**（普通 5 / 精英 6 / 守军 7 / 侵蚀源 7 / Boss **9 摆满**），增援**第 2 回合**就来、波数 2/3/4/4/4；
- ★ **Boss 大技能改成可躲的形状**（打**一条阻挡束**，意图里显示落点）：同种子**不换位挨 40824 → 换位只挨 30837**；
- **敌方也能上 debuff**（命中 −20 / 破甲 / 削装甲）；**大招变稀缺**（开场冷却 3 → 5）。

## D 招募券系统（已交付）

**你要的三条都落地了**（口径照战棋，详见 `协作\招募券系统-实现任务书.md` §7 / §8；证据逐条带出处）：

| 你要的 | 现在的实现 |
|---|---|
| 「选完分队先给我 **3 个招募券**，不是直接给我 5 个」 | 选完分队 → **发 3 张券**（**第 1 张固定是本分队券** + 2 张随机职业券，照战棋 `27-开局.js:47-48`）；**名册不再白送默认五人队**，要自己招 |
| 「**至少要给一张对应分队的券**」 | 分队屏文案已改成「`X`分队：开局第 1 张券固定是「`X`招募券」，另 2 张随机」；`无` 分队 = 3 张全随机 |
| 「**升级就是用券升级**」 | **一张券二选一**：招募该类别一名角色（扣希望）**或**给队里**同类**角色晋升（**希望 + 同类券**，照 `27:78-87`）；**券与希望同时扣** |

## F 要你定的三件事（都不阻塞试玩）

1. **券够不够把队伍推到第 3 层？**（**实测数字**，见任务板「券系统 · 收尾补记」）一张券同时管招募与晋升（这是你要的），于是有取舍：
   - **一局拿到 4–12 张券**（走到第 4 层的那些局：8 / 10 / 11 / 11 / 12；理论上限 31 = 开局 3 + 每层 6 场 ×4 + 招募站 4）；**净能晋升 2–9 次**；
   - 而 **5 人队 Lv10→Lv30 要 10 次晋升** → 量级是「**3 台 Lv30 + 2 台 Lv20**」，而**第 3 层是按 Lv30 队伍标的**（Lv20 打它 = 0%）。
   - → **三选一**：**A** 加券产出 / **B** 晋升不耗券（只耗希望）/ **C** 把第 3 层强度按真实等级回调。**我建议先按现状试玩**，手感不够再选。
   - **口径提醒（如实说）**：上面「一局」的数字来自 `tests/rank.js` 那条模拟，它**在层 1 就会停**（20 局里 14 局停在层 1）→ 只有「走到第 4 层的那些局」的数字可用；那条模拟本身的走法缺陷已记在任务板，**要不要修由你定**（纯测试改动）。
2. **遗迹「只放死胡同」打了折**：78% 密度下约 6/10 张图**没有死胡同**，所以退到「离起点最近的空格」（战棋原版是死胡同硬要求）。两分支都断言了，标着「照抄打折·待你确认」；要不要保留这个兜底？
3. **「侵蚀源」要不要改名？** 它不是明日方舟的叫法（第 7 主题里的「侵蚀」语义不同），而且现在**已经补了代价**（硬闯 = 敌方攻防 +15% / 花 8 源碳净化），**名字我没动**。

**另有一条口径提醒**：`docs/平衡表.md` 的组队表用的是「默认五人队（白送 5 台 Lv10）」，而**真实开局现在是 3 张券招 3 台** → 表里的「Lv10 打第 1 层」数字**比真局宽松**。我建议收尾时把工具口径改成「券系统真实开局」或至少在表头写清口径（**不动任何数值**）。

**确定性红线 bug 的根因（已修，供你了解）**：不是产品逻辑，而是**测试助手**——`tests/relic.js` 那两段先 `界面.动作('开新局')`（**不带种子**）拿到 RUN 之后才改 `R.种子`，而**开局那 3 张券是在开新局那一刻按 `Date.now()` 兜出的种子抽的** → 同进程第二遍的开局券不同（日志第一个不同：A 尖兵/重装/指挥 vs B 狙击/近卫/指挥）。**修法**：测试改成 `界面.动作('开新局:' + 种子)`；产品侧顺手加固（`新的一局` 清界面临时态、发券日志去掉「手上一共 N 张」这类计数）。**现在三条券链全部由 `mulberry32(种子 + 层×613 + 场次×37 + 格号×17 + 偏移)` 现算**，连跑两遍逐字相同。

## 怎么试（我建议的观察点）

1. **开局**：选完分队 → 手上应该是 3 张券、**没有白送的五台**；用券招人再出发；
2. **第 1 层**：普通战**不再无损**（精英剩约 76% HP、守军是真硬仗）；试探**瞭望站 / 遗迹 / 休整 / 事件**是不是都要想一想；
3. **推进剂**：故意走满 → 看**出口换希望**值不值；再试**小径**（换下一层上限）对比；
4. **第 2–3 层**：感受**带伤推进**的压力（血回不满）、**敌人增援第 2 回合**的节奏；
5. **Boss 战**：看意图里**大技能会打哪几个位**，**换位躲**一次试试（伤害应有明显差别）；
6. **晋升**：看**券够不够**（缺券点不动），以及「希望 + 券」两样一起扣的手感。

**玩到任何一处觉得「还是太平」或「这一步很怪」，直接告我原话 + 大概是哪一层哪个节点**，我照你指的地方继续压。
