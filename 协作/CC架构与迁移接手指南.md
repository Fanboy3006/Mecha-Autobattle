### 2.1 必须保留并迁移的 5 大核心玩法语义（What Must Migrate）
1. **确定性随机源（`mulberry32`）与战斗公式内核（Battle Core）**：
   - 正交双排 `4×2` 共 8 格几何（前排 `0..3`、后排 `4..7`）+《兰斯10》四路对位战线规则（同路掩护减伤 `-30%`、重装同路 `100%` 铁壁护卫、破阵突袭、排位修正）—— 见 `src/js/05-阵型.js`、`71-改动-4/5`、`docs/设计/AI速查卡.md` §2；
   - 5 类射程（`melee / direct / indirect / map|support / heal`）、速度公式、伤害/命中/暴击/减免管线（弱点抗性 → 装甲 → 防御 → 公式 → 能量屏障 → $\lambda$力场 → 护盾）—— 见 `src/js/20-战斗计算.js`、`30-射程.js`、`40-单位.js`、`50-AI.js`。
2. **六大职业排位（4 专精 + 2 双态）+ 六大我方势力特色 + 通用标定经济**：
   - 六大职业基础特性 + 前后排专精/双态修正（重装、近卫、狙击、指挥、尖兵、特种）；
   - 六大势力机制（卫星国防军 SEED 觉醒、流星小队单独行动、月球王国 Feena 光环与残月曲射/追加、天人 TRANS-AM、ATX 逐段打空减 CD 与好运加护、秘银 SRT 情报/作战岗标定接力与倒下接管）—— 见 `src/js/72-势力-1..5.js`、`docs/设计/职业与势力特色.md`；
   - 通用标定经济（特种/指挥产标，上限 3 层；狙击暴击引爆、范围武器溅射引爆）。
3. **战术卡牌系统（唯一主动战术指令层 · 取代旧行动方针）**：
   - **三层牌池**：参战机体共同供牌 = 职业牌池（12 张）+ 势力牌池（12 张）+ 角色/统帅牌池（8 张），共 32 张一阶机战精神式卡牌（1-Click 免二级选目标）—— 见 `docs/设计/战术卡牌系统.md`、`src/js/71-改动-5-参数入口.js`；
   - **零随机洗牌抽牌**：分「初始可用牌」（开战直接入 `战术手牌`）与「条件触发发牌」（战中满足 `ctx.战况计数` 或单位状态条件时当场发入 `战术手牌`）；
   - **气力（Morale）唯一轮转资源**：开战初始气势 `25`（上限 `100`），通过 0 费【激励】回气 `+25`、条件牌回气与交战得气，驱动小中费攻防牌与百气统帅牌（【⚡全军总攻】【🛡紧急掩护】）；
   - **肉鸽 3 选 1 构筑**：招募/晋升机师时从该机师三层牌池抽 3 张供玩家 3 选 1 并入队伍牌库。
4. **肉鸽大地图与经济循环（Roguelike Meta Loop）**：

## 4. M1 语义确认答复：`战斗结构.气势总攻` 逐项去留表（ARGON 正式裁定）

针对 CC 提出的第 3 项问题（旧 `战术:总攻/掩护` 已被统帅牌取代，但 `战斗结构.气势总攻` 模块里的气势来源、上限与总攻/掩护参数哪些是现行语义、要迁到 Godot），逐条裁定如下：

| 参数 / 机制项（来自 `71-改动-4` `气势总攻` & `战术卡牌`） | 现行值 | Godot 迁移裁定 | 说明 |
|---|---|---|---|
| `上限` | `100` | **✅ 必迁（保留）** | `ctx.气势` 的硬上限，`clamp(0, 100, ...)`；首次达到 100 时记 `ctx.曾满气势回合 = ctx.turn` |
| 开战初始气势 | `25`（来自 `战术卡牌.初始默认气力`） | **✅ 必迁（保留 `25`）** | 取代了旧 `气势总攻.开场气势: 0`；Godot 中所有战斗开局初始气势统一为 `25`（若导出关牌黄金样例 `战术卡牌: false` 则为 `0`） |
| `每回合自然加` | `10` | **✅ 必迁（保留）** | 第 2 回合起，在 `回合开始()` 阶段自动 `+10` 气势 |
| `击破加` | `15` | **✅ 必迁（保留）** | 我方单位击破敌机时立即 `+15` 气势 |
| `标定引爆加` | `10` | **✅ 必迁（保留）** | 我方狙击暴击引爆标定、或范围武器溅射引爆标定时立即 `+10` 气势 |
| `受重击阈值` / `受重击加` | `0.25` / `10` | **✅ 必迁（保留）** | 我方单位单次受击实际扣血 `>= maxHp * 0.25` 时立即 `+10` 气势 |
| `防御每台加: 15` / `防御每回合上限: 45` | `15` / `45` | **❌ 随行动方针取消而退役（仅保留给旧默认路径黄金样例对账）** | 原先只有选「全军防御 / 前守后攻」方针使单位执行 `defend` 动作时才触发；取消 5 条行动方针后，正常战斗中不再有 `defend` 动作，气势改由 0 费【激励】(`+25`) 与条件触发牌回气 (`+15~25`) 轮转 |
| `设全队憋大招` (`ctx.全队憋大招`) + 单台 `u.holdUlt` | 布尔开关 | **✅ 必迁（保留）** | 单位级大招保留开关与「全队憋大招」开关仍属于单位层有效操作；打出统帅牌 `CMD_ALL_OUT`【⚡全军总攻】时本回合自动解除憋大招限制齐射 |
| 旧 `设战术(ctx, '总攻'|'掩护')` / `ctx.预约战术` / 动作 `战术:总攻` | 预约指令 | **❌ 不迁入 Godot 新 UI（由统帅牌取代）** | 已被手牌中的 `CMD_ALL_OUT`【⚡全军总攻】与 `CMD_COVER`【🛡紧急掩护】（气势 ≥ 75 自动发入手牌，100 气点击 `打战术牌` 立即生效）完全取代；但 `总攻伤害倍率: 1.35 / 总攻命中加: 15 / 总攻减冷却: 1 / 掩护护盾比例: 0.25 / 掩护清减益: true` 这组**效果数值**仍由 `CMD_ALL_OUT` 和 `CMD_COVER` 两张统帅牌复用 |
