## 一、总览：剧本从写到播的四层

```
 ARGON 写             校验 + 编译（离线工具）          Godot 运行时（只读数据）
┌──────────┐      ┌──────────────────────┐      ┌─────────────────────────────────┐
│ 剧本 .md │ ───▶ │ 校验器：报错 / 警告     │ ───▶ │ StoryPlayer（解释器：指令指针、   │
│（中文，  │      │ 编译器：中文 → 英文 id， │      │   等待 / 跳过 / 加速 / 旗标）     │
│  v0 格式）│      │ 秒 → 帧，标签 → 序号    │      │   ├ DialogueBox（上下两窗）       │
└──────────┘      │ 产出 <节>.story.json   │      │   ├ StageView（单位 / 镜头）       │
                  └──────────────────────┘      │   ├ AudioDirector（BGM / 音效）    │
                                                │   ├ ChoiceBox                     │
                                                │   └ GameBridge（战斗 / 教学 / 存档）│
                                                └─────────────────────────────────┘
```

- **剧本是唯一正本**；`.story.json` 是生成物，不手改。
- 播放器**只读**剧本数据；需要改游戏状态的（旗标、开战、教学）一律经 `GameBridge` 交给 `GameSession`（`代码地图.md` 的表现层规矩）。
- 时间单位一律是 **60 帧下的帧数，3 帧一步**（演出协作第 3 节第 8 条）。剧本里可写「秒」「毫秒」，编译时换算成帧并取 3 的倍数。

## 二、剧本文件格式（以 v0 为基础）

### 2.1 文件
- 位置：`协作/私密/剧情/剧本正文/Ch<章>_<节>_<标题>.md`（沿用该目录 README 的命名），UTF-8。一个文件 = 一节，可含多个场景。
- 逐行解析。**一行只属于下面一种**：

| 行的开头 | 类型 | 例 |
|---|---|---|
| `@场景` | 场景头 | `@场景 1-1 废墟·黄昏 BGM:紧张` |
| `【` | 舞台指令 | `【登场 甲 格(3,4)】` |
| `角色名（…）：` / `角色名：` | 台词 | `甲（笑）：今天天气不错。` |
| `旁白：` | 旁白 〔新〕 | `旁白：三天后。` |
| `#` `>` `//`、空行 | 注释，不播 | `# 本场目的：介绍乙` |
| 其它 | **警告 W01**，按旁白播 | — |

> ARGON 写的 markdown 标题、说明、引用块都是注释，不影响播放。冒号全角半角都认（`：` / `:`）。

### 2.2 场景头
```
@场景 <章>-<节> <地点>·<时间> BGM:<情绪或曲键> [地图:<地图键>] [字幕:关]
```
- v0 的前四段照旧；`地图:`、`字幕:` 〔新〕，可省。
- 播放：淡入 30 帧 → 左上角显示「地点·时间」字幕 90 帧（`字幕:关` 不显示）→ 开始执行。场景结束（下一个 `@场景` 或文件末尾）：关窗 → 淡出 30 帧。
- `地图:` 省略 = 黑底 / 纯背景场景（只有对话）。

### 2.3 台词
```
角色名（表情）：台词
角色名（表情·心声）：台词        〔新：表情和心声可同时写〕
角色名（心声）：台词              （v0 写法，表情按「普通」）
角色名〈显示名〉（表情）：台词     〔新：名字栏显示别的名字，如「？？？」〕
角色名：台词                      （省略表情 = 普通）
```
- **一条台词 = 一页**，≤ 2 行、每行 ≤ 14 字（第五节的计字规则）。超了是**错误 E10**，不自动拆页——拆在哪里是写作的事。
- 换行：播放器按 14 字自动折行（带避头尾，见 4.4）；想自己断行，在台词里写 `／`。
- **不要自己写「」或（）**：播放器自动加。写了会被去掉，并给 **W11**。
- 表情（v0 七种 + 编译后 id）：普通 `normal` · 笑 `smile` · 怒 `angry` · 惊 `surprised` · 悲 `sad` · 坚定 `determined` · 冷淡 `cold`。其它词是 **W12**，按「普通」播。头像缺这个表情时也退回「普通」（不报，现阶段表情只画 1 张）。

### 2.4 舞台指令
```
【指令名 参数 参数 键：值；键：值】
```
- 指令名后可以跟空格或 `：`（v0 的 `【自由：描述】` 照样成立）。
- 参数之间用空格、`、` 或 `，`；键值对用 `键：值`，之间用 `；`。
- **认不出的指令、或参数解析失败 → 整条当 `自由` 处理，给 W20**，不报错。这条保证任何 v0 剧本都能播。
- 指令一览见第三节。

### 2.5 一个完整例子（中性占位）
```
@场景 0-1 训练场·清晨 BGM:日常 地图:训练场

【登场 甲 格(4,6) 方式：闪烁】
【镜头 甲】
甲（普通）：今天的训练从移动开始。
【登场 乙 屏外右 方式：进入；到：格(7,6)】
乙（笑）：抱歉，我来晚了！
甲（冷淡·心声）：又是这样……
【选择 原谅他 → 原谅；训他一顿 → 训斥】
【标签 原谅】
甲（笑）：下不为例。
【跳转 合流】
【标签 训斥】
【震动 小】
甲（怒）：再迟到就去扫机库！
【标签 合流】
【战斗 敌方：敌·杂兵×3；胜利条件：全灭敌军；败北条件：甲被击破】
旁白：训练结束。
```

## 三、舞台指令表

> 「v0」列 = v0 已有；〔新〕= v0.1 新增。英文 id 是 Godot 数据里用的（演出协作第 3 节第 13 条）。
> **位置**的写法（所有指令通用）：`格(x,y)`（地图格坐标）· 锚点名（地图里命名的点）· `屏外左 / 屏外右 / 屏外上 / 屏外下` · 单位名（= 该单位所在格）。

| 指令 | id | 参数（可省的写默认） | 播放时做什么 | 等不等它播完 | v0 |
|---|---|---|---|---|---|
| **登场** | `spawn` | 单位, 位置；`方式：闪烁`(默认) / `进入` / `传送` / `降落`；`到：位置`（方式=进入时） | 闪烁 = 闪 4 下、每下 6 帧；进入 = 从屏外走到「到」；传送 = 闪白 + 出现；降落 = 从上方落下 | 等 | v0 |
| **退场** | `exit` | 单位；`方式：消失`(默认) / `撤退` / `击破` / `传送` | 撤退 = 走到最近的屏外；击破 = 调战斗演出的击破宏（简版） | 等 | v0 |
| **移动** | `move` | 单位, 位置；`速度：慢 / 普通 / 快`(12 / 8 / 4 帧每格)；`经：位置、位置` | 按格走，3 帧一步；有「经」就依次经过 | 等；写 `不等` 则与下一条同时进行 | v0 |
| **镜头** | `camera` | 位置 或 `跟随 单位`；`帧：N` | 平移到目标居中，3 帧一步，默认 24 帧；跟随 = 之后一直跟着这个单位 | 等 | v0 |
| **BGM** | `bgm` | 情绪或曲键 / `停` / `淡出 N帧` | 切曲、停止、淡出；情绪 → 曲子的对照表归音乐线 | 不等 | v0 |
| **音效** | `sfx` | 音效键 | 播一次；键名表与战斗演出共用（语-19）+ 剧情专用键 | 不等 | v0 |
| **震动** | `shake` | `小 / 中 / 大`；`帧：N` | 数值与战斗演出同档（演出协作第 3 节第 9 条） | 等 | v0 |
| **闪白** | `flash` | `次数：N`(默认 1)；`色：白 / 黑 / 红` | 全屏闪色，每档 6 帧 | 等 | v0 |
| **等待** | `wait` | `N帧` / `N秒` / `N毫秒` | 什么都不做 | 等 | v0 |
| **选择** | `choice` | `选项文字 → 标签` × 2～3，用 `；` 分隔 | 屏幕中间弹选择框，选完跳到标签 | 等玩家选 | v0 |
| **战斗** | `battle` | `敌方：…；胜利条件：…`；〔新〕`败北条件：…`、`败北：标签` | 交给 GameBridge 开战；战斗结束回来，结果写进旗标 `战斗结果` | 等战斗结束 | v0 |
| **自由** | `free` | 描述 | 正式版不播；调试版在屏幕上方显示黄字描述 90 帧，提醒这里还要补 | 不等 | v0 |
| **旁白** | `narrate` | （写成 `旁白：…` 行） | 下窗位置，无头像、无名字栏，不加「」 | 等翻页 | 〔新〕 |
| **窗口** | `window` | 角色名 `上 / 下` | 指定这个角色以后在哪个窗口说话（覆盖 4.2 的自动规则） | 不等 | 〔新〕 |
| **关窗** | `close` | — | 两个对话窗都收起（地图事件前常用） | 等 | 〔新〕 |
| **淡入 / 淡出** | `fade` | `入 / 出`；`帧：N`(默认 30)；`色：黑 / 白` | 全屏渐变 | 等 | 〔新〕 |
| **字幕** | `caption` | 文字 | 屏幕中间一行字幕，90 帧（章节标题、「三天后」类） | 等 | 〔新〕 |
| **标签** | `label` | 名字 | 跳转目标，不播 | — | 〔新〕 |
| **跳转** | `jump` | 标签 | 跳过去 | — | 〔新〕 |
| **设定** | `set` | 旗标名 `= 值`(默认 真) | 写旗标（经 GameBridge 存档） | — | 〔新〕 |
| **如果** | `if` | 条件 `→` 标签 | 条件成立就跳；条件写 `旗标名`、`旗标名 = 值`、`战斗结果 = 胜利` | — | 〔新〕 |
| **教学** | `tutorial` | 主题键 | 对应细纲里的「游戏功能介绍挂载槽位」；交给 GameBridge 打开对应教学，结束后回来 | 等 | 〔新〕 |

- **战斗占位不写数值**（v0 规矩）：`敌方` 写代号或名字和数量，`胜利条件` 写一句话；数值、AI、地形由主开发会话的关卡数据负责，按「节号 + 第几场战斗」对上。
- **分支只有一层意思**：选择、如果、跳转都只是在同一个文件里跳标签。跨节的走向由章节流程（游戏）按旗标决定，不在剧本里写。

## 四、对话框

### 4.1 尺寸（240×160 画面，12px 像素字体）
```
y=0   ┌─────────────────────────── 240 ───────────────────────────┐
      │┌────┐ 名字栏（12px 高，最多 8 字）                          │
      ││头像│「一二三四五六七八九十一二三四                          │ ← 上窗 48px
      ││32× │  一二三四五六七八九十一二三四」                    ▼   │
y=48  └└────┘───────────────────────────────────────────────────┘
               （中间 64px 露出地图）
y=112 ┌────────────────────────── 下窗同样布局 ─────────────────────┐
y=160 └──────────────────────────────────────────────────────────┘
```
- 窗 240×48；头像 32×32 放在 (4, 8)；名字栏 x=40、y=4；正文两行，y=18 和 y=32，行高 14。
- 正文从 x=52 起（`「` 占 x=40～51），14 字 × 12 = 168 → 到 x=220；`」` 挂在行尾外侧（x=220～231），**不计入 14 字**；翻页箭头 ▼ 在 x=232。
- 旁白窗：同尺寸，放在下窗位置，无头像、无名字栏，正文从 x=8 起，每行仍按 14 字算（保持一致，便于校验）。

### 4.2 上窗还是下窗（自动规则）
1. 一个场景里**第一个说话的人用下窗**，第二个不同的人用上窗。
2. 之后：说话人已经占着一个窗 → 还用那个窗；否则 → 换掉**更久没说话**的那个窗的人。
3. 不说话的那个窗保留最后一页，**调暗**（调色板压暗一档）；遇到 `【关窗】` 或新的 `@场景` 才收起。地图事件（登场 / 移动 / 镜头）不自动关窗，想让出画面就先写 `【关窗】`。
4. 想改就写 `【窗口 甲 上】`。

### 4.3 逐字打出与翻页
| 项 | 1× | 2× | 3× |
|---|---|---|---|
| 每字 | 4 帧 | 2 帧 | 1 帧 |
| 、，后多停 | 6 帧 | 3 帧 | 0 |
| 。！？……后多停 | 12 帧 | 6 帧 | 3 帧 |
| 自动翻页（自动模式）：打完后再等 | 60 帧 + 每字 2 帧 | 减半 | 减为三分之一 |

- 打字声 `blip` 每 2 个字响一次（标点不响）。
- 正在打字时按确定 → 整页立刻显示；再按 → 翻页。打完后 ▼ 每 16 帧闪一次。
- **心声**：用（）代替「」，正文颜色淡一档，不响打字声。
- **跳过**（按住或菜单）：一路执行到下一个**选择、战斗、教学**或场景末尾停下。被跳过的指令**直接落到结束状态**（单位到终点、BGM 切到最后一首、旗标照写），所以跳不跳，结果都一样。

### 4.4 计字规则（校验器和播放器用同一套）
- 全角字（汉字、全角标点、假名）算 1；半角字母数字算 ½，向上取整。
- `……`、`——` 各算 2（就是两个字）。自动加的「」（）不算。
- 自动折行在第 14 字后断；**避头**：`。，、！？……」）` 不放行首（把前一个字一起挪下去）；挪完超过 2 行 → **E10**。
- 名字栏 ≤ 8 字（超了 **W13**，截断显示）。选择项 ≤ 12 字（超了 **E31**）。

## 五、Godot 播放器分层（给实现者）

| 层 | 类（建议名） | 只做什么 | 不做什么 |
|---|---|---|---|
| 数据 | `StoryData`（读 `.story.json`） | 指令数组：`{op, args, line}`，`op` 用第三节英文 id；标签已解析成下标；时间已是帧 | 不含任何播放状态 |
| 解释器 | `StoryPlayer`（Node） | 指令指针、`await` 每条指令、加速档（1 / 2 / 3）、跳过、自动模式；旗标读写都走 GameBridge | 不画任何东西；不碰战斗内核 |
| 指令处理 | 每个 `op` 一个处理器，注册在字典里 | 两个方法：`run(ctx)`（正常播，可 await）和 `finish_now(ctx)`（立刻落到结束状态，跳过时用） | 处理器之间不互相调用 |
| 表现 | `DialogueBox` · `StageView` · `ChoiceBox` · `AudioDirector` · `ScreenFx` | 画窗、画单位、移镜头、放声音、闪色震动 | 不知道剧本的存在，只接收处理器的调用 |
| 桥 | `GameBridge` | 开战（返回胜 / 败）、开教学、旗标存取、角色表查询（角色名 → 头像键、单位键） | 演出层唯一能碰游戏状态的口 |

- **时钟**：播放器自己数帧，按固定 60 帧走；掉帧时补走（和战斗演出同一套，保证重看一致）。
- **加速**：只改「每个显示帧推进几个剧本帧」和 4.3 的打字表；3 帧一步的指令在 2× 下步数减半、步长加倍（演出协作第 3 节第 8 条）。
- **存档点**：只在场景头、选择之后、战斗回来之后可以存；存的是「文件 + 指令下标 + 旗标」，读档时从该下标开始、前面的舞台状态用 `finish_now` 快速重建。
- **缺资源不崩**：缺头像 → 紫色 32×32 占位块；缺单位图 → 紫色方块；缺曲子 → 保持静音并打日志。
- **公开版保密**：GitHub Pages 上的 Web 版只能打包**占位剧本**（例如第 2.5 节的例子）；真剧本的 `.story.json` 只进本机构建。打包脚本要检查这一点（给主开发会话）。

### 5.1 `.story.json` 形状
```json
{
  "format": "story/0.1",
  "source": "Ch00_01_训练.md",
  "scenes": [
    {"id": "0-1", "place": "训练场", "time": "清晨", "bgm": "日常", "map": "训练场", "caption": true,
     "ops": [
       {"op": "spawn", "args": {"unit": "甲", "at": [4, 6], "mode": "blink"}, "line": 3},
       {"op": "say", "args": {"who": "甲", "face": "normal", "inner": false, "name": null,
                               "text": ["今天的训练从移动开始。"]}, "line": 5},
       {"op": "choice", "args": {"items": [["原谅他", 9], ["训他一顿", 12]]}, "line": 8}
     ]}
  ]
}
```
- `text` 是**已折好行**的数组（≤ 2 项），播放器不再折行，校验器和播放器的折行结果因此一定一致。
- `line` 是剧本源文件的行号，报错和调试版「自由」黄字都带上它。

## 六、校验规则（给 DeepSeek 写校验脚本）

**用法**：`校验 <剧本.md 或目录> [--角色表 <路径>] [--输出 json]`。退出码：有错误 = 1，只有警告 = 0。输出每条：`文件:行号 代码 一句话`。

**错误（E，不改不能编译）**

| 代码 | 规则 |
|---|---|
| E01 | 文件里第一条可播放内容之前没有 `@场景` |
| E02 | 场景头缺「章-节」或「地点·时间」 |
| E03 | `【` 没有配对的 `】`（不允许跨行） |
| E10 | 台词或旁白折行后超过 2 行（规则见 4.4） |
| E11 | 台词正文为空 |
| E30 | `跳转` / `选择` / `如果` / `战斗 败北：` 指向不存在的标签 |
| E31 | 选择项少于 2 个或多于 3 个，或某项超过 12 字 |
| E32 | 同一文件里标签重名 |
