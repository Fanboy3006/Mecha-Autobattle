# 剧本写作格式卡 v0.1（给 ARGON）
一节一个文件：`Ch01_01_标题.md`。v0 写法全部照旧有效。

**场景头**
`@场景 1-1 地点·时间 BGM:情绪`（可加 `地图:键`）

**台词**（一条＝一页，≤2行，每行≤14字）
`甲（笑）：台词` · `甲：台词`＝普通
`甲（悲·心声）：台词` 表情+心声
`甲〈？？？〉（怒）：台词` 名字栏显示「？？？」
`旁白：三天后。`
- 表情：普通 笑 怒 惊 悲 坚定 冷淡
- 不写「」（）；手动断行用 `／`
- 计字：汉字和全角标点算1，……和——算2，半角算½

**舞台指令**（单独一行）
【登场 甲 格(3,4)】【退场 甲】【移动 甲 格(5,4)】
【镜头 甲】【BGM 情绪】【音效 键】【震动 小】
【闪白】【等待 1秒】【关窗】【字幕 文字】
【淡入】【淡出】【窗口 甲 上】【自由：描述】
位置：格(x,y) / 锚点名 / 屏外左 / 单位名

**分支**
【选择 选项甲 → 标签A；选项乙 → 标签B】（2～3项，每项≤12字）
【标签 A】【跳转 B】【设定 旗标】【如果 旗标 → A】

**占位**（不写数值）
【战斗 敌方：…；胜利条件：…；败北条件：…】
【教学 主题】

`#` 开头是注释。认不出的【】按「自由」处理。
