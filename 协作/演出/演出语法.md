## 一、分级与时长预算

**语-1 三个档（细化已定规则第 3 条）** 〔草稿〕

| 档 | 什么时候 | 在哪演 | 1× 时长预算 |
|---|---|---|---|
| **完整** | 我方大招（`是记录大招()` 为真）；Boss 大技能；**本场第一次**出现的那一招 | 横版画面 | 4.5–7.5 秒（demo 击破版 7.05 秒） |
| **短版** | 同一招**本场第二次起**；非大招打出的**击破** | 横版画面，**砍掉「起」段**（入场、切入、蓄力，见语-9） | 1.8–2.8 秒 |
| **简版** | 其余普通攻击、修理、增益 | 战场上（现有 `85-播放.js` 的前冲 / 闪白 / 飘字），阶段 4 再设计 | ≤ 1 秒 |

为什么加「短版」：粗算一场 5 台我方 × 每台约 3–4 次大招 ≈ 15–20 次，全部完整演 ≈ 2 分钟纯演出，太拖。机战的做法是给开关；我们多一档「第二次起自动变短」，默认就不会拖。
**击破**按已定规则第 3 条要进横版。我建议**非大招的击破走短版**：只演「发 → 中 → 击破」，约 2.5 秒。

**语-2 演出开关（三档 + 随时跳过）** 〔草稿〕
- 设置里「战斗演出」三档：**完整**（每次都完整）/ **标准**（默认：首次完整、之后短版）/ **关**（全部简版）。
- 演出中点画面或按键 = **跳过当前这一段**，直接跳到结果（血条落到最终值）。
- 2× 倍速对演出同样生效（语-13）。

**语-3 敌方要不要演（待定第 2 条）** 〔草稿〕
建议：**只有 Boss 大技能（`Boss事件:'大技能'`）和头目的 `大招:true` 武器**走完整 / 短版；其余敌方攻击一律简版。

**语-4 普通攻击简版不切横版（待定第 3 条）** 〔草稿〕
建议：不切。简版留在战场上演，阶段 4 再细化。

## 二、画面规范

**语-5 画布与分层** 〔草稿〕
- 逻辑画布 **240×160**，整数倍放大，`imageSmoothingEnabled = false`（已定规则第 1 条）。
- 从下到上的绘制顺序：远景（星空 / 地球，视差 0.08–0.1）→ 中景（山脊，视差 0.4）→ 地面 → 影子 → 机体 → 弹体 / 特效 → 伤害数字 / 印章 →（以上整体受震动）→ 武器名牌 → HUD → 切入 → 全屏闪白 → 转场。
- **震动只作用在 HUD 以下**（HUD、名牌、切入不抖。demo 就是这样，读数不晃眼）。

**语-6 坐标与区域** 〔草稿〕

```
y=0   ┌──────────────── 240 ────────────────┐
      │      [ 武器名牌 x64–176, y2–17 ]      │
      │                                      │
      │  敌方（左，朝右）       我方（右，朝左） │   ← 战斗区 y 0–126
y=118 │━━━━━━━━━━━━━━ 地面线 ━━━━━━━━━━━━━━━━│
y=127 ├──── 敌方 HUD 119×33 ──┬── 我方 HUD ────┤
y=160 └──────────────────────┴───────────────┘
```

- **站位固定**：我方永远在右、面朝左；敌方永远在左、面朝右（机战惯例）。谁攻击都不换边。
- **地面线 y = 118**（机体脚底踩在这一行）。HUD 从 y = 127 起，33 像素高，左敌右我，和站位同侧。
- 世界坐标：敌方站 x = 70，我方站 x = 330，相距 260，一屏（240）放不下两边 → 远程招靠转镜（语-8）。
- 伤害数字：**目标头顶上方 14 像素**，最高不超过 y = 20（避开名牌）。demo 里写死的 `GROUND - 62` 要改成按精灵高度算。

**语-7 尺寸档（待定第 5 条）** 〔草稿〕

| 档 | 高度（像素） | Aseprite 画布 | 说明 |
|---|---|---|---|
| 我方标准 | 56–64 | 64×64 | 和机设线「64×64 画布上涂草图」一致 |
| 我方大型 | 64–76 | 80×80 | 重装、大型机 |
| 小兵 | 40–48 | 48×48 | demo 的 28 像素太小 |
| 精锐 / 头目 | 52–60 | 64×64 | 比小兵大一眼能看出来 |
| Boss | 88–110 | 128×128 | 允许超出画面左边被裁掉一部分（显得巨大）；脚底仍踩地面线 |

在 240×160 里，64 像素高的机体头顶在 y = 54，上面还有 50 多像素放数字、弹道和名牌。我量过不挤。

**语-8 镜头（只有 4 种）** 〔草稿〕

| 镜头 | 用在 | 做法 |
|---|---|---|
| `攻方` | 起段 | 画面中心对准攻方（demo `CAM_ALLY`） |
| `受方` | 中、收段 | 中心对准受方 |
| `转镜` | 远程：发 → 中 | 400 毫秒 ease-in-out 横移，加速度线（demo 的「转镜」拍） |
| `同框` | 近战 | 攻方突进到受方前 40 像素处，两台同框；镜头跟攻方走 |

不做缩放（整数像素画风下缩放会糊）；放大效果用切入头像代替。

## 三、时间语法

**语-9 四段结构，「命中时刻」是唯一同步点** 〔草稿〕
每招的时间轴都由四段组成，所有节拍都**相对命中时刻 T0** 写：

| 段 | 相对 T0 | 包含的拍（demo 名） | 短版 |
|---|---|---|---|
| **起** | 负值 | 入场 · 切入台词 · 蓄力 | **整段砍掉**，只留 150 毫秒淡入 |
| **发** | 负值 | 发射 · 转镜 · 预兆 · 弹道 / 突进 | 保留，可压缩到 60% |
| **中** | T0 起 | **命中停顿** · 冲击 · 扣血 | 保留 |
| **收** | 正值 | 反应（后仰 / 闪避 / 防御 / 击破）· 退场 | 保留 |

- **T0 = 第一段伤害落地的那一刻。** 音效、闪白、震动、数字、血条全部挂在 T0 上，不各自对时间。
- **命中停顿插在 T0**：停顿期间画面冻结、音效照常（demo 已经这样做）。T0 之后的拍全部顺延。
- 模板只需写「发」段多长、「收」段用哪个反应，其余由语法推出来 → 300 招的脚本才写得短。

**语-10 多段攻击** 〔草稿〕
- 第 k 段落在 `T0 + k × 段间隔`：4 段以内间隔 120 毫秒；5 段以上 70 毫秒；**全部段铺开不超过 700 毫秒**。
- 只有第 1 段吃完整命中停顿；中间段 30 毫秒微停；**最后一段**如果击破或暴击，再吃一次完整停顿。
- **只显示总伤害**（记录里只有总数；逐段数字只在 `详情` 文本里，不解析文本）。每段只有火花 + 小震。
- `命中段数 < 段数` 时：前 `命中段数` 段打中，后面的段擦过 + 「MISS」。（记录不知道哪几段没中，统一这么排。只影响观感，不影响结果。）

**语-11 标准值表（初稿，作者在 demo 上调过的以作者为准）** 〔草稿〕

| 项 | 小 | 中 | 大 | 击破最后一击 | demo 现值 |
|---|---|---|---|---|---|
| 命中停顿（毫秒） | 60 | 100 | 140 | 180 | 100 |
| 震动初始振幅（像素） | 1 | 2 | 4 | 4 + 击破二次震 3 | 冲击 4 / 发射 2 / 击破 3 |
| 震动衰减常数（毫秒） | 80 | 120 | 160 | 220 | 160 / 80 / 220 |
| 全屏闪白 | 无 | 1 帧扫描线 | 1 帧白 + 停顿期网点 | 同大 + 大爆炸 1 帧白 | 大 |
| 目标闪白 | 66 | 100 | 100 + 停顿全程 | 同大 | 停顿全程 + 100 |

- 扣血：T0 + 停顿后 350 毫秒开始，600 毫秒 ease-out 落到最终值；白色残影条再晚 200 毫秒跟上（demo）。
- 精灵帧最短停留 66 毫秒（2 帧 @30fps），特效按 33 毫秒步进（GBA 那种一顿一顿的感觉，demo 的 `step(t, 33)`）。
- 「小 / 中 / 大」由脚本的 `停顿` 字段选；不写就按武器威力档自动给（威力 < 1500 小、< 3000 中、其余大）。

**语-12 倍速与跳过** 〔草稿〕
- 2× 对所有拍时长减半；**命中停顿最少保留 50 毫秒**（停顿砍光就没打击感了）。
- 跳过：立刻结束 Promise，血条直接落到记录值。**跳过和不跳过，播放层应用的记录完全一样**。

**语-13 随机与确定性（硬规矩落地）** 〔草稿〕
- 演出里的碎屑、火花、星星**用演出自己的伪随机**，种子 = `战报种子 ^ 记录序号`；**绝不调用 `ctx.rng`，也不调 `Math.random()`**。
- 结果：同一场战斗重看，画面逐帧一样；演出开不开，战斗结果逐字一样（阶段 3 的测试就测这一条）。
- 合成音效里的噪声允许用 `Math.random()`（只影响声音，不进画面，也不进战斗）。

## 四、结果反应清单（记录字段 → 画面）

**语-14 反应表** 〔草稿〕

| 结果 | 怎么从记录认出来 | 画面 | 音效 | 停顿 |
|---|---|---|---|---|
| 命中 | `命中:true, 暴击:0` | 目标闪白 + 后退 3 像素 + 白字数字 | `hit_*` | 按语-11 |
| 暴击 | `暴击 > 0` | 数字放大一档、黄色，上方小字「CRITICAL」；震动 ×1.5 | `hit_*` + 高音叠一层 | +60 毫秒 |
| 未中 | `命中:false` | 目标侧闪 8 像素带 2 帧残影；弹体擦过飞出画面；「MISS」 | `whoosh` | 0 |
| 防御中 | 记录里有 `防御少挨` | 目标换 `guard` 帧（没画就用后仰减半）；数字下方绿色小字「防御 −N」 | `clang` | −20 毫秒 |
| 护盾吸收 | **记录里还没有** → 语-21 | 目标前面闪一层盾面，数字后跟灰色小字「盾 −N」 | `barrier` | 同命中 |
| 屏障 / λ 力场无效化 | **记录里还没有** → 语-21 | 球形 / 六角形力场亮起，弹体在表面炸开；数字显示「0」 | `barrier` 重 | 中 |
| 嘲讽替挨 | 这一发前面紧挨一条 `类型:'嘲讽'` | 「中」段开头插 500 毫秒：重装机从画面外滑进挡在前面，上方「嘲讽！」；之后照常反应 | `clang` | 同命中 |
| 挂 debuff | `debuff` 非空或 `特种减命中 > 0` | 扣血后目标头顶冒一个小图标 + 小字（如「命中↓」），停 500 毫秒 | `blip` 低音 | — |
| **击破** | `目标剩余HP === 0` 且这一下之前 > 0 | demo 击破序列：闪白 3 下 → 连爆 3 个 → 大爆炸 + 1 帧全屏白 → 烟 →「击破」印章 | `pop`×3 + `boom` | 最后一击档 |

- 我方被击破，用同一套击破序列。
- 「被挡」「集中」这些方针反馈**不进横版演出**，留在战场层和战报里（那是三层反馈的地盘）。

## 五、多目标（待定第 1 条）

**语-15 怎么认「一次出手」** 〔草稿〕
播放走到一条 `攻击` 记录时，从这条往后收：**同一个 `单位方 + 单位位 + 武器`** 的连续 `攻击` 记录算一次出手。
- 中间夹的 `嘲讽`、`方针` 记录归进来（嘲讽在演出里演，方针不演）。
- 中间夹的 `残月余响` **不归进来**：它是另一次出手，排在这次演完之后演，用短版。
- 遇到别的单位的记录、`连斩`、`回合`、`结束` 就停。

这样**不需要给记录加「出手编号」字段**（默认路径的记录一个字节都不变）。

**语-16 多目标怎么演** 〔草稿，三选一〕
- **A. 主目标单独演**：镜头只给主目标，其余目标演完后在战场上跳数字。最省，但打整排时看不出「打了一排」。
- **B. 并排同框（推荐）**：横版里受方最多站 **3 台**，前后错开（前 0 / 中 −10 / 后 −20 像素，后面的往上错 4 像素造景深）。同一个 T0 一起反应，数字每台错开 80 毫秒弹出。HUD 只画主目标的大血条，另外两台各一条 2 像素小血条。超过 3 台时站 3 台，另显示「+N」。不用多画任何资产。
- **C. 分屏**：不推荐（240 宽分屏太挤）。

**主目标**：本次击破了的 > 伤害最高的 > 第一条记录的。

## 六、资产规范（待定第 4 条）

**语-17 每台机体要的帧（Aseprite tag 名）** 〔草稿〕

| tag | 帧数 | 必须？ | 缺了怎么办 |
|---|---|---|---|
| `idle` | 2（呼吸，各 400 毫秒） | **必须** | — |
| `attack` | 1–3 | **必须** | — |
| `hit` | 1 | 可选 | 程序生成：闪白 + 后仰 |
| `guard` | 1 | 可选 | 用后仰减半 |
| `dash` | 1 | 可选（近战机建议画） | 用 `attack` 第 1 帧 + 残影 |
| `attack_<后缀>` | 1–3 | 可选 | 一台机体多种攻击姿势时用（如 `attack_beam`、`attack_melee`），脚本里点名 |
| `portrait` | 1 | 可选 | 切入头像。另画 48×48；缺了就截 `idle` 上半身放大 2 倍（demo 做法） |

**最少 = `idle` 2 帧 + `attack` 1 帧。** 只画这两样，所有模板都能演。

**语-18 文件与 JSON** 〔草稿〕
- 位置：`art/battle/<机体键>/<机体键>.aseprite`（作者的唯一源文件）→ 导出 `<机体键>.png` + `<机体键>.json`（Aseprite「json-array + 列出 tags + 列出 slices」）。
- **对齐点 = 脚底中心**（图的最下一行是脚底，和机设线 3.2 一致）。
- **Aseprite slice 标关键点**（演出模块靠它们知道从哪里发射）：
  - `muzzle`：枪口 / 发射点（`attack` 帧上标）。远程模板必需；没标就用画布右边缘的中点。
  - `hand`：持剑手 / 施法手（近战、召唤模板用）。
  - `core`：机体中心（爆炸、闪光的中心）。没标就用包围盒中心。
- **朝向**：资产一律画成**面朝右**；程序给我方做水平镜像。JSON 里不用写朝向。
- 描边：1 像素深色外描边，可以交给程序自动加（demo 的 `buildSprite` 就是自动描边）。
- 特效优先**程序生成**（demo 里的光束、火球、碎屑、冲击环全是代码画的，不占美术工作量）。程序画不好的，再放序列帧到 `art/battle/fx/<名>.png + .json`。

## 七、音效

**语-19 音效分类与键名** 〔草稿〕

| 类 | 键 | demo 里有？ |
|---|---|---|
| 界面 | `cutin`（切入）、`blip`（打字） | 有 |
| 蓄力 | `charge` | 有 |
| 发射 | `fire_beam`、`fire_shell`、`fire_missile`、`launch`（重物射出） | `fire` 一种 |
| 飞行 | `whistle`（下坠）、`beam_hum` | `whistle` |
| 近战 | `swing`、`slash` | 无 |
| 命中 | `hit_s`、`hit_m`、`hit_l`、`hit_beam` | `impact` |
| 防御 | `clang`、`barrier` | `clang` |
| 闪避 | `whoosh` | 无 |
| 爆炸 | `pop`、`boom` | 有 |

- 现在全部用芯片风合成（demo 的 `sfx()`）。以后谁做了真音效文件，放 `audio/sfx/<键>.ogg`：**有文件就播文件，没有就合成**，脚本不用改。
- **BGM 不归演出管**：演出开始 / 结束各发一个事件（`演出开始`、`演出结束`，带脚本 ID 和档），音乐线（`96-音乐.js`）自己决定要不要切大招主题曲。

## 八、接口细化（改 `演出协作.md` 第 4.1 节）

**语-20 钩子签名** 〔草稿〕
`演出.要演(记录, 上下文)` 改成：

```js
演出.要演(战报, 位置, 播放) → null | { 脚本: '<键>', 档: '完整' | '短版', 条数: N, 输入: {…第 4.2 节…} }
```

- `条数` = 这次出手吃掉几条记录（语-15）。播放层：暂停 → `await 演出.播放(结果)` → 把这 N 条记录**照原来的顺序逐条 `应用()`**，每条照常调 `钩子.每步` → 继续。
- **为什么要传 `播放`**：`HP前`、`最大HP` 从 `播放.单位` 的当前状态读（记录还没应用）。这样第 4.2 节那两个字段**不用加进战斗记录**。
- 跳过开关、「关」档、`播放.快进`：`要演` 直接返回 null，播放层一行逻辑都不变。
- 武器的静态信息（`fire`、`dmgType`、`hits`、威力、`isUltimate`）按 `是记录大招()` 的方法查单位身上的武器条目。**读静态数据不算「重算」**，可以读。

**语-21 战斗记录唯一要补的字段（给 DSH，需作者同意）** 〔草稿〕
在 `resolveAttack()` 的 `字段` 里，**照 `防御少挨` 的写法：只在真的发生时才带上**（所以默认路径的记录逐字节不变）：
- `护盾吸收: N`：这一下被护盾吃掉的总量（逐段累加）；
- `无效化: '屏障' | 'λ力场'`：有一段被无效化了。

数字 `dmgCore()` 里都有（`c.steps` / `c.nullified`），只是没往外带。只写记录、不改数值、不碰随机数。

## 九、脚本格式与模板

**语-22 脚本的键和字段** 〔草稿〕
键 = `机体键/武器名`（记录里有 `单位` 和 `武器`，直接拼出来）。**所有字段都可以不写**，不写就用模板默认值。

```js
演出脚本['M1/残月的余响'] = {
  模板: 'summon_drop',          // 见语-23
  切入: { 台词: ['质量加速器，充能完毕——', '月光，坠落吧！'], 招式名: '残月的余响' },  // 写 null = 不切入
  攻方帧: 'attack',             // 用哪个 tag（语-17）
  弹体: 'meteor',               // 弹体样式（程序画的种类）
  主色: '#7ff0ff',              // 光束 / 蓄力 / 拖尾的主色
  命中: 'hit_large',            // 命中特效
  停顿: '大',                   // 小 / 中 / 大（语-11）
  音效: { 发射: 'launch', 命中: 'hit_l' },
  节拍: { 坠落: 600 },          // 只覆盖要改的拍，单位毫秒
};
```

**没写脚本的招也能演**：按武器数据自动选模板（语-23 最后一列），切入用机师名 + 武器名、不带台词。所以 300 招**不用一次写完**，作者只为想要台词、想要特别效果的招写卡。

**语-23 v0.1 模板清单（阶段 1 先做前 3 个）** 〔草稿〕

| 模板 | 演什么 | 发段做法 | 镜头 | 自动选它的条件 |
|---|---|---|---|---|
| `summon_drop` | 从天而降（demo 陨石） | 蓄力 → 向上发射 → 转镜 → 预兆 → 坠落 | 攻方 → 转镜 → 受方 | 脚本点名 |
