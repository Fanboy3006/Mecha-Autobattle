# 剧本写作格式卡 v0.1 · 相对 v0 的变化（给 ARGON，一页）

> 原则：**只增不改**。按 v0 写好的剧本一个字都不用动，照样能播。完整规格见 `协作/演出/剧情演出语法.md`（作者 2026-10-22 拍板）。

## 一、没变的
- 场景头 `@场景 章-节 地点·时间 BGM:情绪`
- 台词 `角色名（表情）：台词`，七种表情；心声 `（心声）`
- 一条台词一页、≤ 2 行、每行 ≤ 14 字
- 【登场 / 退场 / 移动 / 镜头 / BGM / 音效 / 震动 / 闪白 / 等待 / 选择 / 自由：描述】
- 【战斗 敌方：…；胜利条件：…】只写占位，不写数值

## 二、新增的写法
| 新增 | 写法 | 用途 |
|---|---|---|
| 表情 + 心声 | `甲（悲·心声）：` | v0 写了心声就丢了表情 |
| 显示名 | `甲〈？？？〉（怒）：` | 身份还没揭晓的人 |
| 旁白 | `旁白：…` | 无头像的叙述 |
| 手动断行 | 台词里写 `／` | 想控制在哪里换行 |
| 场景头可选项 | `地图:键`、`字幕:关` | 指定地图；不显示地点字幕 |
| 指令 | 【关窗】【字幕】【淡入】【淡出】【窗口 甲 上】 | 让出画面、章节字幕、转场、指定上下窗 |
| 分支 | 【标签】【跳转】【设定】【如果】 | 选择之后跳到哪；记旗标 |
| 占位 | 【战斗 …；败北条件：…；败北：标签】【教学 主题】 | 败北走向；细纲里的「游戏功能介绍挂载槽位」 |

## 三、说清楚了的（v0 没写明，现在定了）
- **【】里的写法**：`【指令 参数 参数 键：值；键：值】`；位置写 `格(x,y)`、锚点名、`屏外左/右/上/下` 或单位名。
- **「」（）不用写**，播放器自动加；写了会被去掉并提示。
- **计字**：汉字、全角标点算 1；`……` `——` 算 2；半角算 ½；自动加的「」不算。行首不能是 。，、！？……」）。超过 2 行是错误，要自己拆成两条台词。
- **选择**：2～3 项，每项 ≤ 12 字，每项都要指向一个【标签】。
- **注释**：`#`、`>`、`//` 开头的行和空行不播放，可以放说明。
- **容错**：认不出的【】按「自由」处理（能播，但会被列出来要补）。
