## 1. 全队方针（★ 2026-10-12，作者拍板的第一件）

**用途**：把「每台下一条指令」换成**两层决策** —— 全队层一条**全军方针**（保持到改为止）+ 单位层只有大招开关。
规格书 = `协作/方向调整-全队方针与反馈.md` 第 1 节（§1.1–§1.8）。

### 1.1 `设方针(ctx, 方针)` —— 全队层

```
设方针(ctx, { 类型, 目标位 }) → ctx
```

| 参数 | 说明 |
|---|---|
| `ctx` | 一次战斗的状态（`开局()` 给的） |
| `类型` | `'全军突击'`（默认）/ `'集中攻击'` / `'攻击后排'` / `'前守后攻'` / `'全军防御'`。**认不出来的当「全军突击」** |
| `目标位` | 只在 `'集中攻击'` 用：敌方**格子号**（`0..8`）。没给 / 那一格已经不活 → 引擎当成「全军突击」 |

- **返回**：同一个 `ctx`（`ctx.方针` 已经改好）。
- **保持到改为止**：回合之间**不重置**；`开局()` 里每一场新战斗是「全军突击」（§1.3 第 1 条）。
- **集中攻击的目标被击破 → 自动回全军突击**，并在**下一个回合开始**写一条
  `〔方针〕集中攻击的目标 X 已击破，恢复全军突击`（判定在 `60-战斗.js` 的 `方针回合()`，读格子号）。
- **备注**：这条**不消耗随机数**；`simulate(…, {}, …)`（不下方针）与改动前「全员进攻」**逐字相同**（§1.8 第 1 条，硬验收）。

### 1.2 `设单位开关(ctx, 开关表)` —— 单位层

```
设单位开关(ctx, { [位]: { 保留大招, TRANSAM, 本回合开TRANSAM } }) → ctx
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `保留大招` | `false` | `true` = 这一回合**不放大招**（推迟，不是作废） |
| `TRANSAM` | `'自动'` | `'手动'` = 天人的 TRANS-AM **不自动开**，等玩家点 |
| `本回合开TRANSAM` | `false` | 手动档下「这一回合点开」（点一次只管本回合） |

- **返回**：同一个 `ctx`。**没写的位 / 没写的字段一律不动**（沿用上一回合）。
- **备注**：这三个字段原来和「类型 / 目标位」挤在同一张逐台指令表里；现在**单位层只剩它们三个**。

### 1.3 `window.__game` 上的相关入口

| 名字 | 用途 |
|---|---|
| `设方针` / `设单位开关` | 上面两个（★ 新增） |
| `方针们` | `['全军突击','集中攻击','攻击后排','前守后攻','全军防御']`（界面画按钮的顺序） |
| `默认方针()` / `规整方针(p)` / `当前方针(ctx)` / `方针目标(ctx)` | 方针对象的小工具（`当前方针(ctx)` 永远有值） |
| `禁止攻击(u, ctx)` / `按防御结算(u, ctx)` | 「这条方针禁止我攻击吗」/「这一下按防御姿态结算吗」（§1.3 第 5 条） |
| `是方针对照表(方针)` / `第几回合的方针(方针, 回合)` | `simulate()` 的「按回合的表」那两个工具 |
| `方针回合(ctx)` | 回合开始时落地 + 「目标被击破 → 回突击」的那一步 |
| **`设指令`** | **已删除**（`window.__game` 上不再有；`60-战斗.js` 里那个内部函数也一起删了） |

### 1.4 `simulate(我方, 敌方, 方针, 种子, 选项)`

`方针` 三种写法（§1.6）：

1. **一条方针**（整场不变）：`'全军防御'` 或 `{ 类型: '集中攻击', 目标位: 4 }`；
2. **按回合的表**：`{ 1: '全军防御', 2: '全军突击' }` —— 表里**没写的回合沿用上一回合**；
3. `{}` / `null` / **不传** = **整场全军突击**。

**返回值不变**：`{ 结果, 原因, 回合数, 记录, 我方, 敌方, 种子, ctx }`。

## 2. 战斗记录（`ctx.log` 的字段）

- **`类型` 取值**：`开始 / 回合 / 攻击 / 修理 / 增益 / 再动 / 防御 / 回复 / 跳过 / 指挥 / 增援 / 嘲讽 / 连斩 /
  残月余响 / 势力 / Boss / 方针 / 结束`（★ 新增 **`方针`**）。
- ★ **2026-10-12 起，攻击记录里这三个字段不再会产生新值**，但**字段本身保留**（值恒为默认），
  这样默认路径的记录格式**一个字节都不变**（§1.8 第 1 条）：
  `集火: false` / `守护挡下: false` / `原目标: null` / `原目标位: null`。
  （实测：改动前的 39 场 / 1638 条记录里，这四个字段**一个 true / 非 null 都没有**。）
- **新增记录**：`类型: '方针'`，文本 `〔方针〕集中攻击的目标 X 已击破，恢复全军突击`，
  字段 `{ 方针, 原方针, 目标位, 目标名, 回合 }`。
- **不再有的记录**：`〔守护〕…替…挡下这一击`、`〔换位〕…换位到…`（机制已删，§1.4）。
- **单位的 `u.指令` / `u.指定目标位` / `u.守护对象` 三个字段已删**：谁都不许再读写它们。
  要「这台单位这一回合做什么」，读它行动时写下的那条记录。

## 3. 界面层（`界面` 对象，测试与肉鸽界面会读）

| 名字 | 说明 |
|---|---|
| `界面.方针` | `{ 类型, 目标位 }`（**保持到改为止**；每一场新战斗重置成全军突击） |
| `界面.单位开关` | `{ 位: { 保留大招, TRANSAM, 本回合开TRANSAM } }`（★ 旧名 `界面.指令` 已删） |
| `界面.选方针(类型)` | 全队层：选一条方针（选「集中攻击」→ 进入选目标状态） |
| `界面.点敌人(位)` | 「集中攻击」的目标：点一张敌方卡片 |
| `界面.切大招(位)` / `界面.切TRANSAM(位)` / `界面.开TRANSAM(位)` | 单位层三个开关 |
| `界面.当前指令(位)` | 这一台的开关（名字沿用旧名，**只含单位层三个字段**） |
| 动作表 `data-act` | `方针:<类型>` / `点敌人:<位>` / `选单位:<位>` / `大招:<位>` / `TRANSAM:<位>` / `开TRANSAM:<位>` |
| **已删** | `界面.下指令(类型)` / `界面.点队友(位)` / `界面.指令` / `data-act="指令:<类型>"` |

- **界面显示口径（§1.7）**：指令阶段战场上方一条**方针栏**（5 个按钮、当前高亮）；**战斗中也一直显示**；
  被「集中攻击」点名的敌机卡片上一直挂「集中攻击（全队打它）」标记（引擎回到突击时它自动消失）。
