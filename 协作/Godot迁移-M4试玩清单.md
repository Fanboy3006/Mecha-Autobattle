## §1 第一优先：D-01 打牌体感（作者签字项，最重要）

**规则事实**（`Godot迁移-ARGON验收对照表.md` §1，已落盘并测试覆盖）：
默认五人队正式开局手牌是 **6 张**——

```
激励 · 乱射 · 满月·星落 · 突击号令 · 月光祈愿 · TRANS-AM 解放
```

其中 **4 张职业牌进「候补」**，不在开局手牌里；它们会在后续回合按条件逐回合补位。
**「一张不丢」**：手牌 + 候补 = 全部初始牌。

### 请只回答一个问题

> **「职业牌开局不在手」是否比「角色牌永远进不了手」更好？**

### 要看的三个现象（在战斗屏底部手牌栏看）

| # | 看什么 | 在哪看 | 期望 |
|---|---|---|---|
| 1.1 | **开局手牌里是不是角色牌在、职业牌不在** | 战斗屏底部手牌栏 | 6 张，全是角色牌 / 势力牌 / 统帅牌 |
| 1.2 | **候补栏有没有真的把手牌之外的牌列出来** | 手牌栏的「候补」区域（**M4-3 重点展示区**） | 能看到那 4 张职业牌的名字与张数 |
| 1.3 | ★ **候补会不会真的补进手牌** | 战斗日志里找 `〔发牌〕手牌有空位 → 补入初始牌【X】` 这种行 | 见下方**重要提醒** |

> ⚠️ **重要提醒（ARGON 实测后补的，直接决定您怎么试玩）**：
> **候补补位的触发条件是「回合初手牌 < 初始上限 6」**，而战斗平均只有 **2~4 回合**。
> ARGON 用同一场战斗跑了两遍，结果完全相反：
> - **一张牌都不打** → 手牌被「条件发牌」顶到 10 → **候补补位 0 次，那 4 张职业牌全程进不来**；
> - **能打就打（第 1 回合打 9 张）** → **候补补位 4 次，4 张全补进手**。
>
> 所以请您**特意试两种玩法**（这一场少出牌 / 这一场猛出牌）再答下面的签字问题。
> **顺带**：日志里**没有**「候补补位」这四个字（原文是「手牌有空位 → 补入初始牌【铁壁】」）——
> 它在结构化字段 `触发条件码` 里，界面高亮读的就是那个字段，**不是 bug**。

> ✅ **已修（复核期第 6 个缺陷）**：**「推进剂用光 → 追击战」这条线原本完全没接线，会当场卡死**
> （走不动也打不了）；而且**触发时机**也和 JS 原版不同（JS 是「**这一格结算完**才触发」，
> 当时是「走上去就触发」→ 用最后 1 点推进剂落在作战格时那一格节点战会被跳过）。
> **两条都已修好并加了回归断言**，所以您现在遇到的应该是：**先结算这一格，结算完才打追击战**。
> 若您在「推进剂用光」这件事上看到任何不对劲，请直接告诉 ARGON。

### 顺带回答的两个手感问题（`ARGON验收对照表` §6.2）

- **出牌节奏**：手牌常年 **6 张**是否够用？想不想更多？
- **高费出口**：耗气 **100** 的统帅牌靠 `气势 ≥ 75` 触发，**够得着吗**？

## §2 第二优先：一局肉鸽能不能完整打通

按这条链子走一遍，**哪一环断了就停在哪一环并告诉 ARGON**：

```
主菜单 → 开始新肉鸽（选分队 [+ 可选种子]）
  →
  ★★ 【第一步是必做的：招募】开局名册是【空的】、分队不带机体、手上只有 3 张招募券
      走顶栏「名册 / 招募 / 晋升」→ 用券招人 →（顺手）「编队」把招到的摆上去
      —— 不招募的话出击 0 台，任何战斗格都进不去
  →
  正方形大地图（悬停格子看「推进剂消耗」+「退路成本预告」）
  → 【走上去就该自动触发】作战 / 精英 / 侵蚀源 / 出口守军 → 直接进战斗屏
  → 战斗屏打牌 → 自动打完 / 逐回合推进
  → 战后结算屏（胜负 / 存活回血 50% 前后 / 源碳·希望·招募券·藏品·零件）
  → 继续前进 → 休整 / 黑市 / 奇遇(事件) / 瞭望站 / 遗迹（走上去自动结算）
  → 3 选 1 战术牌 / 晋升
  → 走到出口（尽头要先打赢守军 / 小径免守军 / 隧道）→ 自动换层 → …… → 第 4 层通关
```

> ⚠️ **ARGON 实测补的两条**（2026-10-16，两条都很容易让人以为「游戏坏了」）：> 1. **名册开局就是空的**（`RosterManager.new_run` 的注释明写「名册是空的、分队不带机体；开局发 N 张招募券——去招募屏用券招人」）。
>    **不是 bug**；但**不先招募就寸步难行**。若大地图上没有提示，请告诉 ARGON（我已让施工方加提示）。
> 2. **「走上去要自动打」是 JS 原版的行为**：封存 JS 里点格子 = `去节点` = **移动 + 立刻按节点类型结算**（`80-界面-5-肉鸽接线与节点.js:207-222`），
>    **没有**「先移动、再点一次才进节点」这种做法。ARGON 用自动驱动器跑出过「**0 场战斗直接通关**」，
>    已回退给施工方修（要验的就是：**走上去就开打，不用点第二次**）。**若您试玩时还能「路过战斗格而不打」，那就是没修好，请立刻告诉 ARGON。**

| # | 检查项 | 期望 | 作者判定 |
|---|---|---|---|
| 2.1 | 顶栏常驻状态条 | 层数 / 推进剂 `当前/上限` / 源碳 / 希望 / 基地耐久 / 等级经验 / 出击上限 / 藏品栏 / 零件栏 **都在** | |
| 2.2 | 大地图 | `5×5 ~ 7×7` 网格，13 种节点**图标或名字能分得清**；当前所在格、已走过、必经点看得出来 | |
| 2.3 | 悬停/选中预告 | 显示推进剂消耗，**并有退路成本预告** | |
| 2.4 | 编队 | **8 格 = 前排 4 + 后排 4（正交 4×2）**；点上阵 / 下阵 / 换位都生效 | |
| 2.5 | 3 选 1 弹窗 | 只在有待选牌时弹；每张显示 层级 / 归属 / 气势消耗 / 冷却 / 触发条件 / 效果说明 | |
| 2.6 | 黑市 | 能买、能刷新、能卖零件、能离开；买价受 `f1` 藏品影响的部分看得出来 | |
| 2.7 | 零件主动使用 | 点零件 → 大地图**高亮合法目标格**（照 `part_targets`）→ 用掉后次数减少 | |
| 2.8 | **存档 → 读档** | 中途「保存并返回主菜单」→「继续游戏」→ **回到原样**（Web 版另用无痕/非无痕各试一次） | |
| 2.9 | 通关闭合 | 第 4 层打完能到「通关」结算，**不是卡住** | |
