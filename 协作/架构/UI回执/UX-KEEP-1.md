# UX-KEEP-1 回执：招募券留存 + 开局随机种子（作者 10-22 试玩反馈）

## 反馈
- 第一仗打完卡住：没有留存招募券的选项，希望不够时招不了，又不能不招。
- 开局种子不必每次一样，随机给一个号码，想复现再记号码。

## 规则（见 `协作/设计/招募券留存规则-v0.1.md`）
- 招募券最多留 3 张（`90-肉鸽-1` 新字段 `券留存上限: 3`，读口 `RosterManager.券留存上限()`）。
- 「必须先决定」只在两种情况：手上 > 3 张；名册还是空的且有券（`SessionRosterFacade.有未决的券`）。
- 其余时候招募面板可以关：同一颗收尾按钮显示【暂不招募 · 返回大地图（留着 N 张券）】（刚开局：【暂不招募 · 去编队…】）。
- 走格子 / 追击战 / 弹窗关闭的拦截都改走 `有未决的招募券()`。
- 招募面板的提示行 + 按钮行挪到面板最上面（说明下方），小窗口不会被挤出屏幕。

## 开局种子
- 菜单的种子框每次随机给一个 8 位号码（`MenuView.随机种子()`），留空也随机。
- 顶栏「第 N 层」悬停显示本局种子。
- `test_layout_flow` 点「开这一局」前把种子框钉成 20261016，保证可复现。
