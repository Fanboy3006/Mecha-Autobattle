# SWAP-RC-a 回执：换位引擎底座（`swapPos` + 刷新链）

> 2026-10-21 · 路线图第 3 项的前半 · 依据 `协作/设计/影世界势力卡牌设计 v0.2.md` §8（月球王国 v0.2.1 §8 是同一份底座）。
> 本批**只做共用底座**，不做影世界 / 月球王国的任何卡牌与数值（作者 10-21 明确）。

## 交付

| 东西 | 位置 |
|---|---|
| 换位原语 + 6 项刷新链 | `godot/core/battle/swap.gd`（`BattleSwap`） |
| 单位断言 51 条 | `godot/tests/unit/test_swap.gd` |

- **`BattleSwap.换位(ctx, side, posA, posB, opts)`**：同方阵内互换 / 移入空格，返回实际改变格子的存活单位数 `k`（0/1/2）；
  两格都空、`posA == posB`、越界、不认识的一方 → 返回 0、不写任何状态。
- **两步权限边界**：`side` 只认 `ally` / `enemy`，**绝不跨阵**（`合法吗` 里挡掉 8 以上与未知方）。
- **6 项刷新链（按 §8.2 的顺序，一个随机数都不掷）**：
  1. 坐标 + 顶位：坐标当场写回；顶位是纯读现算（`Fm.是否顶位`），变化时补一条〔换位顶位〕战报。
  2. 移位计数：`opts.isShadowCard` 为真才累加 `ctx.turnShiftCount` / `battleShiftCount`、给移动过的单位挂〔错位〕；
     `ctx.abyssGateActive` 时对移位的敌机各结算 700 点特殊伤害（每台每回合≤3 次）。
     **月球王国侧的「随侍数」走新钩子 `RuleHooks.顺序["换位后"]`（现为空表 = 无副作用）**，将来它自己注册，`swap.gd` 不用改。
  3. 〔掩护〕连线：不需要重建缓存（`BattleGuard.当前援护连线们` 本来纯读现算），**只保证不动别人的 `掩护剩余`**。
  4. 敌方意图：见下。
  5. 武器 / 大招可用性：`DeckFlow.刷新实时门槛(ctx)`（只重算「亮起条件」，`处理者` 管的槽不重算 —— 它们的大招阶段初带副作用）。
  6. 手牌高亮：表现层纯读现算，本批不改。
- **三步确定性规则（§8.2 第 4 项）**：换位前读 `ctx.敌方意图表` 做快照，换位后按
  ① 原武器原目标仍合法 → 保持；② 原武器可用、原目标不可达 → 同武器按 AI 规则换目标；
  ③ 原武器在新位置用不了（近战被挪到后排）→ 改用可用远程武器，没有就 `〔射程不达 · 待机〕`。
  结果写成 `unit["换位意图锁定"]`（带 `回合`），**预告与实战同源**：`BattleIntent.算意图` 与
  `Boss.bossAction` / `Boss.bossTurn` 都经 `BattleSwap.锁定动作` 这一处读同一把锁（R4）。
- 没有换位时 `锁定动作` 恒返回 `null` → 原有 AI 一个字节都不受影响（`test_swap` ⑨ 有断言）。

## 顺带的地方（都为这一步服务，且零影响）

- `Ai.enemyAction(actor, ctx, 仅远程 = false)`：新增第三参（默认 false = 老行为），第三步 3a 用它按同一套 AI 规则挑远程武器。
- `Boss.bossTurn`：没有 Boss 脚本的敌机原本 `直接 Ai.enemyAction`、绕过了锁定；改为走 `bossAction`（同一条链）。
- `BattleGuard.是掩护者 / 掩护额度`（额度 = 2 + `掩护补充`），`AtxDuo` / `CelestialV01` 的重置点改读它；
  `BattleLog.援护剩余文` 的 `/2` 同步。`掩护补充` 缺省 = 0 → 文案与数值与从前逐字相同。
