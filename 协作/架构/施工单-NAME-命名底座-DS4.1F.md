## 0. 目标与边界
- **目标**：以后去版权化统一改名时，**只改数据表，不改代码**。
- **不改名**：本单不把任何名字换成新名，玩家看到的文字一个字不变。所以原生样例应**逐条不变**；如有差异，停下报告。
- **内部 id 不动**：单位键（S1、CB1…）、卡 id、势力 id（`tags.势力` 里的「天人」「秘银」等）、状态字段名（如 `λ驱动`、`本回合打过Veda`）都属于内部 id，**保持原样**。只有**玩家会看到的文字**要走显示名表。
- 参考名单：`协作/设计/改名对照表 v0.1.md` 的「原名」列（人名、机体名、势力名、组织 / 舰船、机制关键词、招式 / 牌名、台词牌名）。

### 二、显示名表放哪、长什么样（改上文 NAME-2 第一条）

### 三、取名入口
- 新文件 `godot/core/data/display_names.gd`，`class_name DisplayNames`，纯读 `Db.T`：
  - `static func 名(类别: String, id: String, 兜底: String = "") -> String`：表里有就用表里的；没有就返回 `兜底`，`兜底` 为空则返回 `id` 本身。
  - `static func 卡名(卡: Dictionary) -> String`：`卡牌` 区有 `卡.id` 的覆盖就用覆盖，否则用 `卡.名`。
- 改调用点时**句子模板不动**，只把名字换成调用，例如 `"〔TRANS-AM〕%s 的 TRANS-AM 结束"` → `"〔%s〕%s 的 %s 结束" % [TA, 名, TA]`，其中 `TA := DisplayNames.名("关键词", "TRANS-AM")`。
