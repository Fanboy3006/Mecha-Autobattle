- 每张带 `获取`（初始 / 剧情 / 肉鸽三选一）→ 解锁等级 10 / 20 / 30；`+` 版 Lv20 起**替换**（名字带 `+`），数值写在 JSON 的 `武器参["+"]`。
- 装填走 `RuleHooks.装填单位`（内核只认钩子）；大招槽卡由 `DeckFlow.拆分单位牌` 归位，入场牌另由 `装填大招槽` 补。

二、机制落地
- **METEOR 锁定链**：`METEOR·锁定 1` 不销毁主武器，`DeckFlow.压栈武器栏(u, [锁定 2, 发射], "METEOR")`；锁定 2/3 再压一层；`发射`（或「我方阶段末」自动发射）判定 **1 次 QTE**、按锁定顺序逐发 2200 直射光束、命中 −20（武装损伤、同源增益不叠加）、目标已死按「同排 → 任意」转火；结束后 `弹栈武器栏`。可重复锁同一台（挨两发）。
- **贯穿一列**：用现成的 `area = pierce` + `pierce_mul = 1.0`（主目标 + 同列另一排各 100%）。
- **斩首 N%**：挂 `武器攻击后` 钩子，每个被打中的目标各自判「0 < hp ≤ 上限 × N%」→ 直接击破；`不杀中` 标记优先。
- **破隐一击 / 死神的收割**：`无视前排` 是武器上的通用标记（`reach.gd` 的近战可达见到它就直接按真实位距判），因此近战能打敌方后排；必中 + 必暴 + 斩首 35%/25%。
- **旋转破坏步枪**：`武器攻击后` 收尾时 `结束觉醒` → ZERO 结束、入场牌冷却 3、暴伤回 ×2.0。
- **精神牌**：统一走 `"colonial"` 算子的「动作」（战意 / 友军战意 / 增益 / 队友增益 / 下张武器 / 抽精神 / 抽公有 / 减伤 / 标记 / 锁定目标 / 零的预见 / 自损 / 压住ZERO / 自爆装置 / 干扰器 / 破隐降费 / 再次潜伏），代价与一次性标记统一收尾。
- **光束反射装甲**：受方 ×0.5，`受击后` 把实受的一半反射给攻击者（直射光束才反射）。
- 新增钩子/接线：`区规则门槛`、`副武器门槛`、`我方阶段末` 接上 `ColonialV01`；`条件值` 新增「本场开过 / 觉醒中 / 打出过破隐一击」。**core→faction 棘轮仍是 116 / 120**。
