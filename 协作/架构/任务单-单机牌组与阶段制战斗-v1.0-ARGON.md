## §1 作者正式拍板的 7 条核心定案（最高权威，施工必守）

1. **阶段制与敌方行动顺序（问题 1 拍板）**：
   - **我方阶段**：完全取消速度顺序。玩家可任意点选切换要操作的我方机体（也可切回已打过主武器的机体继续打精神牌/衍生攻击卡/公有牌），点「结束回合」后未打过主武器的机体由 AI 自动补打 1 张主武器卡，随后进入敌方阶段。
   - **敌方阶段**：按**敌方阵型格位编号顺序（`前1..前4` → `后1..后4`，即 `slot 0 -> 7`）**依次行动。速度（`speed`）彻底退出行动排序，仅保留命中/闪避公式修正。
2. **「压制射击」彻底从架构删除 & 「再动」统一为「主武器卡回手」（问题 2 拍板）**：
   - **删除压制射击（Overwatch）**：从单机牌组架构及 UI 预告中**完全删除「压制射击」概念**（旧分支仅在 `单机牌组.开 == false` 的封存黄金样例兼容路径下静默保留，新模式零压制射击）。
   - **再动（Again）= 主武器卡回手**：凡触发【连续攻击】或任何【再动】效果（如 W17·中继、秘银接管站位），统一将目标机体的 **`u.主武器已销毁 = false`**，使其所有主武器卡恢复可打出状态（冷却中的仍受冷却限制）。
3. **双排手牌容量与抽牌标尺（问题 3 拍板）**：
   - **上排（选中机体的专属牌）**：
     - 左区 **常驻主武器卡**（固定在手，每回合初全部恢复，不占抽牌上限）；
     - 右区 **专属抽牌（角色大招牌 + 专属精神牌 + 衍生攻击卡）**：**开战起手 `2` 张，每回合初抽 `1` 张，手牌上限 `4` 张**。
   - **下排（全队公有牌：势力牌 / 职业牌 / 统帅牌 / 公共衍生牌）**：
     - **开战起手 `3` 张，每回合初抽 `1` 张，自然抽牌上限 `6` 张，衍生/条件塞牌硬上限 `8` 张**。
4. **个人资源改名为「战意（Will / Morale）」，从 `0` 起算（问题 4 拍板）**：
   - 废除「气力」旧称（机战的气力从 100 起算，与本系统的能量槽语义不同），全系统与 UI 统一命名为 **「战意」**（字段名 `u.战意`）。
   - **战意数值初稿**：
     - **开场初始战意：`0`（或由特定分队/藏品提供开场加成）**，上限 **`100`**；
     - **每回合我方阶段开始：`+5` 战意**；
     - **攻击行动命中（至少 1 段命中）：`+2` 战意**（按攻击行动计，不按段数乘算）；
     - **被敌方攻击命中 / 成功闪避敌方攻击：`+2` 战意**；
     - **击破敌机：`+10` 战意**。
   - **谁打牌扣谁的战意**：无论打上排专属牌还是下排公有牌，一律扣除**当前选中并执行出牌的那台机体 `u`** 的 `u.战意`。
5. **取消「不被销毁」模糊标签，正式确立「主武器卡」与「衍生攻击卡」两类攻击卡（问题 5a 拍板）**：
   - **【主武器卡（Main Weapon Card）】**：
     - 包含：机体自带的常规主武器、角色大招牌、合体技、以及重装职业的「援护防御 / 铁壁架势」武器卡；
     - **销毁规则**：每台机体每回合打出一张【主武器卡】后，本回合该机其余所有【主武器卡】**立即销毁（置为本回合不可用 `u.主武器已销毁 = true`）**，下回合开始时全部恢复（触发【再动 / 连续攻击】时当场恢复）。
   - **【衍生攻击卡（Derived Attack Card）】**：
     - 包含：狙击的【援护射击】、特种的战术副武器/干扰弹、秘银的【TDD-1 导弹】等；
     - **不互毁规则**：【衍生攻击卡】**不属于主武器卡**！打出【主武器卡】**不会销毁**手里的【衍生攻击卡】；打出【衍生攻击卡】也**不会销毁**【主武器卡】。每张【衍生攻击卡】打出后直接消耗销毁（不回库或按每回合生成次数限制）。
6. **确立「6 + 1 = 7 大兵种职业体系」（新增独立【维修】兵种，问题 5b 拍板）**：
   - 在原有 6 职业（**近卫 / 狙击 / 重装 / 尖兵 / 指挥 / 特种**）基础上，正式增设第 7 个独立兵种职业 —— **【维修（Medic / Mechanic）】**（将维诺 `M2`、苏菲 `M3` 等治疗/整备机体划归【维修】职业）：

| 兵种职业 | 阶段制标志性机制与卡牌规则 |
|---|---|
| **近卫** | **【连续攻击】**：每回合限 1 次（击破敌机后自动触发，或主动触发），令本机 `u.主武器已销毁 = false`（所有主武器卡回手，本回合可再打 1 张主武器卡）。 |
| **狙击** | **【援护射击（衍生攻击卡）】**：每回合开始（或友军使用主武器攻击同排/对位目标后），获得 1 张 **【援护射击】衍生攻击卡**（0 战意，不受主武器销毁影响，可在主武器前后自由补枪）。 |
| **重装** | **【援护防御 / 铁壁（主武器卡）】**：重装机拥有常驻主武器卡 **【铁壁护卫】**（视为打出主武器卡，打出后销毁本回合其他攻击型主武器）：本回合自身防御大幅提升（`+50` 防御 / 减伤 `30%`）、回复 `5% HP`，并替同列后排或相邻队友承受单攻，期间每次被击战意额外 `+2`。 |
| **尖兵** | **【机动脱离】**：本回合打出主武器卡后自身闪避 `+15%`；每次成功闪避敌方攻击额外获得 `+2` 战意。 |
| **指挥** | **【战术统筹】**：由指挥机打出下排**公有牌（势力牌 / 统帅牌 / 职业牌）**时，战意消耗 **`-5`**（最低为 `0`）。 |
| **特种** | **【战术副武（衍生攻击卡）】**：每回合开始时自动置入 1 张本机专属的 **【战术干扰/标定】衍生攻击卡**，可每回合打出「1 张衍生攻击卡（先挂破防/干扰状态）+ 1 张主武器卡」组合。 |
| **维修**（新增） | **【战地维修】**：常驻主武器卡为 **【紧急修理】**（指定我方单体回复大量 HP 并清除负面状态）；且每回合或达成条件可产出 **【应急补丁 / 纳米修复】衍生卡**（小额顺发抬血，不占主武器行动），解决阶段制下全队治疗匮乏问题。 |

7. **肉鸽双轨成长模型（问题 6 拍板）**：
   - **上排（单机专属牌库）**：跟随**机体晋升（Lv10 → Lv20 → Lv30）与整备**成长（Lv10 带基础主武器 + 初始角色牌；Lv20/Lv30 解锁高阶大招牌入专属库并提升倍率）；
   - **下排（全队公有牌池）**：跟随**战后三选一 + 黑市买牌/删牌**成长（产出势力牌 / 职业牌 / 统帅牌）。

## §2 四阶段施工拆解（`DECK-1 ~ DECK-4`）

### 子任务 `DECK-1`：阶段制内核 + 单机战意（0 起算）+ 主武器卡/衍生攻击卡 + 7 职业被动底座
- **归属模块**：
  - `godot/core/battle/params.gd`
  - `godot/core/battle/units.gd`
  - `godot/core/battle/setup.gd`
  - `godot/core/battle/flow.gd`
  - `godot/core/battle/btl.gd`
  - `godot/core/battle/calc.gd`
  - `godot/core/battle/ai_deck.gd`（新增：确定性 AI 选牌器）
  - `godot/data/js/12-档位职业.json` · `10-数据.json`（仅在单机牌组开关或扩展表下将维诺/苏菲等修理机体映射为 `维修` 职业）
- **具体规格**：
  1. **总开关 `单机牌组.开`（默认 `false`）**：
     - `Params.单机牌组_开(ctx)` 默认返回 `false`，确保既有 **168 场战斗黄金样例与 1785 项旧测试 100% 零改动全绿**；
     - 在 `GameSession` 新开肉鸽/快速战斗（或显式开启开关）时启用单机牌组阶段制。
  2. **单位初始化（`units.gd` / `setup.gd`）**：
     - 每台我方单位初始化：
       - `u["战意"] = 0`（上限 `100`）；
       - `u["主武器已销毁"] = false`；
       - `u["连续攻击已用"] = false`；
       - `u["专属牌库"]` / `u["专属手牌"]`（起手抽 2 张，上限 4 张）/ `u["专属弃牌堆"]`；
       - `u["衍生手牌"]`（存放本回合生成的【援护射击】【战术副武】【应急补丁】等衍生攻击/支援卡）；
     - 全队初始化：`ctx["公有牌库"]` / `ctx["公有手牌"]`（起手抽 3 张，自然抽牌上限 6 张，塞牌硬上限 8 张）/ `ctx["公有弃牌堆"]`。
  3. **完全移除压制射击**：
     - 当 `Params.单机牌组_开(ctx) == true` 时，`runOverwatch` / `hasOverwatch` 直接短路返回，不执行任何压制射击。
  4. **三段式回合流转（`PLAYER_START` → `PLAYER_MAIN` → `ENEMY_PHASE`）**：
     - `Btl.开始我方阶段(ctx)`：回合 `+1`，我方存活单位 `战意 = min(100, 战意 + 5)`，`主武器已销毁 = false`，专属牌库各抽 1 张，公有牌库抽 1 张，按 7 职业规则派发本回合初始衍生卡（狙击【援护射击】、特种【战术副武】等），调用 `Btl.算意图(ctx)`；
     - `Btl.打出主武器卡(ctx, unit_id, weapon_or_card_id, target_id)`：
       - 检验 `not u.主武器已销毁` 且 `u.战意 >= 费用` 且冷却就绪；
       - 扣 `u.战意` → 执行武器攻击 / 大招效果 / 重装【铁壁护卫】 / 维修【紧急修理】 → 置 **`u.主武器已销毁 = true`**（合体技则置所有参与者 `主武器已销毁 = true`）；
       - 若近卫本次攻击击破敌机且 `not u.连续攻击已用`，自动触发 **【连续攻击】**：`u.连续攻击已用 = true`，`u.主武器已销毁 = false`，写日志 `〔近卫·连续攻击〕【…】主武器卡全部回手！`；
     - `Btl.打出衍生攻击卡(ctx, unit_id, card_inst_id, target_id)`：
       - 扣 `u.战意` → 执行攻击/效果 → 从手牌移除销毁，**不修改 `u.主武器已销毁`**；
     - `Btl.打出精神或公有牌(ctx, unit_id, card_inst_id, target_id)`：
       - 校验 `u` 的职业/势力与牌面 `归属` 对口（指挥职业打公有牌享受 `max(0, 费用 - 5)` 减免），扣 `u.战意` → 执行效果（若效果含 `再动`，则令目标机体 `主武器已销毁 = false`），**不修改 `u.主武器已销毁`**；
     - `Btl.结束我方回合(ctx)`：
       - Step A：按格位 `0..7` 遍历我方 `not u.主武器已销毁` 的存活机体，调用 `AiDeck.auto_play_unit_main_weapon(ctx, u)` 自动打 1 张主武器卡；
       - Step B：按敌方格位 `0..7`（`前1..后4`）顺序依次执行敌方行动；
       - Step C：执行回合末结算，若战斗未结束则自动调 `Btl.开始我方阶段(ctx)` 进入下一回合。

### 子任务 `DECK-3`：战斗屏 UI 改版 —— 点选机体 + 战意条 + 上下双排手牌栏 + 即时 0.5s 演出

- **具体规格**：

  2. **底部双排手牌栏（`battle_view.gd`）**：
     - **上排：`【当前选中机体：XXX（职业·势力）｜战意 N/100】专属排`**：
       - 左侧为 **【主武器卡】**（含常规主武器、已抽到手的角色大招、重装【铁壁护卫】、维修【紧急修理】）：当 `u.主武器已销毁 == true` 时，所有主武器卡标 `〔本回合已销毁〕` 置灰；
       - 中间为 **【衍生攻击卡】**（如狙击【援护射击】、特种【战术副武】、维修【应急补丁】）：带青色边框，标 `〔衍生·不毁主武〕`，打完主武器后依然亮起可点；
       - 右侧为 **【专属精神牌】**（不限张数，够战意即可打）。
     - **下排：`【全队公有排（势力牌 / 职业牌 / 统帅牌 / 公共衍生牌）】`**：
       - 显示全队公共手牌（含秘银 `TDD-1 导弹` 等公共衍生攻击卡）；
       - **动态身份置灰**：当牌面 `归属` 为某职业或某势力，而当前选中的机体 `u` 不属于该职业/势力时，卡片自动置灰并标 `〔需：近卫〕` / `〔需：秘银〕`；当切换到对口机体时立即亮起（若当前选中指挥机，公有牌自动显示 `战意消耗 -5` 折后价）！
  3. **每次打牌立即播放 0.5s 动画 + 「结束回合」与「全员托管」**：
     - 玩家每点打一张主武器卡或衍生攻击卡，立即触发 `UX-5` 的 `0.5s` 单步攻击动画（前冲 + 指向箭头 + 受击飘字）；
     - 原「下一回合」按钮改为 **「结束我方回合」**：点击后按 `0.5s/步` 依次播完「未操作机体 AI 补打主武器」与「敌方 `0..7` 格依次行动」的动画队列；
     - 保留 **「全员自动回合」** 与 **「跳过直达结算」** 按钮。

### 子任务 `DECK-4`：秘银 v0.2 & ATX v0.2 卡表接入双排与双轨肉鸽成长
- **归属模块**：
  - `godot/core/battle/mithril_v02_cards.gd` · `fac_mith.gd` · `fac_atx.gd`
  - `godot/core/run/deck_builder.gd` · `node_resolver.gd`
  - `godot/session/game_session.gd`
- **具体规格**：
  1. **卡表分流**：
     - 角色专属牌（宗介/克鲁兹/毛/克鲁佐/杨、响介/艾克塞琳/布利特/楠叶/龙虎王等）归入对应机体的 `专属牌库`：其中占行动的攻击牌标为 `卡类: "主武器卡"`，纯增益/回战意牌标为 `卡类: "专属精神牌"`，克鲁兹/狙击的援护类标为 `卡类: "衍生攻击卡"`；
     - 秘银势力牌、ATX 势力牌、职业牌、统帅牌归入全队 `公有牌库`；`TDD-1 导弹` 置入 `公有手牌` 并标为 `卡类: "衍生攻击卡"`（打出不销毁主武器，且推进秘银连携计数）。
  2. **合体技规则更新**：
     - 合体技（如 ATX【轮盘双响】）要求两名参与者均存活且 **`not 参与者.主武器已销毁`**；打出后同时扣除发起者战意并将两名参与者的 `主武器已销毁` 均置为 `true`。
