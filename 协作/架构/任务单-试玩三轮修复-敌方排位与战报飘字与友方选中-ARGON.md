## §1 问题根因与修复规格

### 1.1 【P3-1】4×4 棋盘敌方前后排槽位翻转修复（`presentation/battle/battle_view.gd`）
- **现象**：作者指出「敌方的前排应该是在第二排，从上到下应该是：敌方后排、敌方前排、我方前排、我方后排」。
- **根因**：`battle_view.gd:_建一方()` 对敌方 `行序.reverse()` 先建 `第1排`（后排，视觉最上排）再建 `第0排`（前排，视觉第二排，贴战线），但把 `UnitCard` 按视觉创建顺序 `卡们.append(卡)` 存入 `_敌方卡`。结果 `_敌方卡[0..3]` 是视觉第一排（后排盒），而 `_填一方`、`_敌意`、`_卡(方, 位号)` 全部把数组下标当成 `slot (0..3=前排, 4..7=后排)` 使用，导致 `slot 0..3` 的敌方前排机体被填进了最上排的后排盒里，而 `slot 4..7` 的敌方后排机体被填进了第二排的前排盒里！
- **修复要求**：
  1. 在 `battle_view.gd:_建一方()` 中，保持视觉行盒顺序不变（敌方仍是上排 `敌后排`、下排 `敌前排` 贴近中央战线；我方仍是上排 `我前排` 贴近中央战线、下排 `我后排`）；
  2. 将 `卡们` 固定为按 **`slot`（`0..7`）索引** 的数组：先 `卡们.resize(8)`，在循环内用 `var 格位 := int(Fm.slotOf(行, 列号))`（即 `行 == 0` 为 `0..3` 前排，`行 == 1` 为 `4..7` 后排），执行 `卡们[格位] = 卡`；
  3. 同步将行盒标题明确标为：敌方第 1 排（`行==1`）显示 `敌后排`、第 0 排（`行==0`）显示 `敌前排`；我方第 0 排显示 `我前排`、第 1 排显示 `我后排`；
  4. 检查 `_填一方`、`_敌意`、`_卡`、`_命中机体卡` 等所有遍历 `_敌方卡` / `_我方卡` 的地方，确保索引 `i` 均代表真实的 `slot (0..7)`， waardoor 敌方前排（如 `盾卫·靶机 slot 0`）严格显示在第二排（贴近战线），敌方后排（如 `突击兵·靶机 slot 4`）严格显示在第一排（最上方），且弹道、受击飘字、援护连线全部严丝合缝！

### 1.2 【P3-2】卡牌目标阵营识别与友方拖拽选中（`session/game_session.gd` + `presentation/battle/battle_view.gd` + `core/battle/btl.gd`）
- **现象**：作者指出「还有一个 buff 友方的卡似乎没办法选中友方，给我感觉好像是 buff 敌方去了」。
- **根因**：
  1. `game_session.gd` 的 `_专属牌视图` / `_单卡视图` 没有把卡面定义的 `"目标"`（如 `"友军"`、`"秘银成员"`、`"ATX成员"`、`"U7"`、`"U6"`、`"自身"`、`"全队"`、`"敌机"`、`"敌方全体"`）完整透传到前端字典；
  2. `battle_view.gd:可拖拽释放()` 对精神牌與非衍生公有牌一律返回 `false`，且 `_拖拽目标方()` 只认修理武器和 `ATX成员` 筹码牌，其余全部默认返回 `"敌方"`！导致玩家拖不动友方 Buff 卡，或者拖起来只能吸附敌方卡；点击打出时 `target_id=""` 走了内核自动挑血量最低友军的兜底，玩家完全没有「选中友方」的操控感与反馈。
- **修复要求**：
  1. **门面透传 `目标` 与 `目标方`**：在 `game_session.gd` 的卡牌视图组装函数（`_单卡视图`、`_专属牌视图` 等所有手牌/牌库视图）中，透传 `"目标": str(卡.get("目标", ""))`，并计算统一的 `"目标方"` 字段：
     - `"友方"`：当 `目标` 为 `"友军"` / `"秘银成员"` / `"ATX成员"` / `"U7"` / `"U6"`，或 `range_kind == "修理"`，或效果含友军单体指定；
     - `"无"`（免指派直接释放，或拖到棋盘任意处松手即生效）：当 `目标` 为 `"自身"` / `"全队"` / `"敌方全体"` / `"冷却中的秘银大招"`，或无目标的纯自身/全局精神牌与战术牌；
     - `"敌方"`：主武器、副武器（非修理）、大招（攻击型）及 `目标 == "敌机"` 的进攻牌。
  2. **表现层支持拖拽选中友方 & 绿色友方瞄准线**：
     - 在 `battle_view.gd:可拖拽释放(卡)` 中：凡 `"目标方"` 为 `"敌方"` 或 `"友方"` 的可打手牌，一律支持拖拽连线释放！
     - 在 `_拖拽目标方(卡)` 中：若 `str(卡.get("目标方", "")) == "友方"`（或 `目标 in ["友军", "秘银成员", "ATX成员", "U7", "U6"]`），返回 `"我方"`！
     - 当 `_拖拽目标方 == "我方"` 时：拖拽瞄准线与准星使用**翠绿色/青绿色友方高亮**，吸附我方存活 `UnitCard`（若 `目标 == "U7"` / `"U6"` 或 `"秘银成员"` / `"ATX成员"`，优先高亮符合条件的友方单位卡），松手时将该友方的 `key` 作为 `target_id` 传给 `play_unit_card(unit_key, card_id, target_id)` 或 `play_tactical_card(card_id, target_id)`！
     - 若玩家直接点击 `"目标方" == "友方"` 的卡牌（未拖拽）：正常调用并由内核选默认友军，但在日志与飘字中清晰写出 **`→ 作用于【友军名】`**，绝不让玩家误以为打到了敌方。

### 1.3 【P3-3】公有牌带 `武器` 结算修复（`V3_F_2 火力支援请求` 等）
- **现象**：试玩实录中玩家打出公有牌 `V3_F_2 火力支援请求`，战报只写了「打出【火力支援请求】（战意 -10）」，1500 曲射伤害一发都没打出来！
- **根因**：`btl.gd:2458` 仅对 `主武器/大招/副武器` 执行 `_执行武器攻击`，公有牌走 `_执行精神效果`，而 `V3_F_2` 只有 `"武器"` 字典没有 `"效果"` 数组，被静默跳过。
- **修复要求**：
  1. 在 `btl.gd:打出单机卡` 的公有牌/精神牌分支中，若 `卡.get("武器") is Dictionary and not (卡.get("武器") as Dictionary).is_empty()`，先调用 `_执行武器攻击(ctx, 发动者, 卡, 指定目标)` 执行真实攻击结算并生成攻击摘要，再继续执行可能并存的 `"效果"` / `"动作"`；
  2. 检查 `atx_three.gd` 中 `ATX2_U3 好运加护·满开` 的 `"武器": {}` 空字典定义，判空时必须用 `not (卡.get("武器") as Dictionary).is_empty()`，防止空武器字典误触发 0 伤害攻击。

### 1.4 【P3-4】精神卡 / 公有牌 / `Uruz 全员突击` 战报明細与战场飘字可视化（`mithril_v03_cards.gd` + `btl.gd` + `deck_flow.gd` + `battle_view.gd`）
- **现象**：作者指出「有几个精神卡的效果没有体现在右边的战斗记录里面。uruz 全员突击也没有显示，感觉很怪」。
- **根因**：
  1. `mithril_v03_cards.gd` 中不少算子（如 `V3_U2_U3 Uruz 全员突击`、`再动`、`紧急支援`、`集中想象`、`连携多抽` 等）返回的摘要数组只写了牌名（如 `["Uruz 全员突击"]`），而具体效果通过 `_记` 在「打出【XX】」日志**之前**塞了一行 `类型="秘银v03"` 的记录，顺序颠倒且主日志行看不到效果；
  2. `V3_U2_U3`（毛「Uruz 全员突击」）卡面规定「不算武器牌，不销毁武器栏」，但 `mithril_v03_cards.gd:1085` 却错误写了 `施["主武器已销毁"] = true`；
  3. `battle_view.gd:_应用本拍()` 只对 `攻击/镜甲/修理/势力` 播放战场飘字胶囊，`专属精神牌 / 公有牌 / 大招槽 / 连携牌 / 秘银v03` 等非攻击卡打出时棋盘上没有任何飘字/高亮演出，所以玩家打完 `Uruz 全员突击` 或精神卡感觉「什么都没发生」。
- **修复要求**：
  1. **修正 `V3_U2_U3`（Uruz 全员突击）**：
     - 去掉 `mithril_v03_cards.gd:1085` 错误的 `施["主武器已销毁"] = true`（严格遵守卡面「不算武器牌，不销毁主武器」）；
     - 算子返回具体可读摘要：`["宗介/毛/克鲁兹 战意+10，下张主武器伤害+20%，抽1张连携牌"]`（若连携抽牌有卡名则附卡名）；
  2. **统一日志顺序与全量效果摘要**：
     - 在 `btl.gd`（精神牌/公有牌打出）与 `deck_flow.gd`（大招槽/连携牌打出）中，确保 **`〔专属精神牌/公有牌/大招〕X 打出【牌名】 → <具体效果摘要>`** 完整包含算子产出的具体数值变化与作用目标名（如 `→ 作用于【宗介】：战意 +15、本回合伤害 +25%`）；
     - 检查 `mithril_v03_cards.gd`、`atx_three.gd`、`atx_duo.gd`、`atx_faction.gd`、`class_cards.gd`、`card_effects.gd` 的所有精神/公有/大招算子返回值，凡只返回模糊词（如 `["再动"]`、`["紧急支援"]`、`["集中想象"]`、`["连携多抽"]`）或 `（0 台）` 的，全部改为返回带目标名与具体数值的中文短句；且算子内部的 `_记` 在「打出」主日志之后或直接合并进主日志摘要，杜绝「先出子日志、后出打出日志」的倒序；
  3. **棋盘 `UnitCard` 即时飘字演出（`battle_view.gd:_应用本拍`）**：
     - 在 `battle_view.gd:_应用本拍(项)` 中，新增对 `专属精神牌` / `公有牌` / `大招槽` / `连携牌` / `筹码牌` / `秘银v03` 的视觉反馈：在施放者 `UnitCard`（以及若有友方目标 `目标位`，在目标友方 `UnitCard`）上方弹出醒目的金色/青色效果胶囊飘字（如 `【Uruz 全员突击】全员战意+10 伤+20%`、`【补给】→ 宗介 战意+20`）并伴随 `UnitCard` 脉冲高亮！
