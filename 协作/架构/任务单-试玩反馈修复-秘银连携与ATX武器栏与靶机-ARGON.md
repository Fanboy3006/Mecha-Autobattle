## §1 根因诊断（基于 `live_actions.jsonl` 实测还原）

1. **问题 A：「我没看出来秘银连击（连携）怎么触发的」**
   - **真根因 1（时序反置 Bug）**：`btl.gd:1768-1774`（武器栏）与 `btl.gd:2279-2282`（精神/公有牌）先调用了 `DeckFlow.记上张打出牌(ctx, u, 卡)`，后调用 `DeckFlow.触发连携(ctx, u, 卡)`；而 `DeckFlow.连携就绪(ctx, 卡)`（`deck_flow.gd:749-753`）判断 `上.id != card.id`，导致刚记下的自己与自己比对恒返回 `false`，日志打印 `〔连携〕呼叫达纳号：上一张不是秘银牌 → 不触发（连携断开）`。
   - **真根因 2（大招漏调）**：`DeckFlow.打出大招`（`deck_flow.gd:567`）只调用了 `记上张打出牌`，**漏调了 `触发连携`**，导致 5 张带 `连携: true` 的秘银大招槽卡（`导弹齐射·饱和`、`超长距离狙击`、`魔弹`、`单分子刀·猎鹰`、`反坦克导弹·齐射`）打出时从不触发连携。
   - **真根因 3（快速战起手塞满 6/6 公有手牌）**：`game_session.gd:1649-1653` 在 `_开快速战` 开场把 `公有手牌` 强行补抽到 `6/6` 满手，导致毛打出 `V3_U2_S1 呼叫达纳号` 时，基础效果「把 1 张 TDD-1·巡航导弹放进公有手牌」和连携抽牌均因 `6/6` 满手被静默丢弃。

2. **问题 B：「URUZ 的公有牌打不出去」**
   - **真根因 1（公有牌仅校验当前选中机体）**：`game_session.gd:2456-2466`（`_公有牌视图`）与 `:2840-2849`（`_打精神或公有卡`）只用当前 `选中机体` 校验 `Btl.身份对口`。当玩家在上方看克鲁兹（狙击）或宗介（特种）时，下排属于其它职业（如 `指挥`、`尖兵`、`近卫`）的公有牌全部 `disabled = true`（置灰无法点击），必须先猜着切换上方机体才能点亮。
   - **真根因 2（公有牌池混入非本队职业/势力与旧占位牌）**：`setup.gd:273-274` 与 `deck_builder.gd:208-210` 未按本队实际在场的 `战斗分类`（职业）过滤公有牌，导致秘银五人队（无重装）抽到 `铁壁〔需：重装〕` 永远无法打出；且混入了旧版 M3 占位牌。
   - **顺带修复（`V3_URUZ_TRI 乌鲁兹·三角` 门槛绕过）**：`deck_flow.gd:111-118` 中 `卡类 == "主武器卡"` 分支排在 `入库条件` 之前，导致合体技 `乌鲁兹·三角` 跳过了 `连携牌库有三级` 的条件而在第 1 回合直接进了武器栏。

3. **问题 C：「ATX 响介开局好像也没有可以用的武器牌」**
   - **真根因**：`deck_flow.gd:87-97`（`DeckFlow.拆分单位牌`）对带 `"v01卡": true` 的卡牌（`atx_three.gd` 生成的 A1 响介、A2 艾克赛琳、A3 拉米亚全套卡）做了早退，将其全部留在 `专属牌库`（随机精神抽牌堆），未放进 `u.武器栏` 与 `u.副武器栏`。导致 ATX 五人开局时，仅 A6 塔斯克/A7 雷欧娜有常驻主武器，而响介（A1）、艾克赛琳（A2）、拉米亚（A3）的 `武器栏` 为空！

4. **问题 D：「另外 5 人测试搞一个比较肉但是攻击力比较低的对手」**
   - **真根因**：`game_session.gd` 的两个快速测试入口复用第 1 层普通编成 `1-N1`（HP `3000~7200`，攻击 `90~130`），我方 Lv30 五人队第 1 回合两刀就秒杀敌机，根本来不及体验多回合的秘银「连携一→二→三级」与 ATX「闪→赌局→筹码/赌神/轮盘双响」。

## §2 修复规格（4 项原子改动）

### M1. 秘银【连携】触发链路修复与 `乌鲁兹·三角` 门槛归位
1. **`btl.gd` 与 `deck_flow.gd` 时序修正**：
   - 在 `btl.gd:1768-1774`（`打出主武器卡`）与 `btl.gd:2279-2282`（`打出精神或公有牌`）中，**先调 `DeckFlow.触发连携(ctx, u, 卡)`，再调 `DeckFlow.记上张打出牌(ctx, u, 卡)`**。
   - 在 `deck_flow.gd:567`（`DeckFlow.打出大招`）中，在 `记上张打出牌(ctx, u, 卡)` **之前**补调 `触发连携(ctx, u, 卡)`。
2. **`V3_URUZ_TRI`（乌鲁兹·三角）条件检查**：
   - 在 `btl.gd:武器栏不可打原因`（及 `打出主武器卡`）中，若 ` str(w.get("id", "")) == "V3_URUZ_TRI"`，检查 `DeckFlow.入库条件满足吗(ctx, u, w)`（即 `连携牌库曾有三级`）且 `U7/U2/U6` 三人存活；未满足时返回 `"亮起条件未满足：连携牌库需出现过三级牌且宗介/毛/克鲁兹三人在场"`。
3. **快速测试秘银起手连携体验优化**：
   - 在快速测试（`全卡池体验`）下，`Setup.初始化单机牌组` 为秘银队伍装填完后，确保公有手牌起手 3 张中至少含 1 张秘银势力牌（如 `V3_F_1 作战开始` 或 `V3_F_2 火力支援请求`），且毛（`U2`）起手精神牌含 `V3_U2_S1 呼叫达纳号`，玩家第 1 回合随便打一张宗介/秘银牌再点 `呼叫达纳号` 即可 100% 直观触发 `〔连携〕`！

### M2. 公有牌池按本队过滤 + 起手 3 张 + 下排公有牌自动匹配对口队友
1. **移除快速战开场 6/6 塞满**：
   - 删除 `game_session.gd:1649-1653`（`_开快速战` 里把 `公有手牌` 补抽到 6 张的循环），保持 `Setup.初始化单机牌组` 的标准 **起手 3 张**（`3/6`），为 `呼叫达纳号` 与 `〔连携〕` 抽牌留出 3 格手牌空间。
2. **公有牌池按在场队伍过滤（`setup.gd` / `deck_builder.gd`）**：
   - 当 `DeckFlow.开启吗(ctx)`（`卡牌流转` 开启）时，`Setup.初始化单机牌组`（`setup.gd:273-358`）与 `DeckBuilder.公有扩展牌们`（`deck_builder.gd:196-210`）：
     - 过滤掉 `层级 == "职业"` 但我方在场无人属于该 `归属`（`战斗分类`）的职业牌（例如无重装时不塞重装牌）；
     - 过滤掉 `层级 == "势力"` 但我方在场无人属于该 `归属`（`势力`）的势力牌；
     - 当 `秘银v03` 开启时，排除基础表里的旧版 M3 占位职业/势力牌（`C_GUARD_1..2`, `C_VANG_1..2`, `C_SNIPE_1`, `C_SPEC_1..2`, `C_CMD_1..2`, `C_HEAVY_1`, `F_MITH_1..2`, `F_ATX_1..2`），只装填新版 36 张分类牌（`V3_C_*` + `CC_*`）与新版势力牌（`V3_F_*` / `F_ATX_V2_*`）。
3. **下排公有牌自动匹配在场对口队友（`game_session.gd`）**：
   - 新增辅助函数 `_找公有牌可打机体(卡: Dictionary) -> Dictionary`：若当前 `选中机体` 存活且对该公有牌/连携牌/筹码牌对口且可打，优先返回 `选中机体`；否则按 `ctx.allies` 顺序找第一个存活、身份对口且满足费用/门槛的队友返回。
   - 在 `_公有牌视图`（`game_session.gd:2449-2500`）中，用 `_找公有牌可打机体(卡)` 计算 `可打` 与 `原因`；若实际执行者不是当前 `选中机体`，在状态/副标题附上 `〔由 <队友短名> 发动〕`。
   - 在 `_打精神或公有卡`（`:2840-2850`）与 `play_link_card`（`:2875-2895`）中，若该牌在 `ctx.公有手牌` 中且当前 `选中机体` 不对口/不可打，自动切换用 `_找公有牌可打机体(卡)` 找到的队友 key 调用内核打出（并同步更新 `_selected_unit_key`）。
   - *注*：检查 `test_presentation_layout.gd` 段 12b 是否有断言「切不同职业机体时公有牌置灰」——若有，更新或适配该段断言以对齐「队内有对口活人即可打（仅全队无对口活人或战意均不足时才置灰）」。

### M3. ATX 三人（响介 A1 / 艾克赛琳 A2 / 拉米亚 A3）主武器与副武器进栏
1. **`DeckFlow.拆分单位牌`（`deck_flow.gd:87-97`）对齐四区**：
   - 将 `if bool(c.get("v01卡", false)):` 分支改为：
     - `卡类 == "大招槽卡"`：`continue`（由 `AtxThree.装填大招槽` 处理）；
     - `卡类 == "主武器卡"`：放入 `u["武器栏"]`（不再留在随机抽牌堆！响介开局即拥有 `三连机炮 / 方形钢弹 / 左轮打桩机` 等主武器常驻武器栏）；
     - `卡类 == "副武器卡"`（如 `ATX2_D1 援护射击`）：放入 `u["副武器栏"]`；
     - 其余（`精神牌`）：若有 `入库条件`（且非 `开局在手`）进 `u["待入库"]`，否则留 `保留`（`专属牌库`）。
2. **`btl.gd` 武器栏对接 `AtxThree` 校验与结算钩子**：
   - 在 `btl.gd:武器栏不可打原因`（`:1662-1684`）中：若 `bool(w.get("v01卡", false))`，调用 `AtxThree.不可打原因(ctx, u, w)` 校验「满开禁主武」「每场次数上限」「冷却」等门槛。
   - 在 `btl.gd:打出主武器卡`（`:1708-1778`）中：若 `bool(匹配.get("v01卡", false))`，在攻击结算后补齐 `AtxThree` 的武器后处理（每场次数记账 `_记每场次数`、记录 `ctx.上一次攻击` 供「赌神·入局 / 再来一把」读取、【强运】/【雾袭】/【赌局】触发、二次下注）。
   - 在 `atx_three.gd:1344-1361` 中：若卡牌来自 `武器栏`，不将其移入 `专属弃牌堆`。

### M4. 五人快速测试专属「高耐久、低攻击」试玩靶机
1. 在 `game_session.gd` 的 `_开快速战`（`:1629-1635`）中，当 `_快速测试局 == true`（即从主菜单点击「快速测试：秘银五人」或「快速测试：ATX 五人」）时：
   - 将敌方编成的 `波次` 清空（5 台靶机开场同台，不靠波次拖节奏）；
   - 将每台敌机的 `hp` 与 `maxHp` 设为高耐久靶机规格（前排盾卫/重机 **`28000 ~ 32000 HP`**，后排 **`20000 ~ 24000 HP`**，装甲保持 `300 ~ 600` 供测试破甲/共享池）；
   - 将每台敌机的 `melee` / `ranged` 攻击属性设为 **`35`**，并将其武器威力缩放至 **`35%`**（每击只造成约 `50 ~ 180` 点微伤，既能每回合稳定触发我方 ATX「闪 / 赌神 / 掩护」与宗介「λ 驱动」，又绝不会秒杀我方，且耐打 6~10 回合以上）。
