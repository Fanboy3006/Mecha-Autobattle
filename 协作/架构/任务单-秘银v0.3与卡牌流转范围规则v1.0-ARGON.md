## §1 作者拍板的核心架构定案（最高权威，施工必守）

### 1.1 武器范围规则 v0.1（4×4 战场 · 距离 `1..6` · 顶位仅影响近战）
1. **4×4 战场坐标与距离公式**：
   - 每方 8 格：`前1..前4`（`slot 0..3`，`col = slot % 4`，`row = 0` 前排）、`后1..后4`（`slot 4..7`，`col = slot % 4`，`row = 1` 后排）。
   - **真实距离 `dist_real(u, t)`**：
     - `横向差 = abs(col(u) - col(t))`（`0..3`）
     - `纵向差 = row(u) + row(t) + 1`（都在前排 `= 1`，一前一后 `= 2`，都在后排 `= 3`）
     - `dist_real = 横向差 + 纵向差`（取值范围 **`1..6`**）。
2. **顶位规则（仅影响近战）**：
   - 当某一方前排 4 格（`slot 0..3`）**全部没有存活单位（含掩体）**时，该方后排全体处于**「顶位」**（`is_front_effective(side, u) = true`）。
   - **顶位只影响近战**：
     - 近战攻击资格：攻击方必须处于前排（含我方前排全空时的顶位），且目标必须处于敌方前排（含敌方前排全空时的顶位，或打出特种牌「后方渗透」时无视前排限制）；
     - 近战距离 `dist_melee(u, t)`：处于顶位的单位在计算**近战武器距离**时，`row` 按 `0`（前排）计算；
     - **直射、曲射与克鲁兹【远距·N】的距离计算始终使用 `dist_real(u, t)`（照真实前/后排位置算）**！
3. **遮挡与武器类型**：
   - **近战 (`melee`)**：受前排/顶位资格与距离 `[min_range, max_range]` 限制（带 `ignore_block: true` 如「隔空 λ 拳」则后排也能打、也能打敌方后排）；
   - **直射 (`direct`)**：可打距离 `[min_range, max_range]` 内的任意排；打敌方后排时，若敌方同列前排（`slot = col(t)`）有存活单位（或掩体）且武器无 `ignore_block`（且打出者无「破障射击」状态），**命中 `−20`**；
   - **曲射 (`indirect`)**：可打距离 `[min_range, max_range]` 内的任意排，不受遮挡。
4. **范围附加（`area` 枚举）**：
   - `single`（单体）：只打指定目标；
   - `splash`（溅射 `splash_mul`，默认 `0.5` 或 `+` 版 `0.75`）：主目标受 100% 伤害，同方阵内十字相邻格（同排左右相邻列 + 同列另一排，最多 3 格）存活单位受 `splash_mul` 倍伤害；
   - `pierce`（贯穿 `pierce_mul`，默认 `0.5`）：主目标受 100% 伤害，目标同列另一排格受 `pierce_mul` 倍伤害；
   - `row`（横扫）：目标所在排的全部 4 格；
   - `all`（全体）：敌方全部 8 格存活单位。

### 1.2 卡牌流转规则 v0.1（武器栏 / 大招槽 / 副武器 / 精神抽牌堆 / 待入库置顶）
1. **每台机体的上排四区域与流转**：
   - **① 武器栏（主武器）**：常驻上排，每个我方阶段开始时全部恢复可用（`u.主武器已销毁 = false`）；打出一张主武器或算作主武器的大招牌后，本回合其余主武器与武器型大招牌置灰（`u.主武器已销毁 = true`）；支持武器冷却 `cd` 与每场次数 `uses`。
   - **② 副武器栏（不被销毁）**：如狙击通用副武器 **【援护射击】**，常驻上排，**打出主武器不会销毁副武器，打出副武器也不会销毁主武器**（每回合默认可打 1 次；受「天才狙击手可不是吹的」或「交叉火力」加成时本回合可多打 1 次；受克鲁兹「屏息」限制时本回合不可打副武器）。
   - **③ 大招槽（常驻上排，不进抽牌堆！）**：
     - 开战时直接放入 `u.大招槽`，**绝不混入 `u.专属牌库` 抽牌堆**；
     - 每张大招牌包含：`费用`、`冷却 (cd_max)`、`当前冷却 (cd)`、`武器牌 (is_weapon: bool)`、`获取条件`（一旦满足则 `已解锁 = true` 永久有效；状态型门槛如 `λ 开启中`、`战意 ≥ 60` 实时检查）；
     - 亮起条件：`cd == 0` 且 `已解锁` 且 `实时门槛满足` 且 `u.战意 >= 实际费用` 且 `（not is_weapon or not u.主武器已销毁）` 且 `本回合该大招未打出过`；
     - 打出后：留在大招槽内，置 `cd = cd_max`、`本回合已打 = true`；若 `is_weapon == true` 则置 `u.主武器已销毁 = true`。
   - **④ 精神牌（专属抽牌堆 `u.专属牌库` + `u.待入库` + `u.专属手牌` + `u.专属弃牌堆`）**：
     - 无入库条件的精神牌：开战洗入 `u.专属牌库`；
     - 带入库条件的精神牌：开战放入 `u.待入库`；条件第一次满足时，从 `u.待入库` 移出并 **`push_front` 放到 `u.专属牌库` 堆顶**（下次抽牌必抽到），仅入库一次；
     - 开战起手抽 **2 张**，每个我方阶段开始时抽 **1 张**；**手牌上限 4 张（满 4 张时停抽，牌留在牌库顶不烧牌）**；
     - 打出后进 `u.专属弃牌堆`（标 `每场 1 次` 的移入 `ctx.移出牌`）；抽牌时若牌库空则将弃牌堆洗回。
2. **全队公有牌区域（下排）**：
   - 含 `ctx.公有牌库`、`ctx.公有待入库`、`ctx.公有手牌`、`ctx.公有弃牌堆`；
   - 开战起手抽 **3 张**（若队内有对应势力成员，保底至少 1 张势力牌），每个我方阶段开始时抽 **1 张**；
   - **手牌上限 6 张**：自然抽牌、连携抽牌、置入衍生牌（如 `呼叫达纳号` 置入 `TDD-1`）在 **`ctx.公有手牌.size() >= 6` 时一律停抽/不置入**（连携牌留在连携牌库中不浪费）。
3. **我方阶段开始的严格 7 步顺序**：
   1. 冷却 `−1`（大招槽卡牌、带冷却的武器）；
   2. 维持与回合初状态结算 + 战意按回合 `+5`（宗介 λ 驱动若开启且未觉醒，先扣 10 战意维持，检查 `< 40` 则关闭；然后再加回合初 `+5` 战意，或按宗介稿 §1 阶段初扣维持检查）；
   3. 武器牌全部恢复（`u.主武器已销毁 = false`、`u.本回合再动已用 = false`、副武器本回合可用次数重置为 `1`、`ctx.上张打出牌 = null`）；
   4. 各机体抽 1 张精神牌（满 4 停抽）；公有手牌抽 1 张（满 6 停抽）；
   5. 检查 `待入库` 条件与 `大招槽` 亮起条件；
   6. 玩家自由操作各台机体（指定目标出牌）；
   7. 点「结束我方回合」：未打过主武器的存活机体由 AI 自动补打 1 张普通主武器牌 → 敌方按 `slot 0..7` 依次行动。

### 1.3 秘银 v0.3【Uruz 连携作战 · 连携牌库版】与 3 条防死循环硬规则
1. **取消 v0.2 的「本回合秘银牌计数」与 `【连携·N】`**。
2. **`ctx.上张打出牌` 判定口径（拍板定案 2）**：
   - 每个我方阶段开始清空为 `null`；
   - **算「秘银牌」（`is_mithril_card = true`）**：
     - ① 秘银成员（`u.势力 == "秘银"`）打出的**本机主武器牌、副武器牌、大招槽牌、专属精神牌**；
     - ② 公有排中的**秘银势力牌**与**秘银连携牌**。
   - **不算「秘银牌」（`is_mithril_card = false`，会覆盖并打断上一张记录）**：
     - 非秘银成员打出的任何牌；
     - 公有排中的**通用职业分类牌（特种 / 狙击 / 指挥等）、统帅牌、其他势力牌**。
3. **连携触发与「先抽后放」顺序（拍板定案 3）**：
   - 当打出一张带 `【连携】` 的牌时，**先检查** `ctx.上张打出牌 != null and ctx.上张打出牌.is_mithril_card == true`：
     - **Step 1（抽连携牌）**：若 `ctx.公有手牌.size() < 6` 且 `ctx.连携牌库` 非空，用 `ctx.rng` 从 `ctx.连携牌库` 随机抽 1 张放入 `ctx.公有手牌`（若存在 `泰莎的指令` 的「本回合下一次连携多抽 1 张」状态，则再抽 1 张并消耗该状态）；
     - **Step 2（放入更强的连携牌 X）**：若该牌带 `"连携放入": card_id`，将 `card_id` 放入 `ctx.连携牌库`（本场有效）。
   - 连携牌本身：`费用: 0`、`归属势力: "秘银"`、`不占主武器: true`、`带连携: false`；
   - 连携牌打出后：**一级、二级连携牌回到 `ctx.连携牌库`**；**三级连携牌移出本场（进 `ctx.移出牌`）**。
4. **3 条防死循环断路器（拍板定案 e）**：
   - **断路器 1**：三级连携牌（`达纳号·全弹发射`、`达纳号·紧急支援`）每场战斗每种**最多只能被放入 `ctx.连携牌库` 1 次**（用 `ctx.已放入三级连携牌` 集合记录）；
   - **断路器 2**：同一张大招槽卡牌在**同一个我方回合内最多打出 1 次**（`slot_entry.本回合已打`）；
   - **断路器 3**：每台机体在**同一个我方回合内最多触发 1 次「再动（主武器恢复）」**（`u.本回合再动已用`）。

### 1.4 宗介 v0.2【λ 驱动】通用形态状态机
1. **启动**：大招槽中的 `λ 驱动·启动`（`is_weapon: false`，不算武器牌，不销毁武器；要求 `u.战意 >= 60`（受「集中想象」减免时为 `>= 40`）且 λ 未开启；费用 `10`）。
2. **开启效果**：
   - `u.形态["lambda"].开启 = true`；
   - 获得 **λ 力场**：护盾 `4000`（`u.护盾 = 4000, u.护盾上限 = 4000`），每个我方阶段开始时若 λ 开启则回满 `4000`；
   - **武器栏实时替换**：`57mm 散弹炮` → `λ 驱动·散弹炮`（直射·特殊 2750·距离 1–4·溅射 50%·命中 90），`单分子刀` → `λ 单分子刀`（近战·特殊 3100·距离 1–3·贯穿后排 50%），并额外新增常驻主武器 **`隔空 λ 拳`**（近战·特殊 2000·距离 1–4·无视遮挡后排可打；宗介正前方或目标正前方有存活单位时伤害 `×2`）。
3. **维持与关闭**：
   - 每个我方阶段开始时（若 λ 开启且未觉醒）：若 `u.免除下次λ维持 == true` 则消耗该标记免扣；否则扣除 `10` 战意（`+` 版扣 `8`），扣完后若 `u.战意 < 40` 则 **λ 关闭**（武器变回普通版、移除隔空 λ 拳与 λ 力场，`λ 驱动·启动` 进入 `2` 回合冷却）。
4. **λ 觉醒**：
   - 本场战斗中宗介的 `λ 力场` 被完全击破（护盾从 `> 0` 被打到 `0`）累计达到 **2 次**时，立即触发 **【λ 觉醒】**：λ 驱动永久开启、不再扣维持消耗、λ 力场常驻且每回合回满、`λ 驱动·极限放出` 的冷却立即归 `0`。

### 1.5 卡池分层与快速战/肉鸽默认配置（拍板定案 4）
