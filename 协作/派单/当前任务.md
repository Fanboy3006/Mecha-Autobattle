## §0 核心设计思想与架构边界（作者钦定方向，严禁跑偏）

1. **不做传统抽牌/弃牌/洗牌/牌库管理**：
   - 我们的卡牌是**「直观的战术指令与机战精神（信赖、根性、爱、直击、必中、集中、激励、觉醒）」**——*“我现在遇到这个情况，所以我打这一张牌”*；
   - **严禁引入随机洗牌抽牌**（不消耗任何额外 `ctx.rng`），手牌完全由**「参战阵容的初始可用牌」+「战斗中满足条件时动态发给玩家的条件触发牌」**组成。
2. **三层牌池结构（参战机体共同供牌）**：
   - **职业牌池（Class Pool）**：6 大职业各提供 2~3 张职业特色牌（如重装【铁壁/根性】、近卫【热血/连斩追击】、尖兵【集中/幻影反击】、狙击【必中直击/精密锁敌】、指挥【激励/战术点名】、特种【扰乱/破甲引信】）；
   - **势力牌池（Faction Pool）**：6 大势力各提供 2~3 张势力特色牌（如国防军【防线死守/SEED爆种】、流星【游击机动/孤狼突袭】、月球【月光祈愿/残月共鸣】、天人【TRANS-AM解放/GN粒子力场】、ATX【好运加护/赌徒孤注】、秘银【光学迷彩/SRT突击接力】）；
   - **角色/机体特色牌池（Character Pool）**：具体角色提供专属特色牌（如 `CB1` 刹那【觉醒·七剑解放】、`CB2` 洛克昂【乱射·狙击神技】、`M1` Feena【满月·星落】、`A1` 响介【王牌决断·魂】、`S1` 拉克丝【永恒之爱】、`B1` 宗介【突击号令】等）。
3. **两种入牌方式（初始可用 vs 条件触发发牌）**：
   - **初始可用牌（`入牌: '初始'`）**：战斗开始（`开局`）时直接进入 `ctx.战术手牌`，随时可按气力消耗打出；
   - **条件触发牌（`入牌: '条件'`）**：开战时不在手里，而是挂在监控槽 `ctx.待触发战术牌` 上；当战斗中满足特定条件（如*前排重装受击掉血、尖兵闪避打空、近卫击破敌机、叠满 ≥2 层标定、SEED 满 30、残月追加触发、ATX 累计打空 ≥2 段*）时，由对应角色/职业/势力**当场「发牌」进入玩家手牌栏**，并记录 `〔发牌〕`！
4. **气力（`ctx.气势`）作为核心轮转资源**：
   - 打破原先「只能憋满 100 放总攻/掩护」的僵局：
     - **回气/轮转牌**（如指挥【激励】`耗气: 0, 回气: 25`、条件触发牌附带 `+15~25` 气力）；
     - **小中费战术牌**（耗气 `10 ~ 35`：【集中】【铁壁】【必中·直击】【热血】【月光祈愿】【扰乱】）；
     - **高费终极号令/大招牌**（耗气 `60 ~ 100`：【⚡全军总攻】【🛡紧急掩护】【觉醒·专属必杀】）。
5. **肉鸽成长联动（招募/升级 3 选 1 构筑牌池）**：
   - 在肉鸽模式下，玩家招募新机师或晋升机师（Lv10→20→30）时，可从该机师对应的「职业牌池 ∪ 势力牌池 ∪ 角色牌池」中抽取 **3 张候选牌供玩家 3 选 1** 加入队伍战术牌库（`RUN.战术牌库`）。
6. **兼容与开关纪律**：
   - 在 `71-改动-4-战斗结构.js` 新增 `战斗结构.战术卡牌` 配置块：
     - 为保证既有 23 套测试（含 `commands-1` 47 场 `2788` 条记录、`录像.js`、`决策.js`）100% 零污染，**`战斗结构.战术卡牌.开` 默认设为 `false`**（默认路径不写额外记录字段、不改气势初值）；
     - 当 `战斗结构.战术卡牌.开 === true` 或 `开局(..., { 战术卡牌: true })` 时，完整激活「初始手牌 + 条件发牌 + 气力轮转 + 招募晋升选牌 + 手牌栏 UI」！

1. **派生队伍可用牌池 `生成队伍牌池(allies, 选项)`（纯函数，0 `rng`）**：

   - 在回合开始、攻击结算后（造成伤害/暴击/击破/逐段未命中/受击掉血/挂标定/SEED满阈值）调用 `检查条件发牌(ctx, ...)`；
