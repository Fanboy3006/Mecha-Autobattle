## §0 作者拍板定案（4 项组合一次落地）

1. **`1`（气势条与战术指令框架）**：我方在战斗中拥有全队共享的**气势（Morale）**，`0 ~ 100`（开场默认 `0`，上限 `100`）。通过交战自然积攒（我方每次行动出手、受击、击破敌机涨气势）；气势达到 `100` 时，指令阶段可在方针栏旁点选发动 **1 条战术指令**（消耗 `100` 气势，每回合最多发动 1 次，立即在本回合生效）。
2. **`A2`（两条战术指令：⚡全军总攻 / 🛡紧急掩护）**：
   - **⚡全军总攻**：消耗 100 气势 → 本回合我方全队**造成的伤害 ×1.35**、**命中 +15**，且发动瞬间我方全体存活单位**大招当前冷却立即 −1**（`cd = Math.max(0, cd - 1)`，若还在开场冷却则 `readyTurn = Math.max(ctx.turn, readyTurn - 1)`），同时**本回合强制解除「憋大招」限制，所有冷却就绪的大招在本回合自动齐射**！
   - **🛡紧急掩护**：消耗 100 气势 → 回合开始立即为我方全体存活单位赋予 **`Math.round(maxHp * 0.25)` 的护盾**（叠加到 `u.shield` 上，走现有减免管线最后一步护盾抵伤），并**清除我方全体身上的负面状态**（清空 `u.debuffs`、移除 `u.buffs` 中负向的 `hit < 0` 等减益、归零 `u.armorCut`）。
3. **`B2`（Lv10 未解锁大招显式提示）**：机体的大招在 `Lv20` / `Lv30` 解锁。当前 `Lv10` 机体没有可用大招时，单位卡与指令面板的「大招」区域不能只留空白或让人误以为大招坏了，必须显式写出提示 **`「大招：Lv20 解锁」`**（若该机体模板原本拥有 `unlock: 20` 或 `unlock: 30` 的大招但当前等级未达标，明确标出 `Lv20 解锁` / `Lv30 解锁`；全等级都无大招的特殊机体写 `无大招`）。
4. **`C1`（方针栏「全队憋到总攻」一键开关）**：在战斗屏方针栏新增一颗全队级开关 **`「大招：憋到总攻」`**（布尔开关，默认 `false` = 正常按各单位自己的大招开关走）：
   - 当开启「憋到总攻」且本回合**未发动**⚡全军总攻时：我方全体单位视为「保留大招」（本回合不使用大招，攒着 CD）；
   - 当玩家点选发动 **⚡全军总攻** 的那一回合：**无视**「憋到总攻」与单机「保留大招」，全队所有冷却就绪的大招在本回合**集中齐射释放**（释放完后下一回合若开关仍开着，继续憋下一轮，或按参数配置自动复位，见 §1）。

## §1 参数表与总开关（写进 `src/js/71-改动-4-战斗结构.js` 与 `71-改动-5-参数入口.js`）

在 `战斗结构` 下新增 `气势与战术指令`（所有数值一处可调，标 `【初稿·待作者调】`）：

```js
气势与战术指令: {
  开: true,                  // ★ A/B 总开关：false = 整套退回改动前（气势不计、指令不生效、记录零新增字段）
  初始气势: 0,
  上限: 100,
  消耗: 100,
  获取: {
    每回合自然: 10,          // 回合开始（第 2 回合起）+10
    我方出手: 8,             // 我方单位每次执行行动 +8
    我方受击: 6,             // 我方单位每次受到敌方实际伤害（伤害 > 0）+6
    我方击破: 15,            // 我方每次击破敌机 +15
  },
  全军总攻: {
    伤害倍率: 1.35,          // 本回合我方攻击最终伤害 ×1.35（或公式后乘倍率）
    命中加成: 15,            // 本回合我方全体 hit +15
    大招冷却减免: 1,         // 发动时我方全体大招 CD 立即 −1
    强制大招齐射: true,      // 本回合解除憋大招/保留大招，就绪大招全部允许释放
  },
  紧急掩护: {
    护盾比例: 0.25,          // 赋予 Math.round(maxHp * 0.25) 护盾
    清除减益: true,          // 清空 debuffs + 移除负向 buffs + 还原 armorCut
  },
  憋到总攻: {
    总攻后自动关: false,     // false = 保持玩家开关状态；true = 齐射完自动切回自由释放
  },
}
```

- **★ 默认路径逐字节不变铁律**：
  1. 当 `战斗结构.气势与战术指令.开 === false` 时，所有气势字段、记录字段与钩子完全不运行；
  2. 即使 `开 === true`，在**默认不主动下达战术指令、不开启「憋到总攻」**的自动战斗（如 `simulate(我方, 敌方, {}, 种子)`、39/47 场编成表快照、练习默认、调参室默认）中：**气势只在 `ctx.气势` 上静默记账，绝不往 `ctx.log` 插入独立记录行，也绝不在攻击记录上挂载值为 `0/false/null` 的新字段，且绝不消耗 `ctx.rng`**！
  3. 只有当玩家/调用方**真正点选发动了「全军总攻 / 紧急掩护」或开启了「憋到总攻」实际拦住大招**时，才写入 `〔战术〕…` 记录行与攻击记录上的 `总攻增伤` 等字段。这样**默认路径的 `simulate()` 输出与改动前 100% 逐字节相同**！
