## §0 设计目标与核心体验（只做「刹那 7 连斩」精品 Demo + 可移植标准接口）

1. **核心玩法流程（刹那 `CB1` · `七剑·TRANS-AM 乱舞` 7 连斩）**：
   - **第 1 幕 · 我方拔刀特写（`DRAW_CUTIN`）**：刹那（`CB1`）开启 TRANS-AM 红霞粒子，拔出 GN 实体剑特写 + 台词切入（*「TRANS-AM 启动——目标，驱逐！」*）；
   - **第 2 幕 · 敌机机动晃动 & 7 连斩滑动 QTE（`SLASH_QTE` × 7 段）**：
     - 镜头切换至敌方机体正前特写；敌机根据自身**闪避率（`eva`）与当前段有效命中率（`q`）**进行连续机动晃动（带推进残影与核心破绽圈）；
     - 玩家在每段斩击窗口内**按住鼠标/触屏划过晃动中的敌机**完成移动斩击（同时提供键盘方向/空格斩击与「AI 手法模拟」按钮方便调试）：
       - **划穿核心红心（`PERFECT`）**：必中，且奖励暴击修正（默认 `+25%` 暴击率或必暴），触发金色重斩弧 + 120ms 命中停顿；
       - **划中机体有效圈（`HIT`）**：判定命中，按原暴击率结算，触发 GN 光束青白斩弧 + 60ms 停顿；
       - **划偏或超时被敌机晃开（`MISS`）**：判定未命中，敌机侧闪拉出残影 + `MISS` 飘字；
     - **与战棋原生规则联动**：`七剑·TRANS-AM 乱舞` 原生具备 `special:'multi', hits:7, step:10`（命中后下一刀理论命中 `−10`，未中后下一刀 `+10`）：
       - 若玩家连续划中，敌机受惊机动加剧（晃动变快、判定圈收窄）；
       - 若玩家某刀失手 `MISS`，下一刀理论命中率 `+10`（敌机旧力已竭、晃动变慢、判定圈放大），形成极佳的动态手操反馈！
   - **第 3 幕 · 收刀定格与连环爆散（`FINALE`）**：7 刀完毕后刹那转身收刀，敌机身上已命中的斩痕同时引爆，跳出总伤害（若 HP 归零则触发机战式连爆 + `击破` 印章）；
   - **第 4 幕 · 结算对账与 JSON 导出（`RESULT`）**：实时对比「手操 QTE 实际命中/暴击/总伤」与「纯随机数理论期望」，并展示标准 `QTEResult` JSON 载荷。

### 1.2 `src/js/71-改动-5-参数入口.js`：新增纯读辅助函数

- `计算QTE晃动参数(att, def, w, stageIdx = 0, currentHitRate = 80)`（纯函数，0 `rng`）：

    ```js
      晃动频率Hz: +(0.8 + eva * 0.035 + (100 - q) * 0.015).toFixed(2),

      窗口毫秒: Math.round(Math.max(380, 650 - eva * 2.5)),
    }
    ```

## §2 独立 Demo 页 `协作/演出/demo-动作QTE-刹那七连斩.html` 详细规格

必须是**单文件 HTML（内联 CSS + 模块化 JS，双击直接在浏览器打开可玩，且可在 Node `dom-stub` 或无头环境下通过 `window.__actionQTE` 自动化测试）**：

1. **五层清晰代码结构（文件顶部附架构目录注释）**：
   - `// === [Layer 1] ActionQTE Protocol & Defaults (可移植协议与默认预设：CB1 刹那 vs 三档闪避敌机) ===`
   - `// === [Layer 2] Evasion Motion & Slash Geometry (敌机闪避轨迹方程与线段-圆相交判定纯函数) ===`
   - `// === [Layer 3] State Machine Director (四幕导演状态机：DRAW_CUTIN -> SLASH_QTE x7 -> FINALE -> RESULT) ===`
   - `// === [Layer 4] Pixel Canvas Renderer & WebAudio Synth (240x160 整数倍像素渲染与芯片音效) ===`
   - `// === [Layer 5] Interactive Controls & Headless Test API (调试面板与 window.__actionQTE 自动化接口) ===`
2. **核心数学判定（纯函数、确定性、零外部依赖）**：
   - **敌机实时位置 `getTargetPos(tMs, stageParams, seed)`**：基于确定性相位的复合正弦/李萨如轨迹 `x = cx + A_x * sin(2π * f * t + φ1) * cos(π * f * 0.5 * t)`，`y = cy + A_y * sin(2π * f * 1.3 * t + φ2)`。当敌机 `eva` 越高或当前段 `q` 越低，敌机移动越快、幅度越大并拉出残影；
   - **滑动斩击线段判定 `judgeSlashSegment(p1, p2, targetPos, effectiveRadius, perfectRadius)`**：
     - 计算玩家鼠标/触屏划出的线段 `p1 -> p2`（长度需 `>= 18px` 防原地误触）到敌机当前中心 `targetPos` 的**最短几何距离 `d`**；
     - 若 `d <= perfectRadius` → 返回 `{ 命中: true, 评价: 'PERFECT', 精度: +(1 - d / effectiveRadius).toFixed(2), 距离: +d.toFixed(1) }`；
     - 若 `perfectRadius < d <= effectiveRadius` → 返回 `{ 命中: true, 评价: 'HIT', 精度: +(1 - d / effectiveRadius).toFixed(2), 距离: +d.toFixed(1) }`；
     - 若 `d > effectiveRadius` 或超时未划 → 返回 `{ 命中: false, 评价: 'MISS', 精度: 0, 距离: +d.toFixed(1) }`。
3. **交互与调试控制栏（页面内置）**：
   - **敌机靶子切换**：① 量产机 `grunt`（`eva: 10`，低速微晃）· ② 高机动战机 `fighter`（`eva: 30`，中速机动）· ③ 隐形侦察机 `stealth`（等效高闪 `eva: 55`，高速残影晃动）· ④ 自定义闪避滑条（`0 ~ 90`）；
   - **三种操作方式**：① 鼠标拖拽 / 触屏滑动直接斩击画布上的敌机；② 键盘 `Space` / `J` 看准准星重合瞬间挥刀；③ **一键模拟测试按钮**（`[模拟：全 PERFECT 7/7]`、`[模拟：实战混合 5/7]`、`[模拟：全 MISS 0/7]`），点击即可自动演完并生成标准 `QTEResult` JSON！
4. **暴露无头测试接口 `window.__actionQTE`**：
   - `创建会话(请求)`、`取晃动参数(eva, hitRate, stageIdx)`、`取敌机坐标(tMs, 晃动参数, seed)`、`判定斩击(p1, p2, targetPos, 晃动参数)`、`模拟整套七连斩(预设名或轨迹数组, 请求)`（返回完整 7 段 `QTEResult` 与伤害汇总，供 `tests/qte_demo.js` 直接调用断言）。
