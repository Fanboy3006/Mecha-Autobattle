## 步骤

   - `git status --short`
   - `git log --oneline -3`
2. 核对样例：对 `.tmp/l1-boss/native/default.json` 跑 SHA256，和 `SHA256SUMS.txt` 比对。对不上就停下报告。
3. 按编号依次应用 0001 到 0004，每个补丁走同一套流程：
   - 先跑 `git apply --check --index`，失败就停下，把报错原样贴进报告；

   - 用 `git mailinfo` 拼出提交信息，然后 `git commit -F`。
4. 把 `default.json` 覆盖复制到 `godot/tests/golden/native/`，然后：
