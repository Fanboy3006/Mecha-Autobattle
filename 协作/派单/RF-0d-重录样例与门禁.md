# 派活单 RF-0d：RF-0 三处修复后重录原生样例 + 全量门禁

> 依据：`协作/架构/重构规格-RF-v0.1.md` §三 RF-0。前置：RF-0a / 0b / 0c 都已提交。
> 先读 `AGENTS.md`。本单**写明允许重录一次**原生样例。

## 步骤
1. `git status --short` 记下；确认最近 3 个提交是 `[RF-0a]` `[RF-0b]` `[RF-0c]`，不是就停下报告。
2. 先跑一次全量测试，**只记录**哪些项红（预期只有原生样例相关的项红；其它项红 → 停下报告，不要重录）。
3. 重录：`godot --headless --path godot --script res://tools/record_native_golden.gd`（约 3.5 分钟）。
4. 出差异摘要：用 `godot/tools/diff_native_summary.gd`（用法看该文件首部注释），输出写进 `协作/架构/RF回执/RF-0d-样例差异.txt`。
5. **核对差异范围**（这是本单的停点）：
   - 允许：含**殖民卫星军**成员的场次（0a），含**秘银**成员的场次（0b / 0c）。
   - 场次数、事件数、rng 步数的变化只能出现在上述场次。
   - 出现在不含这两个势力的场次 → **停下报告，不提交**，把差异文件留着。
6. 再跑全量测试，必须全绿；跑 `node godot/tools/build_godot_routemap.mjs --check`，EXIT=0（新增了测试文件，必要时先不带 `--check` 重建一次）。
7. 提交（只加样例文件、差异文件、回执、RouteMap 产物）：`[RF-0d] RF-0 修复后重录原生样例`
8. 回执 `协作/架构/RF回执/RF-0d.md`：受影响场次数（按势力分）、每类差异一句话、测试总项数、`--check` 结果。
