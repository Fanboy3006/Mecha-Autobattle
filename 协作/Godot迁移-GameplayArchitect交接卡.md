## 三、M3（肉鸽内核 Run Core）冻结语义清单与验收口径（供 CC 直接施工）

以下是 M3 需要从 `src/js/70-编成.js`、`90-肉鸽-1..6.js`、`91-地图.js`、`93-藏品.js`、`94-零件.js` 迁移到 `godot/core/run/`（及接入 `core/battle/` 藏品开战）的 **完整冻结语义与验收标准**：

### 3.1 必须保留并迁移的 8 块肉鸽核心语义
1. **分队与开局初始化（`90-肉鸽-1` / `90-肉鸽-3`）**：
   - 7 个可选分队（6 个我方势力分队 + 混编/默认分队）；
   - 新局初始状态：部队 `Lv1`（经验 `0`）→ 出击上限 `4` 台（`Lv4→5`、`Lv7→6`，藏品加成绝对封顶 `7` 台）；
   - 开局名册与出击名单为空，发放 **3 张初始招募券**（尖兵招募券 ×1、近卫招募券 ×1、重装招募券 ×1）；初始源碳、希望、基地耐久按 `肉鸽数值` 表初始化。
2. **4 层正方形大地图生成与推进剂规则（`91-地图.js`）**：
   - 4 层网格尺寸：`5×5 / 6×6 / 6×6 / 7×7`，存在率 `0.78 / 0.72 / 0.66 / 0.62`，四邻接连通下限 `17 / 23 / 21 / 27`；
   - 起点 = 最上排中间格；**双出口**：`出口尽头`（最下排离中间最近的连通格，前置必经点放 `守军` 收费站）与 `出口小径`（最右列离尽头 ≥ 3 步，走小径额外奖励推进剂 `+2`）；
   - `废弃隧道` 简单成对（左两列一端、右两列一端，图上距离 ≥ 2）；
   - **推进剂上限** = `该图起点到出口最短路 + 偶数余量[层]`（余量表，最终上限落点约 `8 / 9 / 11 / 12`）；
   - **移动与推进剂消耗**：相邻格移动扣 `1` 点推进剂（`林间空地` 落脚不扣或按节点表规则结算）；支持已访问连通区的跳格移动（按最短路扣推进剂）与純读 `退路成本预告`；推进剂归 `0` 时触发 **追击战**（打赢恢复少量推进剂，不直接判负）。
3. **7 类节点与关卡编成抽取（`70-编成.js` / `90-肉鸽-3..5`）**：
   - 战斗节点（`作战 / 精英 / 守军 / 侵蚀源 / Boss`）：从 `编成表` 对应 `层 × 类型` 池抽取（含 1–2 层 24 条变体的 `词条` 与精英必挂载的 `1-EE / 2-EE` `挂载` 词条组）；
   - 非战斗节点：`休整`（回血 / 希望升阶 / 恢复推进剂弹窗选择）、`黑市`（源碳买藏品/零件/券、刷新）、`奇遇`（瞭望站 / 遗迹 / 废弃隧道等事件选项结算）。
4. **招募券掷骰与★带队核心规则（`90-肉鸽-2`）**：
   - 招募券按券种池掷骰候选机师；耗希望招募入队（若出击名单未满上限则自动编入出击位）；
   - **★带队核心特例**：招募到当前分队的带队核心机师时，直接以 **Lv20** 入队！
5. **晋升（Lv10 → Lv20 → Lv30）与戦后休整回血（`90-肉鸽-2` / `90-肉鸽-4`）**：
   - 消耗希望将机师从 Lv10 升至 Lv20、Lv20 升至 Lv30（不可跳级；Lv20 解锁大部分机体大招，Lv30 解锁终极武器如【满月·月蚀】）；
   - **HP 跨战继承 + 战后自动回血 50%**：战斗结束存活机体保留剩余 HP 比例，战后结算自动恢复最大 HP 的 `50%`（阵亡机体战后以规定残血保留在名册中，不永久死亡）。
6. **肉鸽 3 选 1 战术牌构筑（`90-肉鸽-2` 的 `候选战术牌们` / `选战术牌`）**：
   - 每次**招募新机师**或**晋升已有1机师**时，从该机师所属的「职业 + 势力 + 角色」三层牌池中（剔除已在 `RUN.战术牌库` 中的牌）抽出最多 3 张候选牌放入 `RUN.待选战术牌`；
   - 玩家执行 `选战术牌:<cardId>` 后，将该卡并入 `RUN.战术牌库` 并清空 `RUN.待选战术牌`；
   - 肉鸽开战调用 Battle Core 时，显式传入 `{ 已选战术牌: RUN.战术牌库, 藏品: RUN.藏品 }`。
7. **58 件藏品（`93-藏品.js`）与 13 件大地图零件（`94-零件.js`）**：
   - **藏品**：精英/Boss 战胜利掉落 1 件（不重复，拿满转源碳）；**在 M3 补齐 Battle Core 的 `藏品开战(ctx, 选项.藏品)` 接入**（含我方面板加成 `mods/stat/stack`、敌方削弱 `foe/foeStack`、以及编制上限类藏品 `d1/d2/c1/c2/f4/d3` 对 `出击上限` 的修正）；
   - **零件**：13 件大地图主动/被动道具（11 件主动位移/地形交互件：`轮子/假肢/气垫/外骨骼/引擎/弹簧/喷气背包/小八界/融雪/触须/祭祈` + 推进剂上限加成重算）。
8. **存档与读档（`save_service.gd`）**：
   - 序列化 `RunState`（种子、随机数当前状态或步数、层、地图、位置、推进剂、资源、名册、出击位、券、藏品、零件、`战术牌库`、`待选战术牌`），读档后状态 100% 还原。
