### 4.2 推送 GitHub 的做法（作者要求 push 时使用）

沙箱下 `git push` 默认走 `schannel` TLS 与 `credential.helper=manager`，会因沙箱禁用命名管道与凭据句柄失败。
**★ 严禁编写任何 Win32 API / P/Invoke 脚本读取系统凭据（会触发模型安全过滤器 `PROHIBITED_CONTENT` 中断会话）！**

标准做法：直接对下面这一条纯 Git 原生命令申请一次性 `danger-full-access` 提权即可一步推送成功（改用 `openssl` 后端 + Git 内置原生 `wincred` 助手）：
```powershell
$env:GIT_TERMINAL_PROMPT = '0'; git -c http.sslBackend=openssl -c credential.helper= -c credential.helper=wincred push origin main
```
★ **推送前必须问作者**：`docs/实现/README.md` 写明「**不 push，推送由统筹做**」，仅在作者明确要求 push 时执行。
