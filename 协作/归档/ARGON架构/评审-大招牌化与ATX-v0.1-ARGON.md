## §0 结论

**方向赞成，值得做；但建议排在 M5 收口之后，并且"先落框架、再落卡表"。**

三个理由：
1. **它补的是这个游戏最缺的东西**：现在玩家的能动性只有「方针 + 打几张战术牌」，大招是**自动开火**的（`60-战斗-3-开局与simulate.js:231` `大招: !!(a && a.weapon && isUltimate(a.weapon))`）。把大招变成**玩家逐个决策的牌**，是把「自动战斗」从「看戏」拉回「指挥」的质变。
2. **它顺手解掉两个现存痛点**：① D-01 起手 6 张的构成争议（角色牌入手后牌池语义变清楚）；② Lv10 机体"没有大招"的体验空洞（`大招状态` 的「大招：Lv20 解锁」是 2026-10-13 加的）。
3. **时机上不能与 M5 叠加**：这套改动会同时动 `btl.gd` / `setup.gd` / `flow.gd` 三个核心，而 M5 要做「根路径 `/` 切 Godot 版 + JS 归档」。**两件事叠在一起出问题会很难定位**。建议顺序：**M5 收口 → 大招牌化作为 P2 玩法线**（`Godot迁移架构-v1.md` §9.3 本来就写着「新玩法只在 Godot 里做，排在 M4 之后」）。

## §3 卡牌设计层面的具体反馈

1. **A2「好运加护」是很好的取舍设计**（全体命中 −20 换暴击倍率 +1，**主动制造打空来喂自己的引擎**）—— 这是把"赌徒"主题做成机制而不是做成数值，赞成。但请配 §2 #6 的上下限。
2. **A1「赌神」的段数来源建议改口径**（见 §2 #5）：`本场打空段数` 是**单调递增**的，而"打出后回牌库 + 冷却"意味着它每冷却好一次就更强 → **后期必然失衡**。改成"上次打出以来"就自然有涨有落。
3. **A5「龙王破山剑」（第 3 回合起 / 25 费 / 高威力单体）与「龙雷闪」（打空≥5 / 15 费 / 全体）** 之间缺少区分度描述：前者纯高威力，看起来像"没设计"。建议给它一个**与指挥/统帅身份相称的附加效果**（例如全体获得一层"号令"类增益），否则它不如 A4 的「计都罗睺剑」（伤害随损失 HP 成长，有主题）。
4. **合体技「轮盘双响」少了一条回收规则**：进牌库条件写了（两人大招各打过 1 次），但**打出之后**是"回库 + 冷却 5"还是"一次性退场"**没写**。若是一次性，请明确说清（这决定它值不值 35 费）。
5. **A3「W17·中继」的再动要防无限连锁**：再动者若也是 ATX 成员，它行动后会不会再触发一次中继？现有 `drainAgain()` 是"被点名就立刻行动"，**没有防重入**的设计约束。建议明确「**每回合中继只能触发一次**」或「被再动者不能再触发中继」，并加测试。
6. **A4「守护」用的"相邻"要钉死几何**：阵型 2026-10-13 已改成**正交 4×2（8 格）**，「相邻位」= **十字邻格**（同排左右 + 同路前后），「对位」= 同列前后。设计稿写"替相邻队友承受"——请明确是 `相邻位` 还是 `对位`（**前排替同列后排挡枪**更像"守护"的本意）。
   另外：★ **旧版的「守护」指令在 2026-10-12 已被删除**（全队方针替换逐台指令），所以这是**重新引入**、不是"沿用"。好在 `Fm.相邻位/对位` 几何现成。
7. **A4「硬碰硬」把闪避归零** —— 需要一条"本回合闪避置 0"的 modifier。现有 `defMul` / `eva` 体系应该接得上，但**请让我在落地前确认**（这条我没实测）。
8. **9 张势力牌里 4 张是全场光环**（#1 加注 / #3 必闪 / #5 翻倍，加 #4 读牌）——**这类"开一次管一回合"的牌最适合自动战斗**，方向对。但**它们都直接改命中/暴击公式而不受气势或冷却约束**，会显著抬高随机性（自动战斗里随机性靠"方针"是压不住的）。建议：这类牌**统一加"本回合限一次"**，并配 §2 #6 的上下限。
9. **「读牌」（只看意图）在 Godot 版上有一个跨线依赖**：它要靠 `算意图(ctx)`（JS `60-战斗-3-开局与simulate.js:195`）—— 而 **Godot `core/**` 里还没有这个函数**（我在 M4 已登记为缺口，见 `Godot迁移-ARGON验收对照表.md` §8.2 #13）。所以「读牌」落地前，**得先把 `算意图` 迁进 Godot core**（M4 的 UI 目前是用 `Boss.bossAction` 等纯读拼了一部分）。
10. **「梭哈」冷却清零 + 「赌神」连发** —— 设计稿自己在"待数值"里问了，**问得对**。建议给"冷却清零"加一条硬限制：**同一张牌每场最多被清零 N 次**，或清零后**本次仍要吃一个最小冷却（例如 1）**，否则「打空 ≥10 → 清零 → 立刻再打赌神」会形成闭环。
