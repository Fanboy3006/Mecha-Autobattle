### 1.2 觉醒框架（`觉醒中` 与 `觉醒类型`）
- **单位状态字段**（严格与六维属性 `awakening / 觉醒值` 区分）：
  - `u["觉醒中"] = false`（bool）
  - `u["觉醒类型"] = ""`（`"SEED" | "ZERO" | "隐身" | ""`）
  - `ctx["本场有人觉醒过"] = false`
- **三张觉醒入场牌**（均放在 `u.大招槽`，`is_weapon: false`，`武器牌: false`，无 QTE，亮起时进入中下手牌区【副武器牌】，打出后不销毁主武器栏）：
  1. **`COL_S1_ULT_SEED` `SEED·爆裂`**（拉克丝 `S1`，费用 `10`，冷却 `0`，打出后本场移出大招槽）：
     - 亮起条件：`not bool(u.get("觉醒中", false))` 且 `not bool(u.get("本场已开SEED", false))` 且 `(u.hp * 100 <= u.maxHp * 70 or ctx.round >= 3)` 且 `战意 >= 50`（`+` 版战意门槛为 `40`）。
     - 条件豁免：若 `u.get("本回合无视觉醒战意门槛", false)`（来自 `觉醒连锁` 或 `背水`），战意门槛视为 `0`（仍需付 10 费）；若 `u.get("本回合强制觉醒", false)`（来自三级感应牌 `强制觉醒`），**无视回合、HP、战意门槛与冷却，且实际费用为 `0`**！
     - 效果：开启 `SEED`（`u["觉醒中"] = true`, `u["觉醒类型"] = "SEED"`, `u["本场已开SEED"] = true`, `ctx["本场有人觉醒过"] = true`，槽标记 `已移出 = true`）。
     - **SEED 中效果**：
       - 每段命中 `+15`、闪避 `+15`；
       - 拉克丝打出的大招武器 QTE 结果若为 `失手`，自动视为 **`成功`**；
       - 解锁 `METEOR·锁定 1` 与 `超级 DRAGOON`；
       - **无尽的 SEED**：本场永不关闭、不扣维持；
       - **被动「歌姬」**：每个我方阶段开始时，若拉克丝存活且处于 `SEED` 中，我方所有**其他存活的殖民卫星军成员**战意 `+3`。
  2. **`COL_W1_ULT_ZERO` `ZERO 系统·启动`**（希罗 `W1`，费用 `10`，退醒后冷却 `3`）：
     - 亮起条件：`not bool(u.get("觉醒中", false))` 且 `int(槽.get("cd", 0)) <= 0` 且 `u.hp * 100 > u.maxHp * 30` 且 `战意 >= 40`（支持 `本回合无视觉醒战意门槛` 与 `本回合强制觉醒` 豁免）。
     - 效果：开启 `ZERO`（`u["觉醒中"] = true`, `u["觉醒类型"] = "ZERO"`, `u["本场已开ZERO"] = true`, `ctx["本场有人觉醒过"] = true`）。
     - **ZERO 中效果**：
       - 每段命中 `+20`、闪避 `+20`；
       - 暴击伤害倍率改为 **`2.5`**（平时 `2.0`；若本回合打过精神牌 `压住 ZERO`，则本回合暴击伤害倍率回退为 `2.0`）；
       - 希罗打出的大招武器若 QTE 结果为 **`完美`**，该次攻击每段**必定暴击**；
       - 解锁 `双联破坏步枪` 与 `零式·旋转破坏步枪`。
     - **精神负担与系统拒绝**：
       - 每个我方阶段开始时（在回合初自然战意 `+5` 之后）：若希罗处于 `ZERO` 中，检查 `u.get("下回合免精神负担", false)`——若有则清除该标记并免扣本次 HP；否则扣除 `max(1, int(round(float(u.maxHp) * (0.07 if bool(槽.get("plus", false)) else 0.10))))` 点 HP（最多扣到 `1 HP`，不致死）。
       - **任何时刻 `HP ≤ 30%` 立即退醒**：在阶段初扣血后、自损血后、以及**每次受击扣血结算后**，立刻调用 `ColonialV01.检查系统拒绝(ctx, u)`：若希罗处于 `ZERO` 中且 `u.hp > 0` 且 `u.hp * 100 <= u.maxHp * 30`，当场退出 `ZERO`（`u["觉醒中"] = false`, `u["觉醒类型"] = ""`），将 `ZERO 系统·启动` 槽的 `cd` 设为 `3`（左栏显示 `〔3 回合后进入手牌〕`），并在战报记录 `〔ZERO 系统〕【希罗】HP 降至 30% 以下，触发系统拒绝退出 ZERO！（冷却 3 回合）`。
  3. **`COL_W2_ULT_STEALTH` `超级干扰器·潜入`**（迪奥 `W2`，费用 `10` / `+` 版 `0`，退醒后冷却 `2` / `+` 版 `1`）：
     - 亮起条件：`not bool(u.get("觉醒中", false))` 且 `int(槽.get("cd", 0)) <= 0` 且 `战意 >= 20`（第 1 回合即可开！支持 `本回合无视觉醒战意门槛` 与 `本回合强制觉醒`）。
     - 效果：开启 `隐身`（`u["觉醒中"] = true`, `u["觉醒类型"] = "隐身"`, `u["本场已开隐身"] = true`, `ctx["本场有人觉醒过"] = true`）。
     - **隐身中效果**：
       - **单体不可选中**：敌方选择单体攻击目标（含 `Ai.pickSingleTarget` / `bestWeaponOn` 与 `Btl.算意图`）时，若我方场上存在其他非隐身的存活队友，则过滤排除处于 `隐身` 中的迪奥；若我方仅剩隐身单位存活，则允许选中（默认规则 1）。范围攻击照常波及。
       - **潜伏蓄势**：每个我方阶段开始时，若迪奥处于 `隐身` 中，战意额外 `+5`（合计 `+10`）。
       - **AI 自动出牌跳过**：点「结束我方回合」触发 `AiDeck.auto_play_unit_main_weapon` 时，若迪奥处于 `隐身` 中，直接跳过不替他打主武器。
       - **破隐规则**：迪奥打出任何**武器牌**（主武器、副武器、武器型大招）时，**本次攻击全程仍按 `隐身中` 结算**（吃满隐身条件与加成），攻击结算完毕后立即退出 `隐身`（`u["觉醒中"] = false`, `u["觉醒类型"] = ""`），并将 `超级干扰器·潜入` 槽的 `cd` 设为 `2`（`+` 版设为 `1`）。若打出的是 `破隐一击`，记录 `u["本场打过破隐一击"] = true`。打出精神牌或公有牌**不会**破隐。

### 1.3 QTE 接口与测试期控制（`ColonialV01.取QTE结果`）
- **适用范围**：殖民卫星军 5 名成员所有**武器型大招**（`is_weapon: true` 的大招槽卡，以及 METEOR 锁定链的 `发射` 临时卡，后者在 `发射` 时统一判定 1 次）。
- **标准三档效果表**：
  | 档位 | 代码枚举 | 本次攻击加成（每段生效） | 打出者状态加成 |
  |---|---|---|---|
  | **失手** | `"miss"` | 命中 `+0`，伤害 `+0%` | — |
  | **成功** | `"good"` | 每段命中 **`+10`**，伤害 **`+10%`**（`×1.10`） | — |
  | **完美** | `"perfect"` | 每段命中 **`+20`**，伤害 **`+25%`**（`×1.25`） | 打出者到下个我方阶段前 **闪避 `+20`** |
- **判定与覆写管线 `ColonialV01.取QTE结果(ctx, u, card, 指定结果 = "") -> String`**：
  1. 若 `bool(u.get("本回合极限超频", false))` 为真（三级感应牌 `极限超频`） → 强制返回 `"perfect"`；
  2. 否则确定基础结果 `raw`：
     - 若处于 AI 自动出牌（`bool(ctx.get("_ai自动出牌中", false))`） → `raw = "good"`；
     - 若外部（如 UI 手动弹窗点选或测试传入）显式传入了 `指定结果 in ["miss", "good", "perfect"]` → `raw = 指定结果`；
     - 否则读取 `ctx.get("qte模式", "manual")`：
       - `"perfect"` → `"perfect"`
       - `"good"` → `"good"`
       - `"miss"` → `"miss"`
       - `"random"` → 用 `ctx.rng` 等概率（或 20% 失手 / 50% 成功 / 30% 完美）掷出
       - `"manual"`（无显式弹窗参数时的后备默认） → `str(ctx.get("qte默认结果", "good"))`
  3. **失手保底覆写**：若 `raw == "miss"`，且（`ColonialV01.是SEED中(u)` 或 `bool(ctx.get("本回合全体QTE保底成功", false))`），则升级为 `"good"`！
  4. **ZERO 完美必暴击**：若最终结果为 `"perfect"` 且 `ColonialV01.是ZERO中(u)`，本次大招攻击标记 `必暴击 = true`！
  5. 战报清晰输出：`〔QTE·完美〕【拉克丝】全弹齐射 QTE 判定：完美（命中+20 / 伤害+25% / 闪避+20）`。

### 1.4 势力机制【觉醒感应】与感应牌库（11 张，复用 `SubDeck`）
- **触发时机**：当殖民卫星军成员打出带有 `觉醒感应: true` 的卡牌（武器大招、精神牌、势力牌）时：
  - 在卡牌打出瞬间检查 `not ColonialV01.是觉醒中(u)`：
  - 若打出者**未处于觉醒中**：
    1. 若 `ctx["公有手牌"].size() < 6`，从 `ctx["感应牌库"]` 随机抽 1 张放入 `ctx["公有手牌"]`；
    2. 若该牌带有 `感应放入` 字段（如 `"COL_SD2_CHAIN"` 等），调用 `SubDeck.放入(ctx["感应牌库"], 目标感应卡)` 将其加入感应牌库（受 `SubDeck` 内置断路器 1 保护：三级感应牌每种每场最多放入 1 次；且即使公有手牌满 6 张未抽牌，「放入 X」仍正常生效）。
- **感应牌库 11 张完整规格**（`0` 费，不占主武器，算殖民卫星军牌，不带【觉醒感应】）：
  - **一级（4 张，开场在库，打出后回库）**：
    1. `COL_SD1_PROP` **推进剂**（目标：`卫星军成员`）：指定一台殖民卫星军成员，战意 `+10`。
    2. `COL_SD1_SYNC` **同步**（目标：`卫星军成员`）：指定一台成员，其觉醒入场牌冷却 `-1`。
    3. `COL_SD1_PREMON` **预感**（目标：`卫星军成员`）：指定一台成员，到下个我方阶段前闪避 `+15`。
    4. `COL_SD1_EMPATHY` **共感**（目标：`未觉醒卫星军成员`）：指定一台没在觉醒中的成员，本回合它下一张武器牌命中 `+15`、暴击 `+15`。
  - **二级（4 张，由【觉醒感应】放入，打出后回库）**：
    5. `COL_SD2_CHAIN` **觉醒连锁**（由拉克丝 `全弹齐射` 放入，目标：`未觉醒卫星军成员`）：指定一台没在觉醒中的成员，本回合它的觉醒入场牌无视战意门槛（`u["本回合无视觉醒战意门槛"] = true`）。
    6. `COL_SD2_OVERCLOCK` **超频**（由希罗 `破坏步枪·最大出力` 放入，目标：`觉醒中卫星军成员`）：指定一台觉醒中的成员，本回合它下一张觉醒大招费用 `-10`（`u["本回合觉醒大招降费"] += 10`）。
    7. `COL_SD2_SHADOW` **死神的影子**（由迪奥 `死神镰刀·斩首` 放入，目标：`敌机`）：指定一台敌机，本回合我方对它的下一次攻击必定暴击（`e["本回合下次受击必暴击"] = true`）。
    8. `COL_SD2_FORESIGHT` **零的预见**（由势力牌 `塔莉亚的指挥` 放入，目标：`卫星军成员`）：指定一台成员，到下个我方阶段前，它第一次被攻击时整次打空（`u["零的预见层数"] = 1`）。
  - **三级（3 张，由【觉醒感应】放入，每种每场限放入 1 次，打出后移出本场）**：
