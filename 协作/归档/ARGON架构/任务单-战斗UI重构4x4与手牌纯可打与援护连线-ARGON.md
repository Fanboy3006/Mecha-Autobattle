> **来源**：作者试玩反馈（4 项核心体验与 UI 重构指令）+ `live_actions.jsonl`（466 行）实测对账。

## §1 需求拆解与根因对账

1. **问题 1：「艾克赛琳有多个援护射击，感觉不太对」**
   - **根因**：`setup.gd:246-247`（`_生成初始衍生牌`）与 `btl.gd:1555`（`刷新回合衍生牌`）给所有 `职业 == "狙击"` 的机体塞了一张旧版 M3 通用衍生卡 `D_援护射击`（进 `u.衍生手牌`）；而艾克赛琳（`A2`）已有 `ATX2_D1 援护射击`（在 `u.副武器栏`），克鲁兹（`U6`）已有 `V3_U6_D1 援护射击`（在 `u.副武器栏`），导致上排同时出现两张同名【援护射击】。
   - **修法**：当 `DeckFlow.开启吗(ctx)` 为 `true`（或 `u.副武器栏` 已有援护射击/副武器）时，`setup.gd` 与 `btl.gd` 不再生成旧版 `D_援护射击`（并在 `game_session.gd:_专属牌视图` 中对同名 `援护射击` 去重，只保留 `副武器栏` 的那一张）。

2. **问题 2：「UI 需要改进：中间偏上合并成 4×4；中间偏下显示卡牌（主武器牌、副武器牌、精神牌、公有牌）；手牌里的都要能打，不能用的武器/有 CD 的牌留在左边牌库（CD 体现为 X 回合后自动进入手牌）」**
   - **整体三栏布局（`1280 × 616` 可用区，`y = 104..720`）**：
     - **左栏 `左牌库栏`（宽 `~265px`，高 `608px`）**：显示未激活 / 暂不可用 / 冷却中的牌与副牌库：
       - **【暂不可用武器】**：距离/站位不符（如后排近战刀）、本回合已打其它主武被销毁、本场次数用尽、战意不足的武器；
       - **【冷却中（X 回合后进入手牌）】**：所有 `cd > 0` 的大招、副武器（如用过的【援护射击】`1 回合后进入手牌`、【烟雾弹】`3 回合后进入手牌`）、冷却牌，统一显示醒目标签 **`〔X 回合后进入手牌〕`**；
       - **【待激活牌库】**：亮起条件尚未满足的大招（如 `赌神·入局`、`左轮打桩机·全弹`、`轮盘双响`、`乌鲁兹·三角`）、`u.待入库` 与 `ctx.公有待入库` 中等待条件解锁的牌、以及当前因战意/门槛暂不可打的精神牌/公有牌；
       - **【副牌库（连携 / 筹码）】**：展示连携牌库（一/二/三级）与筹码牌库（小/大/头奖）明细及抽牌堆/弃牌堆张数。
     - **中栏 `中主战区`（宽 `~660px`，高 `608px`）**：
       - **中上 `阵型区`（高 `~352px`）：合并 4×4 战场棋盘**：
         - 将原左右并排的 `我方 4×2` 与 `敌方 4×2` 合并为 **上下对峙、4 列对齐的 4×4 棋盘**（列 1..4 纵向严格对齐，屏幕上正交格数 == 真实距离 `1..6`）：
           - 第 1 行（最上）：`敌方阵型第1排`（敌后排，列 1..4，`slot 4..7`）
           - 第 2 行（次上）：`敌方阵型第0排`（敌前排，列 1..4，`slot 0..3`）
           - `─────── 前线接触线（距离 1）───────`
           - 第 3 行（次下）：`我方阵型第0排`（我前排，列 1..4，`slot 0..3`）
           - 第 4 行（最下）：`我方阵型第1排`（我后排，列 1..4，`slot 4..7`）
         - 每张 `UnitCard` 尺寸约 `152 × 74`（4 列 × 4 行严丝合缝，不重叠、不越界）。
       - **中下 `手牌栏`（高 `~250px`）：四类纯可打手牌区**：
         - 清晰分为四大区块：**`【主武器牌】`**、**`【副武器牌】`**、**`【精神牌】`**（位于 `_专属排`）与 **`【公有牌】`**（位于 `_公有排`）；
         - **铁律（手牌里的都要能打）**：凡出现在中下 `手牌栏` 里的牌，必须 **`可打 == true`**（按钮绝不 `disabled`）；任何 `可打 == false`（有 CD、条件未满、距离不符、本回合已打过、战意不足）的牌一律移入左侧 `左牌库栏`！当下一回合 CD 归零或条件满足时，自动进入中下手牌区。
     - **右栏 `战报栏`（宽 `~330px`，高 `608px`）**：
       - 顶部放 `战斗按钮组`（结束我方回合 / 自动 / 结算），下方全高滚动显示 **`战斗记录`**（上限扩至 150 条）。

3. **问题 3：「右边用来显示战斗记录，现在的战斗记录还不够详细，有时候用了精神之类的东西，没有显示在记录里面」**
   - **根因**：`btl.gd:2396-2403`（`_执行精神效果`）调用 `CardEffects.execute()` 后丢弃了返回的 `摘要` 数组，且 `Btl.加战意`、`Btl.换同源增益` 与多张精神/职业/势力牌未将具体效果写入 `ctx.log`；导致日志只有「X 打出【牌名】」，没有具体效果。
   - **修法**：
     - 在 `btl.gd:打出精神或公有牌` / `_执行精神效果`（以及 `DeckFlow.打出副武器`、`DeckFlow.打出连携牌`、`AtxChips.打出筹码牌`、`AtxThree.打出牌`、`DeckFlow.打出大招`）中，把卡牌产生的具体效果摘要（如 `→ 战意 +20`、`→ 本回合命中 +15、暴击 +15`、`→ 抽 1 张精神牌`、`→ 敌方全体命中 -15`）完整拼入 `pushLog` 的日志文本中！
     - 将 `game_session.gd:519` 监控快照的 `recent_battle_log` 从 8 条扩为 40 条。

4. **问题 4：「另外靶机先只保留 1 个援护设定，如果有援护防御的话需要显示谁保护了谁，还有几个援护次数。在 4×4 的格子上面做一个连线体现。」**
   - **根因**：`1-N1` 靶机里有 2 台重装（`盾卫·靶机` 与 `甲虫型重机·靶机`），且触发了旧版无限次数的 `同路铁壁护卫` 与 `50% 随机重装挡枪`，导致一回合挡枪 6~8 次且日志只写「把这一击勾了过去」看不出谁保护谁。
   - **修法**：
     1. **靶机只保留 1 个明确援护设定**：
        - 在快速测试靶机改造（`game_session.gd`）中，确保敌方后排 `突击兵·靶机` 站在 `slot 4`（敌后排列 1，即 `盾卫·靶机 slot 0` 的正后方同列）；
        - 仅给 **`盾卫·靶机`（`slot 0`）** 设置 `靶机援护剩余 = 2, 靶机援护上限 = 2`（保护同列后排 `slot 4`，每回合敌方阶段初重置为 2）；将其余靶机的重装随机挡枪/无限同路护卫关闭（在 `btl.gd:嘲讽` 中，当 `_快速测试局` 或 `卡牌流转` 开启时，关闭旧版 50% 随机重装挡枪，靶机仅走 `盾卫·靶机` 这 1 条固定同列 2 次援护！）。
     2. **战斗日志写清「谁保护了谁 + 剩余援护次数」**：
        - 在 `flow.gd:252-253`（及 `btl.gd:嘲讽`）中，将日志从 `"%s 把这一击勾了过去"` 升级为：
          **`〔援护防御〕<保护者> 保护 <原目标>，替其挡下攻击！（剩余援护 X/Y 次）`**。
     3. **4×4 棋盘上实时绘制「援护防御连线 + 剩余次数徽章」**：
        - 在 `btl.gd` 新增纯读函数 `当前援护连线们(ctx) -> Array[Dictionary]`，汇总当前在场生效的所有援护防御关系（每条 `{from_key, to_key, from_slot, to_slot, side, remaining, max_count, label}`）：
          - 敌方：`盾卫·靶机 (slot 0)` → 同列后排 `突击兵·靶机 (slot 4)`，显示 `援护 X/2`；
          - 我方：塔斯克 `A6` 被动【掩护】（保护同列后排如艾克赛琳，显示 `掩护 X/2`）、重装【横向掩护】（保护同排左右相邻队友，显示 `掩护 本回合`）、宗介 `U7`【掩护】（保护同列后排，显示 `掩护分摊30%`）、【铁壁护卫】等；
        - 在 `battle_view.gd` 的 `战斗动画层`（`_特效画布`）上，为每条生效的援护关系绘制从 **保护者格子 → 被保护者格子** 的青蓝色护盾连线 + 箭头 + 线中胶囊标签 **`〔援护 X/Y〕`**，并在单位卡上同步标出！
