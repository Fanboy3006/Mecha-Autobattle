## §1 Batch 1 详细规格（`CB-0` + `CB-1`）

### 1.1 `CB-0`：3 条全局断路器 + 近卫「顺劈」
1. **断路器 1（`godot/core/battle/sub_deck.gd`）**：
   - 在 `SubDeck.新建()` 返回的字典中内置 `"已放入三级": {}`；
   - 在 `SubDeck.放入(库, 卡或卡id, 每场限次集合, 记录字段, 等级键, 限次下限)` 中：除了兼容外部传入的 `每场限次集合`，只要目标卡的等级（`连携等级` / `筹码等级` / `太阳炉等级` / `等级`）`>= 3`，强制检查 `库["已放入三级"].get(cid, false)`，若已放入过则直接返回 `false`；首次放入时登记 `库["已放入三级"][cid] = true`！
   - 确保秘银三级牌（`V3_L3_FULL`、`V3_L3_SUPPORT`）、ATX 头奖（`CHIP_L3_ALLIN`、`CHIP_L3_GRAND`）、天人三级牌（`CB_SD3_HERITAGE 伊奥利亚的遗产`、`CB_SD3_OPTIMAL Veda·最优解`）全部严格受此限制，且打出后移出本场（不回库）。
2. **断路器 2（`godot/core/battle/deck_flow.gd` + `atx_chips.gd`）**：
   - 在 `DeckFlow.大招可打吗(ctx, u, 槽或id)` 最顶层（在转交 `AtxThree.不可打原因` 之前）：只要 `bool(槽.get("本回合已打", false))` 为真，立即返回 `false`（不可打原因返回 `"本回合已使用"`）；
   - 在 `atx_chips.gd` 的 `CHIP_L3_ALLIN 梭哈` 结算中，除了把 `u.大招槽` 的 `cd` 清零，同步清空 `u["v01冷却"]` 字典中对应大招的 CD；但若某张大招本回合刚打过（`本回合已打 == true`），因断路器 2 存在，本回合仍不可打第二次，下回合起可打。
3. **断路器 3（`godot/core/battle/deck_flow.gd` + `btl.gd` + `fac_atx.gd`）**：
   - 统一每台机体的每回合恢复锁：在 `DeckFlow.再动(u, ctx)` 与 `Btl.连续攻击可用(u)` / `Btl.连续攻击记(u)` 中，**共享同一个布尔状态**：只要 `bool(u.get("本回合再动已用", false)) or bool(u.get("连续攻击已用", false))` 为真，本回合任何「再动 / 连续攻击 / 主武器恢复」一律拒绝二次触发！
   - 触发一次「近卫连续攻击」时，同时将 `u["连续攻击已用"] = true` 和 `u["本回合再动已用"] = true`；触发一次 `DeckFlow.再动(u, ctx)` 时，也同时将两者置 `true`（在每个我方阶段初统一复位为 `false`）。
   - *注意*：`DeckFlow.再动(u, ctx)` 恢复主武器栏时，**若某张主武器带有 `bool(w.get("出鞘", false)) == true`（刹那出鞘的剑牌），绝对不能恢复它**！同样，近卫「连续攻击」恢复主武器时，**出鞘的剑牌也绝不恢复**！
4. **近卫分类牌删除「连斩」→ 新增「顺劈」（`godot/core/battle/class_cards.gd` + `btl.gd` + `calc.gd`）**：
   - 在 `class_cards.gd` 中：将 `CC_G6` 从「连斩」改为 **「顺劈」**：
     - `"id": "CC_G6"`, `"name": "顺劈"`, `"职业": "近卫"`, `"cost": 5`, `"入库条件": "开战即入库"`, `"获取": "初始"`, `"目标": "自身"`
     - `"效果说明": "本回合打出者下一张近战武器牌附加【顺劈】（目标同排左右相邻的敌机各受 50% 伤害，各自判定命中与暴击）。"`
     - 打出时设置 `u["下张近战附加顺劈"] = true`，返回摘要 `["作用于【%s】：本回合下一张近战武器牌附加【顺劈】（同排左右相邻敌机各受 50%% 伤害）" % str(u.get("name", ""))]`。
   - **武器范围形状 `顺劈`（`area = "cleave"` 或 `"顺劈"`，或近战攻击时消耗 `u["下张近战附加顺劈"]`）**：
     - 当近战武器本身 `area in ["cleave", "顺劈"]` 或攻击方带有 `u.get("下张近战附加顺劈", false)`（仅对 `range_kind == "近战"` 生效，触发后清掉 `下张近战附加顺劈`）时：
     - 找出主目标 `target` 在敌方同排（`Fm.rowOf(target.slot) == Fm.rowOf(e.slot)`）且列号左右相邻（`abs(Fm.colOf(target.slot) - Fm.colOf(e.slot)) == 1`）的所有存活敌机（最多 2 台，只看同排左右，不看前后排）；
     - 按默认值拍板：主目标正常按 100% 威力逐段结算；同时对每台左右相邻敌机，初始化该副目标独立的**装甲共享池**，多段武器的**每一段**都对该副目标按 **`50%` 单段威力** 独立掷命中与暴击、消耗该副目标的装甲池并扣减 HP，写入攻击战报与受击飘字！
   - 同步更新 `tests/unit/test_class_cards.gd` 中对 `CC_G6` 的测试为测试「顺劈」（验证同排左右相邻敌机受 50% 伤害、身后不同排敌机不受伤、多段逐段劈）。

### 1.2 `CB-1`：天人公共机制 + 太阳炉牌库 + 9 张势力牌 + 拉塞 `CB5`（`godot/core/battle/celestial_v01.gd`）
1. **天人成员识别**：
   - 天人 5 人：`CB1`（刹那·近卫）、`CB2`（洛克昂·狙击）、`CB3`（阿雷路亚·特种）、`CB4`（提耶利亚·重装）、`CB5`（拉塞·重装），`tags.势力 == "天人"`。
   - 四名高达驾驶员：`["CB1", "CB2", "CB3", "CB4"]`（拥有 `TRANS-AM·启动`）；`CB5` 拉塞无 TRANS-AM。
2. **`TRANS-AM·启动`（大招槽入场牌，ID：`CB_ULT_TRANSAM`）**：
   - 费用 `20`，`is_weapon: false`，`武器牌: false`（打入副武器手牌区，打出后不销毁主武器栏，本回合仍可照常打主武器）；
   - 亮起条件：`ctx.round >= 3` 且 `not bool(u.get("本场已开TRANSAM", false))` 且 `int(u.get("transam剩余回合", 0)) <= 0`（若肉鸽/剧情配置了 `ctx.禁止TRANSAM入场`，则不装入）；
   - 打出效果：
     - `u["本场已开TRANSAM"] = true`，`ctx["本场有人开过TRANSAM"] = true`；
     - `u["transam剩余回合"] = 3`（打开的当前我方阶段算第 1 个，持续 3 个我方阶段）；
     - `u["粒子耗尽剩余回合"] = 0`（若此前处于粒子耗尽则立即清除）；
     - 若是阿雷路亚 `CB3`，立即激活「超兵同调」（不被动切换，哈雷路亚也能打公有牌）。
   - **持续与衰减时序**：
     - 在**我方阶段结束时**（或下个我方阶段开始时，严格保证打开的那个我方阶段 + 后续 2 个我方阶段共 **3 个完整的我方阶段**享受 TRANS-AM）：每经历完 1 个我方阶段，`transam剩余回合 -= 1`；
     - 当 `transam剩余回合` 从 `1` 减到 `0` 时，转入 **「粒子耗尽」**：设 `u["粒子耗尽剩余回合"] = 1`（持续接下来的 1 个我方阶段，该我方阶段结束时归 0）。
   - **数值效果**：
     - `TRANS-AM 中`（`int(u.get("transam剩余回合", 0)) > 0`）：武器伤害 `×1.3`，闪避 `+15`，本人打出的【武力介入】**必定触发**，解锁要求 `TRANS-AM 中` 的大招与各人专属被动；
     - `粒子耗尽`（`int(u.get("粒子耗尽剩余回合", 0)) > 0`）：武器伤害 `×0.7`（即 `−30%`），精神牌与公有牌照常可打。
3. **敌机「本回合被攻击过」与【武力介入】**：
   - 每个我方阶段开始时，清空所有敌机的 `e["本回合被攻击过"] = false` 与 `e["本回合任务目标"] = false`；
   - 判定【武力介入】是否满足（`CelestialV01.武力介入满足吗(ctx, 施放者, 目标敌机)`）：
     - 若 `施放者` 处于 `TRANS-AM 中` → **必定满足（`true`）**；
     - 否则看玩家指定的主目标 `目标敌机`：若 `not bool(目标敌机.get("本回合被攻击过", false))` 或 `bool(目标敌机.get("本回合任务目标", false))`（`Veda·任务计划`） → **满足（`true`）**！
   - **注意判定与标记的先后顺序**：
     - 打出带【武力介入】的武器牌/大招/精神牌/势力牌时，**先判定**目标在本次攻击前是否满足【武力介入】；
     - 每次我方对敌机执行武器/大招/伤害牌攻击结算完毕后，将该次攻击的主目标及所有被波及结算过的敌机标记 `e["本回合被攻击过"] = true`（即使未命中/打空也算被攻击过；但纯上 Buff/Debuff 不造成伤害的精神牌/势力牌如「武力介入，开始」「同时多发介入」「Veda·弱点解析」不把敌机标为 `已攻击过`，这样后续第一刀武器打上去还能触发，或者按牌面说明：精神牌本身先触发一次武力介入，武器打上去时若精神牌不算“攻击”，武器还能触发；**严格对齐设计稿**：刹那稿 §6 写明「『武力介入，开始』：这台敌机挨过打以后就不再触发【武力介入】，要先打它」，说明精神牌本身不设 `本回合被攻击过 = true`，只有「被我方任何武器、大招或伤害牌选为目标或打到过，打空也算」才设 `本回合被攻击过 = true`！）。
   - 触发【武力介入】时：
     - 先从 `ctx["太阳炉牌库"]` 随机抽 1 张进 `ctx["公有手牌"]`（公有手牌满 6 张时不抽，牌留在库里）；
     - 若该牌带有 `介入放入`（如放入 `GN 全盾·哈罗` / `Veda·行动预测` / `Veda·任务计划` / `超兵反应` / `伊奥利亚的遗产` / `Veda·最优解`），调用 `SubDeck.放入` 塞进太阳炉牌库（即使公有手牌满 6 张，放入也照常执行；三级牌受断路器 1 限制每种每场最多放入 1 次）。
4. **太阳炉牌库（10 张，全队一份，0 费，不占主武器，算天人牌，带 `veda` 标签识别）**：
   - **一级（4 张，开场在库，打出后回库）**：
     1. `CB_SD1_SCATTER` **GN 粒子散布**（粒子，目标：`敌机`）：指定一台敌机所在的一整排，到下个我方阶段前命中 `-10`。
     2. `CB_SD1_REFILL` **GN 粒子补充**（粒子，目标：`天人成员`）：指定一台天人成员，战意 `+10`。
     3. `CB_SD1_HARO_HEAL` **哈罗·紧急修理**（粒子，目标：`天人成员`）：指定一台天人成员，回复最大 HP 的 `10%`。
     4. `CB_SD1_VEDA_SCAN` **Veda·战况分析**（Veda，`veda: true`，目标：`天人成员`）：指定一台天人成员，抽 1 张精神牌。
