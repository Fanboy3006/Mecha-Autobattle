> ★ **一句话**：**Architect 主会话只出设计方案与 `协作/派单/当前任务.md` 任务书（内置 `subagent` 只做只读探针，绝不动手改码）；代码施工一律交人类另开的跨窗口 Worker 会话执行。**

### 零之一、三角色边界（★ 架构 2.0 · 2026-10-13 定案）

| 角色 | 是谁 | **只做** | **绝不做** |
|---|---|---|---|
| **Architect**（架构 / 设计） | 主会话（`gemini-4-argon`） | 定规则与数值、写任务书、**定义不变量**（`协作/架构快照.json` 的机器事实 + `tests/arch.js` 的七段）、维护真相源层级（`L0 CLAUDE.md` → `L3 源码+快照` → `L4 门禁`） | 不读源码大文件、不手改产物、不替 Worker 判「测试绿了」 |
| **Worker**（施工） | `subagent`（`deepseek-flash`）/ 跨窗口 DSH | 照任务书改 `src/js/**`、跑 `build-src` / `--check` / `verify-all`（**23 / 23**）、**只回传 ≤20 行摘要**（改了哪些文件 + 三条命令真实输出 + `规则签名` 真实值） | **不改设计、不放宽既有断言、不 `git commit` / `git push`**、不碰别的并行线未提交的文件 |
| **Guardian**（破坏性审查） | **独立**会话（另一个 DSH 窗口 / 另一个 `subagent`） | **只查不变量**：读快照 + 门禁 + diff，专找「机器可证伪」的反例（改一个 `战斗结构` 参数看 `arch`[1] 红不红、`Math.random` / `ctx.rng` 越权、默认路径是否被污染、旧录像还能不能读） | **不改设计、不改断言、不替 Worker 修码** —— 只出「红 / 绿 + 反例 + 证据」 |

> ★ **三句话边界**：**Architect 定不变量，Worker 让门禁绿，Guardian 只负责把门禁弄红**（破坏者只查不变量，不改设计）。
> ★ Worker 与 Guardian **必须是两个独立会话**（同一个会话既改又审 = 自己给自己发合格证）；Guardian 手里那份 `verify-all` 输出必须是自己跑出来的。

### 零之二、开窗规范（长期 2 会话 + 短期 N 任务会话）

| 窗口 | 寿命 | 干什么 | 满血重开怎么接 |
|---|---|---|---|
| **① Architect**（长期） | 贯穿整条线 | 定规则 / 拆任务 / 维护 `协作/架构快照.json` 与真相源文档 | 重发开机词 ①（下面第三节）；状态全在文件里，**不靠上下文记忆** |
| **② Guardian**（长期） | 与 Architect 同寿 | 每次 Worker 交单后做**破坏性审查**（只查不变量） | 重发开机词 ⑤；只读「任务书 + diff + 快照 + 门禁输出」 |
| **③ Worker × N**（短期） | **一单一窗**（做完即弃） | 每单一个施工子代理 / 跨窗口会话：改码 → 三条命令 → ≤20 行交单 | 用完就丢；**下一单必须新开**（避免上下文里混着上一单的假设） |

> ★ **长期只留 2 个**（Architect + Guardian），**短期按任务数开 N 个** Worker —— 这是「上下文防火墙」的落点：
> 设计记忆留在 Architect、审查标准留在 Guardian，**施工上下文用完即焚**。
> ★ 每单闭环：Architect 出任务书 → Worker 施工（禁 commit）→ Guardian 破坏性审查 → Architect 收单并同步速查卡 / 快照。

## 一、核心机制：四条上下文铁律

### ① 开机只读速查卡（省 85% 上下文）
- **热数据（开机唯一必读）**：
  - **设计 / 评审 / 提案会话** → 只读 [`docs/设计/AI速查卡.md`](../docs/设计/AI速查卡.md)（**72 行**，纯当前生效规则，不含历史变更过程）；
  - **实现 / 施工会话（`subagent` = `deepseek-flash` / 跨窗口 DSH）** → 只读 [`docs/实现/AI速查卡.md`](../docs/实现/AI速查卡.md)（**45 行**，56 个源码片段速查 + 接口 + 四大铁律）。
- **冷数据（按需字典，★ 严禁开机通读）**：`规则总览.md`、`交付记录.md`、`协作/接口约定.md`（1200+ 行）、`协作/任务板/**` 仅在需要核对某条具体历史口径或字段签名时，按章节号定点查阅；**不要一开机连读 10 篇长文档**。

### ② 主会话「零裸读源码 / 大文件」纪律（Probe Subagent）
- **铁律**：主会话（`gemini-4-argon`）**严禁自己调用 `read` 读取 `src/js/**`、`tests/**`、`index.html` 或大型 JSON 录像**（一旦读入，几千行代码会永久驻留主会话上下文）。
- **标准动作**：凡需要**查代码 / 读录像 JSON / 跑脚本 / 改代码**时，**一律调 `subagent`（自动走 `deepseek-flash`）**：
  - 给 Subagent 明确查证问题与目标文件前缀（查速查卡 §1）；
  - 要求 Subagent **只回传 ≤15 行纯结论摘要**（含 `文件名:行号` 与关键表达式，严禁粘贴大段源码）。

### ③ 跨窗口 / 外部会话走信箱或极简开机词
- **外部 Claude 网页端**：**只喂 `docs/设计/AI速查卡.md`**（72 行，纯现行规则），**不喂**历史长文档；
- **跨窗口 DSH 施工**：读 [`协作/派单/当前任务.md`](派单/当前任务.md)，完工覆写 [`协作/派单/最新交付.md`](派单/最新交付.md)；作者侧只需「**按单开工**」与「**验收**」两个词。

**双通道职责硬隔离（探针走内置 `subagent` / 施工走跨窗口文件信箱）**

| 维度 | 通道 X：同窗口内置 `subagent`（**仅限 T1/T5 只读探针**） | 通道 Y：跨窗口文件信箱（**T2–T4 唯一施工通道** · 另一个 DSH 窗口） |
|---|---|---|
| **适用场景** | **仅限只读事实调查**：查源码行号、读录像摘要、跑 `--no-write` 内存平衡测算（**严禁改任何文件**） | **一切代码与测试施工（T2/T3/T4）**：特性落地、参数调整、修 bug、重建生成物与门禁验收 |
| **下单方式** | 主会话把只读探针问题塞进 `subagent` prompt 直接启动 | 主会话将完整规格写入 [`协作/派单/当前任务.md`](派单/当前任务.md) **并立即停下汇报**（未获人类显式指令严禁同窗直派施工） |
| **人类操作** | **0 操作**（同窗口只读取证） | 切到独立施工窗口输入 **「按单开工」**；完工后回主窗口输入 **「验收」** |
| **交单方式** | Subagent 直接返回 **≤20 行** 只读事实摘要 | 施工线将结果覆写进 `协作/派单/最新交付.md`（**≤25 行**） |

- **文件信箱双文件契约**：
  1. `协作/派单/当前任务.md`（主会话写 → 施工线读）：每次只放**当前 1 单**（新单直接覆写），按「目标口径 / 参数表与开关 / 涉及片段 / 接口登记 / 三层反馈 / 测试与验收命令」结构编写；
  2. `协作/派单/最新交付.md`（施工线写 → 主会话读）：施工线跑通 `verify-all.mjs`（**23/23 绿**，含架构门禁 `tests/arch.js`）后写入，只列「改了哪几个文件、新增了什么开关与接口、3 条命令真实输出、`规则签名` 真实值、待拍板项」，控制在 **25 行以内**。

### ④ 上下文水位 50% 熔断与无缝续接
- **熔断线**：当主会话（`gemini-4-argon`）上下文水位**超过 50%**（或完成 2~3 个大特性回合后），主动触发熔断，不在高水位下继续长篇讨论。
- **沉淀动作**：花 1 回合把本轮**已拍板定案的新规则写回** [`docs/设计/AI速查卡.md`](../docs/设计/AI速查卡.md)，未决项更新进 [`docs/设计/待定与开放问题.md`](../docs/设计/待定与开放问题.md)，在建任务写进 `协作/派单/当前任务.md`。
- **满血重开**：**新开会话喂下面 5 行开机词秒接**（第 5 行是「接着做什么」），瞬间以 <5% 水位续接。

## 二、标准闭环流水线（4 步跑完一个特性）

1. **定案（主会话）**：主会话基于 `docs/设计/AI速查卡.md`、`docs/实现/RouteMap.md` 与作者拍板方案（如需查源码细节，派只读 Probe Subagent 探路），产出结构化方案；
2. **下单（写信箱即停）**：作者点头后，主会话把完整施工规格写入 `协作/派单/当前任务.md` **并立即停下汇报**（严禁自己在主会话调内置 `subagent` 改码，除非作者当场显式指示）；
3. **施工（跨窗口执行线）**：人类另开的施工会话读 `docs/实现/AI速查卡.md` + `协作/派单/当前任务.md`，先登记 `协作/接口约定.md`，再改 `src/js/` 对应片段、跑通构建与 `23/23` 验收，将 ≤25 行报告写入 `协作/派单/最新交付.md`；
4. **验收（主会话）**：作者在主会话回「验收」，主会话只读 `协作/派单/最新交付.md`（25 行），确认全绿后同步更新 `AI速查卡.md`。
