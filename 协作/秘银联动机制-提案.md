## 0. 先说清楚：为什么不能照抄战棋里的秘银

战棋里的秘银核心是毛的「指挥网络」：**5×5 区域 + 克鲁兹无视障碍物 + 免费的支援射击**（`协作/势力特色.md:307`）。
这三样正好踩了我们**丢掉的三样东西**——区域 / 障碍物 / 援护的位置判定，
所以 `协作/势力特色.md:337` 对它的判断是「**做不了（按现有引擎）**」，`:351` 的结论是「秘银是七套里落地成本最高的一套」。

**所以这一版的思路不是搬运，是重写**：把丢掉的这三样，各自换成我们引擎里**已经有的**东西。
下面的方案一就是把这件事做到最彻底的一个（表在 §1.2）。

## 1. 原作里秘银是什么定位，哪些设定适合做机制

### 1.1 一段话：秘银是「情报 + 特种作战」组织，不是「更猛的军队」

秘银（Mithril，ミスリル）是《全金属狂潮》里的**非政府反恐军事组织**：1992–93 年伊拉克北部核弹事件之后成立，
名字取自《魔戒》里的秘银；它**不站任何国家一边**，目标之一是**收容「耳语者（Whispered）」**，
所以它是少数知道耳语者与黑科技存在的组织之一（[Mithril](https://fullmetalpanic.fandom.com/wiki/Mithril)）。

它的组织分三个部门：**研究部 / 情报部 / 战术部**，由总理事会统管。其中**情报部最独立、保密级别最高**，
手里有**军用卫星、先进计算机设备、渗透在别的组织里的人**，也负责找耳语者；
战术部下面分五支舰队，太平洋战队的旗舰就是 **TDD-1 塔乌哈·德·丹南（Tuatha de Danaan）**（同上）。

**最关键的两句话**决定了机制方向（同上，逐字）：

> 「Mithril is a specialist organization dependent on fast **surgical strikes with small numbers**.
> It does not possess the numbers or capacity to withstand a conventional war of numbers.」
> ——秘银靠**小规模外科手术式打击**，它**没有**打数量战的本钱。

> 「The command structure of Mithril is very direct… The high level of trust in individual ability gives each
> organizational unit a **strong level of autonomous decision making**.」
> ——指挥结构非常直接，**高度信任个人能力**，所以每个作战单位都有很强的**自主决断**。

再加上地面部队的编制：**SRT（Special Response Team）+ PRT**，
SRT 用**卢恩字母呼号**（Urzu / Kaunan，Urzu 意思是「力量」），而且**几乎每名 SRT 成员既是 AS 机师、也是别的领域的专家**，
还被鼓励**交叉训练**——「不管谁在战场上倒下，任务都还能完成」
（[Special Response Team](https://fullmetalpanic.fandom.com/wiki/Special_Response_Team)、[Mithril](https://fullmetalpanic.fandom.com/wiki/Mithril)）。

**三句话总结成机制方向**：
1. 秘银的强项是**情报与精准**，不是火力 → 特色应该是「**知道该打谁、全队共享这个情报**」，而不是数值加成。
2. 「**小规模 + 自主决断**」和我们「**只下大方向指令、剩下自动打**」「**3→6 台**」的框架天然合拍。
3. TDD-1 与 ECS 给它「**从水下浮上来打一手就撤**」「**电子隐匿**」的味道。

### 1.2 哪些设定适合做机制（一张表，含我们的换义落点）

## 2. 三个方案

三个方案都**只用现有机制**：9 格阵型（`05-阵型.js`）、五条大方向指令 + 大招开关、按速度行动、12 回合上限。
三个方案都**不新增任何绝对数值**，量级我都写成相对口径。

---

### 方案一 ★「URZU 网络」—— 情报共享与标定（推荐）

#### a. 一句话卖点

**秘银全队共用一张战场情报图：谁打过哪台敌机，全队都看得见——前排挡着的后排，在秘银眼里是透明的。**
玩家会看到「标定」在敌人卡片上亮起来，然后毛 / 克鲁兹 / 宗介轮流去**兑现**它。

#### b. 触发条件（在 9 格 / 指令 / 回合框架里怎么触发）

- **标定（情报是怎么产生的）**：任何一台秘银单位**命中**某台敌机 → 这台敌机累积 **1 层「标定」**。
  **一次行动无论打中几段（多段 / 范围）都最多 +1 层**（防叠层暴走，见 e）。
- **共享中枢 = 毛（指挥）**：**毛在场且活着**时，标定是**全队共享**的（谁标的都算数）；
  **毛被击破 → 网络降级**：标定只对**标定者自己**生效，而且每回合结束清空。
  ——这是「指挥网络」的正统重写：**把 5×5 区域换成「组织」**（原作里秘银的强项本来就是情报部的通信网与指挥链，不是某个范围框）。
- **兑现 ①「无视障碍」**：拿到标定的秘银单位，打这台敌机时**取消「被挡 −20」**。
  ——这就是「克鲁兹无视障碍物」在我们这里的等价物：我们**唯一**的「障碍」就是
  「直射打后排、而那个后排位的阻挡位里还有人 → 命中 −20」（`30-射程.js:74-78`，`CLAUDE.md` 第 6 节）。
  **诚实说明**：我们的**狙击**职业本来就没有这个惩罚（`30-射程.js:75`、`CLAUDE.md` 第 6 节），
  所以这一条真正的价值是**把狙击手的特权发给全队**（宗介 / 毛 / 克鲁佐 / 杨这些直射单位）。
- **兑现 ②「标定射击」（2 层及以上）**：标定到 2 层时，这台敌机**破防**——
  走我们**已经通到公式**的 `debuffs` → `breakSum` → `defMul` 管线（`20-战斗计算.js:38-39`）。
  这就是把战棋毛的「标定射击 −20% 破防」（`10-数据.js:262-263` 那把武器的设定）在自动战斗里做出来。
- **衰减**：**每回合结束标定 −1 层**（防滚雪球）。
- **指令怎么和它互动**（玩家要权衡的地方）：
  - **集火** = 让全队把标定压在同一台敌机上（网络叠得最快，2 层来得最快）；
  - **守护毛** = 保住网络（毛一倒，全队共享就没了）；
  - **进攻** = 打散到不同目标 → 标定满天飞但都只有 1 层，只吃「取消被挡」这一半；
  - **防御** = 毛不开火 → 标定来得更慢（网络的产出变少）。

#### c. 效果与强度量级（相对口径）

- **标定本身：0 伤害。** 它只改「**打不打得到**」和「**打不打得穿**」，不新增任何一次攻击。
- **取消被挡**：约等于对后排目标一次直射的**命中率 +20 个百分点**
  （我们引擎里这条惩罚就是 −20，`30-射程.js:77`）→ 命中率从 50% 到 70% 就是**期望伤害大约 +40%**；
  按一般情况算，**大约 +25%~+35%**。
- **2 层破防**：对**高防目标**的**有效伤害大约 +15%~+30%**（防御值越高收益越大；
  对第 4 层那种装甲很厚的 Boss 收益最明显）。
- **编队规模直接变强度**：3 台 ≈ 每回合大约标定 1 台；6 台 ≈ 每回合大约 2 台。
  这是三个方案里**唯一**一个「人多就强、但完全不是靠人多打伤害」的特色，和我们的成长轴（3→6 台）对得上。
- **总账**：一次完整的「标定 → 兑现」大约等于**多打半次到一次普通攻击**的价值，
  但它**分散在多台单位、多个回合**里，不会出现一击秒杀——**所以它大概是七套里最好调的一套**。

#### d. 实现量（三个方案里最低）

- **不需要新指令、不需要格子、不需要援护、不需要新 UI 结构。**
- 新的东西只有**一个「标定」记录**（敌机 → 层数）。两个现成落点随作者挑：
  - 挂在**目标身上**（完全照 `20-战斗计算.js:301-302` 特种挂「命中 −20」的写法：往 `def.buffs` 里 push 一条，`endTurn` 会自己 −1，`60-战斗.js:391`）；
  - 或者做成**战场级一张表**（`ctx` 上挂一个 `Map`，好处是「全队共享」天然表达得清楚）。
- **「取消被挡」的改动点是恰好一处**：`rowBlockPenalty()` 已经拿到了 `attacker` 参数（`30-射程.js:74`），
  在里面加一个「有标定 → 返回 0」的分支即可；调用侧不用改。
- **「破防」的管线已经通到公式**：`defMul` 在 `dmgCore` 里三处生效（弱点乘算 / 装甲 / 防御值，`20-战斗计算.js:150,159,178`）。
  但**全仓库目前没有生产者、也没有每回合衰减**（`endTurn()` 只衰减 `buffs`，`60-战斗.js:391`）
  → 要补一个生产者 + 一条衰减，跟着 `buffs` 一起做。
- **备选（成本一样）**：如果作者更喜欢「情报找到弱点 → **直接削装甲**」而不是「破防百分比」，
  换成 `armorCut`（绝对装甲削减）即可——它同样是「管线通了、没有生产者」：
  `effArmor()` 已经在减它（`20-战斗计算.js:37`），全仓库也没有人往里写。
- **记录文本**：给 `resolveAttack` 的返回加一句「标定 +1」/「标定 2 层：破防」。

#### e. 风险 / 可能过强的地方

- **毛是单点**：毛被击破网络就降级。这是我**故意的**设计意图（逼玩家用「守护」保住她），
  但如果作者觉得秘银太脆，可以改成「**毛只是加速器**：她不在也共享，只是层数上限更低」。
- **多段 / 范围武器一次叠满**：12–16 段的打桩机、范围武器一次行动就能标定一堆
  → **必须写死「一次行动最多 +1 层」**。
- **破防和藏品叠加**：`93-藏品.js:163` 已经有一件藏品给「破防 10%」→ 两个一起上要确认总量上限。
- **对 Boss 可能过强**：第 4 层大肥鱼的装甲是 **1800**（`10-数据.js` 里原样，换算仍归 Claude），
  破防对它的收益极高 → 可能需要给 Boss「标定无效」或者把层数上限卡在 2 层。
- **可见性**：玩家得能一眼看出「标定还在不在、毛死没死」→ 界面要加个标记（成本低，但**得做**）。

### 方案二 「λ 驱动 · 觉醒」—— 护盾被打穿才觉醒

#### a. 一句话卖点

**强弩的 λ 力场被打穿两次就会「觉醒」——之后 λ 武器 0 CD、单分子刀变成隔空 λ 拳。
你要不要故意让他去挨打？**

#### b. 触发条件

- **力场被击破计数**：宗介身上有 λ 力场（`shield: 4000`，数据已经在 `10-数据.js:236`），
  **护盾被完全打空（掉到 0）算一次击破**；数据里写死了 `lambdaAwaken: 2` ——
  这正是战棋原版的「**λ 力场被完全击破 2 次后 λ 觉醒**」（战棋只读出处 `03-能力与减免管线.js:245-251`）。
- **觉醒那一刻**：`awakenSwap` 把「**单分子刀 → 隔空 λ 拳**」「**散弹炮 → λ 驱动·散弹炮**」直接换上去，
  并且 **λ 类武器的 CD 归 0**（战棋原文的提示语是「λ 觉醒中：λ 武器 0 CD，单分子刀已升级」）。
- **势力化（可选，让它不只是一个人的特技）**：把「击破计数」改成**全秘银共享的 λ 计**——
  任何一台秘银单位挨打、或任何一层护盾被击穿，都往 λ 计里加；**宗介是唯一的出口**。
  这样「3→6 台」的编队规模就直接变成「觉醒有多快」，玩家可以把「**谁去挨打**」当成策略。
- **指令互动**：
  - `守护` = 让宗介替队友挨打 → 他的力场更快被打穿 → 觉醒更快（这是本方案最核心的玩法钩子）；
  - `大招：自动 / 保留` 在这个方案里有额外意义：**觉醒之后 λ 大招 0 CD**，
    玩家每一回合都在决定「这一回合放不放」——**用已有的开关做一个「留招还是放招」的决定**，不需要任何新 UI。
- **叙事包装**：战棋原版的「λ 觉醒」是自动的；我们这里有「大招开关」这位现成的接口，
  正好对应原作里 Al（与 λ 驱动共生的机体 AI）「自己判断」的味道。

#### c. 效果与强度量级（相对口径）

- **觉醒之前：收益 0**（只有 λ 力场本身的吸收，那个已经在数据里，不是我新加的）。
- **觉醒之后**：λ 武器从「**CD 3 回合一次**」变成「**每回合都能用**」
  → **单位时间的 λ 输出大约 2–3 倍**（相对量级；绝对值归 Claude）；
  单分子刀换成隔空 λ 拳是**近战射程 1 → 3**（`10-数据.js:243` 的 `range:[1,3]`）、
  伤害类型换成特殊（无视光束 / 物理抗性）。
- **触发需要的时间**：按我们「实际 1–5 回合打完」的节奏（`CLAUDE.md` M6 段实测 Lv20 起很多战斗 1.0–1.7 回合），
  4000 点的力场要被打空一次，差不多就是**一场战斗里的一到两次集火**——
  **两次击破在短战斗里很可能根本来不及**。这是本方案最大的量级风险（见 e）。

#### d. 实现量（中）

- **数据一个字节都不用改**：`shield` / `lambdaAwaken` / `awakenSwap` 已经跟着模板复制进来了（`10-数据.js:236`），
  只是**引擎里没有任何地方读它们**（全仓库搜这三个字段，只有数据行本身命中）。
- 引擎要接三件事：
  1. **护盾归零的时候发一次「击破」**——改动点在 `REDUCTIONS` 的 `shield` 那一条，
     `shieldHp` 就是在这里扣的（`20-战斗计算.js:115-124`，`c.def.shieldHp -= a`）；

#### e. 风险 / 可能过强的地方

- **★ 最大的问题：和卫星国防军的 SEED 撞味道。** 两者都是「越打越强」。

- **觉醒后可能过强**：λ 大招 0 CD 在 12 回合上限里等于「每回合一发特殊伤害、无视抗性」

- **「故意挨打」这件事玩家不一定感知得到**：我们框架里只能靠「守护」和「不给防御指令」间接表达

### 方案三 「ECS 潜航 / TDD-1 强袭」—— 电子战与出场时机

#### a. 一句话卖点

**秘银不靠人多：上一回合没开火的机体还「潜航」在水下，敌人这一回合选不到它。
谁先动手，谁就先暴露。**

#### b. 触发条件

- **潜航判定（回合开始时锁定，整回合不变）**：秘银单位**上一回合没有开过火**
  （没攻击、没修理、没放支援）→ 本回合处于「潜航」。
- **效果**：敌方 AI 挑目标时**跳过**处于潜航的单位（不能把它当目标，也就不出现在敌人意图里）。
- **浮上**：只要它本回合出手，**下一回合**就解除潜航。
- **「防御」就是潜航的开关**：`防御` 本来就是「不攻击 + 防御值 +50 + 下回合回 5% HP」（`CLAUDE.md` 第 6 节）
  ——不开火，所以能一直保持潜航。**我们已有的指令免费变成了 ECS 的开关。**
- **原作出处（这条不是硬凑的）**：ECS 的设定里明确写着「功率极大，
  **AS 一边做战斗机动一边用不了 ECS**」（[Electronic Conceal System](https://fullmetalpanic.fandom.com/wiki/Electronic_Conceal_System)）
  ——所以「**开火 = 浮上**」是原作自洽的，不是我们编的。
- **TDD-1 强袭（可选加项）**：第 3 回合（或每 N 回合）一次「**TDD-1 浮上**」：
  全队潜航刷新一次 + 一发场外导弹（量级 = 一次普通攻击的 **60%** 左右）。
  这是原作「强袭登陆潜水舰打一手就撤」的落点，也是我方对「敌方摆满 9 台 + 增援」的一个非数量解法。
- **我不推荐的一条**：让潜航「只对直射 / 曲射的敌人有效、曲射的敌人靠 ECCS 看穿」——
  味道最正，但规则太难懂，会让玩家算不明白。

#### c. 效果与强度量级（相对口径）

- 潜航**不造成任何伤害**，它换的是「**敌方这一回合的有效输出**」。
- 3 台编队里有 1 台潜航 → 敌人这一回合大约**少打 1/3 次攻击**
  （大约等于替全队省下一次普通攻击的 **40%~70%** 的伤害量）。
- 越到后期越强：6 台时如果大部分都潜航，敌人几乎打不到人——**这是最容易过强的地方**。
- 它和**速度**直接挂钩（我们的行动顺序就是按速度从高到低）：
  **速度快的机体更容易先暴露**，速度慢的天然占便宜——**和「速度快 = 先手」的直觉相反**。
  这是一条新味道，但也可能是**玩家最难理解**的地方。

#### d. 实现量（中，而且有一个硬骨头）

- 引擎要动两处：
  1. 敌方 AI 挑目标时加一个「**不可选**」过滤（`50-AI.js` 挑目标的地方）；
  2. 一个「上一回合有没有开火」的标记（`60-战斗.js` 的回合流程本来就是逐台行动，加一个字段即可）。
- **★ 硬骨头：意图一致。** 指令阶段的敌人意图是 `算意图(ctx)` 算的，它是**纯快照**
  （注释原文：「这里算的是『如果现在开打，这个敌人会打谁』」），**不会按速度预演整个回合**（`60-战斗.js:424-452`）。
  而「潜航」如果按「**本回合还没行动过**的单位不能被选」判定，意图就会和实际不一致
  —— 而「**意图和实际行动一致**」是我们**测试里明确盯着的**（`tests/commands.js`）。
  所以这一条**必须**改成「**回合开始时锁定、整回合不变**」的写法（也就是 b 里写的「上一回合有没有开火」），
  否则就要为了它把 `算意图` 变成一场小模拟（成本会大得多）。
- **不需要新指令**（`防御` 已经存在）；**TDD-1 那个加项是新东西**（场外一发），要单独算。

#### e. 风险 / 可能过强的地方

- **潜航太硬**：「**不能被选为目标**」是一条**规则级**的强效果（比数值难调），一旦过强没法用数值微调
  → 必须配闸门：「只剩它一台时潜航失效」「每台每场最多潜航 N 回合」「第一回合不算」之类。
  **闸门本身要作者拍。**
- **第一回合天然全部潜航**：开场谁都没开过火 → 按规则第一回合全队潜航、敌人全体打空
  → **开局太强**，必须单独处理（推荐「第一回合不算」）。
- **和我们的战斗节奏冲突**：我们实测 Lv20 起很多战斗 **1.0–1.7 回合**就结束（`CLAUDE.md` M6 段）。
  潜航会让敌人打空、把战斗拖长，12 回合上限下可能变成「互相摸」。
- **画面会变闷**：自动战斗的乐趣之一是看伤害数字；潜航会让敌人这一回合什么都打不到。
- **速度的反直觉**：玩家得先理解「慢 = 能多藏一回合」，**教学成本是三个方案里最高的**。

## 3. 推荐哪个

### 推荐：**方案一「URZU 网络」**

一句话理由：**它是战棋「指挥网络」的正统重写——丢掉的 5×5 区域 / 障碍物 / 援护被一对一替掉了
（「毛是共享中枢」/「取消被挡 −20」/「标定」），实现量三个最低（三样新东西里两样是现成管线、只缺生产者），
而且它是唯一一个让 3→6 台的编队规模直接变成强度、又完全不新增任何伤害的势力特色——最好调，也最不会破坏现有的平衡。**

其余两个的定位（万一作者口味不同）：

- **想要「一眼就懂的爆发感」→ 方案二**。它的原作辨识度最高（λ Driver 是全金属狂潮最出名的设定），
  **数据零改动**（`10-数据.js:236` 那三个字段现在引擎一个都没读，等于白放着）。
  代价：和 SEED 撞味道 + 我们战斗太短、可能根本触发不了 + 单点依赖宗介。
- **想要「电子战味道」→ 方案三**。它最像「秘银的战术风格」（打完就潜、浮上来再打）。
  代价：规则级强效果、难调、第一回合要特殊处理、和 1–2 回合结束的节奏冲突、教学成本最高。

**如果作者愿意，方案一 + 方案二的「λ 觉醒」并不冲突**（一个管情报，一个管宗介自己）——
但我**不建议一上来就两套一起上**，先把一套铺下去、看玩家反应再叠，理由是 `CLAUDE.md` 开篇就写了
「难度现在不用管——特色铺下去难度会大幅下降，之后一起调」：**两套一起上，难度会一次崩两档**。
