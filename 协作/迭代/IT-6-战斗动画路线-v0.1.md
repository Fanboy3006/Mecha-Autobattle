## 一、家底：格子简版**已经有了**
Godot 版战斗画面里，下面这些现在就在跑（作者试玩时可能没注意到，因为一拍只有约 0.7 秒）：

| 效果 | 代码位置 |
|---|---|
| 出手方**前冲**（大招和修理也会前冲） | `presentation/widgets/unit_card.gd` 的 `set_combat_fx` → `_前冲` |
| 受击方**闪白 + 震动** | 同上，`_闪一下` / `_震动` |
| 出手方到目标的**弹道线**（直射、曲射、近战颜色不同） | `presentation/battle/battle_animation_layer.gd` 的 `_画弹道` |
| 伤害**飘字**、效果胶囊（含【击破】） | 同上，`_画飘字` |
| 顶部**播报条**（谁打了谁、多少伤害） | `presentation/battle/board_panel.gd` 的 `_写播报条` |
| 演出**帧队列**（每条攻击日志一帧，带「是不是大招」标记） | `presentation/battle/battle_fx_player.gd` 的 `_攻击帧` |

所以「格子简版」不用从零做，要做的是**调手感**：
- 节奏：一拍 0.7 秒偏快，多段攻击看不出段数。
- 段数：多段武器逐段跳数字，这是响介、拉米亚这类角色的卖点。
- 击破：现在只有一个【击破】胶囊和卡底变色，没有爆炸、淡出这类「倒下」的动作。
- 装甲挡掉的段：显示成「挡」，不显示 10（见 IT-4 第三节 ④）。
