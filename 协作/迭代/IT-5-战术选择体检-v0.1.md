## 一、怎么判断「无脑」
一个回合里，如果玩家的最优解**不用看局面**就能说出来，这个决策就是无脑的。常见的四种：

| 类型 | 症状 | 判断方法 |
|---|---|---|
| A 永远打最贵的 | 每回合每台都打威力最高、能打的那张主武器 | 同一台机体在不同局面下，主武器的选择几乎不变 |
| B 顺序无所谓 | 五台按什么顺序出手，结果都一样 | 换顺序不改变伤害，也不改变触发什么 |
| C 目标无所谓 | 永远打血最少的那台，或者永远打最近的 | 目标选择只看血量 |
| D 资源没有取舍 | 战意永远够用，或者永远不够 | 精神牌和大招从来不抢同一份战意 |

## 二、现状（按势力）
| 势力 | 已有的「要动脑」机制 | 还偏无脑的地方 |
|---|---|---|
| ATX | 赌神（续注要战意）；打空喂赌局 | 本来是 B 型：顺序无所谓。**IT-4 已加【押注王牌】**：队友先打，响介最后收割，出手顺序变成一个真正的选择 |
| 秘银 | 连携要求「上一张是秘银牌」，顺序有讲究；λ 要攒战意 | 连携链一旦摸熟，就是固定套路。**IT-4 已加【Uruz 待机】**：连携多攒 λ 的战意，与打精神牌形成取舍（D 型变成有意义） |
| 殖民卫星军 | 觉醒感应 | 输出集中在 W1（样例里一人占 50%），其余人存在感弱（A 型） |
| 天人 | TRANS-AM、Veda | 待试玩 |
| 月球 / 影世界 | 月相、随侍；影世界换位 | 待试玩（新做的，先看作者手感） |
| 全局 | 主武器互毁（一回合只能打一张主武器）；前后排射程 | **A 型**：三张主武器里，通常有一张在大多数情况下都最好 |

## 三、提案（等作者挑）
| # | 提案 | 治哪一型 | 成本 |
|---|---|---|---|
| 1 | **主武器分工**：每台的三张主武器各管一件事（单体高伤 / 打后排 / 破甲或减命中），威力差距缩小到 ±20% 以内，不再有「总是最好」的那一张 | A | 数据改动，按势力逐个过；中 |
| 2 | **集火奖励「破绽」**：同一回合内，被我方第二台机体打中的目标，受到伤害 +15%（第三台起不再叠） | B、C | 一个全局钩子；小。会和【押注王牌】叠，要算一下 |
| 3 | **敌方意图更醒目**：敌方下回合要打谁、打多少，已经算在 `算意图` 里，界面上标得再显眼一点 → 「挡 / 换位 / 先杀」变成有依据的选择 | C | 只改表现层；小 |
| 4 | **装甲保底改成威力的 15%**（见 IT-4 第三节） | A | 一行公式；全样例重录 |
| 5 | **战意更紧**：开场战意 20 → 10，每回合 +5 不变 | D | 一个参数；可能让开局更慢，和「开局人手少」冲突，要试玩 |

**作者 10-21 拍板：先做 2 和 3。** 两条都已落地：
- **②【破绽】**：`core/battle/focus_fire.gd`，开关 `选项.集火破绽`，默认开。
  - 同一回合内，敌机被我方一台机体打中（至少中 1 段）后露出破绽：其他我方机体再打它，伤害 +15%。
  - 不叠层；同一台机体自己补刀不算；换回合清零。
  - 第一次露出破绽时，战报写一行〔破绽〕。
- **③ 敌方意图连线**：战斗画面在我方阶段画红色虚线，从敌机指向它下一拍要打的我方机体，并标期望伤害；大招 / Boss 大技能的线更粗。数据来自门面 `enemy_intents()`。

## 四、怎么验证
- 样例（AI 自动打）验证不了「有没有意义」，因为 AI 的出牌顺序是固定的。
- 要看真人试玩：`live_actions.jsonl` 里每回合的出牌顺序和目标。如果作者在不同局面下选法不同，就说明这是有意义的选择。
