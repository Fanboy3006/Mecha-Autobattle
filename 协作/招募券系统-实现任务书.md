## §0 作者拍板（原话照录）

> 「试玩第一步就和我预想不一样，我选完分队以后应该先给我 **3 个招募券**的。不是直接给我 5 个，然后现在的我方角色不能升级也很怪」
> 「1 **分队不自带机体**，但是**至少要给一张对应分队的招募券**；2 **券系统必须要做了才有试玩的意义**；3 **升级就是用券升级**」

**定案**：
1. 开局：选完分队 → **发 3 张招募券**（**≥1 张是「对应分队」的券**）→ **不再发固定五人队**；**分队不带机体**。
2. **券系统必做**（这是「试玩有意义」的前提）。
3. **机体升级 = 用券晋升**（照战棋 `27-开局.js:78-86`：**希望 + 一张同类券**）；**不做「打经验涨级」那套**。
4. 部队等级（`RUN.等级`，决定出击台数）**保留**，与机体晋升**并存**。

## §2 实现清单（逐条）

1. **开局发券**：`肉鸽.新的一局()`（`90-肉鸽.js:416`）里 —— 名册**不再塞默认五人队**；`RUN.券` = **3 张**，其中 **≥1 张按分队倾向**（沿用 `92-肉鸽界面.js:26-28` 已写好的口径：分队 = 职业或势力时「一半概率出该券」，`无` 分队 = 全随机；用 `mulberry32(种子 + …)`，同一局可复现）。
2. **招募屏接券**：持**对应档**的券 → **免费招该档一台**（消耗该券 + 写日志）；**没券**时走现有希望价（精锐 5 / 骨干 3 / 普通 0，出处见 `90-肉鸽.js` 的招募段）。招募后**券要进存档**。
3. **晋升接券**：`肉鸽.晋升()`（`90-肉鸽.js:342-344` 一带）—— 变成 **希望（现有价格，`22-输入.js:431` 的 `PRICE` / `:446` 的 `promoCost`）+ 1 张同类券**；**Lv10→20 要骨干券、Lv20→30 要精锐券**（若战棋事实与此不同，**以战棋为准并注明出处**）；**没有券时按钮 `disabled` 并写清原因**。
4. **券的来源**（**初稿**，量级照战棋「打完给一张随机招募券」）：
   - 精英 / 守军 / 侵蚀源胜利：**必掉 1 张骨干券**；
   - Boss：**掉 1 张精锐券**；
   - 普通战：**25% 掉 1 张普通券**；
   - **黑市可买**（价格初稿；黑市已有「刷新」与「卖零件」，见节点改造）；
   - 随机数一律 `mulberry32(种子 + …)`，同一局同一场可复现。
5. **界面文案**：删掉那两处「券系统还没做」；分队屏、大地图顶栏、招募屏要**显示手上的券**（档位 + 张数）；晋升屏要把「需要 1 张 X 券」写出来。
6. **存档**：`RUN.券` 进 JSON；**旧存档缺券 / 券值坏 → 补默认（空数组或按开局口径补 3 张，二选一并写清）**，坏值不崩；存档键仍是 v3（只加字段不升版本，除非有把握）。
7. **测试点**（每条都要真跑）：
   - 开局：选完分队 → **名册为空、券 = 3 张、含 ≥1 张分队倾向券**（多种子）；
   - 招募：持券**不花希望**、券 -1；**没券扣希望**、希望不够则 disabled；
   - 晋升：**希望 + 同类券**都扣；**缺券时不允许晋升**；不能跳级；
   - 来源：精英/守军/侵蚀源/Boss/普通战 的掉落（含 25% 的可复现性）；
   - 存档：往返一致 + 旧档补默认值；
   - 同种子两次逐字相同。
8. **量化**：给一份「改前 vs 改后」的**开局与一局收支**（一局平均拿到几张券、几次招募是免费 vs 花希望、一局能晋升几次）。

## §7 ★ 口径更正（2026-10-11，统筹据 `协作\招募券系统-规格.md` 的战棋取证改）

**§2 与 §6 里凡是「券分普通 / 骨干 / 精锐三档」「持券免单」的说法一律作废**（那两条是我（统筹）在没查证前的自拟方案）。**以下以战棋为准**：

| 项 | 战棋口径（出处） | 落地 |
|---|---|---|
| 券分不分档 | **不分档**；精锐/骨干/普通是**角色档位**，不是券的档位（`22-输入.js:425-430`）；券只有「**职业券 / 势力券**」两类（`22:436-437`） | 券 = **职业券或势力券** |

## §8 券规格核对补三条（统筹 2026-10-11 读战棋源码 `27-开局.js:46-90` 逐字核出，**实现时必须照做**）

1. **一张券 = 二选一用途**（`27:78-81`）：同一张券既能「**招募**一名该类别角色（Lv10，扣 `recCost`）」，也能给队里**同类角色「晋升」**（扣 `promoCost`）。
   **券与希望同时消耗**（`27:84` → `:86` / `:87`）→ **券不是免费票，券 = 选择权（类别过滤）**。这正对上作者「升级就是用券升级」。
2. **券可以「先留着」，也可以「丢弃」**（`27:82` 的 `先留着` / `丢弃这张券` 两个按钮）→ 我们的招募屏要有这两个动作。
3. **开局券数**：战棋是「**月之国 3 张、其他分队 2 张**」，且**所有分队第 1 张都固定是本分队券**（`27:48`：`i === 0 ? v : pick(CLASSES)`）。
   → 作者要的「**3 张 + 至少 1 张对应分队的券**」= **把月之国那套套用到所有分队**：**第 1 张固定本分队券 + 2 张随机职业券**（月之国另加一张势力券的口径可保留给月之国）。

**附**：`27:50` 开局会立刻把 3 张券依次弹一遍（`for (const t of [...RUN.tickets]) await useTicket(...)`）——
即「**选完分队 → 立刻进招募流程**」，这正是作者期望的开局节奏；我们的界面也照这个走（发券后直接进招募屏）。
