## 结论（三问，全部是上面两张表的真实数字）

> 口径先说清：我方**一回合指令都不下**（`simulate(…, null, 种子)` = 每回合交给方案 5.1 的默认 AI），
> 所以下面是「完全不手动干预」的下限；玩家会下集火 / 守护 / 防御，实际胜率只会更高。
> 每一条编成的敌人等级是固定的（同一场次 `场次 = 0` = 一进这一层就打这一档），
> 所以同一档里 3 条编成的差异**只来自编成本身**。

- **精英 是真的有挑战**（三个等级里最低 37%）：Lv10 37% / Lv20 67% / Lv30 100%。
