# 设计文档（想法与规则）· 入口

> **这一半是「想法与规则」** —— 游戏该是什么样、规则怎么定、数值目标是什么、还差什么没定。
> **给别的 AI review、改进、加新想法用**（作者 2026-10-13 拍板：「**主要是从想法到代码落地实现这个要分清楚**，
> 代码怎么写的是一回事，**想法规则需要方便交给其他 ai review 改进，加入新的想法**」）。
>
> **另一半（代码怎么写）**：[`docs/实现/`](../实现/README.md) **·** **说明书（索引 + 铁律）**：[`CLAUDE.md`](../../CLAUDE.md)
> —— 里面的「**★ 文档地图：原「第 N 节」现在在哪**」是旧引用（`CLAUDE.md` 第 6 节 / 任务板 M6 段…）的跳转表。
>
> ★ 本目录的正文是从 `CLAUDE.md` **逐字搬过来的**（**一字未改**，连每条的 `文件:行号` 出处一起搬）；本 README 与各文件顶部的说明块是**索引**。
> ★ **路径写法**：**要能点开的链接一律用 `/`**（GitHub 只认 `/`）；**纯叙述**的路径按 Windows 习惯写 `\`。
