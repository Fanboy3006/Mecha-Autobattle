## §1 核心设计思想（作者钦定方向）

1. **不做传统抽牌 / 弃牌 / 洗牌 / 牌库管理**：
   - 本项目的战术卡牌不是传统 DBG（Deck-Building Game）里每回合随机抽 5 张、弃牌堆洗牌循环的机制，而是**「直观的战术指令与机战精神（信赖、根性、爱、直击、必中、集中、激励、觉醒、扰乱、铁壁、热血、魂）」**——*“我现在遇到这个情况，所以我打这一张牌”*。
   - **零随机洗牌抽牌**（不消耗任何额外 `ctx.rng`）：手牌完全由**「参战阵容的初始可用牌」+「战斗中满足特定战况条件时动态发给玩家的条件触发牌」**组成。
2. **三层牌池结构（参战机体共同供牌）**：
   - **职业牌池（Class Pool）**：6 大职业（重装、近卫、尖兵、狙击、指挥、特种）各提供职业特色牌；
   - **势力牌池（Faction Pool）**：6 大我方势力（卫星国防军、流星小队、月球王国、天人、ATX、秘银）各提供势力特色牌；
   - **角色/机体特色牌池（Character Pool）**：具体角色提供专属特色牌（如刹那【觉醒·七剑解放】、洛克昂【乱射·狙击神技】、Feena【满月·星落】、响介【王牌决断·魂】、拉克丝【永恒之爱】、宗介【突击号令】），以及全军统帅牌（【⚡全军总攻】【🛡紧急掩护】）。
3. **两种入牌方式（初始可用 vs 条件触发发牌）**：
   - **初始可用牌（`入牌: '初始'`）**：战斗开始（`开局`）时直接装入 `ctx.战术手牌`（最多 `初始手牌上限 = 6` 张），随时可按气力消耗打出；
   - **条件触发牌（`入牌: '条件'`）**：开战时不在手里，而是挂在监控槽 `ctx.待触发战术牌` 上；当战斗中满足特定战况条件（如前排重装受击残血、场上发生闪避/未命中、近卫击破或暴击、敌机叠满 ≥2 层标定、SEED 满 30、残月追加触发、ATX 累计打空 ≥2 段等）时，由对应角色/职业/势力**当场「发牌」进入玩家手牌栏**（上限 `手牌总上限 = 8` 张），并记录 `〔发牌〕`！
4. **气力（`ctx.气势`）作为核心轮转资源**：
   - 打破原先「只能憋满 100 放总攻/掩护」的单一节奏，形成三档气力循环：
     - **回气 / 轮转启动牌**：如指挥【激励】（`耗气: 0, 回气: 25`）及多张条件触发牌（`耗气: 0~10, 回气: 15~25`），将战况应对转化为气势增量；
     - **小中费战术牌**（耗气 `10 ~ 35`）：【铁壁】【热血】【集中】【必中·直击】【扰乱】【月光祈愿·信赖】【TRANS-AM 解放】等，第一回合起（`初始默认气力: 25`）即可灵活介入战局；
     - **高费终极号令 / 大招牌**（耗气 `60 ~ 100`）：【⚡全军总攻】【🛡紧急掩护】等一锤定音。
5. **肉鸽成长联动（招募 / 晋升 3 选 1 构筑牌池）**：
   - 在肉鸽模式下，玩家招募新机师或晋升机师（Lv10→20→30）时，从该机师对应的「职业牌池 ∪ 势力牌池 ∪ 角色牌池」中提取 **3 张候选牌供玩家 3 选 1** 加入队伍战术牌库（`RUN.战术牌库`），使队伍构筑与手牌战术深度绑定。
6. **全部 1-Click 免二级选目标**：
   - 所有战术卡牌点击即生效，自动作用于对应职业/势力/角色、前排、HP 最低友军、带标敌机或全体，保持自动战斗 RPG 爽快紧凑的指挥体验。

## §3 三层反馈与架构边界

1. **三层反馈闭环**：
   - **预告（指令阶段手牌栏 `.tactical-hand-bar`）**：展示每张手牌的精神标签、牌名、归属徽章（`[职业·指挥]` / `[势力·天人]` / `[角色·刹那]` / 刚触发带 `★条件触发` 角标）、气势消耗与回气（如 `⚡0 → +25气` 或 `⚡20气`）、简明效果说明，气势不足或冷却中时 `disabled`；
   - **即时（战斗记录 `ctx.log`）**：条件满足发牌时记录 `类型: '发牌'`（`〔发牌〕满足「...」→ 获得战术牌【牌名】`），打出卡牌时记录 `类型: '战术牌'`（`〔战术牌〕发动【牌名】（气势 -X/+Y）：效果简述`）；
   - **结算（战后 `战报统计(log).战术卡牌`）**：汇总本场 `{ 打出数, 触发发牌数, 累计回气, 累计耗气, 牌名们 }` 并在战报展示（未触发/未打出时不挂载，零污染旧战报）。
2. **默认路径零污染保证**：
   - `战斗结构.战术卡牌.开` 默认为 `false`；关闭时不改动 `ctx.气势` 初值、不向 `ctx.log` 写入任何发牌记录，确保既有 23 套测试（含 `defaultPathBattleLogCount = 2788`）逐字节不变。
