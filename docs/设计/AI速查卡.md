# 设计层 AI 速查卡（Current State · 开机唯一必读）

> **★ 真相源定位：本速查卡仅是「AI 导航地图」，永远不定义游戏规则。唯一真相源为：`L0 铁律(CLAUDE.md)` → `L3 源码 + 协作/架构快照.json` → `L4 门禁(tests/arch.js)`。**

> **用途**：供设计评审、机制提案、平衡分析 AI 开机建立完整规则基线。**本卡只描述当前生效规则**；开机只需读本卡，无需通读长篇历史文档。**本卡与 `L3 源码` 不一致时，一律以源码 + `协作/架构快照.json` 为准**（`rulesSignature` 是「规则宇宙」的判据）。

## §1 一句话定位与核心循环
- **定位**：浏览器单文件 HTML 自动战斗回合制肉鸽 RPG，双击即玩。玩家在肉鸽大地图走格、招机师、拿藏品与零件；进战斗后将最多 6 台机体摆入前/后排，每回合初下达**全队方针 + 战术指令 + 单位大招开关**，随后全场按速度自动行动并播放结算。
- **确定性内核**：随机源统一使用带显式种子的 `mulberry32`（严禁 `Math.random()`），同种子同输入结果完全一致；播放层（暂停/倍速/跳过）只读取战斗记录，绝不影响战斗结果。

## §2 战场 9 格、射程 5 类与核心公式
- **错位 9 格与阻挡**：双方各**前排 4 格（前1..前4 = slot 0..3）+ 后排 5 格（后1..后5 = slot 4..8）**。前排阻挡对位后排：`前1→后1,后2`、`前2→后2,后3`、`前3→后3,后4`、`前4→后4,后5`。前排全灭后排不自动前移；战斗中无换位。
- **射程 5 类**：
  | 类型 | 目标与规则 |
  |---|---|
  | **近战** (`melee`) | 只能打敌方前排；前排全灭后才可打后排 |
  | **直射** (`direct`) | 可打任意排；打后排时若其遮挡前排仍有存活单位，**命中 −20**（被挡惩罚，非不可选中） |
  | **曲射** (`indirect`) | 可打任意排，**无视阻挡** |
  | **范围** (`map`/`support`) | **无视阻挡**；按 `area` 打一整排 (`row`，默认)、阻挡束 (`col`：前排+其挡的1~2后排)、十字 (`cross`：目标+左右+对位) 或全场 (`all`) |
  | **修理** (`heal`) | 仅当友军有人 **HP 比例严格低于 60%** 时触发，优先修比例最低者；否则该单位正常输出 |
- **核心公式**：
  - **速度** = $\lfloor \text{机动} \times 10 + \text{闪避} \div 2 \rfloor$（全场按速度从高到低行动，支援/增益先于攻击）。
  - **伤害** = $(\text{武器威力} - \text{有效装甲}) \times [1 + (\text{攻击能力值} - \text{防御值}) \div 100]$，命中保底 10；暴击威力 $\times 2$（吃 `critX` 加成）；减免管线顺序：弱点抗性 → 装甲 → 防御值 → 公式 → 能量屏障 → $\lambda$ 力场 → 护盾。
  - **命中率** = $\text{clamp}(\text{武器命中} + (\text{精准} - 160) \div 2 - \text{目标闪避} - \text{被挡}20 + \text{修正}, 0, 100)$。
  - **暴击率** = $10\% + \text{武器暴击修正} + \text{增益}$。

## §3 战斗内两层决策：方针 + 气势战术指令 + 单位开关
- **全队层 · 5 条方针**（每回合初选 1 条，保持到改为止，方针本身无数值 buff）：
  1. **全军突击**：默认自由攻击 AI；
  2. **集中攻击**：点选 1 名敌机，打得到的全员集火它（打不到则自由攻击；目标击破后自动回全军突击）；
  3. **攻击后排**：优先打敌方后排（打不到则按突击）；
  4. **前守后攻**：前排放弃攻击进入防御姿态（防御值 +50、下回合初回复 5% HP，修理/支援照常），后排突击；
  5. **全军防御**：全队放弃攻击进入防御姿态，修理/支援/再动照常执行。
- **全队层 · 气势与战术指令（1 + A2）· ★ 状态：已落地（`71-改动-4` / `60-战斗` / `84-反馈`）**：交战双方行动/受击/击破积攒气势（上限 100），满 100 气势可在指令阶段二选一发动：
  - **⚡全军总攻**：本回合全队伤害 $\times 1.35$、命中 $+15$、全队大招冷却 $-1$，且解除憋大招限制同回合大招齐射；
  - **🛡紧急掩护**：全队获得 $25\%$ 最大 HP 护盾，并清除全体负面减益（破甲/降命中等）。
- **单位层 · 大招开关与天人 TRANS-AM**：
  - **大招**：机体 **Lv20 / Lv30 解锁**（**B2**：Lv10 未解锁时卡片显式提示「Lv20 解锁大招」）；统一**开场冷却 5 回合**（第 6 回合起可用）、**普通冷却至少 3 回合**。每台可切「自动 / 保留」，方针栏提供 **C1「全队憋到总攻」** 一键开关（开启后全队大招平时保留，点⚡全军总攻时自动齐射）。
  - **TRANS-AM**：天人机体专属单位级开关（自动 / 手动点击本回合开启），开启后持续 2 回合（武器威力 $\times 1.3$、闪避 $+15$），冷却 3 回合（第 1/5/9 回合可开）。

## §4 职业特色（敌我对称）· 势力特色（我方六套）· 标定经济
- **六大职业特色（敌我对称生效）**：
  - **重装**：前排嘲讽（强制敌方单体优先打重装）；**近卫**：击破敌机后连斩再动；**尖兵**：每回合首次受击闪避 $+20$；
  - **狙击**：打后排免除被挡 $-20$ 惩罚且暴击 $+10\%$；**指挥**：同排友军命中 $+10$；**特种**：命中目标挂「命中 $-20$」。
- **六大我方势力特色**（影世界无团队特色，只保留个人武器差异）：
  1. **卫星国防军（SEED）**：每回合 $+5$、击破 $+3$，满阈值 30 觉醒（闪避 $+0.15\times$觉醒值，重装改为防御 $+0.25\times$觉醒值，觉醒计入对应大招）。
  2. **流星小队（单独行动）**：相邻位与正前方遮挡位无存活友军时，攻击能力值 $+20$、闪避 $+15$。
  3. **月球王国（围绕 Feena）**：Feena 相邻位友军享月光祝福（Lv10 命/闪 $+15$；Lv20 再加防 $+20$/暴 $+10$；Lv30 命/闪 $+20$、防 $+30$、暴 $+15$）；队友造成伤害后触发 Feena「残月的余响」追加单发陨石（每回合限 1 次）；阿布拉德不动如山（装甲 $+30\%$）、Iris 修理加防 $+15$、Nagi 8 段连射残心。
  4. **天人（TRANS-AM）**：见 §3，威力 $\times 1.3$（乘在公式前武器威力上）、闪避 $+15$。
  5. **ATX（赌徒直觉 + 好运加护）**：场上任意单位每次**逐段未命中**使响介带 `evadeCd` 的大招冷却 $-1$（先减开场 CD 再抵普通 CD）；艾克赛琳支援武器赋予友军暴击倍率 $+1$（$\times 2 \to \times 3$）、命中 $-20$。
  6. **秘银（SRT 岗位接力）**：情报岗（指挥/尖兵）攻击挂标定（最多 2 层），必须由作战岗（特种/狙击/近卫）攻击兑现（每层 $-20\%$ 破防并免被挡，同台不可自兑，回合末 $-1$ 层）；每场 1 次队友被击破时另一台秘银接管其站位并立即再动。
- **全职业标定经济（通用传球闭环，与秘银独立）**：
  - **产标**：特种造成伤害 $+1$ 层、指挥回合初号令点名 $+1$ 层（层数少/位号小优先，**上限 3 层，整场不衰减**）。
  - **引爆**：**狙击**打带标目标，暴击那一段伤害 $\times 1.3$ 并消耗 1 层；**范围武器**命中带标目标，引爆全部层数造成（层数 $\times 15\%$ 主伤害）独立溅射。

## §5 肉鸽外壳与经济当前值
- **4 层正方形网格与推进剂**：1~4 层尺寸为 `5×5 / 6×6 / 6×6 / 7×7`；每层**推进剂上限 = 起点到出口最短路 + 偶数余量（2/4/6/8）**，走 1 格扣 1，跳格按最短路扣，耗尽触发追击战（下层上限 $-2$）。
- **双出口（口径 A）**：**出口尽头**需先击败出口守军（获精英奖 + 额外源碳 + 必掉零件），剩余推进剂按 $1:0.5$ 换希望；**出口小径**免打守军直接换层/通关（无守军关口奖励，下层推进剂上限 $+2$）。
- **招募、带队核心与晋升**：开局选分队发 **3 张招募券**（含 $\ge 1$ 张分队倾向券）；**本局首台成功招募的机体为「★带队核心」直升 Lv20**（不额外花希望），其余按层招募（1/2/3 层为 Lv10/20/30）。招募与晋升（Lv10→20→30）均需**对应券 + 希望**（S 招 5 升 3/4；A 招 3 升 2/3；B 招 0 升 1/2）。
- **出击上限与续航**：按部队等级解锁（**Lv1~3→3 台、Lv4~6→4 台、Lv7~9→5 台、Lv10+→6 台**，藏品可突破至绝对上限 7 台）。每场战斗结束后**全队自动回复 50% 最大 HP**（0 HP 倒下机体亦回至 50%）；休整节点三选一同样顺手回血 50%。
- **希望与关卡池**：起始希望 8、源碳 12、耐久 10；升级按分级表给希望（Lv2~10 给 $+4\sim+8$），一局实战目标约 $40\sim 60$ 希望。第 1~2 层采用扩池变体与词条挂载（普通 7 条、精英 3 条 + 必挂载强化词条组 `1-EE`/`2-EE`、守军含守关 Boss）；敌人含隐匿（非近战/范围命中 $-35$）、镜甲（反伤 $30\%$）、濒死自爆（$<35\%$ HP 击破炸阻挡束）与回合波次增援。

## §6 硬规矩：三层反馈与提案 7 节产出模板
- **玩家每个决策必须具备三层反馈（缺一不可）**：
  1. **预告（指令阶段）**：纯读计算（`preview: true`），**绝不消耗 `ctx.rng`**，在卡片/方针栏直接显示预计结果；
  2. **即时（行动播放）**：生效瞬间在伤害旁与日志挂短标签（仅实际触发时写记录字段，不改播放时序）；
  3. **结算（战后战报）**：完全从 `ctx.log` 统计本场收益/减免/引爆贡献，展示在结算屏与大地图战报。
- **新机制/改动提案标准 7 节模板**：① 一句话目标与玩家决策点；② 规则与数值表（标明战棋出处或【初稿】）；③ 引擎落点与 `战斗结构.*` 开关（确保关掉与改前逐字节一致）；④ 三层反馈文案（预告/即时/结算）；⑤ 界面交互与 `data-act`；⑥ 边界条件与 `rng` 零污染证明；⑦ 验证用例与待作者拍板项。
