## §1 一句话定位与核心循环
- **定位**：浏览器单文件 HTML 自动战斗回合制肉鸽 RPG，双击即玩。玩家在肉鸽大地图走格、招机师、拿藏品与零件；进战斗后将最多 6 台机体摆入前/后排，每回合初下达**全队方针 + 战术指令 + 单位大招开关**，随后全场按速度自动行动并播放结算。
- **确定性内核**：随机源统一使用带显式种子的 `mulberry32`（严禁 `Math.random()`），同种子同输入结果完全一致；播放层（暂停/倍速/跳过）只读取战斗记录，绝不影响战斗结果。

## §2 战场正交双排 `4×2`（8 格）与《兰斯10》四路战线、射程 5 类与核心公式
- **正交双排 `4×2` 共 8 格（★ 已落地：`05-阵型.js` + `战斗结构.兰斯战线`）**：双方各**前排 4 格（`前1..前4 = slot 0..3`）+ 后排 4 格（`后1..后4 = slot 4..7`）**，分 **1~4 路正交对位**（`前1↔后1` … `前4↔后4`，即同路 `slot ± 4`）；`col` 阻挡束 = **同路两格 `[c, c+4]`**，`相邻位` = **正交十字邻格**（同排左右 + 同路前后）；前排全灭后排不自动前移；战斗中无换位（几何只用于编队摆位与界面标位）。
- **《兰斯10》战线规则（`战斗结构.兰斯战线`，默认开；13 项参数全在 `71-改动-4`，判据全在 `71-改动-5`，**纯读零 `ctx.rng`**）**：
  1. **同路掩护**：同路前排存活时，后排被**直射**除命中 −20 外再享**同路掩护减伤 −30%**（狙击 / 秘银破防免除；记录字段 `掩护减伤` 只在真触发时挂）；
  2. **铁壁护卫**：同路前排若为**重装**，对身后后排的单体受击 **100% 铁壁护卫**（代受，零 `rng`）；
  3. **破阵突袭**：某路前排阵亡 / 空缺后，敌方**近战**可直接攻击该路**暴露的后排**（`破阵暴露吗()` / `近战可达()` / `targetableEnemies()`）；
  4. **排位与四路修正**：**前排近战伤害 +15%**、**前排远程贴脸命中 −15**、**后排隔排近战 −25%**、**后排远程伤害 +10% / 命中 +10**；AI 默认**同路优先索敌**（同路 `×1.35` / 相邻路 `×1.10`）；**外侧 1/4 路**尖兵 / 流星小队享**侧翼游击**（闪避 +10 / 暴击 +10%）；**中枢 2/3 路**前排重装**防御 +15**。
- **射程 5 类**：
  | 类型 | 目标与规则 |
  |---|---|
  | **近战** (`melee`) | 只能打敌方前排；**该路前排空了（破阵）才能打该路后排**（`近战可达()`）；前排全灭后全场后排都可达 |
  | **直射** (`direct`) | 可打任意排；打后排时若其**同路**遮挡前排仍有存活单位 → **命中 −20**（被挡惩罚，非不可选中）+ **同路掩护减伤 −30%** |
  | **曲射** (`indirect`) | 可打任意排，**无视阻挡**（因此也**不吃**同路掩护减伤） |
  | **范围** (`map`/`support`) | **无视阻挡**；按 `area` 打一整排 (`row`，默认)、阻挡束 (`col` = **同路纵列两格 `[c, c+4]`**)、十字 (`cross`：目标+左右+同路对位) 或全场 (`all`) |
  | **修理** (`heal`) | 仅当友军有人 **HP 比例严格低于 60%** 时触发，优先修比例最低者；否则该单位正常输出 |
- **核心公式**：
  - **速度** = $\lfloor \text{机动} \times 10 + \text{闪避} \div 2 \rfloor$（全场按速度从高到低行动，支援/增益先于攻击）。
  - **伤害** = $(\text{武器威力} - \text{有效装甲}) \times [1 + (\text{攻击能力值} - \text{防御值}) \div 100]$，命中保底 10；暴击威力 $\times 2$（吃 `critX` 加成）；减免管线顺序：弱点抗性 → 装甲 → 防御值 → 公式 → 能量屏障 → $\lambda$ 力场 → 护盾。
  - **命中率** = $\text{clamp}(\text{武器命中} + (\text{精准} - 160) \div 2 - \text{目标闪避} - \text{被挡}20 + \text{修正}, 0, 100)$。
  - **暴击率** = $10\% + \text{武器暴击修正} + \text{增益}$。

## §3 战斗内两层决策：方针 + 气势战术指令 + 单位开关
- **全队层 · 5 条方针**（每回合初选 1 条，保持到改为止，方针本身无数值 buff）：
  1. **全军突击**：默认自由攻击 AI；
  2. **集中攻击**：点选 1 名敌机，打得到的全员集火它（打不到则自由攻击；目标击破后自动回全军突击）；
  3. **攻击后排**：优先打敌方后排（打不到则按突击）；
  4. **前守后攻**：前排放弃攻击进入防御姿态（防御值 +50、下回合初回复 5% HP，修理/支援照常），后排突击；
  5. **全军防御**：全队放弃攻击进入防御姿态，修理/支援/再动照常执行。
- **全队层 · 气势与战术指令（1 + A2）· ★ 状态：已落地（`71-改动-4` / `60-战斗` / `84-反馈`）**：交战双方行动/受击/击破积攒气势（上限 100），满 100 气势可在指令阶段二选一发动：
  - **⚡全军总攻**：本回合全队伤害 $\times 1.35$、命中 $+15$、全队大招冷却 $-1$，且解除憋大招限制同回合大招齐射；
  - **🛡紧急掩护**：全队获得 $25\%$ 最大 HP 护盾，并清除全体负面减益（破甲/降命中等）。
  - **★ 战术卡牌系统 P1/P1.1（[`战术卡牌系统.md`](战术卡牌系统.md)，`战斗结构.战术卡牌.开` 默认 `true`，纯后台 `simulate()` 默认 `战术卡牌: false` 保 `2788` 基线）**：零随机洗牌抽牌，参战机体按**职业/势力/角色三层牌池**（一阶 32 张机战精神式战术牌）供牌，分**初始可用牌**（开战入 `ctx.战术手牌`）与**条件触发发牌**（战中满足受击/闪避/击破/标定/SEED/残月/打空等条件当场发牌入栏），围绕 `ctx.气势`（初始 25，0 费【激励】回气 +25 → 中高费爆发）轮转，并支持肉鸽招募/晋升 **3 选 1** 构筑 `RUN.战术牌库` 与编队屏实时牌池预览。
- **单位层 · 大招开关与天人 TRANS-AM**：
  - **大招**：机体 **Lv20 / Lv30 解锁**（**B2**：Lv10 未解锁时卡片显式提示「Lv20 解锁大招」）；统一**开场冷却 5 回合**（第 6 回合起可用）、**普通冷却至少 3 回合**。每台可切「自动 / 保留」，方针栏提供 **C1「全队憋到总攻」** 一键开关（开启后全队大招平时保留，点⚡全军总攻时自动齐射）。
  - **TRANS-AM**：天人机体专属单位级开关（自动 / 手动点击本回合开启），开启后持续 2 回合（武器威力 $\times 1.3$、闪避 $+15$），冷却 3 回合（第 1/5/9 回合可开）。
- **动作射击 / 斩击 QTE 玩法接口（`战斗结构.动作QTE`，默认 `开: false` 保自动模拟确定性；已落地：`71-改动-4/5` · `20-战斗计算` · 独立可移植原型 [`协作/演出/demo-动作QTE-刹那七连斩.html`](../../协作/演出/demo-动作QTE-刹那七连斩.html) + [`协作/演出/动作QTE接口规范.md`](../../协作/演出/动作QTE接口规范.md)）**：
  - **1A 触发范围 + 2B 暴击奖励 + 3B 我方进攻先行**：我方拔刀/举枪特写 → 切敌方机体正前特写（按目标 `eva` 与当前段理论命中率 `q` 进行李萨如机动晃动）→ 玩家滑动完成逐段斩击/射击判定（`PERFECT` 必中且暴击率 $+25\%$、`HIT` 命中、`MISS` 擦过；与刹那 `CB1`「七剑·TRANS-AM 乱舞」7 连斩 `-10/+10` 动态命中步进联动），经 `resolveAttack(..., { qte结果 })` 覆写逐段命中/暴击并挂载 `动作QTE` 记录字段。

## §5 肉鸽外壳与经济当前值
- **4 层正方形网格与推进剂**：1~4 层尺寸为 `5×5 / 6×6 / 6×6 / 7×7`；每层**推进剂上限 = 起点到出口尽头最短路 + 偶数余量（2/2/4/4）**，未走过的 `· 空`（林间空地）节点可合法落脚休整，`· 不存在` 格展示为 `⛰ 断层` 地形障碍；走 1 格扣 1，跳格按最短路扣，耗尽触发追击战（下层上限 $-2$）。
- **双出口（口径 A）**：**出口尽头**需先击败出口守军（获精英奖 + 额外源碳 + 必掉零件），剩余推进剂按 $1:0.5$ 换希望；**出口小径**免打守军直接换层/通关（无守军关口奖励，下层推进剂上限 $+2$）。
