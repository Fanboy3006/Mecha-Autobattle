## 0. 一句话概括

《机甲指挥》是一个在浏览器里跑的**自动战斗回合制 RPG**：玩家在肉鸽大地图上走格子、招募机师、拿藏品；
遇到战斗时，把最多 6 台机体摆进**前排 / 后排**，每回合开始给**全队下一条大方向方针**（全军突击 / 集中攻击 / 攻击后排 / 前守后攻 / 全军防御），
单位层只管「大招开不开」，然后这一回合**自动打完**，看结果，再决定下一回合的方针。
玩家不再逐台移动、逐把选武器、逐格点目标——深度来自「看到敌人意图之后怎么下决策」，而不是操作。
★ **2026-10-12 作者拍板（第一件「全队方针」）**：原来是**逐台**下指令（进攻 / 集火 / 守护 / 防御 / 换位），
现在改成**两层决策** —— 全队层一条方针 + 单位层只有大招开关（天人另有 TRANS-AM）；
**战斗中不再有换位**、逐台指令与「守护」整条机制已删。规格书 = `协作/方向调整-全队方针与反馈.md` 第 1 节。
