## 6.界面3 修真 bug：含 **≥2 个 `:`** 的 `data-act` 被事件委托截断（调参室那一屏的选项点了行为不对）· 2026-10-13 · **v0.6.3 → v0.6.4**（已交付）

**动机（他刚打完那一局的真实数据）**：选「卫星国防军」**只给 3 张券** → 名册空 → 招到 **3 台 Lv10**，
而**第 1 层普通编成摆满 5 台** → **开局 3 打 5** → 4 场 1 胜 3 败、耐久 10 → −3，**第 1 层就出局**。
**新旧仓库都没有这套设定**（新仓库只有「教范藏品免费晋升 1 名同职业」，`93-藏品.js:182-210` / `:446-484`）→ 这次做出来。

### 一、口径（作者定的，逐字照做）

1. **选完分队之后，本局第一次成功招募到的那一台直接按 `Lv20` 入队**；其余仍按 `招募等级(层)`
   （第 1 层 Lv10、第 2 层 Lv20、第 3 层 Lv30）。
2. **不花希望、不吃教范、不影响晋升价格、不影响出击上限、不影响 `招募等级(层)` 的其他部分。**
3. **「第一台」= 名册从 0 台变成 1 台的那一次成功招募** —— **用哪张券都算**（开局券 / 事件券 /
   战后券 / 招募站券），**只在本局第一次**；重开新局重新算。
4. **三层反馈**（第 7 节第 10 条的规矩，缺一层不算做完）：
   **预告** = 招募屏「带队核心：这一台直接 Lv20（分队特权）」；
   **即时** = 结果条 + `RUN.日志` 一行「带队核心：<键> 直接 Lv20 入队（分队特权）」；
   **结算** = 「★带队核心」标记（招募屏「当前队伍」/ 晋升屏「名册」/ 大地图「队伍（N）」那一行 /
   大地图队伍卡片 / 本局结算屏名册）。
5. **存档不新增字段**（「名册第一台」这个事实本身就在 `RUN.队伍[0]` 里，**存档仍是 v4 / 同一个键**）；
   读旧存档（v4、名册第一台是 Lv10）**不崩、行为一致、不追认成 Lv20**（只补一行日志）。
