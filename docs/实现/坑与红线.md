## 二、本机 / 工程上的坑（踩过的）

| 坑 | 现象 | 怎么绕 |
|---|---|---|
| **DSH 沙箱不给子进程开管道** | `spawnSync` 默认 `'pipe'` → **EPERM** | 工具把 `main()` 做成「返回结果、不打印不退出」，测试**直接 import 调它**（`tools\balance.mjs` / `replay.mjs` / `战报分析.mjs` 都这么改过）；或脚本里用 `stdio:'inherit'` |
| **没有 Playwright** | 本机 npm 缓存在沙箱外，装不上 | 用 Node 的 `vm` + 最小 DOM / Canvas 替身（`tests\lib\dom-stub.mjs` 的 `loadPage()`）跑 `index.html` |
| **替身测不到 CSS 视觉效果** | 折叠 / `sticky` / 层叠 / 指针遮挡**一条都测不出来**（没有排版引擎 / `getComputedStyle` / `elementFromPoint`） | 测试只保证「DOM 结构 / 类名 / 文本 / 事件派发没变」；**视觉要作者自己看**（自检清单写在任务板对应段） |
| **`classList.add('hit crit')` 一个 token 带空格** | 真浏览器抛 `InvalidCharacterError`；异常从播一步冒出去 → `tick()` 末尾的 `排一次()` 被跳过 → **定时器链断掉、画面卡在前一条**（`tests\lib\dom-stub.mjs` 的 classList 不校验 token，Node 里一直没抓住） | **一个 token 一次 `add()`**；播放层：未知记录类型一律给默认时长 + **每步钩子抛异常绝不许弄断播放链** |
| **含 ≥2 个 `:` 的 `data-act` 被事件委托截断** | 调参室那一屏所有带参数的选项点了行为不对（`split(':')` 取错） | 拆参数要按**第一个** `:` 拆、后面全算参数；同类改动必须让真实浏览器路径可复现 |
| **格子号是分边的** | 我方「位 0」与敌方「位 0」是两个格子 → 只比 `slot` 会把「敌方打我方位 0」误标成集中攻击 | 「是不是点名那一台」**必须比单位对象** |
| **CRLF 假改动** | 直接改写 CRLF 文件会产生**上千行假 diff** | `.gitattributes` 是 `* -text`（不自动转换）；`CLAUDE.md` 是 **CRLF**、`协作\任务板.md` / `协作\协作日志.md` / `docs\**` 是 **LF**（2026-10-13 归档后仍如此）；要么先单独一笔「规范化/重排」并写明，要么逐文件用 §12.1 安全暂存 |
| **共享工作树里别人的未提交改动** | 提交时容易连带提交别人的文件 | 提交前 `git status` + `git diff --cached --name-only` 逐行核；共享文档走 §12.1 |
| **生成物被别的线重建后混进提交**（2026-10-13 **出过两起**） | 提交里混进不属于本线的生成物改动 | **生成物最后一步构建一次、立刻 add**；提交前核暂存区；必要时按 §17 从隔离副本取 |
| **`git add -A` / amend 别人的提交** | 直接违规 | 见红线 8 / 15 |
| **`git show HEAD:文件` 与工作区同名文件** | 想看 HEAD 版别覆盖工作区 | 只读手段：`git show HEAD:文件`、`git diff`、临时 `git worktree`（只读用） |

## 三、事故复盘要点（照实记，别再犯）

1. **2026-10-11 · 覆盖了音乐线未提交的三个文件**：子助手为了定位 `art_audio` 红灯，用 `Copy-Item` 把 HEAD 版盖回主工作树 + `git checkout --` → 音乐线未提交的三个文件**永久丢失**（git 对象库里没有它们的 blob）。
   **教训**：① 别用任何破坏性命令「修红灯」；② 未提交的改动**超过 10 分钟就 `[WIP]` 提交**（工作区不是保险箱）；③ 交接文档里写全自己的改动，出事了还能重落。
2. **2026-10-13 · 共享工作区被切分支 / 变成不可解析**（§14 / §15 就是这么立起来的）：共享工作区的分支**永远是 `main`**；随时保证**可解析**。
3. **2026-10-13 · 两次「生成物被别的线重建后混进提交」**：生成物**最后一步**构建一次、**立刻 add**；提交前 `git diff --cached --name-only`。
4. **2026-10-13 · 第三次「连带提交」**（§18 立规）：暂存区里发现别人的文件 → **停下报统筹**，不许硬提交。
