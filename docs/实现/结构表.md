## 1. 拆分规则（怎么编的号）

1. **拼接顺序 = `src/shell.html` 里 `<!-- @include js/… -->` 的先后**。
   ★ 更正一条旧说法：`CLAUDE.md` 第 3 节写的「按文件名顺序拼接」**不准确** —— 实际由 `tools/assemble-src.mjs`
   读 `shell.html` 的 include 行、**原样**替换（一整行连同换行）。所以片段**插在原文件那一行的位置上**，
   顺序天然不变，与文件名排序无关。
2. **编号规则**：原文件 `NN-名字.js` → 片段 `NN-名字-<序号>-<职责>.js`，序号**单个数字**（`-1-`…`-9-`）。
   这样**磁盘排序 == 拼接顺序 == 执行顺序**，老代码里 `92-肉鸽界面` 这类前缀引用也照旧看得懂。
3. **一个字的注释都没加**：片段头部**不许写**「本段原本属于谁」——`src/js/**` 是原样进产物的，
   加注释就会改字节、破坏硬不变量。**职责写在下面第 2 节这张表里**（原属文件也写在表里）。
4. **片段可以是「作用域不闭合」的**：`90-肉鸽.js` 的 `const 肉鸽 = { … }` 这类大对象横跨多个片段，
   单个片段文件**不能**单独当 JS 解析 —— 这是搬家式拆分的必然结果，**不是错误**：
   唯一要求是「按 include 顺序拼起来」是完整且正确的 JS（`--check` + `verify-all` + `smoke` 三重保证）。

## 4. 测试套件的按段拆分（**入口与套件总数一个都没变**）

`tools/verify-all.mjs` 是**按 `tests/<名>.js` 一个套件一个文件** spawn 的，套件清单与总数是硬要求。
所以 7 个超过 900 行的套件这样拆：

- **同名入口保留**（`tests/map.js` 等仍在原位、仍是唯一入口，`verify-all.mjs` **一个字没动**，
  仍然 **22 / 22**）；入口现在只留「抬头注释 + `import` + `HERE` / `ROOT`」+ 发布 + 调用执行器；
- **正文按「段」搬进编号片段**（`tests/<名>-<序号>-<段名>.js`），片段是**逐行搬的家**（断言一行没改），
  由入口顺序交给 **`tests/lib/跑分段.mjs`** 执行。

**执行器做什么**（`tests/lib/跑分段.mjs`）：把片段文本按序拼成一份，外面包 `(async function () { 'use strict'; … })()`
交给 `vm.runInThisContext`。
- 拼出来的文本 == 拆分前那个文件的**逐字节副本**（片段就是搬家），所以语义不变；
- 所有片段在**同一个函数作用域**里跑 → 顶层 `const/let/函数/全局计数`（`fails` / `errs` / `ok` / `bad`、
  `globalThis.__待收尾` 那套异步记账）照旧互相看得见；
- 顶层 `await`（`map.js` 有 23 处）在 async 函数里合法；`'use strict'` 对齐原来 ESM 的严格模式；
- `process.exit()` 照旧直接退出（退出码就是套件自己的退出码）；
- 入口把 `import` 进来的名字 + `HERE` / `ROOT` `Object.assign(globalThis, …)` 发布出去
  （片段是**脚本**、看不见模块作用域；`import.meta` 在脚本里不合法，所以这两行留在入口）。

## 5. 按路径读源码的辅助函数（旧 → 新 → 为什么）

**问题**：有 4 个套件会**按路径读源码做对账**（`tests/commands.js` / `tests/faction.js` / `tests/map.js` / `tests/tuner.js`），
路径写死成 `src/js/71-改动.js`、`72-势力.js`、`60-战斗.js`、`80-界面.js`、`90-肉鸽.js`、`91-地图.js`、`95-调参室.js`。
源文件一拆就 ENOENT → 套件红。**动的是「读文件这一个动作」，不是断言。**

| | 旧 | 新 |
|---|---|---|
| 实现 | `readFileSync(join(ROOT, p), 'utf8')`（各套件自己写） | 统一走新文件 **`tests/lib/读源码.mjs`**：`读源码(ROOT, …段路径)` |
| 语义 | 直接读那个文件 | **先按原路径找**；找到就原样返回（没被拆的文件走的就是老路）；找不到就把「同名前缀 + `-`」的编号片段**按文件名声顺序拼接**返回 |
| 为什么等价 | — | 拼接产物与拆分前那个文件**逐字节相同**（第 3 节那 8 行证据）；片段序号是单个数字，所以字符串排序 == 拼接顺序 |

调用处只改了一行（`const 源码 = p => 读源码(ROOT, p)` 之类），**所有断言一字未动**；
`tests/map.js` 第 [8] 段那句 `肉源码.slice(肉源码.indexOf('进层('), 肉源码.indexOf('失败耐久('))` 拿到的仍是同一段文本。
