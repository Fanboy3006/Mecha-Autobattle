**「会玩的指令策略」（`策略指令()`，只用现有指令与机制，一处新规则都不发明）**：

1. **集火威胁最高的敌机** —— `算意图()` 给出「每个敌人这一回合打谁、期望多少伤害」，挑期望最高的那台当集火目标（并列取当前 HP 最低、再取位号小的）；
   把这台提前打掉，它这一回合就出不了手。它这一回合打不到人（Boss 蓄力 / 没有可用武器 → 期望 0）时，退成「集火当前 HP 最低的活敌」（收残血）。
   够不到它的机体不用管：`50-AI.js:125-132` 的「集火」打不到时会自己退回「进攻」。
2. **守护** —— `算意图()` 里凡是「**单体**（守护只对非范围生效，`60-战斗.js:370`）、期望伤害 ≥ 该队友当前 HP」的，就是这一回合会被打死的队友；按「**这一回合期望输出最高的先救**」排队，派**这一回合期望输出最低**的队友去守护它（守护者自己攻击 ×0.7，派最闲的那台最划算）。
   一名队友只能被一人守护（引擎规则），一台守护者只领一个目标；**没人可派**时那台自己下「**防御**」（防御值 +50、下回合开始回 5% HP）。
3. **大招：自动（不保留）** —— 方案 5.1.1 的武器优先级本来就是「大招冷却好了就优先用」（`50-AI.js:62-63`）；「保留」只会让这一回合退化成普通武器。对照表里的「大招全保留」把代价量出来了。
4. **天人 TRANS-AM：手动开** —— 每回合给所有机体下 `TRANSAM:'手动'` + `本回合开TRANSAM:true`；引擎（`72-势力.js` 的 `手动开天人()`）只在「CD 已到且不在 TRANS-AM 中」时才真的开，所以效果 = **CD 一到就开**（持续 2 / CD 3 → 第 1、5、9 回合，覆盖率拉满），同时把单位级手动开关这条路真的走了一遍。
5. **Boss 档换位躲大技能** —— 这一回合 `算意图()` 里有 `大技能` 时，用 `areaSlots()` 算它的落点；落点里**HP 比例 < 50%** 的队友如果**对位**（`对位(位)[0]`，和 `换位目标()` 挑的是同一格）站着一位 HP 比例 ≥ 75% 的队友，就让它下「换位」——把残血的换出落点、血厚的换进去。
   ⚠ 这一条**改变不了总伤害**（蓝肥鱼的「周身冲击」`area` 没写 = 默认 `row` = 打一整排，9 台摆满时两排都有人，总有一排要挨打），它换来的是「**这一下别打在快死的那台身上**」；值不值由下一节对照表的「不换位躲大技能」一行回答。
6. 其余人一律「进攻」。全部是决定性的（没有随机数），所以同一颗种子跑两遍数字完全一样。

**为什么这算「会玩」**：它每一步都踩在**引擎真的读得到的信息**上（`算意图()` 的期望伤害、`aiAction()` 的期望输出、`areaSlots()` 的落点、CD 状态），做的都是「**用现成机制换到更多有效伤害 / 少死一台**」的决定：集火省下敌人的一回合输出、守护和防御把「必死」变成「不死」、TRANS-AM 不留空档、大招不留着不用、Boss 回合不惜放弃一次出手去保住残血。对照表里每一项关掉之后的差值，就是这条规则值多少分。
