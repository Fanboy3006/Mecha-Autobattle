**「会玩的全队方针策略」（`策略指令()`，只用现有方针与机制，一处新规则都不发明）**：

> ★ 2026-10-12：作者拍板「全队方针」之后，**逐台指令 / 守护 / 战斗中换位已经删掉**（§1.4）——
> 这一节按新引擎重写：玩家每回合只能改**一条全军方针**（+ 单位层的大招 / TRANS-AM 开关）。

1. **集中攻击威胁最高的敌机** —— `算意图()` 给出「每个敌人这一回合打谁、期望多少伤害」，挑期望最高的那台当目标（并列取当前 HP 最低、再取位号小的）；
   把这台提前打掉，它这一回合就出不了手。它这一回合打不到人（Boss 蓄力 / 没有可用武器 → 期望 0）时，退成「收残血」（挑当前 HP 最低的活敌）。
   够不到它的机体不用管：`50-AI.js` 的 `集中攻击候选()` 打不到时会自己退回「全军突击」。
2. **全军防御** —— `算意图()` 里凡是「单体、期望伤害 ≥ 该队友当前 HP」的，就是这一回合会被打死的队友；这时全队改成**全军防御**（防御值 +50、下回合开始回 5% HP）——放弃这一回合的输出换不死人。
   它的代价与收益由对照表里的「永远全军突击」那一行量出来（这一条在硬仗里才吃得到）。
3. **大招：自动（不保留）** —— 方案 5.1.1 的武器优先级本来就是「大招冷却好了就优先用」（`50-AI.js:62-63`）；「保留」只会让这一回合退化成普通武器。对照表里的「大招全保留」把代价量出来了。
4. **天人 TRANS-AM：手动开** —— 每回合给所有机体下 `TRANSAM:'手动'` + `本回合开TRANSAM:true`；引擎（`72-势力.js` 的 `手动开天人()`）只在「CD 已到且不在 TRANS-AM 中」时才真的开，所以效果 = **CD 一到就开**（持续 2 / CD 3 → 第 1、5、9 回合，覆盖率拉满），同时把单位级手动开关这条路真的走了一遍。
5. 其余回合一律**全军突击**（= 方案 5.1 的默认 AI）。全部是决定性的（没有随机数），所以同一颗种子跑两遍数字完全一样。

**为什么这算「会玩」**：它每一步都踩在**引擎真的读得到的信息**上（`算意图()` 的期望伤害、CD 状态），做的都是「**用现成机制换到更多有效伤害 / 少死一台**」的决定：集中攻击省下敌人的一回合输出、全军防御把「必死」变成「不死」、TRANS-AM 不留空档、大招不留着不用。对照表里每一项关掉之后的差值，就是这条规则值多少分。

## 六、结论（只报数字，怎么调由作者拍板）

1. **作弊口径整体：98%**（1170 场，13 个「层 × 档」组合，平均 3.4 回合、打完平均剩 96% HP）。
   - 第 1 层：**100%**（平均 1.2 回合、剩 100%），满胜 3/3 个档。

   - 第 4 层：**88%**（平均 6.4 回合、剩 93%），满胜 1/2 个档。
2. **「难度太低」的候选（作弊也 100%）**：12 / 13 个组合 —— 第 1 层 · 普通、第 1 层 · 精英、第 1 层 · 守军、第 2 层 · 普通、第 2 层 · 精英、第 2 层 · 守军、第 2 层 · 侵蚀源、第 3 层 · 普通、第 3 层 · 精英、第 3 层 · 守军、第 3 层 · 侵蚀源、第 4 层 · 普通。

4. **「会玩」值多少**：不下方针（整场全军突击 = 方案 5.1 默认 AI）整体 **98%**（3.4 回合、剩 96%）→ 下策略 **98%**（3.4 回合、剩 96%）。
5. **「拿满」值多少**：不带藏品（**只能上 6 台**）整体 **92%**（4.4 回合、剩 93%）→ 满配 **98%**（7 台 + 35 件战斗类藏品）。
6. **Boss（第 4 层终点）是整张表里唯一没有饱和的一档**：作弊满配 **76%** / 10.8 回合 / 剩 88%；**不带藏品（只能上 6 台）→ **0%** / 11.0 回合 / 剩 86%**；指挥位换 Feena → **100%** / 8.7 回合 / 剩 85%；去掉 g3 / n3 → **8%** / 11.0 回合 / 剩 83%。
   - 读法：**「拿满」在 Boss 这一档上是决定性的**（0% → 76%）；而「拿掉两件有代价的藏品（g3 / n3）」反而**更慢**（11.0 回合 vs 10.8 回合）—— 那两件的代价是装甲 −40% / HP −40%，在「几乎不挨打」的对局里换不到任何惩罚。
7. **只报数字**：这一版**没有动任何游戏数值**（角色 / 敌人 / 编成 / 公式 / 藏品数据一个字都没改），难度往哪调、调多少，由作者拍板、DSH 执行。
